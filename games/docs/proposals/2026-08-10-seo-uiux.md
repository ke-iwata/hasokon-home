## 2. games への導線を作る（games 側の主な作業・最優先）

### 根拠

URL検査の「参照元」を見ると、**games 配下のページはどれも参照元が記録されていません。**
Google の認識上、games は「サイトマップにしか載っていないページ群」です。

`hasokon.com` のトップからは各ゲームへリンクが張られていますが、
トップ自体がクロールされたのは 08-08 で、そこからのリンクはまだ辿られていません。
tools 側（13ページ中2ページがインデックス済み）と比べても遅れています。

### 提案する対応

1. **`/games/` から `/tools/` への相互リンクを張る**
   現在フッターは `hasokon.com` トップにしか繋がっておらず、tools へは2ホップかかります。
   tools のほうが先にクロールされているので、**tools ← → games の直接リンクは
   games にとってクロールを引き込む効果があります**（tools 側にも同じ提案を出しています）
2. **BreadcrumbList の構造化データを入れる**
   `hasokon.com > 無料ミニゲーム集 > ソリティア`。
   各 `page.tsx` は既に `VideoGame` + `FAQPage` の JSON-LD を出しているので、同じ場所に足すだけです
3. **「他のゲーム」の一覧を共通コンポーネントに切り出す**
   現在は6つの `page.tsx` それぞれに「他のゲーム」の一覧が直接書かれています。
   tools には `app/RelatedTools.tsx` があるので、games も
   `app/_cards` あたりに同じ形で共通化すると、**ゲームを追加したときのリンク漏れがなくなります**。
   いまの状態だと、7本目を足したときに既存6ページへの追記を忘れると孤立ページになります

### 期待できる効果

games 9ページがクロール対象に入ります。順位を上げる施策ではなく
「土俵に乗せる」施策なので、効果の出方は分かりやすいです。

ゲーム系のキーワード（「ソリティア 無料」「マインスイーパー ブラウザ」など）は
計算ツールより競合が強い一方で検索数も桁違いに多いので、
インデックスさえ入れば表示回数は立ち上がります。

### 工数

- 1：半日
- 2：半日（既存のJSON-LDに追記する形）
- 3：半日〜1日（6ページの書き換えを含む）

## 3. GA4 は計測されているが、入口が測れていない

games の `lib/analytics.ts` には測定ID `G-2Z0K6Y2FX0` が設定済みで、
`trackToolUse(slug, action)` も主要操作に入っています。ここは問題ありません。

問題は**ルートドメイン側（hasokon.com）に GA4 のタグが1つも入っていないこと**です。
`hasokon-home/index.html`・`404.html`・`privacy.html` のいずれにも gtag がありません。

現在クリックを得ているのは `hasokon.com/` だけ（3クリック中3件）なので、
**トップに来た人が games に流れたのかどうかが分かりません。**
games はまだ検索流入がゼロなので、当面はトップからの遷移が唯一の入口です。
そこが測れていないのは痛手です。

**対応**：hasokon-home 側の作業です（home の提案3）。
あわせて、games は tools と**別のデータストリーム**にする方針が CLAUDE.md に書かれていますが、
現状は同じ測定IDです。サイト別に見たいなら分けるか、
GA4のレポートでホスト名／パスで絞る運用に切り替えるか、どちらかに決めておくとよいです。

**工数**：games 側は0〜2時間（方針を決めるだけなら0）

## 4. OGP画像がない（UI/UX・CTR）

`app/layout.tsx` の `openGraph` は `type` / `siteName` / `locale` のみで、
**`og:image` が設定されていません。** home / tools も同様です。

ゲームは「暇つぶしにこれどう」とチャットで共有される導線があるので、
**ツールより OGP の効きは大きい**と考えられます。
LINE や Discord に貼られたときのカードが無地なのはもったいない状態です。

**対応**：3サイト共通のOG画像を1枚作り、`layout.tsx` の `openGraph.images` に設定する。
余力があればゲームごとに変えると効果は上がりますが、まずは共通1枚で足ります。

**工数**：共通1枚なら半日（画像は home / tools と共用）
