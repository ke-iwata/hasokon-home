## 提案1：games への導線を作る（最優先）

### 根拠

URL検査の「参照元」を見ると、**games 配下のページはどれも参照元が記録されていません**。
Google の認識上、games は「サイトマップにしか載っていないページ群」です。

`hasokon.com` のトップからは各ゲームへリンクが張られていますが、
トップがクロールされたのは 08-08 で、そこからのリンクはまだ辿られていません。

### 提案する対応

1. **`/games/` から `/tools/` への相互リンクを張る**
   現在フッターは `hasokon.com` トップにしか繋がっておらず、tools へは2ホップかかります。
   tools のほうが先にクロールされているので、**直接リンクは games にクロールを引き込む効果があります**
   （tools 側にも同じ提案を出しています）
2. **BreadcrumbList の構造化データを入れる**
   `hasokon.com > 無料ミニゲーム集 > ソリティア`。
   各 `page.tsx` は既に `VideoGame` + `FAQPage` の JSON-LD を出しているので、同じ場所に足すだけです
3. **「他のゲーム」の一覧を共通コンポーネントに切り出す**
   現在は6つの `page.tsx` それぞれに直接書かれています。
   tools の `app/RelatedTools.tsx` に相当するものを `app/_cards` あたりに作ると、
   **ゲームを追加したときのリンク漏れがなくなります**。
   いまの状態だと、7本目を足したときに既存6ページへの追記を忘れると孤立ページになります

### 期待できる効果

games 9ページがクロール対象に入ります。順位を上げる施策ではなく
「土俵に乗せる」施策なので、効果の出方は分かりやすいです。

ゲーム系のキーワード（「ソリティア 無料」「マインスイーパー ブラウザ」など）は
計算ツールより競合が強い一方で検索数も桁違いに多いので、
インデックスさえ入れば表示回数は立ち上がります。

### 工数

1.5〜2日（1・2で各半日、3で半日〜1日）

## 提案2：アニメーションの抑制指定（`prefers-reduced-motion`）を入れる（アクセシビリティ）

### 根拠

`app/globals.css` に **`prefers-reduced-motion` の指定が1つもありません**。
一方、`transition` / `animation` は5箇所で使われています。

tools 側の `globals.css` には3箇所の `@media (prefers-reduced-motion: reduce)` があり、
ルーレットの回転などを止めるようにしてあります。**games だけ対応が抜けている**状態です。

OSで「視差効果を減らす」を有効にしている利用者には、
前庭障害・乗り物酔いなどの理由がある場合があります。ゲームは動きが本体なので、
完全に止めるのではなく**移動距離や速度を抑える方向**での対応が現実的です。

### 提案する対応

`app/globals.css` の末尾に `@media (prefers-reduced-motion: reduce)` を足し、
カードのスライド・2048のタイル移動など、装飾に近い動きの `transition-duration` を短くする。
ブロック崩しのボールの動きはゲーム性そのものなので対象外にしてよいはずです。

### 期待できる効果

順位や流入への効果はありません。**遊べない人を減らすための施策**です。
tools と揃うので、3サイトで方針が一貫します。

### 工数

2〜3時間

## その他、気づいたこと（提案には上げないが記録しておく）

- **OGP画像がない。** `app/layout.tsx` の `openGraph` は `type` / `siteName` / `locale` のみで
  `og:image` が未設定（home / tools も同様）。
  ゲームは「暇つぶしにこれどう」とチャットで共有される導線があるので、
  **ツールより OGP の効きは大きい**と考えられます。共通1枚を作れば済みます（半日程度）
- **GA4 は tools と同じ測定ID。** games の CLAUDE.md は「別のデータストリームを作る」と
  書いていますが、実装は tools と同じ `G-2Z0K6Y2FX0` です。方針と実装がずれているので、
  分けるか、ホスト名／パスで絞る運用に切り替えるか決めておくとよいです
- **ルートドメイン（hasokon.com）に GA4 のタグが入っていません。**
  games はまだ検索流入がゼロで当面の入口はトップからの遷移だけなので、そこが測れていないのは痛手です
  （対応は hasokon-home 側）
- **プライバシーポリシーが3箇所に重複**（`/privacy.html`・`/tools/privacy/`・`/games/privacy/`）。
  **AdSense の審査要件なので削除ではなく集約**にすること
- **CLAUDE.md のテスト件数が実態とずれている**（記載111件、実際114件）
- 新しいゲームを足すときの**名称の商標確認**は引き続き必要です
  （CLAUDE.md 参照。「数独」「オセロ」「テトリス」は登録商標）
