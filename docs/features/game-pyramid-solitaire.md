# 新ゲーム「ピラミッドソリティア」（ソリティア群の面を厚くする・カード基盤の再利用）

**状態**：提案（未実装）
**対象**：`games/`（`hasokon.com/games/pyramid-solitaire/`）
**起票**：2026-08-17

---

## 背景と根拠

### GSCで表示が出ているゲーム系クエリは、ほぼすべてソリティア系

GSC（Search Analytics API・直近28日・2026-08-17取得）で、ゲーム側で
表示が付いているクエリはソリティア系に集中している：

- 「ソリティア クロンダイク」11表示（掲載順位 46）
- 「スパイダーソリティアの遊び方」3表示（順位 74.3）
- 「クロンダイクソリティア」1表示（順位 62）
- ページ別でも `games/solitaire/`（20表示・1クリック）と
  `games/spider/`（8表示・1クリック）がゲーム側の上位2枚

つまりGoogleは当サイトを「ソリティアのサイト」としては認識し始めている。
この芽を伸ばすには、個々のページの強化と並んで**ソリティア群そのものの
面を厚くする**のが定石で、クロンダイク・スパイダー・フリーセルに次ぐ
4本目として、日本でも知名度の高い「ピラミッド」を提案する。

### 実装コストが最小級（既存基盤の再利用率が高い）

- カード描画は `games/app/_cards/CardView.tsx`（SVG自前描画）をそのまま再利用
- デッキ生成・シャッフルは `lib/cards.ts` を再利用
- 成績保存は `_records` に乗せるだけ
- **CPU対戦が不要**（1人用）なので、スピードや花札より工数がずっと小さい
- ルールが「足して13になる2枚を取る」だけで、遊び方の説明も短くて済む

### 権利関係は無害

ピラミッドは19世紀から遊ばれている伝統的なソリティアの一種で、
ルール自体に権利者はいない（クロンダイク・スパイダーと同じ扱い）。

## 提案する仕様

1. **ルール（標準的なピラミッド）**
   - 28枚をピラミッド状（1〜7枚の7段）に配置、残り24枚は山札
   - **合計が13になる2枚**を選んで取り除く（Q+A、J+2、10+3…）。
     Kは1枚で13なので単独で取り除ける（J=11・Q=12・K=13の
     数え方は画面に常時表示して初見でも迷わせない）
   - 取れるのは他の札に覆われていない札だけ
   - 山札は1枚ずつめくって捨て札に。捨て札の一番上はピラミッドの札と
     組にできる。山札を引き直せる回数は2回（一般的なルール）
   - ピラミッドを全部取り除けたら勝ち。山札を使い切り手がなくなったら負け
2. **操作（スマホ最優先・タップのみ）**
   - 札をタップで選択 → 相手の札をタップで組成立。ドラッグは要求しない
   - 取れる組が存在しないときだけ「ヒント」ボタンが山札めくりを促す
     （自動でめくらない。テンポは1人用なので本人に委ねる）
   - 合計13にならない組を選んだときは短い揺れアニメーションで無効を伝える
3. **成績**
   - `_records` でクリア回数・クリア率・最短時間を保存
4. **ページ構成（既存ゲームページと同じ）**
   - ルール／コツ（「Kを最優先で取る」「山札の残り回数の使い方」等）／
     由来／FAQ（JSON-LD・パンくず込み）
   - `games/solitaire/`・`spider/`・`freecell/` と相互リンクし、
     ソリティア群の内部リンクを密にする（既存3ページの「他のゲーム」
     枠は registry から出るため、実装は registry への追加だけで済む）

## 期待される効果

- ソリティア群が4本になり、「ソリティア 無料」「ソリティア 種類」系の
  面での評価が上がる。既に表示が出ている `solitaire`／`spider` の
  順位押し上げ（46位・50位 → 20位台）への寄与を狙う
- 「ピラミッドソリティア」自体もアプリ紹介記事が定期的に書かれる
  安定需要があり、ブラウザで今すぐ遊べる受け皿は競合が比較的薄い
- 1人用・1ゲーム3〜5分でスキマ時間の再訪に向き、PWA
  （ホーム画面追加）済みの当サイトと相性がよい

## 必要な工数（消費トークン目安）

- ロジック＋テスト＋UI＋ページ執筆：**約150k〜200kトークン**
  （CPU対戦なし・カード基盤再利用のため、スピード（PR #93）より小さい）
- レビュー・修正の往復を含めて 250k 以内を見込む
