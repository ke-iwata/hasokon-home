# 新ゲーム「七並べ」（CPU対戦・トランプ対戦系2本目）

**状態**：実装済み（2026-08-14。本番反映はタグリリース待ち）
**対象**：`games/`（`hasokon.com/games/shichinarabe/`）
**起票**：2026-08-14

> 実装時に決めたこと（仕様書に書いていなかった点）：
> - **CPUに「強さ3段階」を付けず、3人に別々の性格（せっかち・しんちょう・いじわる）を付けた。**
>   七並べは出せる札が各スート1枚ずつに限られ、読みを深くしても差が出にくい。
>   仕様書の「止め札をいつまで止めるか・パスを何回温存するか」をそのまま
>   パラメータ（`holdAt` / `keepPasses`）にしてある
> - **失格どうしの順位は「失格した時点の残り枚数が少ないほうが上」。**
>   失格した順だけで決めると、たまたま先に手詰まりになった人が不利になりすぎる
> - **場は4スート×13マスの数字の表にした。** 13列を `_cards` の絵柄で並べると
>   スマホで1枚が20px程度になり数字が読めない。`_cards` の再利用は手札のほう
> - **残り1人になった時点で回戦を終える。** 続けても順位は変わらないため
> - **記録の区分はルール（標準／トンネルあり）。** 大富豪の「CPUの強さ」に当たる区分が無いため

## 背景と根拠

### 大富豪で作ったトランプ対戦の基盤が、そのまま2本目に使える

2026-08-13〜14 に大富豪（CPU3人対戦）をリリースし、
`games/app/_cards`（カードの描画・扇形の手札・場のレイアウト）という
**トランプゲーム共通の基盤**ができた（[game-daifugo.md](./game-daifugo.md)）。
この投資を1本で終わらせず、同じ基盤で作れる定番を続けて出すことで
1本あたりの実装コストが下がり、「トランプゲームが揃っているサイト」として
面で戦えるようになる。

七並べは大富豪と同じ「4人・手札・順番に出す」型で、
カード描画・手札UI・ターン制の進行がほぼそのまま流用できる。
一方でAIは「どの札を止めるか」という大富豪と違う思考で、
実装は薄くても駆け引きが成立する。

### 計測値（2026-08-14 取得）

- GA4（Data API・直近14日、hasokon.com のみ）：ゲーム系がPV上位を占める
  （`/games/` 53PV、マインスイーパ・スパイダー・2048・ソリティア各15〜24PV）。
  チャネルは Direct 76 セッションが最大で、**ゲームは繰り返し遊ばれている**
- GSC（Search Analytics API・直近28日）：検索表示が出ているのはソリティア系
  （「ソリティア クロンダイク」「スパイダーソリティアの遊び方」）と
  マインスイーパ・ナンプレで、**定番ゲーム名での指名検索がこのサイトの検索入口**になっている
- 「七並べ 無料」「七並べ オンライン」は定番ゲーム名クエリの中で
  ブラウザで手軽に遊べる供給が比較的薄い（2026-08-14 Web調査。
  大手はアプリ誘導が中心で、インストール不要・登録不要のWeb版は少ない）

### 権利関係が無害

七並べ（Sevens / Fan Tan）は伝統的トランプゲームでルールに権利者がいない。
既存実装の見た目・名称を模倣しない限りリスクはない（大富豪と同じ整理）。

## 現状

games のトランプ系はソリティア・スパイダー・フリーセル（1人用）と
大富豪（対戦）のみ。対戦系トランプは1本しかなく、
`_cards` 基盤の再利用先がまだない。

## 提案する仕様

### ルール（初版）

- 4人（プレイヤー1人＋CPU3人）、ジョーカーなしの52枚
- 7を全員場に出してスタート。手番では場の連続する隣（6か8から外側）に出せる札を出す
- 出せない・出したくないときは**パス（3回まで）**。4回目のパスで失格
  （手札を全部場に開いて順位確定）
- 手札を最初に出し切った人から勝ち抜け。5回戦の合計順位で総合成績
- **トンネル（AとKをつなげる）はオプション**として設定でオン/オフ

### CPU

- 止め札（自分が持つ連続の端の札）をいつまで止めるか、
  パスを何回温存するかを性格づけして3人に差をつける
- 大富豪の実装と同じく、思考時間の演出（数百ms のディレイ）を入れる

### 流用するもの

- `games/app/_cards` のカード描画・手札レイアウト
- 大富豪のターン制進行・結果画面・連戦（5回戦）の構造
- `games/app/_records`（成績保存）が大富豪で使われていれば同じ形で接続

### ページ構成

大富豪と同じく、ゲーム本体＋ルール解説＋コツ＋FAQ
（「パスは何回まで？」「トンネルとは？」「出せる札があるのにパスできる？」）＋
JSON-LD（VideoGame / FAQPage）。registry に1エントリ追加し、
`home/index.html` のゲーム一覧・`home/llms.txt` に1行足す。

## やらないこと

- **ジョーカー入り・どぼん等のローカルルール**。初版は最も標準的な
  「パス3回・トンネルはオプション」に絞る。要望が観測できたら追加
- **オンライン対戦**。静的サイトの制約（サーバーなし）はそのまま。CPU対戦のみ
- **大富豪とのUI共通化の過度な抽象化**。2本目の時点では素直にコピーして育て、
  3本目が見えたときに共通化を判断する
