# 新ツール「自転車の反則金（青切符）早見表・チェッカー」（2026年4月施行の改正道交法対応）

**状態**：実装済み（2026-08-14）
**対象**：`tools/`（`hasokon.com/tools/jitensha-hansokukin/`）
**起票**：2026-08-14

---

## 背景と根拠

### 2026年4月に始まった「自転車の青切符」は、全自転車利用者に効く法改正

道路交通法の一部を改正する法律（**令和6年法律第34号**）により、
**2026年（令和8年）4月1日**から自転車など軽車両にも交通反則通告制度
（いわゆる青切符）が適用された。**16歳以上**の自転車利用者が対象で、
信号無視や一時不停止などに反則金が科される。16歳未満は従来どおり指導警告。

- ながらスマホ（携帯電話使用等・保持）：**12,000円**
- 遮断踏切立入り：**7,000円**
- 信号無視：**6,000円**／通行区分違反（右側通行・逆走）：**6,000円**／
  横断歩行者等妨害等：**6,000円**／安全運転義務違反：**6,000円**
- 一時不停止：**5,000円**／無灯火：**5,000円**／制動装置（ブレーキ）不良：**5,000円**／
  傘さし・イヤホン（公安委員会遵守事項違反）：**5,000円**
- 歩道徐行等義務違反：**3,000円**／二人乗り：**3,000円**／並進：**3,000円**

（金額は警察庁公式一覧PDFと愛媛県警の早見表PDFで確認済み。2026-08-14 取得）

施行から4か月あまり経った現在も取り締まりのニュースが続き、
「自転車 青切符 一覧」「自転車 反則金 いくら」「自転車 イヤホン 違反」
「自転車 歩道 罰金」などの検索需要が**恒常的に**発生している。
通勤・通学で毎日乗る人すべてが対象で、対象人口は年収の壁より広い。

### 「法改正×早見表・計算機」というサイトの柱にそのまま乗る

このサイトの戦略は「制度改正が出るたびに計算機を追加する」
（tools/docs/CONCEPT.md・年収の壁/高校授業料/iDeCoの実績）。
本件は2026年施行の生活系法改正の中でも対象者が最も広い部類でありながら、
**税・社会保険のYMYL領域ではない**（交通ルールの一次情報の整理）。
立ち上げ期のドメインでも上がりやすい非YMYL系で、
睡眠サイクル・ヘボン式に続く3本目の生活系の柱になり得る。

競合は保険会社・銀行のコラム記事と自動車学校のブログが中心で、
**「自分の行為が違反か・いくらか」を対話的に確認できるツールは見当たらない**
（2026-08-14 Web調査）。記事より一覧性と検索性で勝てる余地がある。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **行為から引くチェッカー**：「イヤホンをして乗る」「傘をさして乗る」
   「歩道を走る」「二人乗り」など日常の行為を選ぶと、
   該当する違反名・反則金額・青切符/赤切符の別・注意点を表示。
   （例：イヤホンは都道府県の道路交通規則による「公安委員会遵守事項違反」で5,000円、
   傘さしで運転操作が不確実な場合は安全運転義務違反6,000円になり得る、
   歩道通行は「徐行等義務違反」3,000円だが例外的に通行できる場合がある、など）
2. **反則金の早見表**：警察庁公式一覧の主要項目を金額帯
   （12,000／7,000／6,000／5,000／3,000円）で整理した静的テーブル
3. **解説**：対象（16歳以上）・青切符の流れ（告知→原則7日以内に仮納付→
   納付すれば公訴されない＝前科がつかない→未納なら通告センター→刑事手続）・
   赤切符のまま残る違反（酒気帯び・妨害運転・ながらスマホで危険を生じさせた場合）
4. **FAQ**：「イヤホンは片耳ならOK？（都道府県の規則による）」
   「子どもの二人乗りは？（幼児用座席の例外）」「点数はつく？（免許制度と別）」など

### データの持ち方

`lib/jitensha-hansokukin.ts` に違反項目の配列（違反名・反則金・青/赤・
行為キーワード・注意書き・根拠条文）を**【データ更新箇所】**コメント付きで集約。
計算というより検索・分類ロジックなので、テストは
「全項目に金額と根拠がある」「行為→違反のマッピングが一意」を中心に書く。

### やらないこと

- 都道府県ごとの遵守事項（イヤホン・傘の細則）の全網羅。
  47都道府県の規則を持つと更新が破綻する。「都道府県により異なる」と明示し、
  代表例と確認先（各県警の道路交通規則）への案内にとどめる
- 自動車・原付の反則金への拡張（別ツールの領域。まず自転車で確立する）
- 罰則の法律相談的な断定（「〜になり得る」の表現と一次情報リンクを徹底する）

### 実装時の注意（調査で判明した罠）

- 「113種類」という反則行為数は二次情報（銀行系コラム等）の数え方で、
  警察庁一覧PDFの行為区分は65項目。ページでは「約110種類」のような
  二次情報の数字を使わず、警察庁一覧に載っている項目数・内容だけを根拠にする
- 自治体サイトにも金額の誤りがある（船橋市ページで実例を確認）。
  金額は必ず警察庁PDFを正とする
- 酒気帯び・ながらスマホの**罰則強化自体は2024年11月1日に先行施行**されている。
  「2026年4月に罰則ができた」ではなく「青切符の対象になった」と書き分けること
