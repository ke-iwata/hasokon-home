## 現状

### 年収の壁 計算機がいま返すもの

`evaluateKabe()` は「壁の一覧＋超えているかどうか」を返す。
`nextWall()` で「次の壁まであと◯万円」も出る。金額の増減は一切扱わない。

```
年収 120万円 / 配偶者の扶養内 / 従業員51人以上 / 週20時間以上
→ 住民税の壁 119万円：超えている
→ 社会保険 130万円の壁：あと10万円
```

### 2026年10月以降に起きること

同じ入力で、106万円の壁が `effectiveUntil: '2026-10-01'` により消える。
週20時間以上・51人以上なら `evaluateShaho()` は `enrolled`（年収に関係なく加入）を返す。

**画面は「加入します」と伝えるが、それが手取りにどう効くかは伝えない。**
社会保険料は年収の約15%（労使折半後の本人負担）で、
年収106万円なら**年16万円前後**が新たに引かれる。
一方で厚生年金・傷病手当金・出産手当金という給付が付く。
**この差し引きを、いま誰も計算していない。**

### 再現手順

1. `https://hasokon.com/tools/nenshu-kabe/` を開く
2. 年収 120万円・配偶者の扶養内・従業員51人以上・週20時間以上 を入力
3. 壁の一覧は出るが、**手取り額・保険料額はどこにも出ない**

## 提案する仕様

### 何を出すか

**「扶養内に抑える場合」と「加入して働く場合」を、年収の軸で並べて手取りを比較する。**
出す数字は3つに絞る。

1. **手取りの逆転区間**（働き損ゾーン）
   加入直後は保険料が丸ごと乗るため、年収を上げたのに手取りが下がる区間ができる。
   「年収◯万円〜◯万円は、◯◯万円のときより手取りが少ない」
2. **損益分岐点**
   「年収◯万円まで働けば、扶養内で抑えた場合の手取りを超える」
3. **手取り以外に増えるもの**（金額で出す。ここが競合と決定的に違う点）
   - 将来の厚生年金（年額の増分と、受給開始から◯年で保険料負担を回収する、という形）
   - 傷病手当金・出産手当金の対象になること（`shobyo-teate` へ内部リンク）

### 計算に使う部品（**新規に書くのは1ファイルだけ**）

令和8年分の税額計算は `tools/lib/furusato-nozei.ts` に揃っている。**再利用する。**

| 使うもの | 出どころ |
|---|---|
| `salaryDeduction()` / `salaryIncome()` | `lib/furusato-nozei.ts` |
| `basicDeductionIncomeTax()` / `basicDeductionResidentTax()` | 同上 |
| `incomeTaxAmount()` / `incomeTaxRate()` | 同上 |
| 住民税の所得割額（調整控除込み） | 同上 |
| 社会保険料の概算（厚生年金の上限を年額で反映） | 同上 |
| 標準報酬月額の等級表（1〜50等級） | **`lib/kosodate-shienkin.ts` の `GRADES` を共通化して使う** |
| 賃金要件の撤廃日・加入判定 | `lib/nenshu-kabe.ts` の `WAGE_REQUIREMENT_ABOLISHED_ON` / `evaluateShaho()` |

**この再利用が競合優位そのもの**である。RESEARCH-2026-08.md が指摘したとおり、
量産型のツールサイトは改正そのものは反映できても、
**改正が他の制度へ波及する効果までは追えない**（実例：競合のふるさと納税ツールは
令和7年分の税制のまま）。令和8年分の課税所得から正しく積み上げられるのは、
この部品が揃っているサイトだけである。

### テストで固定すること

- **2026-09-30 と 2026-10-01 で結果が変わる**こと（`asOf` を渡して両日を検証）。
  9月30日は年収106万円未満なら加入しない、10月1日は年収に関係なく加入する
- 加入直後に**手取りが必ず下がる**こと（逆転区間が空にならない）
- 損益分岐点の年収で、**加入した場合の手取りが扶養内の手取り以上**になること
- 標準報酬月額が**等級表の境界値**（例：報酬月額 93,000円ちょうど）で正しい等級を引くこと
- `kosodate-shienkin` の既存テストが**全件そのまま通る**こと（`GRADES` の移設で壊さない）

### 法的根拠として画面に出すもの

`ToolMeta` の `children` に一次情報へのリンクを置く（YMYL なので必須）。

- 厚生労働省「短時間労働者に対する健康保険・厚生年金保険の適用拡大」
- 年金制度改正法（2025年6月成立）の賃金要件撤廃の条文
- 日本年金機構「標準報酬月額の決め方」
- 協会けんぽの保険料額表（都道府県で率が違うことを明記する）

**都道府県ごとの健康保険料率の違いは、注記で断る。**
`furusato-nozei.ts` と同じ全国平均の概算を使い、
「お住まいの都道府県で数%変わる」と書く。47都道府県分の料率表を抱えると
毎年3月の改定に追随する保守が発生し、概算ツールとして割に合わない。

## やらないこと

- **47都道府県ごとの健康保険料率表を持つ**。
  毎年3月の改定に追随する保守が発生する。全国平均の概算＋注記で足りる

- **国民健康保険・国民年金の側を精緻に計算する**。
  国保の保険料は自治体ごとに算定方式が違い、概算にしかならないうえ
  「扶養内 → 加入」の比較には効かない（扶養内なら本人負担は0）

- **年収の壁 計算機に機能として組み込む**。
  あちらは「壁がどこにあるか」に答えるツールで、入力も出力も性格が違う。
  1ページに詰めると両方が読みにくくなる。**相互リンクで繋ぐ**

- **「働き損」という言葉をページタイトルの主語にする**。
  加入は損だけではない（厚生年金・傷病手当金が増える）ため、
  断定的なタイトルは YMYL のページとして不誠実になる。
  タイトルは事実ベースにし、「働き損」は検索語として本文と `description` で受ける

- **2027年分以降の税制での計算**。
  令和8年分の確定した数値だけを使う。
  給与所得控除と公的年金等控除の合計280万円上限（令和9年分から）は、
  対象者が違う（働きながら年金を受け取る人）ので別ツールの話
