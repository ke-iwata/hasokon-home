## 背景と根拠

### 2026年4月に限度額の表が変わり、「駐車場代の加算」という新しい計算が増えた

令和8年度税制改正で、マイカー・自転車などの交通用具で通勤する人の通勤手当の非課税限度額が
**令和8年4月1日以後に支払われるべき通勤手当**から次のように変わった
（国税庁「[通勤手当の非課税限度額の改正について](https://www.nta.go.jp/users/gensen/2026tsukin/index.htm)」・
同「[通勤手当の非課税限度額の改正に関するＱ＆Ａ](https://www.nta.go.jp/users/gensen/2026tsukin/pdf/01.pdf)」
令和8年4月。2026-09-27 に本文を取得して確認）。

1. **片道 55km 以上は一律 38,700円だったのが、65km 以上に 4 区分が新設された**
   （65〜75km 45,700円／75〜85km 52,700円／85〜95km 59,600円／95km 以上 66,400円）
2. **勤務先や駅の周辺の駐車場・駐輪場の料金相当額（上限 5,000円／月）を、距離区分の限度額に加算できる**
   ようになった（片道 2km 未満の人は除く。自宅付近の駐車場は対象外）
3. 交通機関（定期代）と交通用具を併用する人は、運賃＋距離区分＋駐車場代の合計で **最高 150,000円**

改正前は「距離を表で引くだけ」で済んだが、改正後は **「駐車場代の月額換算（月極・年払い・回数券・
コインパーキングで換算方法が違う。Q&A の Q3-3）」→「上限 5,000円」→「距離区分に加算」→「150,000円の頭打ち」**
と段が増え、手で追うと間違えやすい。国税庁の Q&A 自体が **ケースA〜E の計算例を 5 つ載せて説明している**
ほどで、計算機に向いた形になっている。

### 「通勤手当 非課税」は年末調整の時期に検索が立ち、令和8年分はその初回

- 「通勤手当 非課税限度額」「通勤手当 課税 いくらから」「駐車場代 通勤手当 非課税」は、
  給与計算ソフト各社（弥生・freee・OBC）と社労士・税理士事務所が解説記事を出しており、
  改正直後の 2026年4月に記事が集中している（2026-09-27 Web 調査）。
  **一方で「距離と支給額を入れると課税分が出る」個人向けの計算機は、給与計算系の小規模サイト
  （jimu-keisan.jp・keiri-tools.com）の 2 本程度**で、大手は表を載せているだけ
- 需要の山は **4月（改正・新年度）と 11〜12月（年末調整）**。令和8年分の年末調整は改正後の
  限度額で計算する初回で、**「源泉徴収票の支払金額に通勤手当が入っているのはなぜか」**
  （＝限度額を超えた分だけ給与収入に入る）の疑問がこの冬に初めて出る
- サイトの既存導線と噛み合う：手取り計算機（**社会保険の標準報酬月額には通勤手当が全額入る**のに、
  所得税では非課税。ここを混同した質問が多い）・残業代計算機（**割増賃金の算定基礎から除外できる 7 つの
  賃金の 1 つ**）・最低賃金チェッカー（**最低賃金の対象賃金からも除外**）・年末調整。
  「通勤手当の扱いが所得税・社会保険・割増賃金・最低賃金で 4 つとも違う」ことを 1 か所で説明できる
  ページがサイトに無い

## 法的根拠（2026-09-27 確認。実装時に e-Gov の現行条文と国税庁ページで再確認する）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 非課税の根拠 | 通常の給与に加算して受ける通勤手当のうち、通常必要と認められる部分は非課税 | 所得税法 9条1項5号 |
| 限度額の表 | 交通機関：合理的な運賃等の額（最高 150,000円）。交通用具：距離区分の額。併用：合計（最高 150,000円） | 所得税法施行令 20条の2（令和8年改正） |
| 交通用具の距離区分（改正後） | 2km未満 全額課税／2〜10km 4,200／10〜15km 7,300／15〜25km 13,500／25〜35km 19,700／35〜45km 25,900／45〜55km 32,300／55〜65km 38,700／**65〜75km 45,700／75〜85km 52,700／85〜95km 59,600／95km以上 66,400** | Q&A Q1-1 の表② |
| 駐車場等の加算 | 「一定の要件を満たす駐車場等」（**勤務する場所の周辺、または通勤で利用する交通機関の駅・停留所・フェリー乗り場・空港などの周辺**。自宅付近は不可）の 1か月当たりの料金相当額、**上限 5,000円**。駐輪場も含む。複数なら合計（上限は合計に対して 5,000円）。片道 2km 未満の人は加算なし | Q&A Q2-1〜Q2-4・Q3-4 |
| 料金相当額の月額換算 | (1) 月単位の料金はその額（3か月 24,000円 → 8,000円）／(2) 年単位は 12 で割る／(3) 都度負担はその月の合計・1回の額×利用回数・その他合理的な方法／(4) それ以外は年間相当額 ÷ 12。**消費税込みの額** | Q&A Q3-3 |
| 併用のとき | 運賃 ＋ 距離区分 ＋ 駐車場（上限 5,000円）の合計、**最高 150,000円** | Q&A Q3-2（ケースE） |
| 適用時期 | **令和8年4月1日以後に支払われるべき通勤手当**。支給日が定められていればその支給日。**改正前の期間の差額を後から追加支給するものには適用しない**（1〜3月分の遡及はない） | Q&A Q1-2 |
| 会社が駐車場を契約して負担している場合 | 従業員に駐車場代相当の通勤手当を支給したのと同じ扱い（6,000円負担なら 5,000円まで非課税） | Q&A Q4-2 |
| 社会保険 | 通勤手当は**全額**が報酬に含まれ、標準報酬月額の算定に入る（非課税かどうかは関係ない） | 健康保険法 3条5項・厚生年金保険法 3条1項3号（「報酬」の定義） |
| 割増賃金 | 算定基礎から**除外できる**7つの賃金の 1 つ（実費補償の性質に限る。一律支給は除外不可） | 労働基準法 37条5項・施行規則 21条 |
| 最低賃金 | 対象賃金から**除外**（通勤手当は「臨時・賞与・所定外・精皆勤・通勤・家族」の除外 6 種の 1 つ） | 最低賃金法 4条3項・施行規則 1条 |

**社会保険・割増賃金・最低賃金の行は、既存ツール（`tedori-keisan`・`zangyodai-keisan`・`saitei-chingin`）の
仕様書と本文に既にある内容の引き写し**で、本ツールでは説明と内部リンクにだけ使う（計算はしない）。

## 提案する仕様

### 入力（必須 3 つ。任意は `<details>` の「駐車場・定期代」に畳む。#220・#223 と同じ型）

必須：

1. **通勤の手段**：マイカー・バイク・自転車など（既定）／電車・バスなど交通機関のみ／併用
2. **片道の通勤距離（km）**：交通用具のとき。小数 1 桁まで。**区分の境目（10km・15km…）は「以上」側**
   （10.0km は 7,300円）と注記
3. **勤務先から支給されている通勤手当（月額）**：0 でもよい（0 なら「いくらまで非課税で出せるか」の早見になる）

任意（「駐車場・定期代」）：

4. **駐車場・駐輪場の料金**：金額と単位（月／年／3か月など／1回あたり × 月の利用回数／週など）。
   Q3-3 の (1)〜(4) の換算を `monthlyParkingFee()` で行い、**換算前の入力と換算後の月額を両方表示**する。
   「勤務先か駅の周辺の駐車場ですか？（自宅付近は対象外）」のチェックを付け、外れていれば加算しない
5. **定期代など交通機関の運賃（月額。有料道路の料金を含む）**：併用のとき。交通機関のみのときは 2 の代わりにこの欄が必須になる。
   国税庁の表では「交通機関**又は有料道路**を利用している人」が 1 つの区分なので、ラベルと注記に有料道路を明記する
6. **計算する月**：令和8年4月以後（既定）／令和8年3月以前。**3月以前を選ぶと改正前の表**（55km 以上 38,700円・駐車場加算なし）で計算する。
   年末調整で 1〜3月分を確かめる人のため

### 計算（`tools/lib/tsukin-teate.ts`。純関数）

```
距離区分の限度額   = DISTANCE_BANDS（改正後）または DISTANCE_BANDS_BEFORE_2026_04 から片道距離で引く（2km 未満は 0）
駐車場の月額換算   = monthlyParkingFee(料金, 単位, 利用回数)         // Q3-3 (1)〜(4)。1円未満切上げは回数券の例のみ
駐車場の加算       = min(月額換算, 5,000)。2km 未満・要件外・交通機関のみ なら 0
非課税限度額       = 交通用具のみ: 距離区分 + 駐車場
                   = 交通機関のみ: min(運賃, 150,000)
                   = 併用:         min(運賃 + 距離区分 + 駐車場, 150,000)
課税される額（月）  = max(0, 支給額 − 非課税限度額)
課税される額（年）  = 月 × 12（「毎月同額」と注記。4月からの 9 か月分は別に出す）
```

- **テストは国税庁 Q&A のケース A〜E と Q4-2 をそのまま使う**（50km・駐車場 8,000円・支給 40,300円 → 課税 3,000円、
  ケースC 4,400円・支給 37,400円 → 課税 700円、ケースE 定期 115,000円 → 限度額 150,000円・課税 1,300円、
  Q4-2 会社負担 6,000円 → 課税 1,000円）。ここが一次資料の計算例
- 境界値：片道 2.0km（4,200円）・1.9km（0）・65.0km（45,700円）・95.0km（66,400円）・
  駐車場 5,000円ちょうど・150,000円ちょうど・支給額 0・
  **併用で交通用具の区間が片道 2km 未満**（国税庁の表はこの人を併用の区分から除き、運賃だけで判定する。
  いまの式でも距離区分 0・駐車場加算 0 で同じ結果になるが、区分の境目としてテストに 1 本置く）
- 【データ更新箇所】は `DISTANCE_BANDS`・`PARKING_CAP`・`TOTAL_CAP` の 3 定数。`DATA_CHECKED_AT` を持つ
  （たばこ税・酒税と同じ「確認したら日付だけでも更新する」運用）

### 表示

1. **結果の 1 行目は「課税される額（月）」**。0 円なら「全額非課税」と大きく出す
2. 内訳表：距離区分の限度額／駐車場の加算（換算の式つき）／運賃／合計／頭打ち（150,000円）の有無
3. **「この課税分は給与収入（源泉徴収票の支払金額）に入り、所得税・住民税の対象になる」**と 1 行。
   税額そのものは出さない（税率は他の所得で決まる。年末調整計算機・手取り計算機へ渡す）
4. **4 つの制度で扱いが違う表**（所得税：限度額まで非課税／社会保険：全額が報酬／割増賃金：算定基礎から除外可／
   最低賃金：対象賃金から除外）。各行に既存ツールへの内部リンク
5. 早見表（`tables.ts`。[thin-tool-content.md](./thin-tool-content.md) の型）：
   - 距離区分の改正前後（55km 以上の 5 行が変わる）
   - 駐車場料金の月額換算の例（Q3-3 の 6 例をそのまま）
6. FAQ：「1〜3月分は？」（遡及なし。Q1-2）／「自宅近くの月極は？」（対象外。Q2-4）／「駐輪場は？」（含む。Q2-2）／
   「会社が駐車場を借りてくれている」（Q4-2）／「限度額より少ない支給なら全額非課税？」（はい。ケースB・D）／

   ここで独自に数字を書かない**（2026-09-27 のレビュー #267 で、103万円と書いていたのを訂正。令和8年分の税の壁は
   `nenshu-kabe` が 178万・119万で説明している））

## やらないこと

- **所得税・住民税の税額を出すこと。** 税率は他の所得で決まるので、課税分だけ出して年末調整計算機・手取り計算機へ渡す
- **社会保険料の計算。** 「全額が報酬に入る」を説明して手取り計算機へリンクするだけ。同じ数字を 2 か所に置かない
- **新幹線・特急の運賃が「合理的な運賃」か、の判定。** 個別事情（所得税基本通達 9-6の3）で、計算機で決められない。FAQ で「特急料金は含まれるが、グリーン料金は含まれない」と触れるに留める
- **非課税限度額の「改正前」を 2026年3月以前の全期間に広げること。** 令和8年 1〜3月分の年末調整確認に使える範囲（令和7年分の表と同じ）だけ
- **会社側（給与計算担当）向けの一括計算。** 1 人分の計算に絞る。`tools/docs/CONCEPT.md` の「個人が自分の数字を確かめる」の型
