## 提案する仕様

### 入力

1. **文書の種類**（ボタン4つ。迷う人向けに「どれに当たる？」の折りたたみで例を出す）
   - 領収書・レシート（第17号の1 売上代金の受取書）
   - 不動産の売買契約書（第1号の1）
   - 工事の請負契約書（第2号のうち建設工事）
   - 請負契約書（建設工事以外。Web 制作・デザイン・システム開発の請負など。第2号）
     - このボタンを選んだら**「成果物の完成に対して払う契約ですか？」**を聞く（はい／いいえ・作業時間や期間に対して払う／継続して取引する基本契約）
     - 「いいえ」（**準委任**＝作業・時間に払う）または「継続して取引する基本契約」を選んだら**計算しない**。結論は
       「この計算機の対象外です。準委任は第2号に当たりません。継続的取引の基本契約書（第7号）なら1通 4,000円の場合があります。国税庁の印紙税額一覧表で確かめてください」
       （**0円も第2号の額も出さない**。誤った答えになるため）
     - 「どれに当たる？」の折りたたみに、業務委託契約書が請負（第2号）・準委任（不課税）・基本契約（第7号）のどれにもなりうることを例つきで書く
2. **金額**（円・`inputmode="numeric"`。カンマ可）
3. **消費税の書き方**（領収書・契約書とも）：「税込金額だけ書く」／「税抜金額と消費税額を分けて書く（または税込と消費税額）」
   - 分けて書く場合は**税抜金額を記載金額**として判定する（国税庁 No.7124）。入力欄は「税抜金額」に切り替える
4. **作成日**（契約書だけ。既定は今日。2027-03-31 と 2027-04-01 をまたぐ確認用に日付で持つ）。ラベルは「作成日（署名・交付した日。契約書に書いた日付ではなく、実際に作った日）」
5. **紙か電子か**（「PDF・メール・電子契約サービスで交わす」を選ぶと課税されない旨を出して計算を止める）
   - 選択肢の説明に1行：「**電子で作っても、印刷して署名・押印したものを相手に渡す／FAX・メールで送ったあとに原本を郵送する場合は、紙の契約書・領収書として印紙が要ります**」
6. **通数**（契約書だけ。既定 **2**。「2通作って双方が1通ずつ持つなら、2通それぞれに印紙が要ります。片方がコピーを持つなら1通分」と添える）
7. **領収書だけ**：「発行するのはだれ？」
   - **会社（法人）** → 常に「営業に関する」（会社の受取書は営業に関しない扱いにならない）。この選択では非課税の分岐に進まない
   - **個人事業主（商売・小売・フリーランスなど）** → 営業に関する
   - **個人の医師・歯科医師・弁護士・税理士・司法書士などの士業、個人の農業・漁業** → **営業に関しない（非課税）**（No.7105）
   - **個人の私的な売買（フリマ・不用品）** → 営業に関しない（非課税）

### 計算（`tools/lib/inshi-zei.ts`）

- 表は**「いつから・いつまで」つきで持つ**（`yubin-ryokin` の `RATE_TABLES` と同じ形）。
  軽減措置は `{ from: '2014-04-01', to: '2027-03-31' }`。大綱で延長が決まったら `to` を書き換え、廃止なら本則だけが残る
- 判定の順番（画面の結論もこの順で出す）
  1. 電子文書 → **0円**（課税文書の「作成」に当たらない。国税庁の文書回答・質疑応答）
  2. 請負（建設工事以外）で「成果物に払う契約ではない」（準委任・基本契約） → **対象外として計算しない**（額を出さない）
  3. 領収書で「営業に関しない」（個人の士業・医師・農業漁業・私的な売買） → **0円**（第17号 非課税物件欄）。発行者が法人なら必ず課税側
  4. 記載金額が非課税の範囲 → **0円**（領収書 5万円未満／契約書 1万円未満）
  5. 契約書で作成日が軽減措置の期間内かつ対象金額（不動産 10万円超・建設工事 100万円超） → **軽減後の額**
  6. それ以外 → **本則の額**
- 契約書は**1通あたりの額 × 通数**を合計として出す
- **境目は「以下」「超」「未満」を表のとおり整数で比べる**（5万円ちょうどの領収書は 200円、4万9,999円は非課税）
- 金額の記載がない契約書・領収書は **200円**（各号の「記載金額のないもの」）
- 結果には**本則との差額**を添える（「軽減措置が切れると 1万円 → 2万円」のように、2027-04 以降の額を必ず並べる）

### 画面

- 結論を最上段に1行：「**貼る印紙：1通 1万円 × 2通＝合計 2万円**（軽減措置。2027年4月1日以降に作る契約書なら1通 2万円）」。その下に「片方がコピーを持つなら1通分（1万円）」
- その下に「なぜこの額か」を判定の順番どおりに箇条書き（電子？→営業に関する？→金額→作成日）
- 「印紙が要らない書き方」の節：①消費税を分けて書くと税抜で判定（例：税込 5万2,800円＝税抜 4万8,000円＋消費税 4,800円なら非課税）
  ②電子で交わす（ただし印刷して渡す・原本を郵送すると課税）③個人の私的な売買・個人の士業や医師の受取書
- 「貼り忘れたら」の節：過怠税は納付しなかった印紙税の **3倍**（最低1,000円）、税務調査の前に自分から申し出れば **1.1倍**。
  **消印**（印紙と文書にまたがって押す印・署名）を忘れたら、消していない印紙の額面と同額（印紙税法20条）。
  **割印**（契約書2通にまたがって押す印）は印紙税法上の義務ではなく、押さなくても過怠税はかからない（混同しやすいので本文で分けて書く）。過怠税は法人税の損金・所得税の必要経費にならない
- 早見表（よく検索される金額）：領収書 5万円／10万円／100万円、不動産 1,000万円／3,000万円／5,000万円、工事 500万円／1,000万円。
  **2027-03-31 と 2027-04-01 の2列**で出す
- FAQ（JSON-LD）5問：
  1. 2027年4月から印紙税は上がる？（軽減措置の期限と、令和9年度税制改正大綱の結論。大綱前は「延長の要望が出ている」と書き、決まったら書き換える）
  2. 領収書の印紙は税込・税抜どちらで判定？
  3. 電子契約・PDF の領収書に印紙はいる？（いらない。ただし印刷して署名・押印したものを渡す／送ったあと原本を郵送するなら要る）

### 年度の切り替え（大綱の前と後）

- **大綱の前（〜2026-12 中旬）**：期限は 2027-03-31 のまま計算し、本文に「国土交通省が延長を要望している（令和9年度税制改正要望）」と書く。
  2027-04-01 以降の作成日は本則で出し、「延長が決まれば軽減額に戻る」と添える
- **大綱の後**：延長なら `to` を新しい期限に、廃止・縮小なら新しい表を足す。**大綱は閣議決定であって法律の成立ではない**ので、
  「〜予定（令和9年度税制改正大綱）」と書き、法律の成立（例年3月末）で言い切りに直す。成立の確認は実装済みツールの定期点検（kokai-tool-seikaku）で拾う

### 書かないこと

- 特定の電子契約サービス・会計ソフトの名前（推奨と読まれる）
- 「印紙代を節約する方法」として契約書を作らない・分割するなどの指南（脱法の助言と読まれる。電子化と税抜表記は国税庁が示す取扱いなので書いてよい）
- 金銭消費貸借契約書（第1号の3）・継続的取引の基本契約書（第7号）など v1 で扱わない文書の税額（「対象外。国税庁の一覧表を見てください」に留める）

## テスト

- 境目：領収書 49,999円→0・50,000円→200・1,000,000→200・1,000,001→400／不動産 100,000→200・100,001→200（軽減）・500,001→500（軽減）・1,000万→5,000（軽減）／1万（本則）
- 作成日：不動産 3,000万円 の 2027-03-31→1万円・2027-04-01→2万円。建設工事 1,000万円 同様に 5,000円→1万円
- 第1号と第2号の区切りの違い：300万円 は第1号本則 2,000円・第2号本則 1,000円
- 税抜判定：分けて書く＋税抜 48,000円 → 0円。税込だけ 52,800円 → 200円
- 電子・営業に関しない → 0円で、金額に関係なく判定が止まる
- 請負（建設工事以外）で「成果物に払う契約ではない」「継続的な基本契約」を選ぶと、**額を返さず対象外**（0円でも第2号の額でもない）
- 発行者「法人」は「営業に関しない」に進まない（法人＋5万円以上 → 必ず課税）。個人の士業・医師・農業漁業 → 0円
- 通数：不動産 3,000万円・2027-03-31・2通 → 合計 2万円、1通 → 1万円
- 表の行が金額の昇順で、隙間・重なりが無い（表の写し間違いを機械で落とす）

  **期限つきの制度を日付で出し分ける**ので、期限の前後でページの答えが自動で正しく変わる
- フリーランス・個人事業主（インボイス2割特例・青色申告特別控除の利用者）への回遊の入口になる
