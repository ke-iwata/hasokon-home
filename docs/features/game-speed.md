# 新ゲーム「スピード」（トランプ基盤の再利用・リアルタイム対戦の初の面）

**状態**：実装済み（2026-08-15。本番反映はタグリリース待ち）
**対象**：`games/`（`hasokon.com/games/speed/`）
**起票**：2026-08-15

> 実装時に決めたこと（仕様書に書いていなかった点）：
> - **開始も「合図で山札から1枚ずつ」にした。** 配った直後の台札は空で、
>   「はじめる」を押した時点で双方の山札から1枚ずつ台札に置く（本物と同じ開始手順）。
>   開いた瞬間に始めると、盤を見る前にCPUが出し始めてしまうため。
>   手詰まりのめくり直しと同じ関数（`applyFlip`）で書ける。
> - **どちらの山札も尽きて、しかも双方が出せなくなったときの決着**（仕様書に無い場面）。
>   めくる札が1枚も無いのでゲームが進まなくなる。**残り枚数の少ないほうの勝ち、
>   同じなら引き分け**とした。台札を混ぜて山札に戻す一般的なローカルルールは採らない
>   （1ゲーム1〜2分というテンポを崩すため）。※要確認
> - **片方の山札だけが尽きた場合**は、めくり直しの札を相手の山札から出して続行する
>   （標準ルール。場札だけになった側も最後まで戦える）。
> - **手詰まりの判定は局面だけで決める。** CPUが見落としているあいだは手詰まりにしない
>   （こちらに出せる札が残っているのに台札がめくられては困るため）。
> - **先を越された手は黙って捨てる**（`applyPlay` が同じ局面を返す）。リアルタイムなので
>   人間のタップとCPUのタイマーが同じ台札を同時に狙う場面が普通に起きる。
> - **記録の区分**は仕様どおり `cpu-{強さ}`。勝敗と、勝ったときのベストタイムを残す。

## 背景と根拠

### トランプ定番でまだ埋めていない「スピード」は、実は検索の定番

当サイトのトランプ面は ソリティア／スパイダー／フリーセル／大富豪／
七並べ／神経衰弱 と揃ってきたが、日本でトランプ2人遊びの代名詞である
「スピード」が未提供。「スピード トランプ」「スピード ゲーム 無料」は
アプリ紹介記事が毎年更新される程度の恒常需要があり（2026-08-15 Web調査）、
子どもの頃に遊んだ層が名前で直接検索する、権利関係的に無害な題材。

### 既存基盤の再利用率が高く、かつ既存ゲームと客層が重ならない

- カード描画は `games/app/_cards/CardView.tsx`（SVG自前描画）を再利用
- 山札・シャッフルは `lib/cards` を再利用、成績保存は `_records` に乗せるだけ
- 既存のトランプゲームはすべてターン制。**リアルタイム反射系はサイト初**で、
  ソリティア系とは別の「瞬発力ゲーム」の需要（GA4でも粘着度の高い
  block-puzzle・minesweeper 系の層）に当てられる

## 提案する仕様

1. **ルール（標準ルール）**
   - 各自26枚。場札4枚を表に、台札2枚を中央に置く
   - 台札の数字と**連続する数字**（AとKはつながる）を場札から出せる。
     出したら手元の山から場札を補充
   - 双方出せなくなったら、合図とともに山札から1枚ずつ台札に重ねて再開
   - 先に手札と場札をすべて出し切った方が勝ち
2. **CPU対戦**
   - CPUは「反応の速さ（出せる札を見つけてから出すまでの遅延）」と
     「見落とし率」で難易度3段階（弱／普通／強）を表現。
     最強でも人間らしい遅延を残し、理不尽さを避ける
3. **操作（スマホ最優先）**
   - 場札をタップ → 出せる台札が1つならそこへ、2つとも出せるなら
     出したい台札をタップで選択。ドラッグは要求しない
   - 出せる札がないときの「山札から台札へ」は両者自動（合図演出つき）で、
     手詰まり状態の判定ミスによるストレスを避ける
   - 連続プレイを想定し、1ゲーム約1〜2分で終わるテンポを維持する
4. **記録**：`_records` に `cpu-{強さ}` 区分で勝敗・クリアタイム
   （勝利時の所要時間ベスト）を保存
5. **SEO**：VideoGame + FAQPage + BreadcrumbList の jsonLd。
   ルール・コツ（「場札は端から出す」等）・FAQ本文を最初から同梱。
   `llms.txt`・sitemap・home の一覧・registry への追加も実装PRで行う
6. **UI/UXの既存教訓の踏襲**：iOSの文字自動拡大対策・待ち時間の
   タップ短縮（[game-shinkei-suijaku.md](./game-shinkei-suijaku.md)）を踏襲

### やらないこと

- オンライン対戦（通信対戦基盤はサイトの範囲外）
- 同一端末での対人2人プレイ（スピードは両者が同時に手を動かすため
  1画面では物理的に手が交錯する。CPU対戦のみとする）
- ジョーカー入りなどのローカルルール（まずは標準ルールのみ）

## 期待される効果

- 「スピード トランプ」系の恒常検索の獲得と、トランプ面の網羅性向上
  （「トランプ ゲーム 無料」系のまとめ記事で挙がる定番をほぼ網羅する）
- サイト初のリアルタイム反射系として、直帰しにくい滞在の長い面が増える
  （GA4では block-puzzle が平均1,100秒超と突出しており、
  反射・アクション系の粘着度は実証済み）
- 神経衰弱と同様、実装済みトランプ基盤の限界コストの低さを活かせる

## 工数の目安

- 実装（進行ロジック＋CPU＋UI＋テスト＋FAQ・jsonLd）：**約12〜18万トークン**
- ターン制でないぶん神経衰弱よりやや重い。リアルタイム進行
  （CPUタイマー・手詰まり判定・同時出しの調停）のテストが工数の中心
