## 提案する仕様

### ルール（既定）

1. CPU（または次の人）と交互に、**前のことばの最後の字ではじまる名詞**を言う
2. **「ん」で終わることばを言ったら負け**
3. **一度出たことばをもう一度言ったら負け**
4. 一覧に無いことばは「**このことばは一覧にありません（負けにはなりません）**」と出し、**言い直せる**（[ことば当て](./game-kotoba-ate.md)と同じく、一覧の穴でプレイヤーを負けにしない）
5. 制限時間（なし〈既定〉／20秒／10秒）。時間切れは負け
6. CPU が出せることばが無くなったら CPU の「まいった」で、プレイヤーの勝ち

### 選べるルール（「ルール」ボタンの中。既定は太字）

| 項目 | 選択肢 | 例 |
|---|---|---|
| のばす音「ー」で終わるとき | **「ー」をとばして前の字**／前の字の母音（コーヒー→い） | コーヒー → **ひ**／い |
| 小さいかなで終わるとき | **大きい字にする**（ゃ→や）／2文字で続ける（しゃ） | きしゃ → **や**／しゃ |
| 濁点・半濁点 | **そのまま**／取ってもよい（ば→は） | かば → **ば**（「は」も可にできる） |
| 「ぢ」「づ」 | **「じ」「ず」と同じにする** | — |

ルールの組み合わせは結果の画面に1行で出す（「ー：とばす・小さい字：大きく・濁点：そのまま」）。家族で揉めないため。

### モード

- **CPU と対戦**（既定）：よわい／ふつう／つよい
  - よわい：よく使うことば（一覧の「やさしい」印つき）から選ぶ。**10手に1回くらい、わざと「ん」で終わることばを言って負ける**（子ども向け。「あっ、『ん』がついちゃった！」）
  - ふつう：一覧全体から、負けないように選ぶ
  - つよい：相手が続けにくい字（「る」「ぷ」「ぬ」「ぢ」など、一覧の中で**その字ではじまる未使用のことばが少ない字**）で終わることばを優先する。数え方は純関数で、テストで固定
- **みんなで（2〜4人・1台を回す）**：名前を入れて順番に。一覧に無いことばは「**みんなが OK なら続ける**」ボタンで通せる（家族ルール）。CPU は入れない
- **しばり**（どちらのモードにも掛けられる）：テーマ（たべもの・どうぶつ・のりもの・しょくぶつ・からだ・いえのもの）／文字数（3文字だけ・4文字以上）

### ヒント

- 「ヒント」で **「◯ではじまることば」を一覧から1つずつ**出す（伏せ字で1文字目と文字数だけ → もう一度押すと全部）。CPU 対戦では**ヒントを使った回数を結果に出す**（使ってよい。子どもと遊ぶため）
- ヒントのことばは、まだ出ていない・「ん」で終わらない・しばりに合うものから選ぶ

### 入力（パソコン・スマホ）

- 入力欄に**ひらがなかカタカナ**で打つ（カタカナはひらがなに直して判定。全角・半角カタカナとも）。漢字・英字が入ったら「ひらがなかカタカナで入れてね」と出す（漢字の読みは推測しない）
- パソコンは Enter で決定。**スマホでは入力欄に自動でフォーカスしない**（キーボードが盤面を隠すため。[ことば当て](./game-kotoba-ate.md)の約束と同じ）
- 幅 390px で、**直前の3手・いまの頭の字（大きく）・入力欄・決定ボタン**が1画面に収まる（[mobile-one-screen.md](./mobile-one-screen.md)）。それより前の手は折りたたんだ一覧
- 読み上げ（任意。既定はオフ）：CPU のことばを Web Speech API の `speechSynthesis` で読む。端末に日本語の声が無ければボタンを出さない。**マイク入力（音声認識）はしない**（送信が絡むブラウザがあるため）

### ことばの一覧（`games/lib/shiritori-words.ts`）

- **案 A（推奨）：全部自前で書く。** 日常で使う名詞を**ひらがなで 4,000 語以上**。各語に `theme`（上の6種か無し）と `easy`（子どもが知っている）を持たせる。
  既存の辞書・他作品の語彙・しりとり攻略サイトの一覧を写さない
- 案 B：受け付けるだけの一覧を JMdict（CC BY-SA 4.0）のかな表記で増やす。**継承と表示の義務が付く**ので運営者の了承が要る。了承が無ければ案 A のまま
- 入れないもの：固有名詞（人名・地名・商品名・作品名・キャラクター名）、差別語・性的な語・暴力的な語。**禁止語の一覧は平文でリポジトリに並べない**（[ことば当て](./game-kotoba-ate.md)と同じ可逆の変換をかけたテストのフィクスチャで持つ）
- **テストで固定すること**：ひらがなだけ／重複なし／禁止語に当たらない／**「ん」以外の頭の字（46字＋濁音・半濁音）それぞれに、「ん」で終わらない語が 20 語以上**ある（CPU が序盤で詰まない）／テーマごとに 150 語以上
- 一覧のファイルは遅延読み込み（ページを開いた時点で読まず、最初の1手の前に読む）。gzip 後 30KB 程度を目安

### 結果・記録

- 勝ち負け・何往復続いたか・一番長かったことば・使ったヒントの数
- 記録は [game-records.md](./game-records.md) の仕組みで端末に残す（CPU のつよさ別の勝ち数・最長の往復）
- 共有：「しりとりで CPU（つよい）に 23 往復で勝った」のような文だけ。**出したことばは共有文に入れない**（一覧の外の語を自由に打てる「みんなで」モードがあるため）

### ページの構成

1. 見出し・リード（1〜2文）
2. ゲーム（最初の画面にモードの選択と「はじめる」。[desktop-one-screen-card-games.md](./desktop-one-screen-card-games.md) と同じく、スタート前に CPU を動かさない）
3. 遊び方・ルールの違い（「ー」・小さい字・濁点の表）
4. FAQ（6問：「ー」で終わったら／小さい字で終わったら／濁点は取ってよい？／一覧に無いと言われた／「る」で詰まったら（ヒントの使い方）／高齢者のレクで使うときのこつ（大きな文字・時間なし・テーマしばり））
5. JSON-LD（`VideoGame`）と `metadata` の `robots: robotsFor('shiritori')`

### 送らない・残さない

- 打ったことばはどこにも送らない。GA4 には `game_start`・`game_end` 相当（モード・つよさ・勝敗・往復数）だけを送り、**ことばそのものは送らない**
- 「みんなで」の名前は端末にも保存しない（画面を閉じたら消える）

## 確かめること（テストとテスト環境）

- 頭の字の判定（`lastKana`）：「コーヒー」「きしゃ」「かば」「はなぢ」「バレエ」など、ルールの組み合わせごとの期待値を表で固定
- 「ん」・同じことば・時間切れの負け、一覧に無いことばで負けにならないこと
- CPU（つよい）が選ぶ語の終わりの字が、残りの語数の少ない字になること（小さな一覧のフィクスチャで固定）
- CPU が出せる語が無いとき「まいった」になること（無限ループ・例外にならない）
- 一覧のテスト（上の「テストで固定すること」）
- `games/tests/stage.test.ts`・`tests/llms.test.ts` が通ること
- テスト環境で、幅 390px（iPhone 13）・320×568・1366×768 の1画面に入力欄と頭の字が収まること、スマホでキーボードを出しても頭の字が隠れないこと

## やらないこと

- **オンライン対戦**（サーバーが要り、知らない相手と子どもを会わせない）
- **音声入力**（ブラウザによって音声が外部に送られるため）
- ことばの意味の説明（辞書の要約になり、量・正確さ・権利の負担がかさむ）
- 「◯から始まる言葉」の一覧ページを字ごとに作ること（一覧そのものを公開すると編集著作物の流出・薄いページの量産になる。ゲーム内のヒントに留める）
