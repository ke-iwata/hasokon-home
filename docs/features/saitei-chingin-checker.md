**状態**：提案（未実装）
**対象**：`tools/`（`hasokon.com/tools/saitei-chingin/`）
**起票**：2026-08-14

## 背景と根拠

### 2026年度の改定目安が答申され、検索需要の季節ピークが始まった

2026年7月28日、中央最低賃金審議会が令和8年度の地域別最低賃金の
改定目安を答申した（2026-08-14 Web調査で確認）。

- **Aランク +54円**：埼玉・千葉・東京・神奈川・愛知・大阪の6都府県
- **Bランク +56円**：北海道・宮城など28道府県
- **Cランク +56円**：青森・岩手など13県
- 目安どおりなら**全国加重平均 1,121円 → 1,176円（+55円、+4.9%）**
- 例：東京 1,226円 → 1,280円、神奈川 1,225円 → 1,279円

ここから8〜9月に各都道府県の地方最低賃金審議会が答申を出し、
**10月以降に順次発効**する。つまり「最低賃金 いくら」「最低賃金 2026 自分の県」
「10月 時給 上がる」系の検索需要は**いままさに立ち上がり、10月にピークを迎える**。
毎年必ず繰り返される季節需要で、一度作れば毎年データ更新だけで回る。

### サイトの柱「法改正×計算機」にそのまま乗り、年収の壁ツール群と噛み合う

このサイトの戦略は「制度改正が出るたびに計算機を追加する」
（年収の壁・高校授業料・iDeCo・自転車反則金の実績）。最低賃金の引き上げは
**時給で働く人全員**が対象で、対象人口はこれまでのどのツールよりも広い。

さらに既存ツールと相互送客できる：最低賃金が上がると**同じ労働時間でも
年収の壁（106万/130万等）に早く到達する**。「時給が上がった結果、
扶養から外れそう」という悩みは `nenshu-kabe` / `hatarakizon` の入口そのもので、
内部リンクの導線が自然につながる。

### 計測値（2026-08-14 取得）

- GA4（Data API・直近14日）：Organic Search セッションが前期間比 10 → 61 と
  立ち上がり始めており、法改正系ツール（nenshu-kabe 17PV など）が牽引している
- GSC（Search Analytics API・直近28日）：税・制度系では
  `tool.hasokon.com/nenshu-kabe/`（掲載順位 55.5）などまだ順位は低いが表示は出ている。
  最低賃金は現状サイトに受け皿ページが**存在しない**

## 現状

最低賃金に関するページ・計算機能はサイト内に一切ない。
「年収の壁」ツールは年収側からの視点のみで、「時給×労働時間」から
月収・年収を出す入口がない。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **都道府県の早見表・チェッカー**：都道府県を選ぶと
   現行額（令和7年度）・2026年度改定額・発効日・引き上げ幅を表示。
   改定額は「目安（答申前）/ 答申済み / 発効済み」のステータス付きで出し、
   確定前は「目安ベース」であることを明示する
2. **自分の時給チェック**：時給を入力すると、選択した都道府県の
   新旧最低賃金と比較して「10月以降は最低賃金を下回る」等を判定
3. **月収・年収換算**：時給×週労働時間から月収・年収を概算し、
   106万・130万など**年収の壁までの余裕**を表示して
   `nenshu-kabe` / `hatarakizon` へ内部リンク
4. **解説・FAQ**：最低賃金の仕組み（地域別・発効日が県ごとに違う）、
   確認方法（厚労省の地域別最低賃金一覧）、
   「最低賃金を下回っていたら？（差額請求・労基署相談）」
   「月給制でも対象？（月給を時間換算して比較）」など

### データの持ち方

`lib/saitei-chingin.ts` に47都道府県の配列
（都道府県名・令和7年度額・令和8年度額・ステータス・発効日・ランク）を
**【データ更新箇所】**コメント付きで集約。8〜9月の各県答申のたびに
この1ファイルだけ更新すればよい構造にする。

テストは「47件すべて存在する」「新額 ≧ 旧額」「ランクと引き上げ幅の整合」
「発効日の形式」を中心に書く。

## やらないこと

- **特定（産業別）最低賃金の網羅**。県×産業のマトリクスは更新が破綻する。
  「産業別に高い最低賃金がある場合がある」と明示し、厚労省へのリンクにとどめる
- **過去年度の全履歴**。直近（令和7年度）と改定（令和8年度）の比較だけで
  検索意図の大半を満たせる
- **業務改善助成金など事業主向け支援策の詳細**。対象読者を働く側に絞る。
  事業主向けは1行紹介とリンクのみ
- **答申前の確定額の断定**。目安と確定を必ず区別して表示する
