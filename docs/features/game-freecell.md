## 背景と根拠

### なぜフリーセルか

ゲームは現在6本（ソリティア・スパイダー・マインスイーパー・2048・ナンプレ・ブロック崩し）。
このうち**トランプ系が2本あり、共有基盤がすでに出来上がっている**。

| 既存の資産 | 内容 |
|---|---|
| `games/lib/cards.ts` | `Card` 型・`makeDeck()`・`shuffle()`・`seededRng()`・`SUIT_SYMBOL`・`isRed()` |
| `games/app/_cards/CardView.tsx` | カード1枚のSVG描画（255行）。2026-08-10 にSVG化とスマホ拡大を実施済み |
| `games/lib/registry.ts` | ここに1行足すとトップの一覧と sitemap に自動反映 |
| `games/app/solitaire/Game.tsx` | タップ移動・undo・勝利判定のUIパターン（205行） |

**フリーセルは、この4つをそのまま使える唯一の未実装な定番ゲーム**である。
ルールの実装（`lib/freecell.ts`）だけが新規で、クロンダイク（`lib/klondike.ts`、188行）と
同じくらいの規模で収まる。

### 需要の根拠

- Windows に標準搭載されていた時代が長く、**「フリーセル 無料」で探す層が安定して存在する**。
  既存の無料ゲームサイト（SDIN・トランプスタジアム・ワーカービー・ドコモのゲーム広場・
  富士通FMVゲームなど）がいずれもフリーセルを持っている。**定番として需要が確認できる**
- ソリティア・スパイダーで来た人の**回遊先**になる。既存2本の「他のゲーム」欄に並ぶ

### 権利関係

**問題なし。** フリーセルはトランプの一人遊びの一種で、ルールに著作権は無い。
`games/lib/cards.ts` の冒頭にあるとおり、カードの絵柄はUnicodeとSVGで自前描画しており、
画像アセットを持ち込まない。

**マイクロソフト版の「ゲーム番号1〜32000」の配り方は再現しない**（後述の「やらないこと」参照）。

## 提案する仕様

### ルール（標準フリーセル）

- 52枚1組。**最初から全カードが表向き**で配られる（運の要素がほぼ無いのが特徴）
- **場札（tableau）8列**。左4列に7枚ずつ、右4列に6枚ずつ（7×4 + 6×4 = 52）
- **フリーセル4つ**。カードを1枚ずつ一時的に置ける
- **ホームセル（foundation）4つ**。同じスートを A → K の順に積む
- 場札の移動：**色違いで1つ小さいランク**の上に置ける（クロンダイクと同じ）。
  空列にはどのカードも置ける
- 勝利条件：52枚すべてがホームセルに乗ること

### 複数枚移動（スーパームーブ）

フリーセルの本質は「一度に動かせる枚数は空きの数で決まる」ところにある。

```
一度に動かせる枚数 = (空きフリーセル数 + 1) × 2 ^ (空き列数)
```

移動先が空列の場合は、その空列を数に入れない（一般的な実装に合わせる）。

**内部的には1枚ずつの移動の連続だが、UIでは1操作として扱う。**
1枚ずつ手で動かさせるのは操作数が多すぎて、スマホでは特に苦痛になるため。

### 画面

`games/app/solitaire/Game.tsx` のパターンを踏襲する。

| 要素 | 仕様 |
|---|---|
| 上段 | フリーセル4つ・ホームセル4つを横並び |
| 下段 | 場札8列。重なりは既存のソリティアと同じオフセット |
| タップ | カードをタップ → 移動できる先があれば自動で移動（ホームセル優先） |
| ドラッグ | 対応しない（既存2本と同じ。タップ主体で統一する） |
| もどす | 何手でも遡れる undo（既存2本と同じ実装） |
| 新しく配る | 確認ダイアログののち再配布 |
| 手数・時間 | 画面上部に表示 |
| クリア時 | 手数と時間を出す。ベストは `localStorage` に保存（2048と同じ方式） |

### 詰み検出

フリーセルは詰むことがある（配られた時点で解けない配置もまれに存在する）。
**「動かせる手が1つも無い」状態になったら、その旨とやり直しの導線を出す。**
解けるかどうかの探索はしない（後述）。

- **トランプ系の回遊が増える。** ソリティア・スパイダーの「他のゲーム」欄に並ぶので、
  既存の29表示（28日）からの流入が見込める
- **検索の入口が1つ増える。** 定番ゲームなので指名検索（「フリーセル 無料」など）が存在する。
  ただし競合サイトが多く、新規ドメインで上位に出るには時間がかかる。
  **短期の集客効果は期待しないこと**

  現状のゲーム平均セッション時間は 268秒（2026-08-10 取得、全デバイス平均）で、
  ここを押し上げる方向に働く

表示回数・平均エンゲージメント時間を取る。あわせて Search Console で

## やらないこと

- **マイクロソフト版のゲーム番号（1〜32000）の再現はしない。**
  「同じ番号なら同じ配り」を期待する層はいるが、あの配り方は特定の実装の乱数に依存する。
  再現しようとすると検証の手間が大きく、番号の解釈違いで「番号が違う」という
  苦情の元になる。代わりに `seededRng` を使った自前のシード番号を表示し、
  同じ配りをもう一度遊べるようにする
- **解けるかどうかの事前判定（ソルバー）は入れない。**
  フリーセルの求解は探索が要り、静的サイトのクライアント側で回すには重い。
  「動かせる手が無い」の検出だけで実用上足りる
- **ヒント機能は入れない。** 最初の1本としては範囲を広げすぎる。
  遊ばれることが分かってから足す
- **ドラッグ＆ドロップは入れない。** 既存のソリティア・スパイダーがタップ主体で、
  ここだけ操作体系を変えると学習がやり直しになる
- **オセロ・五目並べなどのボードゲームは今回は選ばない。**
  カード基盤を使い回せず、対戦AIの実装が別途必要になる。
  同じ工数ならフリーセルのほうが安く出せる
