## 背景と根拠

### 制度（一次情報で確認。2026-11-13）

厚生労働省 保険局保険課長・年金局年金課長・年金局事業管理課長の通知
**「療養、育児又は介護により報酬が急減した者についての健康保険法及び厚生年金保険法の標準報酬月額の保険者算定の特例について」**
（保保発0731第4号・年年発0731第1号・年管管発0731第7号、令和8年7月31日）
<https://www.mhlw.go.jp/content/001731743.pdf> の要点：

| 項目 | 通知の内容 |
|---|---|
| 根拠 | 健康保険法 44条1項・厚生年金保険法 24条1項（保険者算定）。**通常の随時改定（健保法43条・厚年法23条）とは別の取扱い** |
| 対象者 | 健保・厚年の被保険者と厚年の70歳以上被用者で、①療養等と仕事を両立するための就労調整（所定労働時間の短縮・**時間外労働の抑制**等）が行われ ②その結果、急減後の報酬の総額による標準報酬月額が**従前より2等級以上低下**し、**3か月以上続く見込み** ③**本人が書面で同意** |
| 療養・育児・介護の範囲 | 療養＝本人の治療等、または**家族の治療等に伴う看護**／育児＝**小学校就学前の子**の養育／介護＝要介護・要支援認定を受けた家族の介護 |
| 改定 | **固定的賃金の変動の有無にかかわらず**、報酬減となった初月に受けた報酬の総額で、**その翌月から**改定 |
| 対象外 | 初月の支払基礎日数が17日未満（短時間労働者は11日未満）／初月に全く勤務せず報酬ゼロ／初月の翌月に資格喪失／初月を含め被保険者期間3か月未満 |
| 支払基礎日数 | 就労調整で勤務しなかった日も、所定労働日数が変わらず雇用が続いていれば**支払基礎日数に数える**（戻すときは数えない） |
| 戻すとき | 就労調整が終わって**2等級以上上昇**したら、速やかに届け出て、報酬増の初月の報酬総額で改定 |
| 本人への説明 | 「**将来の年金給付が減少すること、傷病手当金及び出産手当金に影響が生じること**」を十分説明のうえ、あらかじめ同意を得る |
| 届出 | 「被保険者報酬月額変更届（特例改定用）」＋「申立書兼同意書」を事業主が事務センター（年金事務所）へ。**健保・厚年は同時に** |
| 書類の保存 | 出勤簿・賃金台帳・診断書・子の年齢の証明・要介護認定の証明などを**届出から2年間** |
| その後 | 定時決定（算定基礎届）は通常どおり。固定的賃金が変わって2等級以上動けば通常の随時改定も必要 |
| 適用 | **令和9年（2027年）1月1日から** |

**いちばん効くのは「残業を減らしただけ」のケース。** 通常の随時改定は固定的賃金（基本給・手当の単価）が変わらないと
起きないので、残業の抑制だけで手取りが大きく減っても、**次の定時決定（9月）まで前の高い標準報酬月額のまま保険料を払い続ける**。
特例ではこれが翌月から下がる。時短（固定的賃金が変わる）でも、通常の随時改定は4か月目からなので、**2か月早まる**（初月 2027-01 なら特例は2月分から、随時改定は4月分から。早く下がるのは2月・3月の2か月分。通知の「3か月を要する」は従前の額が続く1〜3月のこと）。
残業の抑制だけなら比較相手は次の定時決定（9月分から）なので、初月 1月なら**2〜8月の7か月**早まる（下「早まる月数の式」）。

## 作るもの

### 入力（段階的に出す）

**最初に見せるのは 理由・従前の標準報酬月額・初月の報酬総額・初月 の4つだけ。** 支払基礎日数・短時間労働者・続く見込み・年齢・加入している健康保険・退職予定は、既定値つきの「詳しい条件」に折りたたむ。
子の生年月日（と養育を始めた前月の標準報酬月額）・認定のチェックは、その理由を選んだときだけ出す。

| 入力 | 既定 | 備考 |
|---|---|---|
| 就労調整の理由 | 療養（本人）／療養（家族の看護）／育児／介護 | 育児なら「子の生年月日」、介護なら「要介護・要支援の認定あり」のチェック |
| 子の生年月日（育児のとき） | — | 就学前か（**6歳に達した日以後の最初の3月31日まで**）と、**3歳未満か**を判定 |
| 従前の標準報酬月額 | — | 給与明細・「標準報酬決定通知書」の値。**分からなければ「月の報酬の目安」から等級表で出す**（切替） |
| 報酬減となった初月の報酬の総額 | — | 残業代・通勤手当を含む総額（通勤手当を含む点を入力欄の下に書く） |
| 初月の支払基礎日数 | 20 | 「勤務しなかった日も、所定労働日数が変わらなければ数える」と入力欄の下に書く |
| 短時間労働者（4分の3未満）か | いいえ | はい なら17日→11日 |
| 減った状態が続く見込み | 3か月以上 | 「3か月未満」を選ぶと対象外 |
| 報酬減となった初月 | 今日の翌月 | 年月。**2027-01 より前を選んだら「2027-01-01 適用」の注記**（下「決めること」1） |
| 年齢 | 35 | 40〜64歳なら介護保険料を含める |
| 加入している健康保険 | 協会けんぽ（都道府県を選ぶ） | 健保組合なら料率を入力（`shaho-ryoritsu.ts` の既存の扱いに合わせる） |
| 初月の翌月に退職するか | いいえ | はい なら対象外 |

### 判定（上から順に、当たらない理由を1つずつ出す）

1. 理由が療養・育児（就学前）・介護（認定あり）のどれかに当たるか
2. 支払基礎日数が17日（短時間は11日）以上か、報酬がゼロでないか
3. 初月の報酬総額で引いた等級が、従前より**2等級以上**低いか
   - 健保50級（報酬月額141万5,000円以上に限る）→49級以下、厚年32級（66万5,000円以上に限る）→31級以下も2等級として扱う
   - 第2級→健保5万3,000円未満・厚年8万3,000円未満も同様（通知の※2）
   - **健保と厚年で等級の数え方が違う**（厚年は1〜32級）。通知は「双方で同時に手続」なので、**健保の等級で2等級以上を判定し、厚年はその改定後の額を厚年の等級に当てはめる**（下「決めること」2）
4. 3か月以上続く見込みか／翌月に資格喪失しないか
5. 上がすべて当たれば「**特例の対象になりうる。事業主の届出と、あなたの書面の同意が要る**」と出す
   （判定は目安で、最終的には事業主・年金事務所が判断する、を必ず添える）

**対象外のときに「通常の随時改定なら」を併記する。** 固定的賃金が変わっていれば4か月目に改定されうる、
残業の減少だけなら次の定時決定（9月改定）まで変わらない、の2通りを出す。

### 結果（対象になりうるとき）

**結果の冒頭に要約を1段置く**：対象になりうるか／何月分から下がるか／月いくら下がるか（本人分）／年金が年いくら減るか。詳細の表はその下。

#### 早まる月数の式

初月を M（年月）とする。特例による改定は M+1 月分から。

- **固定的賃金の変動あり（時短など）**：比較相手は通常の随時改定（M+3 月分から）→ 早まるのは **M+1・M+2 の2か月**
- **固定的賃金の変動なし（残業の抑制のみ）**：比較相手は次の定時決定（9月分から）。
  - M+1 が 1〜6月 → その年の9月分まで、早まる月数 = 9 − (M+1 の月)
  - M+1 が 7〜9月（初月が6〜8月）→ 特例改定が7〜9月なので**その年の定時決定の対象外**（通知「(3)②」）。比較相手は**翌年**の9月分から
  - M+1 が 10〜12月 → 比較相手は翌年9月分から
  - 初月が**5月**のときは、その年の定時決定（4〜6月の平均）に**減る前の4月の報酬が混ざる**ので（初月4月なら3か月とも減った月、初月6月は定時決定の対象外）、9月分からの額が減った額まで下がらないことがある。その場合は「9月分からも一部しか下がらない」と注記し、早まる月数は9月分までで数える
- 早まる月の保険料の合計は、**その月ごとの料率**で足す（協会けんぽは3月分、子ども・子育て支援金は4月分から変わる。`shaho-ryoritsu.ts` の料率表を月で引く）。料率が未公表の月は直近の料率で通し、そう注記する

| 段 | 出すもの |
|---|---|
| いつから | 「報酬減の初月が **2027年1月** → **2月分の標準報酬月額から**改定（多くの会社は**3月の給与から天引きが下がる**＝翌月徴収）」。通常の随時改定なら「4月分から」を並べ、**早まる月数**を出す |
| 毎月の保険料（本人分） | 健康保険・介護保険・厚生年金・子ども・子育て支援金を、改定前→改定後で並べる。差額の月額と、**通常の随時改定（または定時決定）より早く下がる分の合計**（月数は下「早まる月数の式」） |
| 事業主の負担（折りたたみ） | 同じ表の事業主分（人事担当向け） |
| 引き換えに減るもの | ①**厚生年金（老齢）**：報酬比例部分の減少の目安＝(従前 − 改定後の厚年の標準報酬月額) × 5.481/1000 × 特例の月数（**年額・生涯毎年**）。「月数」は入力（既定12か月）<br>②**傷病手当金・出産手当金**：支給開始日以前12か月の標準報酬月額の平均で決まるので、特例の月数ぶん平均が下がる。`kenpo-daily-amount.ts` で「特例を使わなかった場合／使った場合（12か月後）」の日額を並べる |
| 3歳未満の子の育児のとき | 「**養育期間の標準報酬月額の特例（厚生年金保険 養育期間標準報酬月額特例申出書）を併せて出せば、①の年金は子が生まれる（養育を始める）前の月の標準報酬月額で計算される**」を、①の行のすぐ下に強調して出す。<br>**みなしの基準は厚年法26条の「養育を始めた月の前月」（その月に被保険者でなければ1年以内で直近の月）の標準報酬月額**で、特例改定の直前の額と同じとは限らない（第2子・復職後の昇給など）。そのため入力に「養育を始めた前月の標準報酬月額」を足し（既定は従前と同じ額、と注記）、**基準の額 ≧ 従前の額のときだけ** ①の減少額に打ち消し線を引いて0円を並べる。基準の額 < 従前の額なら、**(従前 − max(基準, 改定後の厚年の標準報酬月額))** に対する減少額を出す（みなしは「基準の額と実際の額の高いほう」。基準が改定後より低ければみなしは効かない）。<br>強調表示のすぐ下に：**守られるのは厚生年金だけ**（傷病手当金・出産手当金は守られない）／**申出書は本人が事業主を通して出す** |
| 戻すとき | 「時短・残業抑制が終わって2等級以上上がったら、事業主が速やかに届け出て翌月から戻る」 |
| 手続きの一覧 | 事業主が出すもの（月額変更届〈特例改定用〉＋申立書兼同意書、健保組合にも同時に）、本人がすること（書面の同意）、保存する書類（2年） |

**例（ページの本文に入れる）**：東京都・協会けんぽ・35歳、従前 30万円（健保22級・厚年19級）、
残業の抑制で 2027-01 の報酬が 22万円（健保18級）→ 4等級低下で対象になりうる。
厚生年金の本人分は月 27,450円 → 20,130円（**月 7,320円減**）、健康保険の本人分も下がる。残業の抑制だけなら比較相手は9月分からの定時決定なので、**2〜8月の7か月分**が早く下がる（厚年だけで 7,320円 × 7 = 51,240円）。
引き換えに、12か月続けた場合の老齢厚生年金は (300,000 − 220,000) × 5.481/1000 × 12 ≒ **年 5,262円 減（生涯毎年）**。
（実装時に `shaho-ryoritsu.ts` の料率で計算し直し、テストの期待値にする。上の厚年は 9.15% で計算）

## 決めること（実装前に運営者と）

1. **2026年中に始まった就労調整は使えるか。** 通知は「令和9年1月1日から適用」としか書いていない。
   **「報酬減となった初月」が 2027-01 以降のときだけ対象**と読むのが安全側なので、既定はそれにし、2026-12 以前を選んだら
   「適用は2027年1月から。2027年1月以降の月を初月として届け出られるかは年金事務所に確認を」と出す。
   日本年金機構の Q&A が出たら、その記述に合わせて直す（**実装の PR で出典の有無を確認する**）
2. **健保と厚年で等級が違うときの判定。** 通知は「標準報酬月額が2等級以上低下」としか書かず、手続は健保・厚年同時。
   コロナ特例のときの機構の Q&A（[令和2年 Q&A](https://www.nenkin.go.jp/oshirase/topics/2020/0625.files/QA.pdf)）の扱いに倣うのが自然だが、今回分の Q&A は未確認。
   **実装時に今回の様式（別紙1）と Q&A を確認し、見つからなければ「健保の等級で判定」と画面に明記する**
3. 2027-09 からの厚生年金の上限 68万円（33級）に、`pensionCapAt(date)` で追従させる（既存関数を使うので追加作業はない）。
   **※2 の特則のしきい値（健保 141万5,000円・厚年 66万5,000円）は固定値で書かない。** 最上位の等級を `GRADES`／`pensionCapAt()` から引き、「最上位の等級の報酬月額の下限 ＋ 1等級ぶんの幅」で出す（33級になると厚年の値が変わるため）

## 期待される効果

- **2027-01-01 に始まる新制度で、計算機が無い**（調べた範囲）。CONCEPT.md の「新制度 × 計算ツール」の勝ち筋そのもの。
  需要は 2026-12（人事の準備）と 2027-01〜03（最初の届出）に立ち、その後も時短・介護離職の対策として通年で残る
- 既存の社会保険の計算機（働き損・傷病手当金・育児時短就業給付）と**相互リンク**できる。働き損の計算機（エンゲージ率 88%）からの回遊
- **本人の「同意していいのか」に答える唯一の場所**になれる（年金・手当金の減少と、養育特例で年金を守れることを数字で出す）
- 測り方：公開後 4 週の着地セッション（下限 20）と `tool_use`（計算の実行）率。社会保険の計算機の中央値と比べる
