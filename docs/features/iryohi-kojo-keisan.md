# 新ツール「医療費控除・セルフメディケーション税制 計算機」（いくら戻るか・どちらが得か）

**状態**：提案（2026-08-31 起票・未実装）。実装したら `stage: 'wip'` → `preview` で確認 →
確定申告シーズン前（遅くとも2026年12月）に `public` へ。
**対象**：`tools/`（`hasokon.com/tools/iryohi-kojo/` を想定）
**起票**：2026-08-31

## 背景と根拠

### 「医療費控除 計算」は税金系で最大級の定番クエリで、サイトの得意分野そのもの

- 医療費控除は**年末調整では手続きできず、給与所得者でも確定申告が必要**な数少ない控除。
  「自分で計算して申告するか決める」需要が構造的にあり、
  「医療費控除 計算」「医療費控除 いくら戻る」「医療費控除 10万円以下」は
  毎年12月〜3月に大きく動く定番クエリ
- 本サイトの税・社会保険クラスタ（年末調整・ふるさと納税・高額療養費・年収の壁など）と
  完全に地続きで、**給与収入 → 課税所得 → 累進税率**の変換ロジックは
  `tools/lib/nenmatsu-chosei.ts` / `furusato-nozei.ts` に実装済み。流用できる
- [kogaku-ryoyohi.md](./kogaku-ryoyohi.md)（高額療養費）と対になる。
  「高額療養費（月単位・事前に負担を抑える）」と「医療費控除（年単位・後から税金が戻る）」の
  混同は定番の疑問で、相互リンク・FAQで両ページの回遊と検索面が広がる

### 2026年ならではの時事フック：セルフメディケーション税制が今年12月末で期限を迎える

セルフメディケーション税制（医療費控除の特例）は、5年延長された現行の適用期限が
**2026年（令和8年）12月31日**。延長の有無は令和9年度税制改正の議論待ちで、
秋〜年末に「今年で終わり？」「駆け込みで買うべき？」という検索・記事が増えるタイミング。
「対象のOTC医薬品をあといくら買えば控除ラインを越えるか」を出せる計算機は
この時期に固有の価値がある。

### 競合状況

保険会社・税理士サイトに解説記事は多いが、**その場で両制度を並べて比較計算できる
無料ツールは少ない**（多くは解説＋数式のみ、または医療費控除単体の簡易計算）。
「両方計算してどちらが得か」を1画面で出すのが差別化点。

## 制度の要点（実装時に一次情報で再確認すること）

| 項目 | 医療費控除（所得税法73条） | セルフメディケーション税制（租税特別措置法41条の17の2） |
|---|---|---|
| 控除額 | （支払医療費 − 保険金等の補填額）−（**10万円** と **総所得金額等×5%** の小さい方） | 対象OTC医薬品の購入額 − **1.2万円** |
| 上限 | 200万円 | 8.8万円 |
| 要件 | 生計を一にする家族分を合算可 | 健康診断・予防接種等の「一定の取組」が必要 |
| 適用期限 | 恒久 | **2026年12月31日**（延長は令和9年度税制改正待ち） |
| 併用 | **選択適用（併用不可）** | 同左 |

- 戻る額の概算：**所得税＝控除額×限界税率×1.021（復興特別所得税）**（申告後に還付）、
  **住民税＝控除額×10%**（翌年度の住民税から減る）。この2段構えを明示するのが
  分かりやすさの肝（「10万円戻る」ではなく「控除が10万円で、戻るのはその2〜5割」）
- 「総所得金額等×5%」の分岐により、**総所得200万円未満（給与収入だと約297万円未満）なら
  医療費が10万円以下でも控除できる**。これが最頻の誤解（「10万円超えないと無理」）で、
  FAQ・結果表示で必ず拾う

## 提案する仕様

1. **入力**：①年収（給与収入。パート・年金は簡易対応）②その年に支払った医療費の合計
   ③保険金などで補填される金額 ④対象OTC医薬品の年間購入額（任意）
   ⑤健康診断等の取組の有無（チェックボックス。セルフメディケーション税制の要件）
2. **出力**：
   - 医療費控除の控除額と、戻る額の概算（所得税の還付＋住民税の軽減を分けて表示）
   - セルフメディケーション税制の控除額と戻る額の概算（要件を満たす場合のみ）
   - **どちらが得かの判定**と、その差額
   - 足切り未満の場合は「あといくらで控除が始まるか」を表示（駆け込み判断に効く）
3. **給与収入 → 課税所得・限界税率**は `lib/nenmatsu-chosei.ts` 等の既存実装を流用。
   社会保険料は既存ツールと同じ簡易推計でよい（結果に「概算」と明記）
4. **静的コンテンツ**（SEOの受け皿）：
   - 対象になる費用・ならない費用の早見表（通院交通費○・自家用車のガソリン代×など定番）
   - 「高額療養費との違い」（`/tools/kogaku-ryoyohi/` と相互リンク）
   - 「年末調整ではできない・確定申告のやり方」（`/tools/nenmatsu-chosei/` と相互リンク）
   - セルフメディケーション税制の期限と延長議論の現在地（**状態を日付つきで書く**。
     税制改正大綱が出たら更新する運用を状態行に残す）
5. **FAQ + JSON-LD**（FAQPage）・`robots: robotsFor('iryohi-kojo')`・
   stage は `wip` から。既存ツールの作法（mobile-one-screen・game-recordsは対象外）に従う
6. **テスト**：控除額の境界（10万円 / 総所得×5% の分岐、200万円・8.8万円の上限、
   補填額が医療費を超えるケース、マイナスにならないこと）を `tools/tests/` に置く

## やらないこと

- **確定申告書の作成・出力**（国税庁の確定申告書等作成コーナーの領分。リンクで案内する）
- **医療費の明細管理**（件数入力・CSV取り込みなどはしない。合計額を入れる設計に絞る）
- **セルフメディケーション対象品目の検索**（品目リストは厚労省の一覧へリンク）
- 住民税の細かい調整控除・所得割非課税の判定（「概算」の注記で扱う）
