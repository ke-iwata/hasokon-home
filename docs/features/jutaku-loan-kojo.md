## 背景と根拠

### 令和8年度税制改正で、住宅ローン控除の適用期限が 5 年延びた

財務省「[令和8年度税制改正の大綱の概要](https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_gaiyou.htm)」に
「**適用期限を５年延長する**」「既存住宅のうち省エネ性能の高い認定住宅・ＺＥＨ水準省エネ住宅に係る
**借入限度額の引上げ**」「**子育て世帯への上乗せ措置の対象の拡充**」「**床面積要件の緩和**等の
見直しを行った上で」とある。改正法は
**所得税法等の一部を改正する法律（令和8年法律第12号）**（インボイスの 3 割特例と同じ改正法。
`tools/lib/invoice-nozeigaku.ts` に `LAW_R8_KAISEI` として既にある）。

つまり**令和12年（2030年）12月31日までに入居した人まで対象**になった。
これまで「2025年末で終わる」前提で書かれた記事が大量にあり、
**「2026年 住宅ローン控除 いつまで」という検索が発生する条件が揃っている**。

### 当サイトの型にそのまま乗る

| 観点 | 評価 |
|---|---|
| 法令ベースで答えが一意 | ◎ 租税特別措置法41条。借入残高 × 控除率 × 控除期間の掛け算 |
| 一次資料がある | ◎ 国税庁タックスアンサー・国土交通省「住宅ローン減税」 |
| 制度改正で数字が動く | ◎ 当サイトが毎回追いかけている型（酒税・たばこ税・年収の壁と同じ） |
| 既存ツールとつながる | ◎ **`furusato-nozei` は既に「住宅ローン控除との併用」に対応している**。 |
| | `nenmatsu-chosei`（年末調整 還付金）・`iryohi-kojo`（医療費控除）とも同じ客 |
| 投資助言にあたらない | ◎ 税額計算であって金融商品の推奨ではない。`learn/` の制約（金商法38条2号）とは別 |

### 競合との比較

- 大手（住宅メーカー・銀行・不動産ポータル）は**解説記事が主で、その場で数字が出る計算機は
  自社サービスへの誘導が前提**のものが多い
- 税理士法人のページは正確だが**令和8年度改正後の借入限度額を反映していないものが混在**する
  （2026-09-24 時点で「2025年末まで」と書いたままの記事が検索上位に残っている）
- **当サイトの強み**：登録不要・入力をサーバーに送らない・出典と最終更新日を各ページに出す。
  年収の壁やインボイスで確立した「改正日を軸にした計算機＋早見表」の型をそのまま当てられる

## 実装前に確定させること（一次確認）

**ここが埋まるまでコードを書かない。** 下記はすべて**未確認**で、
上の背景は財務省の大綱概要と国土交通省の資料の見出しレベルまでしか読んでいない。

1. **借入限度額の表**（住宅の区分 × 入居年）。認定住宅 / ZEH水準省エネ住宅 /
   省エネ基準適合住宅 / その他、の 4 区分 × 令和8〜12年分。
   **新築等と既存住宅（中古）で別表**になる
   → 国税庁タックスアンサー No.1211-1 系・国土交通省「住宅ローン減税」の最新版
2. **子育て世帯・若者夫婦世帯への上乗せ措置**：対象の定義（年齢・子の有無）、
   上乗せ後の借入限度額、**令和8年度改正で「対象の拡充」が何を指すか**、
   既存住宅にも及ぶか
3. **控除期間**：新築13年・既存10年が原則。改正で**既存住宅の一部が13年に拡充**された範囲
4. **床面積要件**：40㎡以上への緩和が既存住宅にも及ぶ条件、
   および「合計所得金額1,000万円超」「上乗せ措置利用者」は50㎡以上という例外
5. **省エネ基準適合住宅の扱い**：借入限度額の引下げと、
   令和10年（2028年）以降は原則適用対象外になる旨（これが本当なら**早見表に年で出す**）
6. **控除率 0.7%** が据え置きか
7. **所得要件 2,000万円以下**（床面積40㎡台は1,000万円以下）が据え置きか
8. **住民税からの控除の上限**（課税総所得金額等の5% / 97,500円）が据え置きか
9. **年末調整と確定申告の別**：1年目は確定申告、2年目以降は年末調整という扱いの現状

**出典は国税庁・国土交通省の一次資料に限る。** 税理士法人・住宅メーカーの解説は
確認の取っかかりにはしてよいが、`source` には入れない（既存ツールと同じ約束）。

## ツールの中身（想定）

### 入力

- 入居（予定）年 … 令和8年〜令和12年 ＋ 令和7年以前（過去の人の確認用）
- 住宅の種類 … 新築 / 買取再販 / 既存（中古）
- 省エネ区分 … 認定長期優良・低炭素 / ZEH水準 / 省エネ基準適合 / その他
- 世帯 … 子育て世帯・若者夫婦世帯にあたるか
- 年末の借入残高（または借入額・金利・返済期間から概算）
- 床面積
- 合計所得金額（所得要件と住民税側の上限の判定に要る）
- 源泉徴収税額（実際にいくら戻るかを出すのに要る）

### 出力

1. **適用できるか**の判定（所得要件・床面積要件・入居年）
2. **借入限度額**と、そこで頭打ちになるか
3. **各年の控除額**と控除期間合計（13年 or 10年）
4. **実際に戻る額**＝所得税からの控除 ＋ 住民税からの控除（上限つき）。
   **「控除額＝戻る額」ではない**ことを画面で明示する（ここが誤解の最頻出点）
5. **改正前後の比較**：令和7年以前の入居と令和8年以降で、区分ごとにいくら変わるか
6. **早見表**：入居年 × 住宅区分 × 世帯 の借入限度額
7. **1年目は確定申告・2年目以降は年末調整**という手続きの案内

### やらないこと（ツールとして）

- **借りるべきかどうか・繰上げ返済すべきかの助言**：当サイトは制度の計算に限る
- **金融機関・住宅メーカーの個別商品名**：`learn/` の約束に揃える
- **ふるさと納税の上限額の再計算をこのツールでやる**：
  併用の計算は `furusato-nozei` 側にあるので、**相互リンクで済ませる**（二重管理を作らない）

## 期待される効果

- **検索**：「住宅ローン控除 2026」「住宅ローン控除 いつまで」「住宅ローン減税 中古」等。
  ただし**Google は当サイトを 128 URL 中 1 件しか登録していない**
  （[google-index-recovery.md](./google-index-recovery.md)）ので、
  **短期の流入は Bing と AI アシスタント経由が主**という前提で出す。
  Bing には入っているので、出せば届く経路はある
- **サイト内の回遊**：年末調整・医療費控除・ふるさと納税と同じ客層で、
  11月〜3月の山が重なる。既存の 3 本と相互リンクできる
- **寿命**：5年延長されたので、税制改正のたびの手入れはあっても**URL は長く使える**。
  スラッグに年や「2026」を入れないこと（一度公開した URL は引っ込められない）

## 代案（今回は選ばなかったもの）

- **年金の繰上げ・繰下げ受給 損益分岐点計算機**：需要は大きいが競合が多く、
  `zaishoku-rorei-nenkin` と客層が重なる。住宅ローン控除のほうが
  **法改正フックが新しく（令和8年度改正）**、年末調整の山にも乗る
- **郵便料金・送料の比較**：需要は大きいが、料金は民間事業者の商品名に踏み込みやすく、
  改定のたびの保守が重い
- **エンジニア向けツール群**（Unix時間・JSON整形・Base64 など）：
  当サイトにこのジャンルは1本も無く、伸びしろはある。ただし
  **制度の計算機という当サイトの強み（一次資料・法令根拠）が効かない領域**で、
  差別化が「広告が少ない」だけになる。別途 1 本ずつ検討したい
