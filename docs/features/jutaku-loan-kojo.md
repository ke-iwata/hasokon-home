## 背景と根拠

住宅ローン控除（住宅借入金等特別控除）は、**令和8年度税制改正で適用期限が
令和8年1月1日〜令和12年12月31日入居まで5年延長**され、借入限度額・控除期間・床面積要件が
組み替えられた（所得税法等の一部を改正する法律、**2026年3月31日成立**。国土交通省の報道発表
「住宅ローン減税等の延長・拡充が閣議決定されました」2025-12-26、令和8年4月追記で成立を明記
https://www.mlit.go.jp/report/press/house02_hh_000241.html ）。

改正後の数字は国土交通省「住宅ローン減税（令和8年度税制改正後）Q&A【2026年7月更新】」
https://www.mlit.go.jp/jutakukentiku/house/content/002011976.pdf の Q13〜Q19 にそのまま載っている
（**この提案の数字はすべてこの Q&A から写した**。2026-09-17 に取得して確認）。

## 提案する仕様

### 入力

1. **入居した年**（2026〜2030。改正前の 2022〜2025 入居は初版では扱わない。下記「やらないこと」）
2. **住宅の種類**：新築（注文・分譲）／ 買取再販 ／ 既存（中古）／ 増改築・リフォーム
3. **省エネ性能の区分**：長期優良住宅・低炭素住宅 ／ ZEH水準省エネ住宅 ／ 省エネ基準適合住宅 ／ その他
   （新築で「その他」を選んだら「2024年以降の入居は対象外」を出す。
   「省エネ基準適合住宅の新築」で 2028年以降の入居なら「原則対象外。2027年末までに建築確認を
   受けた住宅または 2028年6月30日までに建築された住宅は 2,000万円・10年」の分岐を出す）
4. **子育て世帯・若者夫婦世帯か**（入居した年の 12月31日時点で **19歳未満の扶養親族がいる**、
   または **夫婦のいずれかが 40歳未満**。Q&A Q93〜Q98）。「わからない」は無し。判定の説明を
   その場に置く
5. **床面積**（㎡。40㎡以上 50㎡未満なら「合計所得 1,000万円以下に限る」「子育て世帯等の上乗せは
   使えない（Q3）」の2つを出し、上乗せの選択を自動で外す）
6. **借入額（当初）・金利（年%）・返済期間（年）・返済方式（元利均等／元金均等）**。
   年末残高の推移を出すために要る。「年末残高を直接入れる」切り替えも置く
   （初年度の残高が分かっている人向け。以後は同じ返済条件で減らす）
7. **年収（額面）**・配偶者の有無・扶養人数・社会保険料（null なら概算。`estimateSocialInsurance()`）。
   ふるさと納税 計算機と同じ入力部品を流用する
8. 任意：**ペアローン・連帯債務の持分**（%）。Q&A に「合計所得金額はそれぞれ1人ずつ判断」とあるので、
   持分をかけた年末残高で本人分だけを計算する

### 計算（租税特別措置法 第41条・第41条の2の2、地方税法附則 第5条の4の2。数字は MLIT Q&A Q13〜Q19）

**借入限度額と控除期間（2026〜2030年入居）**

| 住宅の種類 | 区分 | 一般 | 子育て・若者夫婦 | 期間 |
|---|---|---|---|---|
| 新築・買取再販 | 長期優良・低炭素 | 4,500万円 | 5,000万円 | 13年 |
| 新築・買取再販 | ZEH水準 | 3,500万円 | 4,500万円 | 13年 |
| 新築 | 省エネ基準適合（**2026・2027年入居まで**） | 2,000万円 | 3,000万円 | 13年 |
| 新築 | 省エネ基準適合（2028年以降。建築確認 2027年末まで／2028-06-30 までに建築） | 2,000万円 | ― | 10年 |
| 新築 | その他 | **対象外**（2023年末までに新築された家屋に 2030年末までに入居 → 2,000万円・10年） | | |
| 買取再販 | 省エネ基準適合 | 2,000万円 | 3,000万円 | 13年 |
| 買取再販 | その他 | 2,000万円 | ― | 10年 |
| 既存 | 長期優良・低炭素／ZEH水準 | 3,500万円 | 4,500万円 | 13年 |
| 既存 | 省エネ基準適合 | 2,000万円 | 3,000万円 | 13年 |
| 既存 | その他 | 2,000万円 | ― | 10年 |
| 増改築・リフォーム | ― | 2,000万円 | ― | 10年 |

- **控除率 0.7%**（区分によらず一律。Q11）
- 年ごとの控除額 = min(年末残高, 借入限度額) × 0.7%（**100円未満切捨て**）
- **所得税から引き、引ききれない分は翌年度の住民税から**。住民税側は
  「所得税の課税総所得金額等 × 5%、上限 97,500円」（`housingLoanResidentCap(…, 'rate5')`。
  `HousingLoanTier` の `rate5` は「令和4年1月〜令和12年12月入居」と定義済みなので改正後もそのまま）
- **所得要件**：合計所得金額 2,000万円以下の年だけ適用（Q5。3,000万円→2,000万円は令和4年以降の入居）。
  年収から `salaryIncome()` で出し、超えていれば「この年は適用なし」
- **床面積 40㎡以上 50㎡未満**：合計所得 1,000万円以下の年に限る（Q2〜Q3）。
  子育て世帯等の上乗せは使えない
- **年末残高の推移**：元利均等は毎月返済額 = P × r(1+r)^n / ((1+r)^n − 1)（r = 月利）。
  元金均等は元金を n で割る。各年 12月末の残高を出す。**金利は入力値のまま固定**（変動金利の
  見直しは扱わない。結果の脇に「金利が変わると残高も変わる」を出す）
- 所得税額の概算は `furusato-nozei.ts` の `calcFurusato()` と同じ段取り
  （給与所得 → 所得控除 → 課税所得 → 速算表 → 復興特別所得税 1.021 は**控除前の基準所得税額に
  対して**かかる。`applyHousingLoan()` の JSDoc どおり）。**年収は控除期間中ずっと同じと仮定**して、
  その旨を出す

### 出力

- **13年（10年）の合計控除額**（大きく）と、**年別の表**：年末残高・控除の上限額・所得税から・
  住民税から・**引ききれずに使えない額**（`HousingLoanResult.wasted`）
- 「借入限度額で頭打ち」「所得税＋住民税の上限で頭打ち」のどちらが効いているかを年ごとに色分け
- 子育て世帯等の上乗せが効いている場合、「上乗せなしなら◯◯万円」を併記
  （上乗せの要件が入居年の 12/31 時点で判定されることを注記）
- 早見表：借入 2,000万〜6,000万 × 年収 400万〜1,000万 の 13年合計（新築・長期優良・一般世帯・
  返済期間 35年・金利 1%・独身の前提を表の上に明記。区分を増やして 3 次元にしない）。幅 390px では収まらないので
  **外側を `overflow-x: auto` のラッパーで囲む**（`saitei-chingin` / `furusato-nozei` と同じ形。
  新しい CSS クラスは増やさない）

### 解説（ページ下部）

- 令和8年度改正で何が変わったか（5年延長・既存住宅の限度額引上げと 13年化・40㎡緩和の既存住宅への
  拡大・2028年以降の省エネ基準適合新築の除外・令和10年以降の災害レッドゾーン除外）。
  **「その他の住宅」の新築が 2024年から対象外**という、いちばん引っかかる点を最初に
- 子育て世帯・若者夫婦世帯の定義（19歳未満の扶養親族／夫婦のいずれか 40歳未満、入居年の 12/31 時点）
- 初年度は確定申告、2年目以降は年末調整（会社員）。入居翌年の 2〜3月の申告期限
- ふるさと納税との併用（引ききれなくなる仕組み。ふるさと納税 計算機へリンク）
- 住民税の控除上限 97,500円の意味（所得税が少ない人ほど「使えない額」が出る）
- 免責：概算であること。省エネ性能の区分は証明書（建設住宅性能評価書・住宅省エネルギー性能証明書）で
  決まること（Q20〜）。個別の税務は税理士・税務署へ

### テストで固定すること

- 限度額の表：新築 長期優良 4,500万／子育て 5,000万、既存 長期優良 3,500万／4,500万、
  既存 その他 2,000万・10年、省エネ基準適合の新築が 2027年入居まで 2,000万・13年で
  2028年入居は対象外、リフォーム 2,000万・10年。**Q&A の該当 Q 番号をテスト名に入れる**
- 40㎡以上 50㎡未満で上乗せが外れること、合計所得 1,000万円超で適用なしになること
- 合計所得 2,000万円超の年は控除 0
- 100円未満切捨て、残高が限度額を下回った年から残高ベースになること
- 元利均等の残高推移（借入 3,000万・金利 1%・35年 → 毎月 84,686円、初年度末残高 29,280,480円。
  起票時に式で検算した値。1円単位の丸めは実装の約束に合わせて許容差を持たせる）と
  元金均等の残高が毎年同額ずつ減ること
- `applyHousingLoan()` との結合：所得税額が控除額より小さいとき住民税へ回り、
  97,500円で頭打ちになること（**MLIT Q&A の例「年末残高 4,000万円・借入限度額 3,000万円・
  居住用割合 50% → 3,000万円 × 50% × 0.7% = 10.5万円」を再現**）
- ペアローン持分 50% で残高が半分になること

## やらないこと

- **改正前（2022〜2025年入居）の計算。** 入居年でその年の表に切り替える形は簡単だが、
  改正前の表（新築 5,000/4,500/4,000/3,000万円、既存 3,000/2,000万円）は国税庁 No.1211-1 に
  あるので、初版は 2026年以降に絞って表を 1 つにする。需要があれば次版で `YEAR_TABLES` を足す
- **変動金利の見直し・繰上げ返済のシミュレーション。** 残高推移は入力金利で固定する。
  返済額そのもののシミュレーションは銀行のサイトが強く、当サイトの差別化点（控除の頭打ち）ではない
- **災害レッドゾーン（令和10年以降入居）の判定。** 所在地の入力が要り、判定に自治体データが必要。
  解説で触れるだけにする
- **住宅取得等資金の贈与税非課税（1,000万円／500万円）。** 別の税目。解説の関連情報に 1 行置く
- **個別の省エネ区分の判定。** 証明書で決まるものを推測しない（Q20〜 を案内する）
