## 背景と根拠

### 令和8年度税制改正で、住宅ローン控除の適用期限が 5 年延びた

財務省「[令和8年度税制改正の大綱の概要](https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_gaiyou.htm)」に
「**適用期限を５年延長する**」「既存住宅のうち省エネ性能の高い認定住宅・ＺＥＨ水準省エネ住宅に係る
**借入限度額の引上げ**」「**子育て世帯への上乗せ措置の対象の拡充**」「**床面積要件の緩和**等の
見直しを行った上で」とある。改正法は
**所得税法等の一部を改正する法律（令和8年法律第12号）**（インボイスの 3 割特例と同じ改正法。
`tools/lib/invoice-nozeigaku.ts` に `LAW_R8_KAISEI` として既にある）。

つまり**令和12年（2030年）12月31日までに入居した人まで対象**になった。
これまで「2025年末で終わる」前提で書かれた記事が大量にあり、
**「2026年 住宅ローン控除 いつまで」という検索が発生する条件が揃っている**。

### 当サイトの型にそのまま乗る

| 観点 | 評価 |
|---|---|
| 法令ベースで答えが一意 | ◎ 租税特別措置法41条。借入残高 × 控除率 × 控除期間の掛け算 |
| 一次資料がある | ◎ 国税庁タックスアンサー・国土交通省「住宅ローン減税」 |
| 制度改正で数字が動く | ◎ 当サイトが毎回追いかけている型（酒税・たばこ税・年収の壁と同じ） |
| 既存ツールとつながる | ◎ **`furusato-nozei` は既に「住宅ローン控除との併用」に対応している**。 |
| | `nenmatsu-chosei`（年末調整 還付金）・`iryohi-kojo`（医療費控除）とも同じ客 |
| 投資助言にあたらない | ◎ 税額計算であって金融商品の推奨ではない。`learn/` の制約（金商法38条2号）とは別 |

### 競合との比較

- 大手（住宅メーカー・銀行・不動産ポータル）は**解説記事が主で、その場で数字が出る計算機は
  自社サービスへの誘導が前提**のものが多い
- 税理士法人のページは正確だが**令和8年度改正後の借入限度額を反映していないものが混在**する
  （2026-09-24 時点で「2025年末まで」と書いたままの記事が検索上位に残っている）
- **当サイトの強み**：登録不要・入力をサーバーに送らない・出典と最終更新日を各ページに出す。
  年収の壁やインボイスで確立した「改正日を軸にした計算機＋早見表」の型をそのまま当てられる

### 0. 適用期限の5年延長そのもの（最優先だった項目）— **確定**

3つの一次資料が一致した。**設計判断（スラッグに年を入れない）の根拠は崩れていない。**

- 財務省 大綱概要：「住宅ローン控除の拡充 … **適用期限を５年延長する**」
- 国土交通省：「**適用期限を５年間延長（入居日が令和８年１月１日から令和12年12月31日まで）**」
- 国税庁 No.1211-1 ほか：「**令和4年1月1日から令和12年12月31日までの間に自己の居住の用に供したとき**」

**リポジトリ側との照合**：`tools/lib/furusato-nozei.ts` の `HousingLoanTier.rate5` が
「令和4年1月〜令和12年12月入居」と書いているのと一致した。食い違いは無かった。

### 1. 借入限度額（令和8年〜令和12年入居）— **確定**

原典は「各年の控除額の計算（控除限度額）」として**年あたりの控除限度額**を載せている。
下表の借入限度額は、それを控除率0.7%で割り戻したもの（例：31.5万円 ÷ 0.007 ＝ 4,500万円）。
カッコ内は特例対象個人（子育て世帯・若者夫婦世帯）の上乗せ後。

**新築等**（No.1211-1）

| 省エネ区分 | 令和8・9年 | 令和10〜12年 | 控除期間 |
|---|---|---|---|
| 認定長期優良・低炭素 | 4,500万円（5,000万円） | 同左 | 13年 |
| ZEH水準省エネ | 3,500万円（4,500万円） | 同左 | 13年 |
| 省エネ基準適合 | 2,000万円（3,000万円） | **対象外** | 13年 |
| その他の住宅 | **対象外** | **対象外** | — |

**買取再販住宅**（No.1211-2）

| 省エネ区分 | 令和8〜12年 | 控除期間 |
|---|---|---|
| 認定長期優良・低炭素 | 4,500万円（5,000万円） | 13年 |
| ZEH水準省エネ | 3,500万円（4,500万円） | 13年 |
| 省エネ基準適合 | 2,000万円（3,000万円） | 13年 |
| その他の住宅 | 2,000万円（上乗せなし） | 10年 |

**経過措置（建築確認の時期による）**。いずれも借入限度額2,000万円・控除期間10年で、
**上乗せの記載は原典に無い**（＝上乗せなしとして実装した）。

- 新築の省エネ基準適合住宅：令和9年12月31日までに建築確認、または令和10年6月30日までに建築（注2）
- 新築のその他の住宅：令和5年12月31日までに建築確認、または令和6年6月30日までに建築（注1）

### 2. 子育て世帯・若者夫婦世帯への上乗せ — **確定**

**定義（国税庁のいう「特例対象個人」）**：個人で、①年齢40歳未満で配偶者がいる者
②年齢40歳以上で年齢40歳未満の配偶者がいる者 ③年齢19歳未満の扶養親族がいる者。
判定は**居住年の12月31日**の現状による。

**「対象の拡充」が指すもの**：改正前は上乗せの対象年が令和6年・令和7年に限られ、
新築・買取再販だけだった。改正後は**令和8〜12年に延び、既存住宅にも及ぶ**ようになった。

**効かない場合**：「**令和8年1月1日以降に特例認定住宅等に居住した場合、
特例対象個人への借入限度額上乗せ措置を適用できません**」（No.1211-1 の注）。
特例認定住宅等＝床面積40㎡以上50㎡未満の認定住宅等。国土交通省の
「子育て世帯等への上乗せ措置利用者は50㎡以上」と同じことを言っている。

### 3. 控除期間 — **確定**

新築・買取再販の認定住宅等は13年。**既存住宅の認定住宅等は令和8年入居から10年→13年に拡充**
（改正前は一律10年）。既存・買取再販の「その他の住宅」は10年。

### 4. 床面積要件 — **確定**

原則50㎡以上。国土交通省「**床面積要件を新築住宅・既存住宅ともに40㎡以上に緩和
（合計所得金額1,000万円超の者、子育て世帯等への上乗せ措置利用者は50㎡以上）**」。
国税庁側では「小規模居住用家屋（40㎡以上50㎡未満）」の扱いとして、
40〜50㎡は**合計所得金額1,000万円以下**が条件（No.1211-1 適用要件3(2)）。
床面積は登記事項証明書の表示で判断し、マンションは専有部分で見る。

### 5. 省エネ基準適合住宅の扱い — **確定**

**新築は令和10年入居から対象外**（No.1211-1 の表で控除期間0年）。
国土交通省も「建築確認が令和10年以降の省エネ基準適合住宅は適用対象外
（登記簿上の建築日が令和10年６月30日までは適用対象）」と書いている。
経過措置は上記1のとおり。**買取再販・既存住宅の省エネ基準適合住宅は令和12年入居まで対象**。

### 6. 控除率 0.7% — **据え置き（確定）**

3本のタックスアンサーいずれも「年末残高等×0.7％」。100円未満の端数は切り捨て。

### 7. 所得要件 2,000万円以下 — **据え置き（確定）**

床面積40〜50㎡は1,000万円以下（上記4）。**その年だけ受けられなくなるもの**で、
控除そのものが打ち切られるわけではない。

### 8. 住民税からの控除の上限 — **既存の定数と一致（確定）**

課税総所得金額等 × 5%・上限97,500円。`tools/lib/furusato-nozei.ts` の
`HousingLoanTier.rate5` / `housingLoanResidentCap()` と**食い違わなかった**ので、
`furusato-nozei` と `nenmatsu-chosei` に手を入れる必要は無い。
新ツールも同じ関数を import する（二重管理を作らない）。

### 9. 年末調整と確定申告の別 — **確定**

控除を受ける最初の年は確定申告。給与所得者は**2年目以降は年末調整**で受けられる
（税務署から届く「年末調整のための住宅借入金等特別控除証明書兼給与所得者の
住宅借入金等特別控除申告書」と年末残高等証明書を勤務先に提出）。

### 10. 仕様書に無かったが確認できた要件：災害レッドゾーン

国土交通省「**入居日が令和10年以降の場合、土砂災害等の災害レッドゾーンの新築住宅は
適用対象外（建替え・既存住宅・リフォームは適用対象）**」。国税庁も用語として
「災害レッドゾーン」（土砂災害特別警戒区域・地すべり防止区域・急傾斜地崩壊危険区域・
浸水被害防止区域・災害危険区域）と「特定建替え」を定義している。**判定に入れた。**

## 初版の範囲：令和8年〜12年入居に絞る

入力に「令和7年以前（過去の人の確認用）」を置くと、**限度額テーブルが令和4年改正分まで遡り、
「実装前に確定させること」の 1〜3 が過去年分にも増える**（工数 275k はその前提では足りない）。

**初版は令和8年〜令和12年入居に絞り、令和7年以前を選んだら「このツールの対象外」と表示する。**
改正の直後で「2026年からどうなるか」を知りたい人が主なので、過去年は後追いで足せる。

**実装では、改正前後の比較（下記の出力5）のためだけに令和7年入居の限度額を
`LIMITS_R7` として持っている。** これは上の確認結果と同じタックスアンサーの
「令和6年・令和7年」「令和4年から令和7年」の行を写したもので、推測ではない。
`calculate()` からは参照せず、令和7年以前を入れると `out-of-range` を返す
（＝計算の対象は広げていない）。
抱えることにした場合は、一次確認の項目 1〜3 に「令和4〜7年入居分の限度額・控除期間」を
明記して工数を積み増すこと。

## ツールの中身（想定）

### 入力

- 入居（予定）年 … **令和8年〜令和12年のみ**（初版の範囲。下記）
- 住宅の種類 … 新築 / 買取再販 / 既存（中古）
- 省エネ区分 … 認定長期優良・低炭素 / ZEH水準 / 省エネ基準適合 / その他
- 世帯 … 子育て世帯・若者夫婦世帯にあたるか
- 年末の借入残高 … **初版は直接入力のみ**。借入額・金利・返済期間からの概算
  （元利均等返済の残高計算）は検証対象が増えるので後追いで足す
- 床面積
- 合計所得金額（所得要件と住民税側の上限の判定に要る）
- 源泉徴収税額（実際にいくら戻るかを出すのに要る）

### 出力

1. **適用できるか**の判定（所得要件・床面積要件・入居年）
2. **借入限度額**と、そこで頭打ちになるか
3. **各年の控除額**と控除期間合計（13年 or 10年）
4. **実際に戻る額**＝所得税からの控除 ＋ 住民税からの控除（上限つき）。
   **「控除額＝戻る額」ではない**ことを画面で明示する（ここが誤解の最頻出点）
5. **改正前後の比較**：令和7年以前の入居と令和8年以降で、区分ごとにいくら変わるか
6. **早見表**：入居年 × 住宅区分 × 世帯 の借入限度額。
   **3軸なので素直に組むとスマホで横スクロールが出る。**
   既存の `shuzei-kaisei`・`nenshu-kabe` の早見表と同じ見せかた
   （[mobile-one-screen.md](./mobile-one-screen.md) の方針）に揃えること
7. **1年目は確定申告・2年目以降は年末調整**という手続きの案内

### やらないこと（ツールとして）

- **借りるべきかどうか・繰上げ返済すべきかの助言**：当サイトは制度の計算に限る
- **金融機関・住宅メーカーの個別商品名**：`learn/` の約束に揃える
- **ふるさと納税の上限額の再計算をこのツールでやる**：
  併用の計算は `furusato-nozei` 側にあるので、**相互リンクで済ませる**（二重管理を作らない）
- **住民税側の控除限度額と「所得税→住民税」の適用順を新規に書く**：
  すでに `tools/lib/furusato-nozei.ts` にある（`applyHousingLoan` `:311` /
  `housingLoanResidentCap` `:292` / `HousingLoanTier` `:263` / `HousingLoanResult` `:270`）。
  `tools/lib/nenmatsu-chosei.ts:96-105` が `@/lib/furusato-nozei` から import しているのが
  このリポジトリの作法なので、**同じように import する**。
  新規に書くと、改正で動く数字（税率と上限額）が3ファイルに散る
- **ツール固有の免責文を新設する**：`tools/app/ToolMeta.tsx` に共通の文言があり
  （「計算結果は…目安です。…本サイトは特定の個人に向けた税務・法律の助言を行うものではありません」）、
  **税理士法まわりはこれで足りている**。端数処理・考慮していない要素のような
  **このツール固有の但し書きが要るなら FAQ 側に置く**（`invoice-nozeigaku` と同じ切り分け）
- **初版で令和7年以前の入居に対応する**：下記「初版の範囲」のとおり

- **サイト内の回遊**：年末調整・医療費控除・ふるさと納税と同じ客層で、
  11月〜3月の山が重なる。既存の 3 本と相互リンクできる
- **寿命**：5年延長されたので、税制改正のたびの手入れはあっても**URL は長く使える**。
  スラッグに年や「2026」を入れないこと（一度公開した URL は引っ込められない）

## 代案（今回は選ばなかったもの）

- **年金の繰上げ・繰下げ受給 損益分岐点計算機**：需要は大きいが競合が多く、
  `zaishoku-rorei-nenkin` と客層が重なる。住宅ローン控除のほうが
  **法改正フックが新しく（令和8年度改正）**、年末調整の山にも乗る
- **郵便料金・送料の比較**：需要は大きいが、料金は民間事業者の商品名に踏み込みやすく、
  改定のたびの保守が重い
- **エンジニア向けツール群**（Unix時間・JSON整形・Base64 など）：
  当サイトにこのジャンルは1本も無く、伸びしろはある。ただし
  **制度の計算機という当サイトの強み（一次資料・法令根拠）が効かない領域**で、
  差別化が「広告が少ない」だけになる。別途 1 本ずつ検討したい
