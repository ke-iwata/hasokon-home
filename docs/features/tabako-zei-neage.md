# 新ツール「たばこ値上げ早見表・負担額計算」（2026年10月・2027年4月からの段階増税対応）

**状態**：実装済み（2026-08-15。本番反映はタグリリース待ち）
**対象**：`tools/`（`hasokon.com/tools/tabako-zei-neage/`）
**起票**：2026-08-15

---

## 背景と根拠

### 増税スケジュールが確定しており、検索需要の発生時期が読める

防衛財源確保のための税制措置（令和7年度税制改正で決定）により、
たばこ税は次のスケジュールで段階的に上がることが確定している。

| 時期 | 内容 |
|---|---|
| 2026年10月1日 | 加熱式たばこの課税見直し第2弾（紙巻との税負担差の解消） |
| 2027年4月1日 | 紙巻・加熱式とも国たばこ税 +0.5円/本（1箱20本で+10円） |
| 2028年4月1日 | 同上（+0.5円/本） |
| 2029年4月1日 | 同上（+0.5円/本） |

「たばこ 値上げ いつ」「たばこ 値上げ いくら」は増税・価格改定の
発表のたびに跳ねる消費者検索の定番で、**2026年10月と毎年4月に
需要が再発する持続型テーマ**。最低賃金チェッカー
（[saitei-chingin-checker.md](./saitei-chingin-checker.md)）と同じ
「施行日が確定している制度改定を早見表で先回りする」型にあたる。

### 既存ツールとの相性

「働き損」「年収の壁」「年末調整」など家計負担系のクラスタに
「嗜好品の負担」の面を足せる。禁煙による節約額の提示は
健康系（睡眠サイクル計算）への回遊導線にもなる。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **値上げ早見表**
   - 紙巻・加熱式の別に、2026年10月 → 2029年4月までの
     税額・想定小売価格の推移を表で表示（代表価格帯 500〜650円で例示）
   - 「自分の銘柄の今の価格」を入力すると、各時点の想定価格を再計算
2. **負担額計算**
   - 1日の本数 × 銘柄価格 → 月間・年間の支出と、増税後の増加分
   - **禁煙したら浮く額**（1年・5年・10年）を大きく表示。
     禁煙外来などへの誘導はしない（医療的助言をしない）
3. **データの持ち方**
   - 税率・施行日は `lib/tabako-zei.ts` に**【データ更新箇所】**コメント付きの
     静的テーブルで持つ。実装時に財務省・国税庁の一次資料
     （たばこ税等の税率表・改正法条文）で数値を確定させること。
     小売価格は各社の届出制（財務省認可）のため「想定」であることを明記
4. **FAQ**：「なぜ上がる？（防衛財源確保の税制措置）」「加熱式はどうなる？」
   「小売価格はいつ決まる？（メーカー届出・財務省認可後）」など
5. **SEO**：WebApplication + FAQPage + BreadcrumbList の jsonLd。
   `llms.txt`・sitemap・home の一覧・registry への追加も実装PRで行う

### やらないこと

- 銘柄別の価格データベース（数百銘柄の維持は無理。代表価格帯＋自分で入力）
- 健康影響の記述・禁煙の推奨（事実としての節約額の提示に留める）
- 地方たばこ税の市区町村別内訳（税額合計のみ扱う）

## 期待される効果

- 「たばこ 値上げ」系の検索は改定のたびに大きく跳ね、
  2026年10月・2027年4月の2回のピークを先回りできる
- 早見表型は saitei-chingin で実績のある型で、
  施行日前後に「〇年〇月から」のクエリを面で取れる
- 増税は2029年まで毎年続くため、一度作れば毎年4月に需要が再発し、
  年1回のデータ更新だけで維持できる
