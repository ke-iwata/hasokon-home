## 提案する仕様

### 1. 「決定」の段階をデータに持たせる（`tools/lib/saitei-chingin.ts`）

- `Answered` に `decidedOn?: string`（労働局長の決定・公示日）を足す。
  **`decidedOn` を持つ県の `effectiveOn` は必須**（決定公示は必ず発効日を含むため）。
  型で強制できないので、テストで「`decidedOn` があれば `effectiveOn` もある」を落とす
- `RevisionStatus` に `'決定'` を足す：`'目安' | '答申' | '決定' | '発効済み'`。
  `revisionOf()` は `decidedOn` があり発効日前なら `'決定'`、発効日以後は `'発効済み'`
- **11県の `effectiveOn` は、労働局の決定公示を確認できた県から順に入れる**
  （出典 `source` も決定公示のページへ差し替える）。実装日に未決定の県が残る場合は、
  別紙の「発効日（予定）」を `plannedEffectiveOn?: string` として入れ、UIでは
  「10月3日 発効予定（答申）」と**予定である旨を添えて**出す。`plannedEffectiveOn` だけでは
  `'発効済み'` に切り替えない（推測で埋めない約束は保つ。異議申出で動く余地があるため）
- `NATIONAL_AVERAGE` に `answered: 1177` を足し、リード文の「見込み 1,176円」を
  「答申ベース 1,177円（+56円）」に変える（出典：別紙）
- `DATA_CHECKED_AT` を実装日に更新（数値が変わらなくても更新する既存の約束）

### 2. 切れた出典 3件を差し替える

| 県 | いま（404） | 差し替え先（2026-09-16 に 200 を確認） |
|---|---|---|
| 広島 | `…/hiroshima-roudoukyoku/content/contents/002778056.pdf` | https://jsite.mhlw.go.jp/hiroshima-roudoukyoku/news_topics/houdou_newpage_00512.html |
| 徳島 | `…/tokushima-roudoukyoku/content/contents/002787799.pdf` | https://jsite.mhlw.go.jp/tokushima-roudoukyoku/newpage_02189.html |
| 山梨 | `…/yamanashi-roudoukyoku/content/contents/002362423.pdf` | https://jsite.mhlw.go.jp/yamanashi-roudoukyoku/news_topics/houdou/houdouR080828.html |

労働局の PDF は差し替えで URL が変わりやすいので、**PDF 直リンクではなく報道発表の
HTML ページを出典にする**方針にそろえる（他の県も次回のメンテで順次 HTML へ寄せる）。

### 3. 出典URLの生存確認を手元で回せるようにする（`tools/scripts/check-sources.mjs`、任意）

- `PREFECTURES` の `source.url` を全件 HEAD/GET して 200 以外を一覧する小さなスクリプト。
  CI には入れない（外部サイトへの依存で CI が落ちるのは避ける）。年1回の改定作業の前に手で回す

### 4. UI（`tools/app/saitei-chingin/`）

- 状態バッジに「決定」を足す（色は答申と発効済みの中間）
- 「発効予定」の県には「予定日は労働局の公示で変わることがあります」の1行を出す
- 解説の「改定の流れ」に「答申 → 異議申出（15日）→ 決定・公示 → 発効」を1段足す
  （最低賃金法 第11条・第12条を根拠として示す）

### テスト（`tools/tests/saitei-chingin.test.ts`）

- 「発効日が示されていない県は…『答申』のまま」のテストは、**対象県を「決定公示が
  まだ確認できていない県」の一覧に置き換える**（実装日に残った県だけ）。11県全部が
  決定済みなら、このテストは削除してよい
- `decidedOn` があれば `effectiveOn` がある／`effectiveOn > decidedOn > answeredOn`
- 東京：`revisionOf(東京, 2026-09-20)` が `'決定'`、`2026-10-01` が `'発効済み'`
- `NATIONAL_AVERAGE.answered === 1177`
- 差し替えた 3 URL が `https://jsite.mhlw.go.jp/` 配下で `.pdf` で終わらない

## やらないこと

- **別紙の「発効日（予定）」をそのまま `effectiveOn` に入れて `'発効済み'` に切り替える。**
  異議申出で変わりうる日付で「発効済み」と断定しない（既存の「推測で埋めない」の約束）
- **二次情報（集計記事）を出典にする。** 労働局・厚労省の一次情報のみ
- **令和7年度の表を消す。** 発効日が県ごとにばらけるので、10〜12月は「現行」と「改定後」の
  両方が要る。全県発効後（2026-12-02 以降）に翌年度の型へ戻すのは別作業
- **出典の生存確認を CI に入れる。** 外部サイト都合で落ちるのを避ける
