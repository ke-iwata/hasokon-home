## 提案する仕様

### 1. 11県の発効日を決定公示から入れ、未決定の県は「予定」として持つ（`tools/lib/saitei-chingin.ts`）

**今回は `'決定'` という状態を入れない（データ中心の変更に絞る）。** 理由：11県だけに
`decidedOn` を持たせて「決定」バッジを出すと、08-27 に決定公示が出ている神奈川が「答申」・
東京が「決定」と並び、利用者には「神奈川はまだ決まっていない」と読める。36県ぶんの確認を
足すと工数が倍になるうえ、10月中に大半の県が「発効済み」に切り替わるので「決定」が見える
期間は短い。いちばん見られている YMYL ページでロジックと UI を同時に触るリスクも避ける。
「決定」の段階を見せるかは、10/1 以降に別提案として起票する。

- **11県の `effectiveOn` は、労働局の決定公示を確認できた県から入れる**（出典 `source` も
  決定公示のページへ差し替える。東京は 09-01 の公示ページで「効力発生日は令和8年10月1日」を
  確認済み）。決定公示の日付は既存の `RevisionStatus`（`'答申'` → `'発効済み'`）の切り替えに
  そのまま使える
- **実装日に決定公示を確認できない県**は、厚労省 別紙の「発効日（予定）」を
  `plannedEffectiveOn?: string` として入れる。`revisionOf()` は `plannedEffectiveOn` だけでは
  `'発効済み'` に切り替えない（推測で埋めない約束は保つ。別紙の注記どおり、異議申出で動く余地があるため）
- **`plannedEffectiveOn` の予定日を過ぎても決定公示を確認できていないとき**（例：宮崎が未決定のまま
  10/24 を過ぎる）は、日付を出さず「予定日を過ぎています。労働局の公示をご確認ください」に
  切り替える。`revisionOf()` の戻り値に `plannedEffectiveOn` と `plannedDatePassed: boolean` を足し、
  UI はそれで分岐する（予定日を過ぎた表示が 10/30 にも出続けるのを防ぐ）
- `Answered.effectiveOn` のコメントに「決定公示で確認した日付だけを入れる。予定は
  `plannedEffectiveOn`」と書き足す
- `NATIONAL_AVERAGE` に `answered: 1177` を足し、リード文の「見込み 1,176円」を
  「答申ベース 1,177円（+56円）」に変える（出典：別紙）
- `DATA_CHECKED_AT` を実装日に更新（数値が変わらなくても更新する既存の約束）

労働局の PDF は差し替えで URL が変わりやすいので、**PDF 直リンクではなく報道発表の
HTML ページを出典にする**方針にそろえる（他の県も次回のメンテで順次 HTML へ寄せる）。

### 3. 出典URLの生存確認を手元で回せるようにする（`tools/scripts/check-sources.mjs`、任意）

- `PREFECTURES` の `source.url` を全件 HEAD/GET して 200 以外を一覧する小さなスクリプト。
  CI には入れない（外部サイトへの依存で CI が落ちるのは避ける）。年1回の改定作業の前に手で回す

### 4. UI（`tools/app/saitei-chingin/Calculator.tsx`）

- **新しい色や CSS クラスを足さない**（tools/CLAUDE.md「新しいCSSクラスを増やさない」）。
  状態の区別は既存の `.chip` と `STATUS_NOTE` の文言だけで行う
- `STATUS_NOTE.答申`（現在「異議申出の手続を経て正式に決定されます」）は、決定公示が済んだ県にも
  同じ文言が出るため古くなる。**「労働局の決定・公示を経て、発効日から効力が生じます」のように
  段階を断定しない文言に直す**
- `plannedEffectiveOn` を持つ県は「10月3日 発効予定」＋「予定日は労働局の公示で変わることがあります」、
  `plannedDatePassed` なら「予定日を過ぎています。労働局の公示をご確認ください」（日付は出さない）
- 解説の「改定の流れ」を「審議会の答申（第10条）→ 意見の要旨の公示・15日以内の異議申出（第11条）
  → 改正の決定（第12条・第10条の例による）→ 決定の公示・公示の日から30日経過した日または
  別に定めた日に効力発生（第14条）」の4段にする。**条番号は 2026-09-16 に e-Gov 法令検索の
  最低賃金法（昭和34年法律第137号）で確認済み**：異議申出（公示の日から15日以内）と異議に
  ついての審議会への意見聴取はどちらも第11条（第2項・第3項）、第12条は改正・廃止の決定、
  第14条第2項が公示から30日の効力発生。東京の 09-01 公示 → 10-01 発効はこの30日と符合する。
  ページ本文に出す前に実装者ももう一度 e-Gov で条文を確認すること（YMYL ページなので
  条番号の誤りは避ける）

### テスト（`tools/tests/saitei-chingin.test.ts`）

- 「発効日が示されていない県は…『答申』のまま」のテストは、**現在 8県（群馬・新潟・富山・岐阜・
  和歌山・香川・宮崎・鹿児島）で、千葉・東京・大阪が入っていない**（11県との差を把握したうえで
  書き換える）。対象を「実装日に決定公示を確認できなかった県」に置き換え、11県全部が決定済みなら
  このテストは削除してよい
- `plannedEffectiveOn` を持つ県は `effectiveOn` を持たない（両方持つ状態を作らない）
- 予定日前：`revisionOf(宮崎, 2026-10-20)` は `'答申'` で `plannedDatePassed === false`。
  予定日後：`revisionOf(宮崎, 2026-10-30)` は `'答申'` のままで `plannedDatePassed === true`
  （実装日に宮崎が決定済みなら、テスト用の仮データで固定する）
- 東京：`revisionOf(東京, 2026-09-30)` が `'答申'`、`2026-10-01` が `'発効済み'`
- `NATIONAL_AVERAGE.answered === 1177`
- 差し替えた 3 URL が `https://jsite.mhlw.go.jp/` 配下で `.pdf` で終わらない

## やらないこと

- **別紙の「発効日（予定）」をそのまま `effectiveOn` に入れて `'発効済み'` に切り替える。**
  異議申出で変わりうる日付で「発効済み」と断定しない（既存の「推測で埋めない」の約束）
- **今回 `'決定'` の状態・`decidedOn` を入れる。** 11県だけに入れると残り36県が「まだ答申段階」に
  見える。47県ぶんの確認は 10/1 に間に合わせる本 PR の範囲を超えるので、別提案にする
- **二次情報（集計記事）を出典にする。** 労働局・厚労省の一次情報のみ
- **令和7年度の表を消す。** 発効日が県ごとにばらけるので、10〜12月は「現行」と「改定後」の
  両方が要る。全県発効後（2026-12-02 以降）に翌年度の型へ戻すのは別作業
- **出典の生存確認を CI に入れる。** 外部サイト都合で落ちるのを避ける
