# 新ゲーム「四川省（二角取り）」（麻雀牌ペアマッチ・牌アセット再利用の1本）

**状態**：提案（2026-08-20起票、未実装）
**対象**：`games/`（`hasokon.com/games/shisensho/` を想定）
**起票**：2026-08-20

---

## 背景と根拠

### 日本のブラウザゲームで最古参級の定番なのに、サイトにまだない

- 「四川省」「二角取り」は日本の無料ブラウザゲームポータルの**看板常設ジャンル**。
  ダンボール・SDIN・ゲームのつぼ・無料ゲームnet 等、主要ポータルのほぼすべてが
  置いており、「四川省 無料」「二角取り」は年間を通じて安定した検索がある
  恒常クエリ（2026-08-20 のトレンド調査で確認。アプリ紹介媒体でも
  2026年版の特集が組まれ続けている）
- 当サイトには**麻雀ソリティア（上海型）が既にあり、牌のアセット・タップ操作の
  UIをそのまま再利用できる**。四川省は上海と客層が重なる（麻雀牌×パズル）ので、
  相互の「他のゲーム」導線で回遊が見込める
- 2026年のカジュアルゲーム市場ではタイル系マッチが主力サブジャンルの一角で、
  牌を消すパズルへの需要は衰えていない（スパイスマート調査 2026）

### 権利関係は無害

- ルーツは麻雀牌を使った伝統的なペアマッチパズルで、**ルールに権利者はいない**
  （クロンダイク・上海型ソリティアと同じ整理）。「四川省」「二角取り」は
  ジャンルの一般名称として無数の実装に使われている
- 麻雀牌の絵柄はパブリックドメイン。当サイトの麻雀ソリティアで描いた
  牌をそのまま使う
- 慣例どおり、実装時に J-PlatPat で「四川省」「二角取り」の商標登録を確認し、
  ゲーム区分での登録があれば一般記述的な別名（「麻雀牌の二角取りパズル」等）に
  切り替える（スネーク・ナンプレで踏んだ手順と同じ）

## 提案する仕様

1. **ルール（ジャンル標準）**
   - 盤面に麻雀牌を格子状に並べる（1層のみ。上海と違い重なりなし）
   - **同じ絵柄の2枚**を選ぶと、2枚を結ぶ経路が**盤外を含めて直線3本以内
     （曲がり角2回以内）**で、途中に他の牌がなければ取れる
   - 全部取れればクリア。取れるペアが無くなったら手詰まり
2. **盤面サイズと難易度**
   - 3段階（例：小 10×6 / 中 12×7 / 標準 14×8。スマホ縦画面では牌を
     大きめにした小盤面を既定にする）
   - **シャッフルは「必ず解ける」保証つき**（クリア状態から逆順に置いていく
     生成、または生成後にソルバーで可解性を検証してリトライ）。
     乱数は注入できる形にしてテスト可能にする（games の作法どおり）
   - 手詰まり時は「シャッフル」（残り牌を可解に並べ直す・回数無制限だが
     成績に記録）と「もどす」を置く
3. **操作**：タップ2回（1枚目 → 2枚目）だけ。取れたときは**経路の線を一瞬描いて
   消す**（二角取りの気持ちよさの核。なぜ取れたかが見える）。
   取れないペアをタップしたときは牌を振動させて理由を邪魔しない程度に示す
4. **ヒント**：取れるペアを1組ハイライトする「ヒント」ボタン（使用回数を成績に記録）
5. **成績**：`_records` でクリア回数・最短時間・ヒント/シャッフル使用数を難易度別に保存
6. **画面**：`games/CLAUDE.md` の「1画面に収める」約束に従う。
   牌は麻雀ソリティアのSVG描画を共通化して使う
7. **ページ構成**：既存ゲームページと同じ
   （metadata / `robots: robotsFor('shisensho')` / JSON-LD(VideoGame+FAQPage+
   BreadcrumbList) / パンくず / 遊び方 / コツ / 「二角取りとは」の由来解説 /
   FAQ / AdUnit×2 / 他のゲーム一覧）。registry へは `stage: 'preview'` で追加
8. **テスト**：経路探索（0曲がり・1曲がり・2曲がり・盤外経由・遮蔽あり）、
   可解性保証、手詰まり検出、シャッフルの可解性を純関数
   （`games/lib/shisensho.ts`）の単体テストで固定

## やらないこと

- **多層の盤面**（それは上海＝既存の麻雀ソリティア。四川省は1層が標準）
- **制限時間モード**（初版では入れない。落ち着いて遊べるのがブラウザ版の需要）
- **特定アプリ・ポータルの見た目の再現**（牌の並べ方・配色は自前）

## 期待される効果

- 「四川省 無料」「四川省 ブラウザ」「二角取り 無料」等の恒常クエリの受け皿。
  ポータル系が強い領域だが、**スマホで遊びやすい実装**（タップ操作・1画面・
  牌の大きさ）と経路表示の丁寧さで差別化できる
- 麻雀ソリティア・花札こいこいと客層が重なり、ゲーム間回遊と再訪の積み増し
- 効果は GSC の表示（`games/shisensho/`）と GA4 の滞在時間・再訪で計測
