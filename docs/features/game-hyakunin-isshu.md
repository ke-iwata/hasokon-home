## 提案する仕様

### 遊び方は3つ（タブ）

| タブ | 中身 | 1回の長さ |
|---|---|---|
| **決まり字れんしゅう**（既定） | 上の句が1文字ずつ現れる。並んだ取り札（既定 8 枚）から**その歌の下の句の札**をタップ。決まり字が出そろう前・出た直後・遅れて、の3段で評価 | 10首で 2〜3 分 |
| **ちらし取り（ひとり）** | 25 枚（または 50・100 枚）の取り札を並べ、読まれた歌の札を探して取る。全部取るまでのタイムとお手つきの数 | 5〜15 分 |
| **一覧** | 100首を番号順・決まり字順（1字決まり→6字決まり）で。決まり字に色、作者名つき。「1字決まりだけ」などで絞って練習に送る | ― |

- **「今日の10首」**：日付から決まる10首（`games/lib/daily.ts` と同じ考え方。同じ日はだれでも同じ10首）。連続日数を `records.ts` に残す。冬休みの毎日の練習に使ってもらう
- 出題の範囲：**全100首／1字決まり（7首）／2字決まり（42首）／…／番号 1〜20・21〜40…**（学校の宿題が「20首ずつ」の形で出ることが多い）
- 苦手の札：間違えた歌を端末の中（`localStorage`）に覚えておき、「まちがえた歌だけ」を出題範囲に足す。送信はしない

### 決まり字れんしゅうの1問

1. 取り札を 8 枚並べる（正解 1 枚＋ほかの歌から 7 枚。**同じ音で始まる歌（友札）を優先して混ぜる**＝「む」「す」は1字で取れるが、「あさぼらけ」の2首は6字まで聞かないと取れない、を体で覚えるため）
2. 上の句をかなで**1文字ずつ**表示する（既定 0.35 秒/字。0.2〜0.6 秒の3段で選べる）。決まり字の位置は出題中は**見せない**
3. 札をタップした時点の表示文字数で評価：
   - **決まり字の文字数ちょうど**で正解 → 「決まり字で取れた！」（いちばん良い）
   - 決まり字より**前**で正解 → 「当てずっぽう」（正解だが評価は下げる。友札のある歌で起きる）
   - 決まり字より**後**で正解 → 「◯文字遅れ」
   - 不正解 → 「お手つき」。正解の札と、その歌の決まり字を色つきで見せる
4. 答えのあとに上の句・下の句の全文と作者名（漢字かな交じり）を出す

### ちらし取り（ひとり）

- 取り札を格子に並べる（パソコンは 1 画面に 25 枚が収まる大きさ。スマホは 25 枚で縦スクロールを許す。札の当たり判定は 44px 以上）
- 上の句を1文字ずつ（または一度に）出し、札を探してタップ。取れた札は消える。お手つきは +5 秒
- 終わったら合計タイム・平均の取り時間・遅かった歌3首を出す

### 札の見た目

- 取り札：**下の句をかなだけで縦書き**（`writing-mode: vertical-rl`）。実物の取り札と同じ「かなだけ」にするのは、上の句（漢字かな交じり）と見比べる力を練習するため
- 札の絵（歌仙絵）は描かない。無地の札に緑の縁（[game-hanafuda-koikoi.md](./game-hanafuda-koikoi.md) と同じく CSS のみ、画像ファイルを足さない）
- 文字の大きさ：取り札の文字はスマホで 14px 以上。「大きな字」スイッチで札を 6 枚に減らして文字を大きくする（祖父母と孫で遊ぶ場面を想定）

### データ（`games/lib/hyakunin-isshu-data.ts`）

1首ごとに次を持つ。**決まり字はデータに書かず、計算で出す**（手で書くと写し間違いが残る）。

```ts
interface Uta {
  no: number;          // 1〜100（小倉百人一首の歌番号）
  author: string;      // 作者名（例：天智天皇）
  kami: string;        // 上の句（漢字かな交じり。表示用）
  shimo: string;       // 下の句（漢字かな交じり。表示用）
  kamiYomi: string;    // 上の句の読み（読み上げの音どおりのひらがな。決まり字の計算に使う）
  shimoKana: string;   // 下の句のかな（取り札の表記。歴史的仮名遣い）
}
```

- `kamiYomi` は**読み上げの音どおり**（例：「おほけなく」→「おおけなく」、「あはれとも」→「あわれとも」）。競技かるたの決まり字は読みの音で決まるため
- `shimoKana` は取り札の表記（歴史的仮名遣い）
- 原典は**パブリックドメインのもの**を使い、2つ以上の資料（例：国立国会図書館デジタルコレクションの版本、国文学研究資料館のデータ）で照合した記録を、データファイル冒頭のコメントに残す

### 決まり字の計算（`games/lib/hyakunin-isshu.ts`。純関数）

- `kimariji(uta, pool)`：`pool`（既定は100首）の中で、`kamiYomi` の先頭から何文字で1首に絞れるか（**最短で一意になる接頭辞の長さ**）
- 出題範囲を絞っても、決まり字は**100首基準**で表示する（学校・競技の言い方と合わせる）。ちらし取りで札が減ったときの「場の決まり字」（減った札で短くなる）は今回はやらない（下「やらないこと」）
- `pickChoices(answer, pool, n, rng)`：友札（`kamiYomi` の先頭1字が同じ歌）を優先して混ぜる
- 乱数は既存の `games/lib/daily.ts` の種つき乱数を使う

### ページの構成

- `h1`「百人一首かるた」、リードは「上の句が1文字ずつ現れます。下の句の札を見つけてタップ。決まり字で取れたら一人前。インストール不要、無料」
- 遊び方・決まり字とは（「むすめふさほせ」＝1字決まり7首の覚え方、2字〜6字決まりの数）・よくある質問（FAQ 5問。`FAQPage` の JSON-LD）

## やらないこと

- **現代語訳・歌の解説**：市販の訳・解説は著作物。自前で100首ぶん書くのは工数が大きく、誤訳の責任も負う。一覧には原文と作者名だけを載せる
- **絵札（歌仙絵）・坊主めくり**：絵を描き起こす工数が大きく、市販の札の絵に似せるリスクもある
- **2人対戦・オンライン対戦**：ひとり練習で需要を確かめてから
- **場の決まり字（札が減るごとに短くなる決まり字）**：競技者向け。初心者の練習には100首基準で足りる
- **音声の読み上げ**：上「決めること」2
