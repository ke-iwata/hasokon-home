## 背景と根拠

### 法的根拠（一次情報で確認。2026-11-15、e-Gov 法令API）

**製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律**（昭和31年法律第120号。略称「中小受託取引適正化法」「取適法」。
令和7年法律第41号で旧「下請代金支払遅延等防止法」から改題・改正。**2026-01-01 施行**。法令ID `331AC0000000120`）

- **第3条第1項（支払期日）**：「製造委託等代金の支払期日は、委託事業者が中小受託事業者の給付の内容について検査をするかどうかを問わず、
  委託事業者が中小受託事業者の給付を受領した日（役務提供委託又は特定運送委託の場合にあつては、…役務の提供を受けた日。以下同じ。）から
  起算して、**六十日の期間内において、かつ、できる限り短い期間内において**、定められなければならない。」
- **第3条第2項（みなし支払期日）**：支払期日を**定めなかったとき**は**受領した日**が、60日を超えて定めたときは
  **受領した日から起算して六十日を経過した日の前日**が、それぞれ支払期日とみなされる
  → 受領日を1日目として数えて **60日目**（＝受領日＋59日）が法律上の最も遅い支払期日
- **第5条第1項第2号（支払遅延の禁止）**：支払期日の経過後なお支払わないこと。**「手形を交付すること」並びに金銭及び手形以外の支払手段であって
  支払期日までに代金の額に相当する額の金銭と引き換えることが困難であるもの（電子記録債権・ファクタリング等）を使用することを含む**（改正で追加。手形払いの禁止）
- **第5条第1項第3号（減額の禁止）**・**第2項第4号（協議に応じない一方的な代金決定の禁止。改正で追加）**
- **第6条第1項（遅延利息）**：支払期日までに支払わなかったときは、「中小受託事業者の給付を受領した日から起算して**六十日を経過した日から支払をする日までの期間**について、
  その日数に応じ、当該未払金額に公正取引委員会規則で定める率を乗じて得た金額」を遅延利息として支払う。
  **第2項**：不当に減額したときは、減じた日と60日を経過した日の**いずれか遅い日から**減じた額を支払う日まで、同じ率
  - **起算点は「定めた支払期日」ではなく「受領日から60日を経過した日」**。支払期日を30日目に定めていて45日目に払っても、取適法の遅延利息は生じない
    （契約上の遅延損害金は別。「やらないこと」）
- **令和7年公正取引委員会規則第9号**（`507M60200000009`。2026-01-01 施行）：第6条第1項・第2項の率は **年14.6%**
- **第2条第8項・第9項（適用対象）**：資本金基準に**従業員基準が加わった**（改正の目玉。第5号・第6号）

  | 取引の種類 | 委託事業者（発注側） | 中小受託事業者（受注側） |
  |---|---|---|
  | 製造委託・修理委託・特定運送委託・政令で定める情報成果物／役務（プログラム作成・運送・倉庫保管・情報処理） | 資本金 3億円超 | 個人 または 資本金 3億円以下 |
  | 〃 | 資本金 1千万円超〜3億円以下 | 個人 または 資本金 1千万円以下 |
  | 上記以外の情報成果物作成委託・役務提供委託 | 資本金 5千万円超 | 個人 または 資本金 5千万円以下 |
  | 〃 | 資本金 1千万円超〜5千万円以下 | 個人 または 資本金 1千万円以下 |
  | 製造委託等（従業員基準） | **常時使用する従業員 300人超**の法人 | **従業員 300人以下**の個人・法人 |
  | 情報成果物作成委託・役務提供委託（従業員基準） | **従業員 100人超**の法人 | **従業員 100人以下**の個人・法人 |

- **第2条第5項（特定運送委託）**：販売・製造等の目的物を取引の相手方へ運ぶ運送の委託（いわゆる発荷主から運送事業者への委託）を新たに対象に
- **附則（令和7年法律第41号）第2条**：新法の第4条・第5条・第6条第2項等は**施行後にした製造委託等**に適用（2025年中の発注には旧法）。
  ツールは「発注日が 2025-12-31 以前なら旧下請法（支払期日・遅延利息の規定と率は同じ）」と1行添える

**特定受託事業者に係る取引の適正化等に関する法律**（令和5年法律第25号。フリーランス・事業者間取引適正化等法。2024-11-01 施行）

- **第4条第1項**：特定業務委託事業者は、給付を受領した日から起算して**60日の期間内**において、かつ、できる限り短い期間内に報酬の支払期日を定める
  （**再委託の例外**：第3項で、元委託の支払期日から起算して30日以内）
- 取適法の対象外（発注側の資本金が1千万円以下など）でも、**受注側が従業員を使用しない個人・一人法人で、発注側が従業員を使用する事業者なら**
  60日ルールはこちらでかかる。**ただし遅延利息の規定は無い**（ツールは「遅延利息：取適法の対象のときだけ」と出し分ける）

## 作るもの

### 入力（上から順に。1画面に収める）

1. **モードの切り替え**（タブ）：「納品日から期日を出す」（既定）／「支払条件をチェック」／「遅延利息を出す」
2. 共通：**受領日（納品日・役務の提供を受けた日）**。日付の部品は `mynumber-kigen` と同じ（和暦入力可）
3. 「支払条件をチェック」：**締め日**（毎月 5・10・15・20・25・末日／締めなし）。**「締めなし」は納品ごとに支払日を決める取引**で、支払日の入力は「受領日から○日後」に変わると**支払日**（翌月・翌々月 × 5・10・15・20・25・末日）。
   **納品日を入れなくても、その条件の「最も長くなる納品日」**（締め期間の初日）**で判定する**
4. 「遅延利息を出す」：**未払金額**（円）と**実際に支払った（支払う）日**
5. 折りたたみ：**適用の判定**（発注側・受注側の資本金／常時使用する従業員数、取引の種類 4 択）。開かなければ「取適法の対象だとして」計算する

### 結果（上から順に）

1. **法律上の支払期日**：「**2027年3月10日（水）まで**（受領日 1/10 を1日目として60日目）」。
   期日が土日祝なら「金融機関の休業日です」と添える（**期日そのものは動かさない**。下の「決めること 2」）
2. **支払条件の判定**（チェックモード）：「最も長いケース：**7/1 納品 → 8/31 払い＝62日**。60日を超えます」。
   月ごとに12か月分の表を出し、超える月に印。**判定は条文の「60日」で出し、公取委の運用（2か月の読み替え）は注記で別に出す**
   - **表は結果の要約（最も長いケース）の下に置く。列は「月・最長日数・判定」の3列まで**にし、最短の日数・納品日・支払日の詳細は行を開くと見える形にする。
     320px 幅でも**横スクロールを出さない**
3. **遅延利息**：「60日を経過した日（3/11）から支払日（3/31）まで **21日 × 年14.6% × 1,000,000円 ÷ 365 ＝ 8,400円**」。
   式をそのまま見せる（円未満の扱いは「決めること 3」）
4. **適用の判定**（開いたとき）：次の **4 つ**を、どの号・条に当たるかと一緒に
   - **取適法とフリーランス法の両方**（受注側が従業員を使用しない個人・一人法人で、発注側が取適法の委託事業者でもあるとき。**フリーランスの読者がいちばん入れそうな組み合わせ**）。
     遅延利息は取適法第6条の規定で出す。どちらの法律で扱われるかは「決めること 5」の結果で書く
   - 取適法だけ／フリーランス法の60日だけ（遅延利息の規定なし）／どちらも対象外
5. 注記（常に）：「手形払い、期日までに満額を現金化できない電子記録債権・ファクタリングでの支払いは、期日内でも支払遅延になります（第5条第1項第2号）」

## 決めること（実装前に運営者と）

1. **月単位の締切制度の「2か月」読み替え**：公取委の『下請取引適正化推進講習会テキスト』（旧下請法）には、月単位の締切制度では「受領後60日以内」を
   「受領後2か月以内」として運用する旨の記載があったとされる。**取適法の講習会テキスト（2025-11 以降の版）で同じ記載が残っているかを一次資料で確かめる**。
   - 残っていれば：判定は2段（「条文の60日では超える／公取委の運用（2か月）では問題としない」）
   - 確かめられなければ：条文の60日だけで判定し、「運用上の扱いは公取委に確認を」と書く
2. **支払期日が金融機関の休業日に当たるとき**：旧下請法の運用では「順延が2日以内で、あらかじめ書面で合意していれば問題としない」扱いがあったとされる。
   これも取適法の版で確かめ、確かめられたら結果1の注記に「2日以内の順延の合意があれば…」を足す。**確かめられなければ期日は動かさず「休業日です」だけ**
3. **遅延利息の日割りの基礎**（365日／閏年は366日）と**円未満の扱い**：規則は「年14.6%」だけを定める。公取委の計算例に合わせる（確かめられなければ365日・円未満切り捨てで、式を見せる）
4. ~~ツール名に「下請法」を入れるか~~ → **title にだけ入れる**（h1・本文は「取適法（旧下請法）」の表記。検索はまだ旧名のほうが多いため。企画レビュー #505 で確定）
5. **両方の法律に当てはまるとき、どちらで扱われるか**：公取委は「両方に違反する行為は、原則としてフリーランス法を優先して適用する」と整理していたとされる。
   フリーランス法の解釈ガイドライン・Q&A（公正取引委員会・厚生労働省）の一次資料で確かめる。
   - 確かめられたら：結果4の「両方」に「違反行為は原則としてフリーランス法で扱われます（遅延利息は取適法第6条）」と書く
   - **確かめられなければ：両方の法律の名前を並べるだけ**にし、どちらが優先されるかは書かない

## やらないこと

- **違反かどうかの最終判断**：「正当な理由」（第3条・第5条）や個別の契約の事情は判断しない。**計算と条文の当てはめまで**
- **契約上の遅延損害金（民法の法定利率3%・約定利率）**：取適法の遅延利息とは別の制度。FAQ で違いを1問だけ
- **建設工事の下請（建設業法）**：取適法の対象外（第2条第4項括弧書き）。建設業法第24条の3〜6（1か月・50日）は別ツールの候補として残す
- **電子記録債権・ファクタリングの手数料の計算**
- **民間の会計ソフト・ファクタリング会社の名前を出すこと**
