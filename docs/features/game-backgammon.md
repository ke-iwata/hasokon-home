## 提案する仕様

### ルール（標準のバックギャモン）

- 盤は 24 ポイント。各自 15 個の駒。初期配置は標準のもの（自分から見て 24 に 2・13 に 5・8 に 3・6 に 5）
- 先手決め：互いに1個ずつ振り、大きいほうが**その2つの目で**最初の手を指す（同じ目なら振り直し）
- サイコロ2個の目のぶん、駒を進める。**ゾロ目は同じ目を4回**使う
- 相手の駒が **2個以上**あるポイントには止まれない。**1個（ブロット）**なら止まって打ち（ヒット）、その駒はバーへ
- バーに駒があるうちは、それを相手の陣地に入れる（エンター）まで他の駒を動かせない
- 15 個すべてが自分のインナーボード（1〜6）に入ったら上げられる（ベアオフ）。目より大きい数のポイントに駒が無ければ、いちばん遠い駒を上げられる
- **目の使い方の決まり（機械が守らせる）**：
  - 2つの目を両方使える手があるなら、両方使わなければならない
  - 片方しか使えないなら、**大きいほうの目**を使える限り大きいほうを使う
  - 使える手が無ければパス（「動かせる手がありません」と出して自動で手番を渡す）
- 勝ち：先に 15 個を上げきったほう。**ギャモン**（相手が1個も上げていない＝2点）・**バックギャモン**（さらに相手の駒がバーか勝者のインナーボードに残る＝3点）を結果に出す
- **ダブリングキューブは v1 では入れない**（下記「やらないこと」）

### 操作

- 「振る」ボタン（または `Space`）でサイコロ2個を振る
- **タップ2回**：動かす駒のポイント → 行き先。1回目で、動かせる駒の列だけを光らせ、2回目の候補（使える目ごとの行き先）を光らせる。
  2つの目を合わせた行き先も候補に出す（途中で止まれる場合だけ）
- **ドラッグ**：駒をつまんで候補の上で離す
- **「1手戻す」で戻せるのは、その手番で振ったあと・手番を渡す前の手**（何手でも）。**振った目は戻せない**（振り直しはできない）。前の手番の手・CPU の手も戻せない
- **手番の渡し方の既定は「確認してから渡す」**：目を全部使う（または使える手が尽きる）と「手番を終える」ボタンが光り、押すまでは最後の1手も戻せる。
  設定で「自動で渡す」に切り替えられる。**自動のときは最後の1手を置いた瞬間に手番が渡るので、その1手は戻せない**（設定の説明にそう書く）。
  使える手が1つも無いときのパスは、どちらの設定でも「動かせる手がありません」を 1 秒出して自動で渡す（戻すものが無いため）
- キーボード：`Space` で振る、`Z` で戻す、`Enter` で手番を終える

### CPU（`games/lib/backgammon-cpu.ts`、Web Worker）

| 強さ | 考え方 | 思考時間の目安 |
|---|---|---|
| かんたん | 合法手から無作為。ただし「打てるブロットを打つ」「上げられる駒を上げる」だけは優先 | 即時 |
| ふつう | 1手読み：合法手ごとの局面を評価関数で比べる | 〜100ms |
| つよい | 2手読み：相手の 21 通りの目（ゾロ目 1/36・それ以外 2/36）の期待値で比べる（expectimax）。候補が多いときは1手読みの上位 8 手だけ読む | 〜1秒（[cpu-speed.md](./cpu-speed.md) の上限に合わせる） |

- 評価関数：ピップカウントの差・ブロットの数と打たれる確率（直接・間接の目の数）・作ったポイント（特にインナーボード）・連続したブロック（プライム）・バーの駒・上げた駒の数
- **CPU の手はアニメーションで1つずつ見せる**。まとめて瞬間移動させない。速さは [cpu-speed.md](./cpu-speed.md) の共通部品 `CpuSpeed`（`app/_cpu/CpuSpeed.tsx`）に乗せ、
  **このゲームが決めるのは「ふつう」の 1 駒あたり 350ms だけ**（ゆっくり 560ms・はやい 175ms は共通の倍率 1.6／1／0.5 から決まる）。サイコロを振る見せ方も同じ倍率に乗せる
- **`StartGate`（`app/_cpu/StartGate.tsx`）で CPU を堰き止める。** 先手決めで **CPU が勝ったとき**、ページを開いただけで CPU が動き出さない（「スタート」を押すまで待つ）。
  人が先手のときは、人が「振る」を押したのが合図になる（余計な1タップを増やさない）。幕は盤の上に重ねる絶対配置で、出ても消えてもレイアウトを動かさない
- CPU は乱数のサイコロを人と同じ関数で振る（CPU に有利な目を出さない）
- **乱数は games 側に置く**（`tools/lib/password.ts` は別アプリなので import できない）。`games/lib/backgammon.ts` に置き、
  サイコロは `DieSource`（`() => 1|2|3|4|5|6`）として**注入**する。
  - 本番は `cryptoDie()`：`crypto.getRandomValues()` で 32 bit の整数 x を引き、**x ≥ 2³² − (2³² mod 6) なら捨てて引き直し**、受け入れた x の `x % 6 + 1` を返す（剰余バイアスなし）
  - テストは `dieFromRng(rng)`（`Math.floor(rng() * 6) + 1`）に [yacht.ts](../../games/lib/yacht.ts) と同じ `Rng` 型の `seededRng` を渡して固定する

### 画面

- 盤は横長。パソコンでは盤を中央に大きく、右に「振る」とサイコロ・ピップカウント（両者）。
- **スマホ（375px）の寸法**：左右 16px の余白を引いた 343px を、**ポイント 12 列 × 25px＝300px・中央のバー 20px・右端のベアオフの置き場 23px** に割る。
  - ベアオフの置き場は盤の外の右端の細い列で、上半分が相手・下半分が自分の上げた駒。駒は横向きの薄い板（23×6px）で積み、15 枚で 90px に収める
  - 駒の直径 23px（ポイントの幅 − 2px）。1 列に 5 個まで重ねて 115px、6 個目からは 5 個目の上に数字
  - 盤の高さ：上下の半分が各 115px＋中央の帯 24px＋上下の縁 8px で **約 262px**。375×667 でヘッダー・サイコロとピップカウントの行・ボタン行を足しても1画面に収まる
  - **タップの的は三角形ではなくポイントの縦長の列全体**（25×115px）。幅 25px は 44px に届かないが、WCAG 2.2 の最小の的（24×24px）は満たす。
    取り違えの対策として、**2回目のタップは光っている候補の列だけが受け付け**、それ以外の列を叩いたら選択を取り消すだけで駒は動かない
  - ピップカウントはベアオフの置き場と兼ねず、盤の上のサイコロの行に出す
- **盤・サイコロとピップカウントの行・ボタンの行は `height` で高さを固定する**（`min-height` にしない。[cpu-speed.md](./cpu-speed.md) の約束）。
  サイコロの有無・「動かせる手がありません」の文言・ピップカウントの桁が変わっても、盤より下が動かない
- ドラッグがあるので、**盤の上だけ `touch-action: none`**（`games/app/globals.css` の既存の約束どおり。盤の外はスクロールできる）
- [mobile-one-screen.md](./mobile-one-screen.md) の約束どおり、スタート後は盤・サイコロ・ボタンが1画面に収まる
- 1つのポイントに 6 個以上重なったら、5 個目の上に数字（「7」など）を出す
- 駒の色は2色＋縁取りで区別し、**色だけに頼らない**（片方は塗り、片方は白地に太い縁）
- ピップカウント（上がりまでの残りの目の合計）を常に出す。「どちらが有利か」の目安になり、ルールの学びにもなる
- 本文（SSR）：遊び方（初期配置の図・駒の進む向き・打つ・エンター・ベアオフ）／ギャモンとバックギャモン／初心者の3つのコツ（ブロットを残さない・インナーボードにポイントを作る・6-1 は 7 ポイントを作る）／FAQ 4問
  （「ゾロ目はどう動かす」「動かせないときは」「ギャモンとは」「バーの駒はどこに入る」）。FAQ は `FAQPage` の JSON-LD に同じ文
- `metadata` に `robots: robotsFor('backgammon')`。title 案：「バックギャモン 無料｜CPU対戦（かんたん・ふつう・つよい）・ルール解説」

## テスト

- 初期配置のピップカウントが両者 167
- 合法手：
  - 2つの目を両方使える局面で、片方しか使わない手が合法手に含まれない
  - 片方しか使えない局面で、大きいほうが使えるなら大きいほうだけが合法
  - ゾロ目で4回使える／途中までしか使えない局面
  - バーに駒があるとき、エンター以外の手が合法手に含まれない
  - 相手の駒が2個以上のポイントに止まる手が含まれない
  - ベアオフ：全駒がインナーボードに無いと上げられない／目より大きいポイントに駒が無いときだけ遠い駒を上げられる
- 打ったブロットがバーへ行き、相手のピップカウントが正しく増える
- **ベアオフ中に打たれたら、エンターしてその駒をインナーボードに戻すまで上げられない**（上げる手が合法手に含まれない）
- **同じ局面になる手は1つにまとめる**：例として 6-1 の「24→18→17」と「24→23→17」は同じ局面なので合法手は1つ。候補の光らせ方（行き先の重複が出ない）と CPU の読み（同じ局面を2回評価しない）の両方で確かめる
- 1手戻す：振ったあとの手は何手でも戻せ、振った目は変わらない。「確認してから渡す」では最後の1手も戻せ、「自動で渡す」では戻せない
- ギャモン・バックギャモンの点数判定（2点・3点）の境目
- CPU：どの強さも合法手しか返さない（ランダム局面 1,000 個）。つよいの1手が思考時間の上限内に返る。
  「つよい」が「かんたん」に 200 局で勝ち越す（固定シードの乱数で再現できるようにする）
- 乱数：`cryptoDie()` の 60,000 回の出目の偏りがカイ二乗検定の範囲内。`cryptoDie` に渡す整数の源を差し替えて、棄却の境目（2³² − 4 以上）が引き直しになることを確かめる。`dieFromRng(seededRng)` で同じ出目の列が再現できる
