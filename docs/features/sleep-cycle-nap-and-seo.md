# 睡眠サイクル計算機に仮眠モードを足し、検索面を広げる

**状態**：実装済み（2026-08-13。本番反映はタグリリース待ち）
**対象**：`tools/`（`hasokon.com/tools/sleep-cycle/`）
**起票**：2026-08-13

---

## 背景と根拠

### 検索に「表示され始めている」唯一の実用ページ

Search Console API（2026-08-13 取得 / `https://hasokon.com/` プロパティ、
2026-07-15〜08-11 のページ別集計）で、表示回数が2桁あるのは次の2つだけ。

| ページ | クリック | 表示 | 掲載順位 |
|---|---|---|---|
| `/`（トップ） | 3 | 10 | 1.0（指名検索） |
| **`/tools/sleep-cycle/`** | 0 | **10** | **16.8** |

つまり指名検索を除くと、**Googleが評価し始めているのは睡眠サイクル計算機だけ**。
掲載順位16.8位は2ページ目相当で、ここを1ページ目に押し上げるのが
現状もっとも近い自然検索の勝ち筋になっている
（クエリ別データはまだ匿名化されてほぼ出ない。表示10回・クリック0もこのため）。

なお税・社会保険系ツールはいわゆる YMYL 領域で、立ち上げ期のサイトが
上位に入るには時間がかかる。**生活系（非YMYL）のこのページが先に動いている**のは
その構造どおりで、伸びている芽に足すのが効率的。

### ページ自身が「仮眠は別物」と言っているのに、仮眠は計算できない

現状のFAQに「昼寝にも90分サイクルは使えますか？→ 15〜20分程度の短い仮眠のほうが
向いている」という問答が既にある（`tools/app/sleep-cycle/page.tsx`）。
つまり**仮眠の検索意図に答える文章はあるのに、計算機能が無い**。
「仮眠 時間 計算」「昼寝 何分」「パワーナップ 時間」系の検索意図を
受け止める受け皿を、既存ページの拡張として作れる状態にある。

## 現状

- 計算機（`tools/app/sleep-cycle/Calculator.tsx`・122行）は
  「起きたい時刻から逆算」「今から寝たら」の2モードのみ。90分サイクル固定
- ページ（`page.tsx`・129行）は解説1見出し＋FAQ5問。FAQPage の JSON-LD あり
- タイトル・説明文は夜の睡眠に限定した書き方になっている

## 提案する仕様

### 1. 仮眠モードの追加（`Calculator.tsx`・`lib/sleep-cycle.ts`）

- モード切替に「仮眠」を追加。今の時刻（または開始時刻）を入れると、
  次の3案を起床時刻つきで提示する
  - **15〜20分**：短い仮眠。深い眠りに入る前に起きる（だるさが残りにくい）
  - **30分**：昼休みに収まる上限の目安。起き抜けのだるさ（睡眠慣性）の
    注意書きを添える
  - **90分**：1サイクル。夜の睡眠への影響の注意書きを添える
- 入眠までの時間（既存の設定）を仮眠にも適用する
- `lib/sleep-cycle.ts` に仮眠の提案ロジックを純関数で追加し、
  `tools/tests/sleep-cycle.test.ts` にケースを足す

### 2. 検索面を広げるコンテンツ拡充（`page.tsx`）

- 見出しを2つ追加：「仮眠は90分ではなく15〜20分」「年齢・生活リズムと睡眠時間の目安」
  （出典として厚生労働省「健康づくりのための睡眠ガイド2023」を明記。
  医療的な診断・治療に踏み込む記述はしない）
- FAQに「仮眠の最適な長さ」「コーヒーを飲んでから仮眠するとよい？」等を2〜3問追加
  （JSON-LDは既存の仕組みでそのまま反映される）
- title / description を「仮眠・昼寝の時間計算にも対応」を含む形に更新する
  （キーワードの詰め込みはしない。1文足す程度）

## 期待される効果

- 掲載順位16.8位のページの内容が厚くなり、既存クエリでの順位改善と
  仮眠系クエリでの新規表示が見込める
- 測り方：Search Console のページ別（`/tools/sleep-cycle/`）の表示回数・
  掲載順位・クリックを実装前後8週間で比較。仮眠系クエリの出現も見る
- 仮眠モードは昼休みのリピート利用（平日昼の再訪）を生む可能性がある。
  GA4の時間帯別アクセスで確認する

## 工数の見積り

- 実装1セッション。消費トークンの目安：**4万〜6万**
  （ロジック＋テストで1〜2万、UI追加で1.5〜2万、コンテンツ・メタ更新で1〜2万）

## やらないこと

- **睡眠の質の診断・アドバイス機能** — 医療領域に踏み込まない。
  一般的な目安と出典の提示にとどめる
- **アラーム・通知機能** — 静的サイトの範囲を超える（バックグラウンド動作・
  通知権限）。時刻の提示までにとどめる
- **別ページ（/nap/ など）としての切り出し** — 評価され始めている
  既存URLに積む。ページを割ると内部競合と評価分散のリスクがある
