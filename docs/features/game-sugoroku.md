## 提案する仕様

### ルール（基本）

- 順番にサイコロ（1個）をふり、出た目だけコマを進める。**最初にゴールに着いた人が1位**。全員がゴールするまで続けて順位を出す（「1位が出たら終わり」も選べる）
- ゴールの止まり方は2つから選ぶ：
  - **こえてもOK**（既定。小さい子でも終わる）
  - **ぴったり**（余った目のぶん戻る。おとな向け）
- サイコロは「1個」（既定）と「2個（合計）」。「ながい」盤では2個を勧める

### 盤（自前。3段階の長さ × 2つの絵柄）

| 長さ | マス | 2人での目安 |
|---|---|---|
| みじかい | 20 | 3〜5分（小さい子と） |
| ふつう | 40 | 8〜12分 |
| ながい | 60 | 15〜20分（サイコロ2個推奨） |

- 絵柄は「**お正月**」（門松・鏡もち・こま・凧・羽子板・初日の出。自前の SVG）と「**どうぶつ**」（干支にとらわれない動物）の2つ
- マスの効果は**子ども向けにやさしく**：「2つすすむ」「3つすすむ」「1回やすみ」「もう1回ふれる」「2つもどる」。
  **「ふりだしにもどる」は既定で入れない**（オプション「いじわるマスあり」で入る。小さい子が泣く元になる）
- 効果マスの割合はおよそ3割。**効果マスの行き先が別の効果マスにならない**（連鎖・無限ループを作らない）
- 「今日の盤」：長さごとに日付から盤を決める（`games/lib/daily.ts` の `dailySeed`）。「新しい盤」でその場で作り直せる

### 遊ぶ人

- 2〜4人。名前（既定は「1ばん」「2ばん」…）とコマの色・形を選ぶ。**1人で始めたら CPU を1〜3人足す**
- CPU はサイコロをふるだけ（すごろくに戦略は無い）。CPU の番は自動で進み、「はやく」で待ち時間を短くできる
- 名前は端末の中だけ（`localStorage`。送信しない）

### 操作

- 大きな「サイコロをふる」ボタン（タップ・クリック・スペースキー・Enter）。サイコロは転がる演出のあと目が止まる
- コマは1マスずつ進む（数えながら見られる）。効果マスでは吹き出しで「2つすすむ！」と出してから動く
- **出目と効果は文字でも出す**（スクリーンリーダー向けに `aria-live="polite"`。「2ばんさん：4。ゴールまであと11マス」）
- 「アニメを短く」（`prefers-reduced-motion` のときは既定でオン）

### 乱数

- サイコロの目は `crypto.getRandomValues` から作る（偏りを作らない。`% 6` ではなく棄却法）
- 盤の生成は `mulberry32`（`daily.ts`）にシードを注入する（今日の盤を全員同じにし、テストで再現できるようにする）

### 印刷（迷路と同じ作法）

- 「印刷する」で **A4 横1枚に盤**、2枚目に**コマ（4人分の切り抜き）とサイコロの展開図**（のりしろつき）
- 盤の線は黒・太め、背景は白（インクを使わない）。マスの絵は線画にする
- 印刷物の下に小さく `hasokon.com/games/sugoroku/` を入れる。**広告は印刷しない**
- 印刷の CSS は迷路で `games/app/globals.css` に足す `@media print` の書き方にそろえる（迷路の実装が先に入る。入っていなければこのゲームで足す）
- 配布の可否は迷路の規約の決定に従う（上の「運営者の確認待ち」）

### 計測

新しいイベント名を作らず、既存の `trackToolUse`（`games/lib/analytics.ts`）に統一する。

| 操作 | action |
|---|---|
| 1ゲーム目のサイコロ | `start-{short|normal|long}` |
| 全員ゴール（または1位で終了） | `finish` |
| 印刷ボタン | `print` |

**名前・人数の内訳・出目は送らない。** 印刷は「ボタンを押した回数」で、印刷された枚数ではない

### ロジック（`games/lib/sugoroku.ts`。純関数のみ）

- `generateBoard(seed, length, theme, options)`：マスの並びと効果を返す。効果マスは「行き先が効果マスでない」「ゴールの直前3マスに『もどる』を置かない」を守る
- `rollDie(rand)`：1〜6（棄却法）
- `applyRoll(state, roll)`：進む・ゴールの止まり方・効果マス（1回だけ適用）・やすみ・もう1回を処理して次の状態を返す
- `nextPlayer(state)`：やすみの人を飛ばし、ゴール済みの人を飛ばす
- 盤は SVG 1枚。マスはくねくね道（蛇行）に並べ、幅 360px でも 40 マスが1画面に収まる配置にする

### テスト（`games/tests/sugoroku.test.ts`）

- 長さ3種 × シード 100 個で、**効果マスの行き先が盤の中で、効果マスでない**・ゴールの直前に「もどる」が無い
- 同じシードで同じ盤、違う日付で違う今日の盤
- `applyRoll`：「こえてもOK」でゴールを越えたら止まる／「ぴったり」で余りの目だけ戻る／やすみが1回で解ける／「もう1回」が連続しても止まる（最大回数で打ち切り）
- **シミュレーション**：2人・各長さで 1,000 ゲーム回し、全ゲームが有限の手数で終わる・平均手番数が上の目安の範囲に入る（盤の作り方を変えたら目安から外れたことが分かる）
- `rollDie` を 60,000 回ふって各目が 10,000 ± 4% に入る（棄却法の書き間違いを落とす。乱数は固定シードで再現）
- ページの `metadata` に `robots: robotsFor('sugoroku')`（既存の `stage.test.ts` が見る）

### 画面（[mobile-one-screen.md](./mobile-one-screen.md)）

- 幅 360px で盤（40 マスまで）・今の番の人・サイコロのボタンが1画面に入る。60 マスは盤を少し小さくし、今の番の人のコマのまわりを拡大して見せる
- コマは色だけに頼らない（形も変える：まる・さんかく・しかく・ほし）。今の番は名前の太字と枠でも示す
- 文字は子どもが読めるようにひらがな中心（「サイコロをふる」「ゴール！ 1いは ◯◯さん」）

### 本文

- 遊び方・長さの目安・印刷して紙で遊ぶ方法（コマとサイコロの作り方）・「すごろくの歴史（絵すごろくと盤双六）」の短い読み物
- FAQ 4問：何人で遊べるか／小さい子と遊ぶ設定は（みじかい・こえてもOK・いじわるマスなし）／印刷して配ってよいか（迷路の規約の決定に従う）／サイコロに偏りはないか
- 出典：すごろくの由来は公的な資料（自治体の子育て・文化資料）を1つ以上あげる（実装 PR で URL を確かめてから載せる）

### 子ども向けと広告

[game-meiro.md](./game-meiro.md) の「子ども向けと広告」と同じ方針（保護者が子どもと遊ぶページとして扱い、子ども向けのタグは付けない）。迷路で運営者の確認が取れた内容に合わせる

### やらないこと

- **オンライン対戦・離れた家族との同時プレイ**：サーバーが要る。「送信なし」の約束が崩れる
- **お金・株・職業などの人生もの**：特定の商品（人生ゲーム）に寄る。お金の扱いは子ども向けに合わない
- **自分で盤を作る（マスの文言を自由入力）**：入力の検査と印刷の崩れが重い。好評なら次の提案で
- 盤双六（バックギャモン系のルール）：[game-backgammon.md](./game-backgammon.md) の領分
