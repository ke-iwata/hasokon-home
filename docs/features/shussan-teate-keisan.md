## 背景と根拠

産休中の収入は **出産手当金（健康保険）** と **出産育児一時金（健康保険）** の2本で、
そのあとに **育児休業給付金（雇用保険）** が続く。当サイトは 3本目を
[ikuji-kyugyo-kyufu.md](./ikuji-kyugyo-kyufu.md)（#199 起票・#202 実装中）で持とうとしているが、
**時系列でその前に来る 2本が無い**。「出産でもらえるお金」を検索する人は妊娠中で、
産休（出産手当金）→ 育休（育児休業給付金）の順に必要になる。前半が無いと、
後半のツールに来た人を「産休中はいくら」の問いで取りこぼす。

### 計算式は傷病手当金と同じ（実装済みのロジックを流用できる）

出産手当金の日額は **健康保険法 第102条2項が 第99条2項（傷病手当金の額）を準用**しており、
`tools/lib/shobyo-teate.ts` が持つ計算と同一である：

- 支給開始日以前12か月の各月の標準報酬月額の平均 ÷ 30（**10円未満四捨五入**）× 2/3（**1円未満四捨五入**）
- 被保険者期間が 12か月未満なら「その平均」と「全被保険者の平均（協会けんぽ：**32万円**、
  支給開始日が令和7年4月1日以降）」の低いほう（`SHORT_TENURE_CAP = 320_000`）

つまり **日額の計算は新しく書かない**。`shobyo-teate.ts` から日額の関数を切り出して import する
（同じ数字を2か所に置かない。#218 が `waribiki-percent.ts` の消費税率で採ったのと同じ）。
新しく書くのは「**支給期間を日付から出す**」部分と「出産育児一時金」の分岐だけ。

### 支給期間・一時金の根拠（2026-09-17 取得）

協会けんぽ「出産手当金」「出産育児一時金」（下記 一次情報）より：

| 項目 | 内容 |
|---|---|
| 産前 | 出産の日（**実際の出産が予定日より後のときは出産予定日**）以前 **42日**（多胎妊娠は **98日**） |
| 産後 | 出産の翌日以後 **56日** |
| 予定日超過 | 出産が予定日より遅れた場合、**遅れた日数分も支給**される |
| 給与との調整 | 休んだ期間に給与が出ても、その日額が出産手当金の日額より少なければ **差額を支給** |
| 対象外 | 任意継続被保険者（法102条1項かっこ書き）・国民健康保険（出産手当金の給付が無い）・被扶養者 |
| 資格喪失後 | 継続1年以上の被保険者期間があり、喪失日の前日に受給中（または受けられる状態）なら継続給付（法104条） |

### 競合との差

計算サイト各社に「出産手当金 計算」はある（keisan.site・keisan-navi・社労士事務所のツール等）。
差別化は次の 3点で、どれも既存ロジック（日付計算 `lib/date-parts.ts`・等級表 `lib/shaho-grades.ts`）の
組み合わせで出せる：

1. **日付から支給期間を出す**（予定日・実際の出産日・単胎/多胎 → 開始日・終了日・日数の内訳）。
   「予定日より 5日遅れたら何日分増えるか」まで答える
2. **一時金の 50万 / 48.8万 の分岐と多胎**を同じ画面で足す（別ツールに分けない）
3. **育児休業給付金への橋渡し**：産後 56日の翌日が育休の開始日。
   [ikuji-kyugyo-kyufu.md](./ikuji-kyugyo-kyufu.md) が実装されたら、その日付を渡すリンクを置く

## 提案する仕様

### 入力

**スマホで 7つが縦に並ぶと結果が 1画面に入らない**ので、必須の 4つを上に置き、任意の 3つは
`<details><summary>詳しい条件</summary>` に畳む（`furusato-nozei` / `iryohi-kojo` / `nenmatsu-chosei` の
`Calculator.tsx` が同じ型を持っているので流用する）。

必須（常に表示）：

1. **出産予定日**（必須。`<input type="date">`）
2. **実際の出産日**（任意だが上に置く。空なら予定日と同じとして計算し、「出産後に入れ直すと確定額が出ます」と案内）
3. **単胎 / 多胎**（既定：単胎）
4. **月給（額面）**（必須。傷病手当金と同じ入力。標準報酬月額は `standardMonthly()` で等級に丸める）

任意（「詳しい条件」に畳む。既定値のままなら開かなくてよい）：

5. **健康保険の加入期間が 12か月以上か**（既定：はい。いいえなら `SHORT_TENURE_CAP` の低いほう）
6. **産休中に会社から給与が出るか**（任意。月額を入れると日額換算して差額支給に直す。既定 0）
7. **産科医療補償制度に加入している医療機関で出産するか**（既定：はい。大半の分娩機関が加入。
   「わからない」は「はい」扱いにし、結果側に確認の一文を出す）

### 計算（`tools/lib/shussan-teate.ts`。純関数）

```
産前日数   = (多胎 ? 98 : 42) + max(0, 出産日 − 予定日)   // 予定日超過分を含む
産後日数   = 56
産前開始日 = (出産日 <= 予定日 ? 出産日 : 予定日) − (多胎 ? 97 : 41)   // 起算日を含めて数える
産後終了日 = 出産日 + 56
日額       = 傷病手当金と同じ（shobyo-teate.ts から切り出した関数）
給与調整   = max(0, 日額 − 給与日額)   // 給与日額 = 月額 ÷ 30 は当サイト側の換算（下記）
総額       = 給与調整後の日額 × (産前日数 + 産後日数)
一時金     = (産科医療補償制度 ? 500,000 : 488,000) × 胎児数
```

- 「出産日が予定日より早い」場合は出産日を起点に 42日を数え直す（産前日数は 42 のまま、
  開始日が前にずれる）。「遅い」場合は予定日を起点にし、遅れた日数を産前に足す
- 実際に休んだ日数（産前を短く働いた等）は初版では扱わない。**「出産手当金は休んだ日に対して
  支給される」注記を出し、「産前は何日休みましたか」の入力は次版**（要望があれば）。
  結果には必ず「**産前 42日（多胎 98日）をフルに休んだ場合**の額」の一文を出す
- 給与との差額調整の「給与日額 = 月額 ÷ 30」は当サイト側の換算で、実際の申請では**事業主が
  証明する日額**が使われる。結果の脇に「目安」と添える。確認先：協会けんぽ「出産手当金支給申請書」の
  記入例（事業主記入欄の「支給した（する）賃金」の項）を実装時に見る
- 日付計算は `lib/date-parts.ts`（`addDays` / `daysBetween` / `formatJa`）を使う。
  `Date` を直接いじらない（ideco.ts のコメントにある UTC の罠）

### 表示

- **支給期間**：産前開始日 〜 産後終了日（日数の内訳：産前 42・予定日超過 n・産後 56）
- **出産手当金**：日額・総額。給与が出る場合は「差額支給」の行に切り替える
- **出産育児一時金**：金額（多胎なら「× 2」）。直接支払制度なら病院への支払いに充当される旨
- **合計**（手当金＋一時金）と、**非課税・社会保険料免除**の一文
- **育休へのつなぎ**：「産後 56日の翌日（YYYY年M月D日）から育児休業。給付金の目安は
  → 育児休業給付金 計算機」（#202 が `public` になるまではリンクを出さず文だけ）
- 結果は入力の直下に出し、**スマホ幅（390px）で必須入力 4つ〜合計の行が 1スクロール以内**に見える高さにする。
  解説と育休へのつなぎはその下。日付入力の高さはサイト共通 CSS のまま（#202 のレビューで指摘のある
  21px の件はこの PR の範囲外）

## やらないこと

- **健康保険組合の付加給付（出産手当金付加金・出産育児一時金付加金）。** 組合ごとに額が違い、
  データとして持てない。FAQ で「組合なら上乗せがある場合がある」と案内する
- **国民健康保険。** 出産手当金の給付が無い（任意給付で実施している保険者はほぼ無い）。
  一時金だけなら金額は同じなので、注記で足りる
- **産前産後休業中の社会保険料免除額の計算。** `hatarakizon.ts` の料率で出せるが、
  「もらえる額」の画面に「払わなくて済む額」を混ぜると合計の意味がぶれる。次版候補
- **育児休業給付金との合算表示。** #202 が `public` になってから、日付を渡すリンクで足す
- **出産費用無償化後の額。** 改正法は公布済みだが施行日が政令待ちで、制度の中身（一時金を残すか、
  全国一律価格の額）も未確定。一次資料に無いものは書かない（learn の暗号資産の章と同じ判断）
- **実際に休んだ日数の入力。** 初版は「産前 42日をフルに休む」前提。要望があれば次版
