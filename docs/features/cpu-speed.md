# CPU対戦の共通の作法（スタート待ち・CPUの速さ・大きさを変えない）

**状態**：実装済み（2026-08-16。本番反映はタグリリース待ち）
**対象**：`games/`（CPU対戦のある全ゲーム）
**起票**：2026-08-16（運営者のフィードバックから）

CPU対戦のゲームが増えてきて、同じ体験の粗さが横並びで出るようになった。
1本ずつ直すのではなく、**共通の部品にして全ゲームへ横展開する**ための記録。

## 解いている問題

運営者から挙がった3点：

1. 「開くとともに開始してしまうことがある。CPU操作が勝手に行われてしまう」
2. 「ゲームスペースの大きさが変わるのはすごいストレスになるので固定幅にしてほしい
   （これはどのゲームも同じなので横展開して）」
3. 「CPU対戦系のゲームはゲームスピードを変更できるようにしてほしい」

## 1. スタート待ち（`app/_cpu/StartGate.tsx`）

配った直後は `begun = false` で、**CPUを動かす effect を堰き止める**。
「スタート」を押すか、**自分が先手なら自分の初手**が合図になる
（先手のときに余計な1タップを増やさない）。

**ボタンは行として置かず、盤の上に半透明の幕として重ねる。**
最初は盤の下に普通の行として置いたが、押した瞬間にその行ごと消えて
**盤より下が57〜72pxせり上がる**（実測）。これは問題2そのものだった。
絶対配置なら出ても消えてもレイアウトは1pxも動かない。
幕は盤を透かす（配られた手札を見てから始められるように）。

2回戦目以降（「第n回戦へ」「次の月へ」）は、そのボタンを押すこと自体が
合図なので待たない。

## 2. 大きさを変えない

**原因は「条件付きで出し入れされる行」だった。** 盤そのものは動いていない。

守る約束：

- **`min-height` ではなく `height` で固定する。** `min-height` は下限しか
  決めないので、文言が1行から2行に増えた瞬間に伸びる。`line-height` を
  明示して「何行ぶん」で高さを決める（`.hint-row` が元からこの形）
- **毎局出るものは、条件付きで出し入れしない。** 終局の知らせは
  `.result-row` として常に置き、中身が無いときは空のまま高さだけ取る
- **毎局出ないものでも、現れると大きく動くなら最初から出す。** 戦績の帯
  （`RecordStrip`）は初めて1局を終えた瞬間に現れて盤を**139px**押し下げていた。
  空欄を確保するのではなく、0勝0敗0分を最初から見せることで解決した
  （場所も情報も無駄にならない）
- **増減する札置き場は上限を決めて固定する。** 花札の取り札は取るたびに伸び、
  手札は出すたびに縮む。取り札は2段ぶんで固定してあふれたら中でスクロール、
  手札は配りたて（8枚）のぶんで固定する。空きが目立つ取り札には
  「置き場」と分かる受け皿の下地を敷く

**`min-height` は書いた時点では気づけない。** 実装当初は1行に収まっていて、
文言を足したときに初めて2行になる。`.sp-msg` は「高さを固定する」という
コメント付きで `min-height` になっていた（意図と実装がずれていた実例）。
CSSに `min-height` を書きたくなったら、まず `height` で足りないか考えること。

対象クラス：`.df-msg` / `.sn-msg` / `.ss-msg` / `.hf-msg` / `.sp-msg`
（実況・手番の案内）、`.result-row`（終局・パスの知らせ）、`.hint-row`（既存）、
`.df-seat-state` / `.sn-seat-state`（席の状態）、`.df-flags`（革命・縛りの表示）、
`.hf-strip` / `.hf-hand`（花札の札置き場）。

## 3. CPUの速さ（`app/_cpu/CpuSpeed.tsx`）

ゆっくり／ふつう／はやいの3段階。元は大富豪と七並べが別々に持っていた。

**ゲームが決めるのは「ふつう」の遅延1つだけで、倍率は共通で持つ**
（`slow` 1.6倍 / `normal` 1倍 / `fast` 0.5倍）。ゲームごとに3つの数値を
置くと段階の比が揃わなくなるため。倍率は元の2ゲームの実測値から取った。

- **間を消す選択肢は作らない。** 0にすると何が起きたか分からないうちに
  自分の番が来る。いちばん速い「はやい」でも半分まで
- **速さを変えても配り直さない。** 見せ方の設定であってルールではないので、
  その場で効く（強さやローカルルールを変えたときは仕切り直す）
- 神経衰弱では**めくった札を見せる時間も一緒に動かす**。CPUの手番だけ
  速くしても、札が伏せられるのを待つ時間が変わらなければ体感は速くならない

「ふつう」の遅延（ms）：リバーシ420 / 五目並べ320 / 大富豪1300 /
七並べ1000 / 神経衰弱700（めくり見せ 当たり500・はずれ1000）/
花札750（めくり）・800（CPUの手）・600（取り札とこいこい）。

## やらないこと

- 速さをゲームごとにバラバラの段階数にしない（3段階で揃える）
- スピード（リアルタイムの面）はこの枠に入れない。手番の概念が無く、
  元から「はじめる」ボタンと強さ設定を持っている
