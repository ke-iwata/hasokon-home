# テスト環境のトップに、公開前のものも並べる

**状態**：実装済み（テスト環境のみ）。本番のHTMLは無改変
**対象**：`scripts/build-test-home.mjs` / `.github/workflows/deploy.yml`
**起票**：2026-09-05（運営者の「test環境だけは全部homeに出してほしい。
バッジみたいなので本番でないやつはわかるようにしておいてほしい」から）

## 何を解決するか

`tools` / `games` は `lib/registry.ts` の `stage` で公開を切り替えられる
（[feature-flags.md](./feature-flags.md)）。ところが **`home/` にはビルド工程が無く、
S3バケット直下にそのまま同期される**ので、`stage` が効かない。トップの一覧は手書きで、
公開前のものは載っていない。

そのため運営者が公開前のものをテスト環境で見るには、**slug を知っていてURLを直接打つ**
しかなかった。「いま何が未公開のまま溜まっているのか」もトップからは分からない。
公開前のものは**運営者が実機で見て公開を判断する**建て付け（ピンボールの係数確認など）
なので、その入口が無いのは効く。

## どうするか

**テスト環境に配るときだけ**、`home/index.html` に公開前のものを差し込む。

- `scripts/build-test-home.mjs` が registry を読み、`stage` が `public` 以外の
  エントリをトップの一覧に足す
- `.github/workflows/deploy.yml` の `if: ${{ !startsWith(github.ref, 'refs/tags/') }}`
  の枝で走る。**タグ（本番）のデプロイは通らない**
- 書き換えるのはCI上のチェックアウトだけ。リポジトリの `home/index.html` は
  公開中のものだけを載せた状態のまま

## 本番に漏れない仕掛け

このやり方の肝は、**本番のHTMLが1バイトも変わらない**ことにある。

未公開ページは `noindex` だが「見えない」わけではない（feature-flags.md の表）。
もし本番のトップから未公開ページへリンクすると、
「一覧・sitemap・llms.txt から外す」という建て付けと食い違う。
クローラーはリンクを辿るので、`noindex` でも**発見はされる**。

そのため `scripts/test/build-test-home.test.mjs` が2つを見張っている。

1. `home/index.html` に差し込み（`data-testenv-only`）が**commitされていない**こと
2. `home/index.html` が**未公開ページへのリンクを持たない**こと

うっかり生成結果をcommitする事故は、1で止まる。

## 画面の作り

- 未公開のカードは**枠を破線**にし、名前の後ろに「**本番未公開**」の印を付ける
- アイコンは公開中のカードとわざと違う**フラスコ**にしてある。
  印を読まなくても、一覧に混ざった状態で「試験中のもの」と分かるように
- `title` に `stage: preview` / `stage: wip` を入れてあるので、どちらの段階かも分かる
- ページの上に**テスト環境である旨の帯**を出す
- 印の文字は絞り込み（`home/find.js`）の対象にもなる。
  **「未公開」と打つと未公開のものだけが並ぶ**（`find.js` はカードの
  `textContent` を見ているので、特別な仕掛けは要らない）
- `.quicknav` の件数は、差し込んだあとのカードの枚数で数え直す
  （手書きの数字のままだと一覧と食い違う）

説明文は registry の `description` の**最初の1文**だけを採る。そのまま出すと
そのカードだけ背が高くなり、一覧の並びが崩れる（公開中のカードの説明は30文字前後）。

## やらないこと

- **`home/llms.txt` には足さない。** AIアシスタント向けの案内で、
  テスト環境はBasic認証の内側にあり読まれない。公開前のものを載せる意味がない
- **`home/404.html` には足さない。** もともと一覧を持っていない
- **本番でこのスクリプトを走らせない。** 公開は `stage` を上げるPRで行う
  （そのPRで `home/index.html` のカードと `home/llms.txt` の行を手で足す。
  この運用は変わらない）
