# 新ツール「文字数カウント」（テキスト系クラスタの定番・恒常需要）

**状態**：実装済み（2026-08-17。本番反映はタグリリース待ち）
**対象**：`tools/`（`hasokon.com/tools/mojisu-count/`）
**起票**：2026-08-17

---

## 背景と根拠

### 「文字数カウント」は無料ツール系サイトの最大級の定番で、当サイトに受け皿がない

「文字数 カウント」「文字数 数える」は、レポート・エントリーシート・
SNS投稿・ブログ執筆・Webライティングの現場で毎日発生する恒常需要で、
季節性がなく年間を通して安定して検索される（2026-08-17 Web調査）。
制度改正系ツールが持つ「施行日を過ぎると需要が落ちる」性質を補う、
非YMYLの安定した柱になりうる。

当サイトにはテキスト系ツールとして 全角半角変換（`hankaku-zenkaku`）・
ヘボン式ローマ字変換（`hebon-romaji`）があるが、テキスト系で最も検索される
文字数カウントが**存在しない**。この2本と相互リンクすることで
「テキスト処理ツール群」としてのトピッククラスタを形成できる。

### ヘッドキーワードは競合が強い。狙いは長い尾と回遊

「文字数カウント」単体は老舗の専用サイトが上位を占めており、
新規サイトが短期で1位を取れるキーワードではない。それでも提案する理由：

1. **長い尾が広い**：「原稿用紙 換算 何枚」「レポート 2000字 どれくらい」
   「X（Twitter）文字数 数え方」「小論文 文字数 数える」など、
   周辺クエリの裾野が非常に広い
2. **実装が最小級**：外部データ・法令根拠が不要で、純関数と
   1ページで完結する。当サイトの新ツールの中で最も工数が小さい部類
3. **回遊の入口**：文字数を数えに来た層（学生・ライター）は
   全角半角変換・ヘボン式ローマ字の利用者層と重なる

### 計測値（2026-08-17 取得）

- GSC（直近28日・hasokon.com）：サイト全体でクリック5・表示は少数。
  テキスト系では `hebon-romaji` がSEO強化済み（PR #66）だが、
  クラスタとしての面がまだ薄い
- GA4（直近14日）：`/tools/hankaku-zenkaku/` 5PV、`/hebon-romaji/` 5PV。
  テキスト系の入口が弱く、最大需要の受け皿から作る意義がある

## 提案する仕様

### 機能（すべてクライアントサイド。入力テキストは外部に送信しない）

1. **リアルタイムカウント**：テキストエリアに入力・貼り付けした瞬間に更新
   - 文字数（スペース・改行を**含む**／**含まない**の両方を常時表示）
   - 行数・段落数（空行区切り）
   - 全角・半角の内訳（`hankaku-zenkaku` の判定ロジックの知見を再利用）
   - バイト数（UTF-8）
2. **原稿用紙換算**：400字詰め原稿用紙で何枚か（小数1桁）。
   「20x20の升目に改行を反映した厳密計算」ではなく単純な文字数÷400とし、
   その旨をページに明記する（升目シミュレーションはスコープ外）
3. **目標文字数モード**：目標値（例：2000字）を入れると残り文字数と
   達成率を表示。ES・小論文・レポート用途を想定
4. **コピー・クリア**：結果の数値ではなく本文のコピーとクリアのみ。
   `trackToolUse('mojisu-count', action)` はコピー・クリア・
   目標設定の操作で送る
5. **プライバシーの明記**：「入力した文章はブラウザ内でのみ処理され、
   サーバーに送信されません」をツール直下に表示（このサイトの
   静的サイト構成がそのまま差別化になる）

### 数え方の約束（テストで固定する）

- 文字数は **コードポイント単位**（`Array.from(text).length`）。
  サロゲートペア（絵文字・𩸽など）を2文字と数えない
- 結合文字・異体字セレクタは仕様として深追いせず、コードポイント数で
  数えることをFAQに明記（Wordの文字数と食い違う理由もFAQで説明）
- 改行コードは CR/LF/CRLF を正規化してから数える

### 構成（tools/CLAUDE.md の追加手順どおり）

- `lib/mojisu-count.ts`：純関数（カウント本体・原稿用紙換算・目標判定）
- `tests/mojisu-count.test.ts`：絵文字・サロゲートペア・CRLF・空文字・
  全角半角混在の境界値を必ず入れる
- `app/mojisu-count/page.tsx`：解説（数え方の約束・Wordとの差）＋FAQ
  （「スペースは1文字?」「絵文字は?」「原稿用紙換算の考え方」
  「Xの文字数制限の数え方（半角0.5換算）との違い」）
- `app/mojisu-count/Calculator.tsx`：`'use client'`。テキストエリアと結果表示
- `lib/registry.ts`：カテゴリ「計算・変換」に追加

## 期待される効果

- テキスト系トピッククラスタ（文字数カウント・全角半角・ローマ字）の核が揃い、
  相互内部リンクで3ページとも評価が上がる
- 長い尾（原稿用紙換算・目標文字数系クエリ）での流入。ヘッドは長期戦
- 学生・ライター層という新しい利用者層の入口。リピート利用
  （ブックマーク・ホーム画面追加）が期待できる数少ないツール
