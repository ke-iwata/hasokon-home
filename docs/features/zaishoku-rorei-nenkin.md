# 在職老齢年金 計算機（令和8年4月の基準額引上げ対応）

**状態**：実装済み（2026-08-13）
**対象**：`tools/`（新規ツール `zaishoku-rorei-nenkin`）
**起票**：2026-08-13

---

## 背景と根拠

### なぜ今か：令和8年4月に基準額が 51万円 → 65万円 になった

令和7年年金制度改正法（**令和7年法律第74号**）により、令和8年4月から
在職老齢年金の支給停止調整額が **月51万円から月65万円**に引き上げられた。
賃金と老齢厚生年金の合計がこの額を超えると年金が減らされる、という基準である。

一次情報（いずれも 2026-08-13 に取得。更新日は 2026年4月1日）:

- 日本年金機構「在職老齢年金制度が改正されました」
  https://www.nenkin.go.jp/tokusetsu/zairoukaisei.html
- 日本年金機構「在職老齢年金の計算方法」
  https://www.nenkin.go.jp/service/jukyu/seido/roureinenkin/zaishoku/20150401-01.html

### 「62万円」と書いている記事が多い。これが最大の勝ち筋

改正の解説記事は **「62万円に引き上げ」** と書いているものが非常に多い。
検索で上位に出てくる社労士事務所・FP系メディアの記事もそうなっている。

**62万円は法律に書かれた令和6年度水準の額で、実際に適用される額ではない。**
支給停止調整額は毎年度、賃金の変動に応じて改定される。名目賃金変動率を織り込んだ結果、
**令和8年度に実際に使われる額は65万円**である。日本年金機構の解説にもこう書かれている。

> 令和7年年金制度改正法（令和7年法律第74号）に基づき、令和8年4月から、
> 年金が減額になる基準額（賃金と老齢厚生年金の合計）が月51万円から
> **65万円**に引き上げられました。
>
> ※4 **令和8年度の基準額**で、毎年度、賃金の変動に応じて改定されます。

62万円で計算すると、合計が62万〜65万円に入る人について
**「年金が減る」と誤って表示される。**その帯の人は実際には全額支給である。
3万円ぶんの帯で結論が逆になるので、実害のある間違いになる。

**「62万円ではなく65万円です」と正面から書いてあるページは、この題材で強い。**
改正の解説記事が多いということは検索需要があるということで、
そのうえで多数が数字を間違えているなら、正確なツールが入る余地がある。

### 計測値：このサイトに年金のツールが1本も無い（2026-08-13 取得）

`tools/lib/registry.ts` の16本を分類すると、「お金・社会保険」は6本ある。

| slug | 扱う制度 |
|---|---|
| `kosodate-shienkin` | 子ども・子育て支援金 |
| `furusato-nozei` | ふるさと納税（所得税・住民税） |
| `nenshu-kabe` | 年収の壁（税・社会保険） |
| `hatarakizon` | 社会保険の加入と手取り |
| `shobyo-teate` | 健康保険（傷病手当金） |
| `nenmatsu-chosei` | 年末調整（所得税） |

**年金の給付を扱うものは1本も無い。**現役世代の「払う側」の計算は揃っているが、
「もらう側」が空いている。在職老齢年金は**その2つの境目にいる人の話**
（働いて厚生年金を払いながら、老齢厚生年金を受け取る60歳以上）なので、
既存の6本と地続きで、いちばん近いところにある空白である。

Search Analytics API で見た直近の実績（2026-07-17〜2026-08-11、`dataState: all`）では、
社会保険まわりのクエリはこの2件しか拾えていない。

| クエリ | 表示 | クリック | 掲載順位 | 着地ページ |
|---|---|---|---|---|
| `年収の壁 2026 早見表` | 1 | 1 | 100.0 | `/nenshu-kabe/` |
| `傷病手当計算` | 1 | 0 | 28.0 | `/shobyo-teate/` |

**この題材で既に取れているクエリは無い**（ゼロからの積み上げになる）。
ドメイン統合から5日で全体の表示回数が371回しかないため、
「既存クエリの取りこぼし」を根拠にできる段階に無い。
そのため本提案の根拠は**制度改正の新しさと、競合の数字の誤り**に置いている。

## 現状

`/tools/` に在職老齢年金を扱うページが無い。
「働きながら年金をもらうと、いくら止まるのか」を計算する手段が無い。

隣接する `hatarakizon`（社会保険 損得計算機）は、
**社会保険に加入していない人が加入すると手取りがどう変わるか**を扱っている。
在職老齢年金は**すでに加入していて年金も受け取っている人**の話なので、
入力も出力も対象年齢も別で、既存ツールに機能を足して済ませられるものではない。

## 提案する仕様

### 計算ロジック（一次情報のとおり）

```
基本月額       = 加給年金額を除いた老齢厚生年金（報酬比例部分）の月額
総報酬月額相当額 = その月の標準報酬月額 + （その月以前1年間の標準賞与額の合計 ÷ 12）

合計 = 基本月額 + 総報酬月額相当額

合計 ≤ 支給停止調整額         → 全額支給
合計 >  支給停止調整額         → 基本月額 －（合計 － 支給停止調整額）÷ 2
```

支給停止調整額は年度ごとに持つ。**令和8年度＝650,000円 / 令和7年度以前＝510,000円。**
毎年度改定されるので、定数は年度をキーにした表で持ち、
更新箇所であることをコメントで明示する（`shaho-grades.ts` と同じ流儀）。

必ず守る境界条件（すべて一次情報に明記されている）:

1. **年金支給月額がマイナスになる場合は、老齢厚生年金（加給年金額を含む）は全額支給停止。**
   マイナスを表示しない
2. **老齢基礎年金と経過的加算額は調整の対象外で、全額支給される。**
   これを混ぜると答えが大きく狂う。入力を分けて、画面上も分けて出す
3. **加給年金額は基本月額に含めない。** ただし全部支給停止のときは加給年金額も止まる
4. **70歳以上も在職支給停止は行われる。** ただし厚生年金の被保険者ではないので
   保険料負担は無い（70歳以上は「標準報酬月額に相当する額」で見る）
5. **厚生年金基金の加入期間がある場合**は代行部分を国が支払うべき年金額とみなして
   基本月額を算出する。ツールでは注記に留める（利用者が代行部分の額を把握していない）

### 入力

| 項目 | 備考 |
|---|---|
| 老齢厚生年金の年額（報酬比例部分） | 加給年金額を除く。÷12 して基本月額にする |
| 標準報酬月額 | 月給からの自動判定と直接入力の両方。`shaho-grades.ts` の `pensionStandardMonthly()` を使う |
| 直近1年間の賞与の合計 | ÷12 して総報酬月額相当額に足す。0円も普通にある |
| 年度 | 令和8年度（65万円）／令和7年度以前（51万円）。**既定は令和8年度** |
| 老齢基礎年金の年額 | 任意。入れると「止まらない分」を含めた受取総額が出せる |

### 出力

1. **調整後の年金支給月額**（＝いくらもらえるか）と**支給停止額**（＝いくら止まるか）
2. **改正前（51万円）との比較。** 「改正前なら○円止まっていたが、いまは○円」。
   一次情報の例（基本月額10万円・総報酬月額相当額46万円 → 改正前は2.5万円停止、
   改正後は全額支給）がそのまま出ることをテストで固定する
3. **あと何円稼ぐと止まり始めるか**（＝65万円までの余裕）。
   全額支給の人にはこれが一番知りたい数字になる
4. **老齢基礎年金を足した合計の受取月額。** 「止まるのは厚生年金の一部だけ」と示す

## やらないこと

- **老齢厚生年金の額そのものを計算する**

  報酬比例部分の額は、全期間の標準報酬月額の履歴と加入月数から決まる。
  利用者が入力できる情報ではなく、ねんきん定期便やねんきんネットに書いてある。
  **「年金額は定期便の数字を入れてください」という設計にする。**
  ここを推計にすると、答えの精度がその推計の精度に引きずられる。

- **令和4年3月以前の65歳未満の計算式（28万円・47万円の4分岐）を載せる**

  一次情報には残っているが、4年以上前の話で、いま計算する人はいない。
  分岐が4つ増えて画面も複雑になる。**改正前（51万円）との比較だけ持つ。**

- **厚生年金の標準報酬月額の上限引上げを織り込む**

  令和9年9月から上限が段階的に引き上げられるという情報があるが、
  **一次情報での裏取りができていない**（確認できたのは社労士事務所の記事のみ）。
  現時点では `shaho-grades.ts` の 650,000円 のままにする。
  上限が動くと総報酬月額相当額の上限も動くので、
  **改定が近づいたら官報・厚生労働省の資料で確認してから `shaho-grades.ts` を直す**
  （1箇所直せば支援金・傷病手当金・働き損・このツールの4本に効く）。

- **共済組合等からの老齢厚生年金との合算**

  一次情報では、共済組合等からも受け取っている場合は全ての老齢厚生年金を
  合わせた額で判定し、支給停止の総額をそれぞれの年金額に応じて割り振るとされている。
  該当者は限られ、割り振りの説明で画面が重くなる。
  **注記で「合算して判定される」ことだけ伝え、計算は単一の年金前提にする。**

- **在職定時改定・退職改定による年金額の増加を反映する**

  9月1日基準で翌10月分から年金額が見直される制度だが、
  増える額は加入期間と報酬によるので、このツールの入力からは出せない。
  **FAQで「毎年10月に年金額が見直される」ことに触れるだけにする。**
