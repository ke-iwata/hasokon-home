## 背景と根拠

### 「増えるの？増えないの？」の混乱が大きい新税なのに、計算ツールがない

- 令和8年度税制改正で**防衛特別所得税**が創設された。**令和9年（2027年）分以後**、
  基準所得税額 × 1% を付加する。同時に**復興特別所得税を 2.1% → 1.1% に引き下げ**、
  課税期間を令和19年（2037年）まで → **令和29年（2047年）まで10年延長**する。
  **防衛特別所得税自体の課税期間は「令和9年以後の当分の間」で、終期の定めがない**
- 一次情報：
  - 国税庁「防衛特別所得税及び復興特別所得税（源泉徴収関係）Q&A」（令和8年5月）
    https://www.nta.go.jp/publication/pamph/pdf/0026005-024_03.pdf
  - 財務省・令和8年度税制改正の大綱（6/9・防衛関係）
    https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_06.htm
    （大綱は閣議決定であって条文ではない。**根拠として最終的に引くのは
    改正法とQ&A**とし、改正法の法律番号は実装時に特定して
    ソース冒頭コメントに記載する。年収の壁ツールで法律番号まで
    特定している作法に揃える）
- 単年の付加税率は計 2.1%（所得税率 × 102.1%）で改正前後とも変わらず、
  **2027年の手取りは実質変わらない**。一方で、改正前なら課税が終わっていた
  **2038年以降の負担が新たに生じ、しかも防衛特別分には終わりの定めがない**。
  この「増えるようで当面増えない、でも将来はずっと増える」という構造が
  誤解を生んでおり、税理士事務所の解説記事は多数出ている一方、
  **2026-08-20 の調査では入力型の計算ツール・年収別早見表は見当たらなかった**
  （競合ほぼゼロ）
- 給与の**源泉徴収は 2027年1月支払分から新税額表**に切り替わるため、
  2026年末〜2027年初に「給与明細が変わるのか」の検索が立つ。
  さらに 2027年秋の年末調整・2028年春の確定申告と、**検索の山が3回来る**テーマ

### 当サイトの資産と噛み合う

- `tools/lib` には令和8年分の所得税速算表・給与所得控除・基礎控除・
  社会保険料概算の部品が揃っている（ふるさと納税・年末調整で実装済み）。
  **年収 → 所得税額の計算を再利用**でき、量産型サイトが苦手な
  「改正が他制度へ波及する効果」まで正確に出せる
- 「たばこ税」「酒税」「年収の壁」と同じく**改正起点×早見表**の型で、
  当サイトの勝ちパターンに乗る

## 提案する仕様

1. **入力**：年収（給与収入）だけの1入力を基本に、扶養・iDeCo等は
   任意の詳細入力（初版は年収＋扶養人数まで）
2. **出力**
   - **防衛特別所得税の年額**（基準所得税額 × 1%）
   - **2027年の手取り変化**：復興特別 2.1%→1.1% との相殺で
     **「差し引きゼロ」を金額で可視化**（このツールの一番の答え）
   - **2038〜2047年の累計追加負担**：改正前なら課税が終わっていた期間の
     復興特別 1.1% ＋ 防衛特別 1% の10年分合計。
     **この額は下限であることを必ず併記する**——防衛特別所得税は
     「当分の間」とされ終期の定めがないため、**2048年以降も1%が続く**。
     「10年で終わる」と読める見せ方にしない
   - 計算過程（給与所得控除 → 課税所得 → 所得税 → **税額控除 → 基準所得税額**）を
     開ける形で表示
3. **基準所得税額の定義を実装前に確定する**：基準所得税額は
   **住宅ローン控除等の税額控除を差し引いたあと**の所得税額が基礎になる。
   つまり住宅ローン控除がある人は防衛特別所得税も小さくなる（解説記事が
   あまり触れていない、実務で効く差別化点）。定義の細部（外国税額控除等の扱い）は
   上記Q&Aで裏を取り、**復興特別と防衛特別で基準所得税額の定義が同一かどうかも
   Q&Aで確認する**（同一でなければ「差し引きゼロ」の看板が一部の人で崩れるため、
   確認そのものを実装の前提とする）。初版の入力は年収＋扶養人数に絞るので、
   結果には**「住宅ローン控除等がある場合、実際の税額はこれより少なくなる」**旨を添える
4. **年収別早見表**：300万〜1,500万円の代表年収で
   「防衛特別所得税／2027年の手取り変化／2038年以降の年間負担」を静的に置き、
   「防衛増税 いくら」系のクエリを受ける。
   **表の作りは既存の早見表ツール（たばこ税・酒税・最低賃金）に揃える**
   （モバイル幅での見せ方・CSSを新設しない）
5. **解説・FAQ**：「2027年1月から給与明細はどう変わるか」（源泉徴収税額表の
   切り替え。合計 102.1% で改正前後とも不変であることを税額表で確認して書く）、
   「なぜ手取りが変わらないのか」、「実際に負担が増えるのは誰か・いつか」、
   **「防衛特別所得税には終期の定めがない（当分の間）」**をFAQで明文化。
   たばこ税（防衛財源のもう1本）ツールと相互リンク
6. **施行日またぎの表示**：2026年内に公開して2027年1月施行なので、
   「今」と「2027年1月以降」で表示が変わる。
   **`lib/nenshu-kabe.ts` の `effectiveFrom`/`effectiveUntil` と `asOf` の方式に
   揃える**（静的書き出しなのでビルド時刻で固定せず、`Calculator.tsx` は
   ビルド時刻を初期値にしてマウント後に現在日へ差し替える。既存パターンに
   従い、自己流の日付切り替えを作らない）。
   **切替日の値そのものは `tools/lib/tedori-keisan.ts` の `WITHHOLDING_TABLE_EFFECTIVE_ON`（2027-01-01）と
   `REFORM_EFFECTIVE_ON`（2026-12-01）を参照し、このツールで日付を二重に持たない**
   （切替の仕組みは nenshu-kabe 方式、日付の値は tedori-keisan の定数、という分担）
7. **ページ構成**：既存ツールと同じ
   （metadata / `robots: robotsFor('boei-tokubetsu-shotokuzei')` /
   JSON-LD(WebApplication+FAQPage+BreadcrumbList) / パンくず / 使い方 /
   計算式と法的根拠 / FAQ / AdUnit / 関連ツール）。
   registry へは `stage: 'preview'`・カテゴリ「お金・社会保険」で追加
8. **計算ロジック**：`tools/lib/boei-tokubetsu-shotokuzei.ts` の純関数。
   既存の所得税部品を再利用し、境界値（課税所得ゼロ近辺・速算表の段差・
   税額控除で基準所得税額がゼロになる場合）を単体テストで固定。
   **令和9年分 源泉徴収税額表の公開後に着手し、代表ケースを税額表と
   突き合わせるテストを含める**
9. **データ更新箇所の明記**：ソースコード冒頭に【データ更新箇所】として、
   一次情報（上記の国税庁Q&A＋改正法。法律番号は実装時に特定して記載）と、
   税率・開始年など改正で動き得る定数の置き場所を書く（失業保険と同じ作法）

## やらないこと

- **法人税・たばこ税を含む「防衛増税3点セット」の合算シミュレーション**
  （法人税は個人の検索意図と違う。たばこ税は既存ツールへのリンクで足りる）
- **住民税・社会保険まで含めた完全な手取り計算**（別提案の「手取り計算」の領分。
  ここは「防衛特別所得税でいくら変わるか」に絞る）
- **2037年以前の復興特別所得税の申告計算**（既存の確定申告ツール群の領分）

## 期待される効果

- 「防衛増税 いつから いくら」「防衛特別所得税 計算」「2027年 所得税 増える」
  「復興特別所得税 延長」等の新税クエリを**競合不在のうちに**押さえる。
  源泉切替（2027年1月）・年末調整・確定申告と検索の山が3回来るため、
  2026年内に公開しておく価値が高い

  実践枠。量産型サイトが追いつく前の先行者利益を取る。
  **「2027年の手取りは変わりません」と正直に答えること自体が最大の差別化**
- 効果は GSC の表示・掲載順位（`tools/boei-tokubetsu-shotokuzei/`）で計測
