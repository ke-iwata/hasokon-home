# 新ツール「防衛特別所得税 計算機・早見表」（2027年1月開始・競合ツール不在）

**状態**：提案（2026-08-20起票、未実装）
**対象**：`tools/`（`hasokon.com/tools/boei-tokubetsu-shotokuzei/` を想定）
**起票**：2026-08-20

---

## 背景と根拠

### 「増えるの？増えないの？」の混乱が大きい新税なのに、計算ツールがない

- 令和8年度税制改正で**防衛特別所得税**が創設された。**令和9年（2027年）分以後**、
  基準所得税額 × 1% を付加する。同時に**復興特別所得税を 2.1% → 1.1% に引き下げ**、
  課税期間を 2037年末 → **2047年末まで10年延長**する
  （一次情報：財務省・令和8年度税制改正の大綱
  https://www.mof.go.jp/tax_policy/tax_reform/outline/fy2026/08taikou_06.htm ）
- つまり単年の付加税率は計 2.1% で変わらず、**2027年の手取りは実質変わらない**が、
  **2038〜2047年の10年分の負担が新たに延びる**。この「増えるようで当面増えない、
  でも将来は増える」という構造が誤解を生んでおり、税理士事務所の解説記事は
  多数出ている一方、**2026-08-20 の調査では入力型の計算ツール・年収別早見表は
  見当たらなかった**（競合ほぼゼロ）
- 給与の**源泉徴収は 2027年1月支払分から新税額表**に切り替わるため、
  2026年末〜2027年初に「給与明細が変わるのか」の検索が立つ。
  さらに 2027年秋の年末調整・2028年春の確定申告と、**検索の山が3回来る**テーマ

### 当サイトの資産と噛み合う

- `tools/lib` には令和8年分の所得税速算表・給与所得控除・基礎控除・
  社会保険料概算の部品が揃っている（ふるさと納税・年末調整で実装済み）。
  **年収 → 基準所得税額の計算を再利用**でき、量産型サイトが苦手な
  「改正が他制度へ波及する効果」まで正確に出せる
- 「たばこ税」「酒税」「年収の壁」と同じく**改正起点×早見表**の型で、
  当サイトの勝ちパターンに乗る

## 提案する仕様

1. **入力**：年収（給与収入）だけの1入力を基本に、扶養・iDeCo等は
   任意の詳細入力（初版は年収＋扶養人数まで）
2. **出力**
   - **防衛特別所得税の年額**（基準所得税額 × 1%）
   - **2027年の手取り変化**：復興特別 2.1%→1.1% との相殺で
     **「差し引きゼロ」を金額で可視化**（このツールの一番の答え）
   - **2038〜2047年の累計追加負担**：改正前なら課税が終わっていた期間の
     復興特別 1.1% ＋ 防衛特別 1% の10年分合計
   - 計算過程（給与所得控除 → 課税所得 → 所得税 → 基準所得税額）を開ける形で表示
3. **年収別早見表**：300万〜1,500万円の代表年収で
   「防衛特別所得税／2027年の手取り変化／2038年以降の年間負担」を静的に置き、
   「防衛増税 いくら」系のクエリを受ける
4. **解説**：「2027年1月から給与明細はどう変わるか」（源泉徴収税額表の
   切り替え）、「なぜ手取りが変わらないのか」、「実際に負担が増えるのは誰か・いつか」
   をFAQで明文化。**たばこ税（防衛財源のもう1本）ツールと相互リンク**
5. **ページ構成**：既存ツールと同じ
   （metadata / `robots: robotsFor('boei-tokubetsu-shotokuzei')` /
   JSON-LD(WebApplication+FAQPage+BreadcrumbList) / パンくず / 使い方 /
   計算式と法的根拠 / FAQ / AdUnit / 関連ツール）。
   registry へは `stage: 'preview'`・カテゴリ「お金・社会保険」で追加
6. **計算ロジック**：`tools/lib/boei-tokubetsu-shotokuzei.ts` の純関数。
   既存の所得税部品を再利用し、境界値（課税所得ゼロ近辺・速算表の段差）を
   単体テストで固定
7. **データ更新箇所の明記**：税率・開始年は法改正で動き得るため、
   ソースコード冒頭に一次情報URLと【データ更新箇所】を書く（失業保険と同じ作法）

## やらないこと

- **法人税・たばこ税を含む「防衛増税3点セット」の合算シミュレーション**
  （法人税は個人の検索意図と違う。たばこ税は既存ツールへのリンクで足りる）
- **住民税・社会保険まで含めた完全な手取り計算**（別提案の「手取り計算」の領分。
  ここは「防衛特別所得税でいくら変わるか」に絞る）
- **2037年以前の復興特別所得税の申告計算**（既存の確定申告ツール群の領分）

## 期待される効果

- 「防衛増税 いつから いくら」「防衛特別所得税 計算」「2027年 所得税 増える」
  「復興特別所得税 延長」等の新税クエリを**競合不在のうちに**押さえる。
  源泉切替（2027年1月）・年末調整・確定申告と検索の山が3回来るため、
  2026年内に公開しておく価値が高い
- 「新制度の開始前にツールを置く」という当サイトの戦略（CONCEPT.md）の
  実践枠。量産型サイトが追いつく前の先行者利益を取る
- 効果は GSC の表示・掲載順位（`tools/boei-tokubetsu-shotokuzei/`）で計測
