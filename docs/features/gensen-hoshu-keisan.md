### 2027-01-01 から内訳が変わる（合計の率は変わらない）

国税庁「令和9年分 源泉徴収税額表」の説明（https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2027/data/00.pdf 、2026-11-25 確認）：

- **令和9年1月1日以後に生ずる所得**について、所得税を源泉徴収するときに**防衛特別所得税（所得税の額の1%）**を併せて徴収する
- **復興特別所得税は 2.1% → 1.1%** に下がり、課税期間は令和29年12月31日まで延びる
- **合計（2.1%）は変わらない**

このため報酬・料金の源泉は**2027年以降も 10.21%（100万円超の部分は 20.42%）のまま**だが、
「復興特別所得税を含めて10.21%」という定番の説明は**内訳が違う**ことになる。請求書・支払調書の注記を書き直す人が調べる。
**実装PR では、国税庁「源泉徴収のあらまし（令和9年版）」の報酬・料金の章で 10.21% / 20.42% の記載を確かめてから載せる**
（2026-11-25 の検索では、給与の税額表の説明までしか一次情報で確認できていない）。

### 世の中の競合（2026-11-25 の Web 調査）

「源泉徴収 計算 報酬」の上位は、会計ソフト各社と税理士事務所の解説記事、keisan 系の汎用電卓。
**税込・税抜の切り替え、100万円超の2段階、逆算（手取りから請求額）を1画面で全部やるもの**は少なく、
**2027年からの内訳（防衛特別所得税）に触れた計算機は見当たらなかった**。

当サイトに無い理由は単に未着手で、既存の `boei-tokubetsu-shotokuzei`（給与）が同じ改正を扱っている。報酬の側が空いている。

## 提案する仕様

### 根拠条文（実装PR で e-Gov で条番号を確かめてから本文に載せる）

| 内容 | 根拠 |
|---|---|
| 報酬・料金の源泉徴収（原稿料・講演料・デザイン料・弁護士・税理士等） | 所得税法 204条1項 |
| 税率 10%、同一人に1回に支払う額が100万円を超える部分は 20% | 所得税法 205条1号 |
| 司法書士・土地家屋調査士・海事代理士は「1回の支払額 − 1万円」に 10% | 所得税法 205条2号、所得税法施行令 322条 |
| 復興特別所得税（基準所得税額の2.1%。2027年以後は1.1%） | 東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法 |
| 防衛特別所得税（2027年以後、基準所得税額の1%） | 令和7年度・8年度の税制改正（[boei-tokubetsu-shotokuzei.md](./boei-tokubetsu-shotokuzei.md) の根拠をそのまま使う） |
| 請求書で報酬と消費税を区分していれば税抜額に源泉してよい | 国税庁 タックスアンサー No.2795（平成元年 直法6-1） |
| 1円未満の端数は切り捨て | 国税通則法 119条 |

### 入力

- **計算の向き**（タブ）：「請求額から」／「手取り（振込額）から」
- **金額**（円・整数）
- **消費税**：「税抜で入れる（消費税を別に足す）」／「税込で入れる（区分して書いてある）」／「税込で入れる（区分していない）」
  - 区分していない場合は**税込額に源泉**（No.2795 のとおり）。差が出ることを結果の下に1行で出す
- **消費税率**：10%（既定）／8%
- **支払う相手**：「ふつうの報酬（原稿料・講演料・デザイン料・士業など）」（既定）／「司法書士・土地家屋調査士・海事代理士」
- **支払う年**：2026年（既定は今日の日付から自動）／2027年以降 — **税額は同じ**で、内訳の表示だけが変わる

### 出力

- **源泉徴収税額**（大きく）
- **差引の振込額**（請求額 ＋ 消費税 − 源泉徴収税額）
- **計算の式**：「(1,000,000 × 10.21%) ＋ (200,000 × 20.42%) ＝ 102,100 ＋ 40,840 ＝ 142,940円」のように実際の数字で
- **内訳**：2026年まで「所得税 ◯円・復興特別所得税 ◯円」／2027年以降「所得税 ◯円・防衛特別所得税 ◯円・復興特別所得税 ◯円」
  - 内訳の分け方は**参考表示**（納付は合計で行う）と明記する。端数の寄せ方は実装PRで国税庁の説明に合わせる
- **請求書の書き方の例**（コピーボタンつき）：報酬・消費税・小計・源泉徴収税額・差引請求額の5行
- 「手取りから」のときは、**その手取りになる請求額**と、1円ずれる境目がある場合はその旨

### ロジック（`tools/lib/gensen-hoshu.ts`。純関数のみ）

- `withholding(base, kind)`：
  - ふつう：`base <= 1_000_000 ? floor(base × 0.1021) : floor((base − 1_000_000) × 0.2042 + 102_100)`
  - 司法書士等：`floor(max(0, base − 10_000) × 0.1021)`
  - 浮動小数の誤差を避けるため**整数演算（×10000 してから割る）**で行う
- `fromNet(net, opts)`：振込額から請求額を求める。式の逆算で目星をつけ、前後数円を `withholding` で確かめて**最小の請求額**を返す（切り捨てで同じ手取りになる額が2つ出ることがある）
- `breakdown(total, year)`：参考の内訳
- 係数は `boei-tokubetsu-shotokuzei` と同じく **1.021 を改正前後で共有**する

### テスト（`tools/tests/gensen-hoshu.test.ts`）

- 10万円 → 10,210円、100万円 → 102,100円、120万円 → 142,940円、99,999円 → 10,209円（切り捨て）
- 税抜11万円（税込121,000円・区分あり）→ 源泉 11,231円 ／ 区分なし → 12,354円
- 司法書士 5万円 → 4,084円、1万円 → 0円
- `fromNet` で、任意の請求額 g に対し `fromNet(g + tax(g) − withholding(g)) <= g` かつ同じ振込額になる（1〜300万円を乱数で1,000本）
- 2027年の内訳の合計が2026年の合計と一致する
- ページの `metadata` に `robots: robotsFor('gensen-hoshu')`（既存の `stage.test.ts` が見る）

### 本文（[thin-tool-content.md](./thin-tool-content.md) の型）

- 「源泉徴収が必要な報酬・不要な報酬」（個人に払う場合だけ。法人への支払いは原則不要／支払う側が源泉徴収義務者でない個人なら不要）
- 「100万円を超えると 20.42%」「消費税を分けて書くと源泉が減る」
- 「2027年1月から何が変わるか — 率は同じ、内訳が変わる」
