# 新ゲーム「神経衰弱」（トランプ基盤の再利用で低コスト・定番の面を埋める）

**状態**：提案（2026-08-14起票、未実装）
**対象**：`games/`（`hasokon.com/games/shinkei-suijaku/`）
**起票**：2026-08-14

---

## 背景と根拠

### トランプ定番ゲームの「面」であと1枚欠けているのが神経衰弱

当サイトは ソリティア／スパイダー／フリーセル／大富豪／七並べ と
トランプゲームを揃えてきた。神経衰弱は
「トランプ ゲーム 無料」系の検索で必ず名前が挙がる定番でありながら未提供。
アプリ紹介サイトが「2026年おすすめ神経衰弱アプリ」記事を出し続ける程度には
恒常需要があり（2026-08-14 Web調査）、子ども・家族層にも届く
権利関係的に無害な題材。

### 実装コストが極端に低い

- カード描画は `games/app/_cards/CardView.tsx`（SVG自前描画）をそのまま再利用
- 山札・シャッフルは `lib/cards` の既存ロジックを再利用
- 成績保存は `_records`（ゲーム成績）基盤に乗せるだけ
- ドラッグ操作が不要（タップでめくるだけ）なので、
  スマホ対応で悩む要素がほぼない

既存基盤の再利用率が全ゲーム中もっとも高く、
**1ゲーム追加の限界コストが最小**の案件。

## 提案する仕様

1. **モード**
   - ひとりで：全ペア発見までの手数とタイムを計測（タイムアタック）
   - CPU対戦：交互にめくり、ペア獲得数で勝負。ペアを当てたら連続手番
     （標準ルール）
2. **難易度**
   - 枚数：12枚（6組）／20枚（10組）／28枚（14組）／52枚（26組）
   - CPUの強さ：弱／普通／強 — 公開済みカードを覚えている確率で表現
     （弱=30%・普通=60%・強=90%程度。完全記憶にしないことで理不尽さを避ける）
3. **UI/UX**
   - タップでめくる → 2枚目が不一致なら約1秒見せて裏返す
     （待ち時間は画面タップで短縮可）
   - めくった枚数・ペア数・経過時間を常時表示。ベスト記録は `_records` に保存
   - iOSの文字自動拡大・枠はみ出し対策は既存ゲームの教訓
     （game-shichinarabe.md 参照）を踏襲
4. **SEO**：既存ゲームと同じく VideoGame + FAQPage + BreadcrumbList の
   jsonLd、ルール・コツ・FAQの本文を最初から同梱。
   `llms.txt`・`sitemap`・home の一覧・registry への追加も同PRで行う

### やらないこと

- オンライン対戦・2人プレイ（同一端末での交互プレイはCPU対戦で代替）
- 絵札のテーマ替え（イラスト差し替え）。SVGトランプ1種で開始する

## 期待される効果

- 「神経衰弱 無料」「神経衰弱 ブラウザ」系の検索流入。
  競合は古いFlash移植系サイトが多く、スマホUIの質で差別化できる
- トランプ系ゲームの回遊導線が強くなる（相互リンク網の完成度向上）
- 子ども・家族層の獲得。滞在時間が長いゲーム群（2048で平均697秒/セッション
  という実測がある）はAdSense収益にも寄与
