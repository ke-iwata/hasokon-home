# 新ツール「養育費計算ツール」（2026年4月施行の改正民法・法定養育費対応）

**状態**：提案（2026-08-14起票、未実装）
**対象**：`tools/`（`hasokon.com/tools/yoikuhi-keisan/`）
**起票**：2026-08-14

---

## 背景と根拠

### 2026年4月に家族法が70年ぶりに大改正され、養育費の検索需要が構造的に増えた

民法等の一部を改正する法律（**令和6年法律第33号**、2024年5月成立）が
**2026年（令和8年）4月1日**に施行され、離婚後の**共同親権**の選択が可能になった。
同時に、養育費の取り決めをせずに離婚した場合でも一定額を請求できる
**法定養育費**（子1人あたり**月2万円**・法務省令で規定）と、
養育費債権への**先取特権**（差押えを容易にする）が新設された。

- 施行が2026年4月のため、2026年は制度解説・計算ニーズが恒常的に発生している
  （「養育費 計算」「養育費 相場」「法定養育費」「共同親権 養育費」等）
- 大手法律事務所（デイライト・アディーレ・ベリーベスト等）が
  「2026年版」を掲げて計算ツールを相次いで更新しており、需要の裏付けがある
  （2026-08-14 Web調査）

### 競合はほぼ全て弁護士事務所のリード獲得ページ

既存の計算ツールは法律事務所の集客ページが中心で、
入力後に相談誘導が挟まるものが多い。当サイトは
**中立・登録不要・広告のみ**で完結する点で差別化できる。
「年収の壁」「在職老齢年金」「傷病手当金」と同じ
**制度改正×計算機**というサイトの柱にそのまま乗る案件でもある。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **算定表ベースの月額目安計算**
   - 入力：支払う側・受け取る側それぞれの年収（給与収入／自営収入の別）、
     子の人数（1〜3人）と各年齢帯（0〜14歳／15歳以上）
   - 出力：裁判所の**標準算定方式（令和元年12月改定）**による月額の目安と、
     算定表の該当レンジ（例「4〜6万円」）
   - 計算は表のルックアップではなく標準算定方式で実装する：
     基礎収入（総収入×基礎収入割合）→ 生活費指数（親100・0〜14歳62・15歳以上85）
     で子に充てられる生活費を按分 → 義務者・権利者の基礎収入比で分担
2. **法定養育費の解説ブロック**：取り決めなしで離婚した場合の
   子1人あたり月2万円（法務省令）、先取特権、
   「あくまで暫定額であり算定表による取り決めが原則」という位置づけ。
   次の2点は誤解が生じやすいため、**それぞれ独立した見出し（または強調表示）で**明記する：
   - **適用は2026年4月1日以降に成立した離婚のみ（遡及適用なし）**。
     施行前に離婚が成立している場合は法定養育費の対象外
   - **先取特権には上限がある**：先取特権が及ぶのは
     **子1人あたり月額8万円まで**（法務省令で定める標準額の範囲内）。
     協議・審判で定めた養育費の全額が差押えの対象になるわけではない
3. **FAQ**：「共同親権だと養育費は不要？（不要にはならない）」
   「再婚したら？」「いつまで払う？（原則18歳〜、取り決めで22歳等）」
   「取り決めなしで離婚してしまったら？（法定養育費。
   ただし2026年4月1日より前に成立した離婚には適用されない）」
   「先取特権で全額差し押さえられる？（上限は子1人あたり月8万円）」など。
   FAQ内には一次情報の**具体的なURL**（法務省の改正解説ページ・
   裁判所の標準算定方式/算定表PDF）を明記する
4. 免責：目安の提示であり、実際の金額は協議・調停・審判で決まる旨を、
   **計算結果の直下（キャプションやアラート等、必ず目に入る位置）に固定表示**する。
   ページ末尾に一度書くだけの形にはしない

### データの持ち方

`lib/yoikuhi.ts` に基礎収入割合テーブル・生活費指数・法定養育費額・
先取特権の上限額を**【データ更新箇所】**コメント付きで集約。

**実装着手時の再確認を必須とする**：法定養育費の金額（月2万円）・
先取特権の上限（月8万円）はいずれも法務省令への委任事項であり、
本提案は起票時点（2026-08-14のWeb調査）の情報に基づく。
実装を始める時点で、法務省の改正解説ページと裁判所の公表資料
（省令の内容・算定表の最新版）を必ず突き合わせ直し、
数値が変わっていればデータとこの仕様書を先に更新する。
テストは裁判所公表の算定表と突き合わせた代表ケース
（例：義務者給与500万・権利者給与100万・子1人0〜14歳 → 4〜6万円の枠）を
複数持ち、方式の実装が表とずれていないことを保証する。

### やらないこと

- 婚姻費用（別居中の生活費）の計算。別ツールの領域
- 年収2,000万円超・子4人以上など算定表の範囲外は
  「調停・弁護士相談の領域」と明示して計算しない
- 弁護士紹介・相談誘導の類い（中立性が差別化点のため）

## 期待される効果

- 「養育費 計算」系の恒常的な検索需要の獲得。制度改正年（2026）は
  解説記事の更新が活発＝検索も活発で、参入タイミングとして適切
- 既存の家計系ツール（年収の壁・児童手当関連の子育て支援金・高校無償化）
  との内部リンクで、ライフイベント系クラスタの網羅性が上がる
- YMYLだが、当サイトは既に税・社会保険ツールを多数持ち、
  一次情報リンク＋免責の運用が確立している
