**対象**：`tools/app/ToolArt.tsx` / `games/app/GameIcon.tsx`（`BOARD`）/
`tools/app/globals.css` / `games/app/globals.css` / `home/index.html` /
`scripts/sync-home-card-art.mjs`
**起票**：2026-09-29（運営者の「機能が増えてきたのでパット見でどういったものなのかが
分かりづらく成ってきた。イラストてきなのでパット見でどういった機能かわかるようなデザインに

## 何を解決するか

ツール・ゲームが合わせて70本近くになり、一覧のカードが**同じ太さの線画アイコン＋名前**の
繰り返しになっていた。線画（Phosphor）は「税金」「時計」のような**概念**を指すので、
お金のツールが24本並ぶと、どれも似た記号（書類・¥・グラフ）に落ちて見分けがつかない。
名前を読まないと何のページか分からない状態だった。

## どうするか

**概念ではなく、そのページで出てくるものを描く。**

- **ツールは出力を描く。** 割り勘なら切り分けたパイ、坪・畳なら4.5畳の敷き方、
  QRコードならQRコード。「何を計算するか」ではなく「開くと何が出てくるか」
- **ゲームは盤面をそのまま描く。** リバーシなら盤と石、2048なら数字のタイル。
  ゲームは画面そのものが一番の説明になる
- **色は分類だけを表す。形で個々を見分ける。** 色を個々のツールに割り当てると
  70色が必要になり、どれも区別できなくなる。分類は5色（お金・生活・計算・選ぶ・遊ぶ）
- **色だけで区別しない**（learn/CLAUDE.md と同じ約束）。分類は見出しでも分かれているので、
  色が見えなくても情報は落ちない

### 絵の描き方

- `viewBox="0 0 64 64"` の2トーン。線と塗りは `currentColor`、薄い面は `fillOpacity={0.2}`
- **白抜きは地色の変数で塗る**（`var(--tile-bg, var(--accent-soft))`）。
  生のカラーコードを書かない（明暗どちらかのテーマで地と同化する）。
  `{tools,games}/tests/*-art.test.ts` が直書きの色を落とす
- タイルは 60px 角・角丸14px、絵は 44px。線の太さは 3 を基準にする

### タイルの色

分類ごとに `--cat-{token}`（線）と `--cat-{token}-bg`（地）を明暗の両方で定義する。
カードには**クラスを増やさず**、インラインの変数（`--tile-ink` / `--tile-bg`）で渡す
（tools/CLAUDE.md「新しいCSSクラスを増やさない」）。

| 分類 | token | 明（線 / 地） | 暗（線 / 地） |
|---|---|---|---|
| お金・社会保険 | `money` | #15803d / #e8f4ec | #4ade80 / #1f4430 |
| 計算・変換 | `calc` | #1d4ed8 / #e8eefc | #8fb1f9 / #233459 |
| 生活・健康 | `life` | #b45309 / #fdf0e0 | #fbbf24 / #4a3713 |
| 決める・選ぶ | `pick` | #6d28d9 / #f0e9fd | #c4a7f8 / #3a2a59 |
| ゲーム | `play` | #be123c / #fde9ee | #fb8a9c / #552536 |

- 線と地のコントラストはどの組も 4.4 以上
- **暗いテーマの地はカード（`--surface`）から 1.26〜1.47 離してある。** 最初は 1.01〜1.04 で、
  タイルがほぼ見えなかった

### トップ（home/）

`home/` にはビルド工程が無く React の絵をそのまま使えないので、
**`scripts/sync-home-card-art.mjs` が tools / games の一覧ページのビルド結果から写す。**

```bash
(cd tools && npm run build) && (cd games && npm run build)
node scripts/sync-home-card-art.mjs
```

- 絵とタイルの `style` を差し替えるだけで、何度かけても同じ結果になる
- 一覧に無いカード（公開前・削除済み）があれば終了コード1で知らせる
- **トップの絵を手で描き替えない。** 原本（`ToolArt.tsx` / `BOARD`）を直して写し直す
- `scripts/test/home-card-art.test.mjs` が、写し忘れのカードと分類・色のずれを落とす

## ツール一覧（/tools/）は「結果の形」の大きい絵（2026-10-07 追加）

運営者が /design の比較（案A 情景カード・案B 結果をそのまま見せる・案C くらしの地図）から
**案B** を選んだ。ツールの一覧だけ、カードの上半分を**そのツールで出てくる答えの形**の絵にする。

- 原本は `tools/app/ToolPreview.tsx`（公開中の全ツール）。枠は 340×150 で、PCでもスマホでも
  カードの幅いっぱいに同じ絵を置く（PCは2列、スマホは1列）
- 円グラフ・段差・期限の日付・数直線など、**開いたときに出てくる結果画面の形**を描く。
  説明は2行で切る（全文は各ページに）
- 色は分類の線・その薄め・分類の地・紙面（`--surface`）に、**目立たせる1点**の
  `--cat-mark`（明 #c2410c／暗 #fb923c）を足した5つ。生のカラーコードは書かない
- **数字は制度で決まっている値だけ**（80%・119万・6.2万円・+0.5円など）。人によって変わる額は
  ［◯円］のような伏せ字にする。それらしい架空の額を描くと、見た人が自分の答えだと受け取りうる
- 小さいタイルの絵（`ToolArt.tsx`）は、**関連ツール・404** で使い続ける。
  タイル 60px に結果の形は収まらないため（トップは翌日に大きい絵へ。下の節）
- 404ページも素のリンク一覧からタイルのカードに変わった
- 見張り：`tools/tests/tool-preview.test.ts`（公開中に絵が無い・色の直書き・概数・一覧と404の使い分け）

## ゲーム一覧（/games/）とトップ（home/）も大きい絵に（2026-10-08 追加）

運営者の「ゲームの方とホームもお願い」から。

- **ゲーム一覧は「遊んでいる最中の画面」**（`games/app/GamePreview.tsx`、公開中の24本）。
  盤・札・駒がどう並ぶかを 340×150 で描く。札は数字だけ（スートの記号は潰れるので描かない）。
  点数・記録は［◯］の伏せ字。目立たせる色 `--cat-mark` は、線（赤）と見分けがつく黄土
  （明 #b45309／暗 #fbbf24）
- **トップのカードも一覧と同じ大きい絵**。`scripts/sync-home-card-art.mjs` は写し元を
  **一覧ページ（`tools/out/index.html`・`games/out/index.html`）に戻した**。
  ゲームのカードは `<a>` の style で `--cat-mark` を `--cat-play-mark`（黄土）に差し替える
- トップは2列（スマホは1列）、絵は幅いっぱい、説明は2行で切る。スマホで絵を左に置く横並びはやめた
- テスト環境だけに出る「本番未公開」のカードは、フラスコの印を60pxのタイルのまま出す
  （`scripts/build-test-home.mjs` の差し込みCSS）
- 小さいタイルの絵（`ToolArt.tsx`・`GameIcon.tsx` の `BOARD`）は、各ページの
  「他のツール」「他のゲーム」と tools の404で使い続ける。**公開するPRでは大小2枚を描く**
- 見張り：`games/tests/game-preview.test.ts`、`scripts/test/home-card-art.test.mjs`（トップが 340×150 の絵か）

## 踏んだ失敗（次に描くときも守ること）

- **直角の折り返しは数字に見える。**（2026-10-08 にゲーム一覧の数字つなぎの絵でも、往復する道を描いて3度目を踏みかけた。外周をまわる道にした）
   スネークを `M12 50 H34 V34 H20 V18 H44` で描いたら
  以前の線画と同じく「2.」に読めた（SnakeIcon のコメントに同じ指摘が残っていた）。
  数字つなぎ一筆書きの往復する道（`M16 16 H48 V32 H16 V48 H48`）も「2」に見えた。
  スネークは曲線に、一筆書きはマス目の盤を引いて渦を巻く道にした。
  **一覧は通し番号と誤解されうるので、数字の形を作る線は避ける**
- **縮小して見ないと分からない。** 割り勘の最初の絵（横棒に玉）はそろばんに、
  坪・畳の最初の絵（罫線の長方形）はノートに見えた。描いたら一覧の大きさで
  並べたスクリーンショットを撮って確かめる
- 絵が無い公開中のツール・ゲームがあると線画に落ち、並びが崩れる。
  **公開する（`stage` を `public` にする）PRで絵も描く**
  （`tools/tests/tool-art.test.ts`・`games/tests/game-art.test.ts` が落とす）

## やらないこと

- 個々のツールに色を割り当てる（上記）
- 画像ファイル（PNG・外部SVG）にする。インラインSVGなら明暗テーマに追随し、
  リクエストも増えない
- 公開前のものの絵を先に描く。公開の判断が付くまで中身が動くので、公開するPRで描く
