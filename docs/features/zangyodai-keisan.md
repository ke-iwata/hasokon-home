## 背景と根拠

### いちばん人が来ているページの「次の問い」が無い

GA4（プロパティ 548154955、2026-09-04〜09-17 の 14日、2026-09-18 取得）で、着地セッションの 1位は
**最低賃金 早見表・チェッカー（`/tools/saitei-chingin/`）41 セッション・エンゲージメント時間 3,215秒**
（2位 たばこ税 36・3位 養育費 17）。参照元はほぼ Bing（サイト全体で bing 149 ／ google 18 ／ chatgpt.com 24）。

最低賃金チェッカーは「自分の時給は最低賃金を下回っていないか」に答え、時給 × 労働時間から月収・年収を
出すところまで持っている。**ここに来る人の次の問いは「残業したぶんは正しく払われているか」**で、
それに答えるツールがサイトに無い。月給制の人は「自分の時給がいくらか」も分からないので、
最低賃金チェッカーに月給を持ち込めない（時給を入れる設計）。

### 「残業代 計算」は恒常需要で、季節の山も 2つある

- 「残業代 計算」「割増賃金 計算」「残業 時給 換算」は弁護士事務所・社労士・給与ソフト各社が
  計算ツールと解説を並べる定番の語で、年間を通して検索される（2026-09-18 Web 調査）。
  法改正型と違って山が去っても残る（`interval-timer`・`sleep-cycle` と同じ「恒常型」）
- 山は **10〜12月**（最低賃金の改定が 10/1〜12/2 に都道府県ごとに発効し、時給の話題が増える。
  令和8年度は全国加重平均 1,177円・東京 1,280円）と **3〜4月**（昇給・異動・新入社員）
- 労働基準法の大改正（14連勤禁止・副業の労働時間通算など）は 2026年の通常国会への提出が見送られ、
  施行は 2027年4月以降の見込み。**成立したら「残業」の検索が跳ねる**ので、そのとき既に育っている
  ページを 1本持っておく（[shohizei-keisan-shokuryohin-1percent.md](./shohizei-keisan-shokuryohin-1percent.md) と同じ考え方）

### 競合との差

弁護士事務所のツールは「未払い残業代の請求額」に寄っていて、入力が多く（出退勤の一覧など）、
結果が相談への導線になっている。給与ソフト各社の解説は事業者向け。
**「自分の月給から時給を出し、今月の残業代がいくらのはずか、その時給は最低賃金を下回っていないか」**を
1画面で出す個人向けの簡単なものが空いている。差別化は次の 3点：

1. **月給 → 1時間あたりの賃金の算定を法令どおりに出す**（除外できる手当を選ぶ・所定労働時間から月平均を出す）。
   ここを省いたツールが多く、「基本給 ÷ 160」のような概算になっている
2. **最低賃金チェッカーの都道府県データ（`lib/saitei-chingin.ts` の `PREFECTURES`）をそのまま使い、
   時給換算が最低賃金を下回っていないかを同じ画面で判定**する（同じ数字を 2か所に置かない）
3. **手取り計算機への橋渡し**：残業代込みの月収を `/tools/tedori-keisan/` に渡すリンク

## 提案する仕様

### 入力（必須 4つを上に、任意は `<details>` の「詳しい条件」に畳む。#220 と同じ型）

必須：

1. **賃金の形態**：月給制（既定）／時給制。時給制なら 4 を飛ばして時給を直接入れる
2. **月給（額面）**：基本給＋手当の合計。円
3. **1日の所定労働時間**（既定 8時間。7 / 7.5 / 7.75 / 8 の選択肢＋自由入力）
4. **年間の所定労働日数** または **年間休日数**（どちらかを入れる。既定：年間休日 120日 → 245日）。
   ここから **1か月平均所定労働時間 = 日数 × 1日の時間 ÷ 12** を出して表示する

任意（「詳しい条件」）：

5. **除外できる手当の月額**（家族手当・通勤手当・住宅手当…の合計。上表の 7つを列挙し、
   「一律支給の手当は除外できません」の注記つき）
6. **今月の残業時間**：法定内残業（所定〜8時間の分）／時間外労働（8時間・週40時間超）／
   うち深夜（22〜5時）／法定休日労働／うち深夜。**時間と分**で入れる
7. **端数処理**：法令どおり（既定。丸めない）／通達の簡便法（上表の (1)〜(3)）
8. **固定残業代（みなし残業）**：月額と「何時間分」。入れると「固定分を超えた時間の差額」を出す

### 計算（`tools/lib/zangyodai.ts`。純関数）

```
算定基礎賃金     = 月給 − 除外できる手当
1時間あたりの賃金 = 算定基礎賃金 ÷ (年間所定労働日数 × 1日の所定労働時間 ÷ 12)   // 時給制なら時給そのまま
法定内残業       = 単価 × 1.00 × 時間
時間外（60h以内） = 単価 × 1.25 × 時間            // 深夜と重なる分は 1.50
時間外（60h超）   = 単価 × 1.50 × 時間            // 深夜と重なる分は 1.75
法定休日         = 単価 × 1.35 × 時間            // 深夜と重なる分は 1.60。60h の算定に含めない
残業代の合計     = 上の和（端数処理は選択に従う）
固定残業代の差額 = max(0, 合計 − 固定残業代)      // 固定分の「何時間分」が単価×1.25で足りているかも判定
```

- 60時間超の判定は「時間外労働の月合計」で行い、法定休日労働は含めない（法どおり）。
  深夜の重なりは「時間外のうち深夜」「休日のうち深夜」の入力からそれぞれ取る
- 単価は円未満を丸めずに持ち、**表示だけ**小数第2位まで（端数処理「法令どおり」のとき）。
  「簡便法」を選んだときだけ (1)〜(3) を順に適用する
- 時給換算が **最低賃金を下回っていないか**：`lib/saitei-chingin.ts` の `PREFECTURES` から都道府県を選ばせ、
  `hourlyYen` と比較する既存の判定（`verdict()` 相当）を re-export して使う。
  **時給換算に入れるのは算定基礎賃金ではなく「最低賃金の対象になる賃金」**（最低賃金法 4条3項・
  最低賃金法施行規則 1条：精皆勤手当・通勤手当・家族手当・臨時の賃金・賞与・割増賃金を除く）なので、
  除外の範囲が割増賃金の 7つと**違う**。ここは混ぜず、最低賃金の比較は「基本給＋対象になる手当」で別に出す
  （画面では「参考：最低賃金との比較」の小さな枝にする。判定の主役ではない）

### 表示

- **1時間あたりの賃金**（算定の式を展開して見せる：「(月給 − 手当) ÷ (245日 × 8h ÷ 12 = 163.3h)」）
- **残業代の内訳表**：種類 × 時間 × 割増率 × 金額。合計と、**残業代込みの今月の額面**
- **年換算**（今月と同じなら年いくら）と、`/tools/tedori-keisan/` への橋渡し（額面を渡す）
- 固定残業代を入れたときは「固定分は◯時間分に相当。今月は◯時間超えているので差額◯円」
- 端数処理を切り替えたときの差額を 1行で（「簡便法だと −◯円」）
- **注意書き**：「この計算機は労働基準法の最低限度で計算しています。就業規則・給与規程でこれ以上の率や
  手当を定めている場合はそちらが優先します。管理監督者・変形労働時間制・フレックスタイム・
  事業場外みなし・裁量労働制は計算が違います」

## やらないこと

- **未払い残業代の「請求額」を出す。** 遅延損害金・付加金・時効の起算は個別事情で、法律相談の領域。
  「今月の計算上の残業代」に留め、請求は労基署・弁護士へ案内する
- **出退勤の一覧から残業時間を集計する。** 入力が重くなる。時間の合計を入れてもらう（次版で
  「週ごとの入力」を検討）
- **変形労働時間制・フレックス・裁量労働制・管理監督者の判定。** 計算の前提が違う。注意書きで除外する
- **就業規則で法定を上回る率**の入力。まず最低限度で出す（要望があれば率の上書きを次版で）
- **最低賃金チェッカーへの相乗り。** 入力（月給・所定労働時間・手当）と出力（内訳表）が別物で、
  最低賃金チェッカーの「都道府県を選ぶだけ」の軽さを壊す。判定関数だけ共有する
- **事業者向け（36協定の上限チェック・割増賃金の仕訳）。** 個人向けに絞る
