## 背景と根拠

### いちばん人が来ているページの「次の問い」が無い

GA4（プロパティ 548154955、2026-09-04〜09-17 の 14日、2026-09-18 取得）で、着地セッションの 1位は
**最低賃金 早見表・チェッカー（`/tools/saitei-chingin/`）41 セッション・エンゲージメント時間 3,215秒**
（2位 たばこ税 36・3位 養育費 17）。参照元はほぼ Bing（サイト全体で bing 149 ／ google 18 ／ chatgpt.com 24）。

最低賃金チェッカーは「自分の時給は最低賃金を下回っていないか」に答え、時給 × 労働時間から月収・年収を
出すところまで持っている。**ここに来る人の次の問いは「残業したぶんは正しく払われているか」**で、
それに答えるツールがサイトに無い。月給制の人は「自分の時給がいくらか」も分からないので、
最低賃金チェッカーに月給を持ち込めない（時給を入れる設計）。

### 「残業代 計算」は恒常需要で、季節の山も 2つある

- 「残業代 計算」「割増賃金 計算」「残業 時給 換算」は弁護士事務所・社労士・給与ソフト各社が
  計算ツールと解説を並べる定番の語で、年間を通して検索される（2026-09-18 Web 調査）。
  法改正型と違って山が去っても残る（`interval-timer`・`sleep-cycle` と同じ「恒常型」）
- 山は **10〜12月**（最低賃金の改定が 10/1〜12/2 に都道府県ごとに発効し、時給の話題が増える。
  令和8年度は全国加重平均 1,177円・東京 1,280円）と **3〜4月**（昇給・異動・新入社員）
- 労働基準法の大改正（14連勤禁止・副業の労働時間通算など）は 2026年の通常国会への提出が見送られ、
  施行は 2027年4月以降の見込み。**成立したら「残業」の検索が跳ねる**ので、そのとき既に育っている
  ページを 1本持っておく（[shohizei-keisan-shokuryohin-1percent.md](./shohizei-keisan-shokuryohin-1percent.md) と同じ考え方）

### 競合との差

弁護士事務所のツールは「未払い残業代の請求額」に寄っていて、入力が多く（出退勤の一覧など）、
結果が相談への導線になっている。給与ソフト各社の解説は事業者向け。
**「自分の月給から時給を出し、今月の残業代がいくらのはずか、その時給は最低賃金を下回っていないか」**を
1画面で出す個人向けの簡単なものが空いている。差別化は次の 3点：

1. **月給 → 1時間あたりの賃金の算定を法令どおりに出す**（除外できる手当を選ぶ・所定労働時間から月平均を出す）。
   ここを省いたツールが多く、「基本給 ÷ 160」のような概算になっている
2. **最低賃金チェッカーの都道府県データ（`lib/saitei-chingin.ts` の `PREFECTURES`）をそのまま使い、
   時給換算が最低賃金を下回っていないかを同じ画面で判定**する（同じ数字を 2か所に置かない）
3. **手取り計算機への橋渡し**：残業代込みの月収を `/tools/tedori-keisan/` に渡すリンク

## 提案する仕様

### 入力（必須 5つを上に、任意は `<details>` の「詳しい条件」に畳む。#220 と同じ型）

必須（畳まない。**ツール名が「残業代」なので、残業時間は必ず見える位置に置く**）：

1. **賃金の形態**：月給制（既定）／時給制
2. **月給（額面）**：基本給＋手当の合計。円。**時給制のときはこの欄が「時給」に変わり、3・4 は隠す**
3. **1日の所定労働時間**（既定 8時間。7 / 7.5 / 7.75 / 8 の選択肢＋自由入力）
4. **年間の所定労働日数**（既定 245日）。補助として「年間休日から出す」を置き、
   休日数を入れたら **365 − 休日数** を目安として日数欄に入れる（**閏年は 366 なので目安と注記**し、
   正確には就業規則の年間所定労働日数を入れてもらう）。
   ここから **1か月平均所定労働時間 = 日数 × 1日の時間 ÷ 12** を出して表示する
5. **今月の時間外労働（時間・分）**：法定労働時間（1日8時間・週40時間）を超えた分の合計。**0 でもよい**

任意（「詳しい条件」）：

6. **残業の内訳**：法定内残業（所定〜8時間の分）／時間外のうち深夜（22〜5時）／法定休日労働／
   休日のうち深夜／**所定労働時間内の深夜（夜勤）**。いずれも**時間と分**。5 の時間外と合わせて計算に使う
7. **除外できる手当の月額**を **3つの枝**に分けて入れる（上表の 7つを列挙し、「一律支給の手当は除外できません」の注記つき）：
   - (i) **通勤手当・家族手当**：割増の算定基礎からも、最低賃金の対象賃金からも除く
   - (ii) **住宅手当・別居手当・子女教育手当**：割増の算定基礎からは除くが、**最低賃金の対象賃金には含める**
   - (iii) **精皆勤手当**：割増の算定基礎には**含める**が、最低賃金の対象賃金からは除く
   （臨時の賃金・賞与は月給に入っていない前提なので入力しない。3つに分けるのは、割増賃金と最低賃金で
   除外の範囲が違うため。1つの合計にすると最低賃金の比較ができない）
8. **端数処理**：法令どおり（既定。丸めない）／通達の簡便法（上表の (1)〜(3)）
9. **固定残業代（みなし残業）**：月額と「何時間分」。入れると「固定分を超えた時間の差額」を出す
10. **都道府県**（「参考：最低賃金との比較」のための選択。未選択なら比較の枝を出さない）

### 計算（`tools/lib/zangyodai.ts`。純関数）

```
算定基礎賃金     = 月給 − (i) 通勤・家族 − (ii) 住宅・別居・子女教育     // (iii) 精皆勤は引かない
最低賃金の対象賃金 = 月給 − (i) 通勤・家族 − (iii) 精皆勤                 // (ii) は引かない
1時間あたりの賃金 = 算定基礎賃金 ÷ (年間所定労働日数 × 1日の所定労働時間 ÷ 12)   // 時給制なら時給そのまま
法定内残業       = 単価 × 1.00 × 時間
時間外（60h以内） = 単価 × 1.25 × 時間            // 深夜と重なる分は 1.50
時間外（60h超）   = 単価 × 1.50 × 時間            // 深夜と重なる分は 1.75
法定休日         = 単価 × 1.35 × 時間            // 何時間でも 1.35（8時間超でも 1.25 を重ねない）。深夜と重なる分は 1.60。60h の算定に含めない
所定内の深夜     = 単価 × 0.25 × 時間            // 割増分だけ。1.0 の部分は月給に含まれている
残業代の合計     = 上の和（端数処理は選択に従う）
固定残業代の差額 = max(0, 合計 − 固定残業代)      // 固定分の「何時間分」が単価×1.25で足りているかも判定
```

- **時給制のとき**：単価は入力した時給そのまま。3・4 は使わないが、**法定内残業（所定〜8時間）の入力は
  時給制でも意味を持つ**（所定 7時間の時給制なら 8時間目は 1.00 で払われる）ので隠さない。
  最低賃金の比較には**時給をそのまま**使う（手当の枝は月給制のときだけ出す）

- 60時間超の判定は「時間外労働の月合計」で行い、法定休日労働は含めない（法どおり）。
  深夜の重なりは「時間外のうち深夜」「休日のうち深夜」の入力からそれぞれ取る
- **実装では深夜を「+0.25 の加算」1行にまとめた**（内訳表も1行）。深夜は時間外・法定休日の
  どちらと重なっても +0.25 なので、`5h×1.25 + 2h×0.25` は `3h×1.25 + 2h×1.50` と同額になる。
  こうしないと「時間外70時間のうち深夜10時間」が 60時間枠とその超過のどちらに入るかを
  決めないと金額が出せないが、**それは入力からは分からない**（1.50 と 1.75 のどちらにするかで
  額が変わってしまう）。加算1行なら配分を決めずに正しい額が出る
- **端数処理「法令どおり」（既定）の円未満の扱い**：単価・内訳の各金額・合計は**小数第2位まで持つ**
  （`lib` は丸めない数値を返す）。画面では単価を小数第2位まで、**内訳の各金額と合計（円）は切り上げ**で
  見せる（切り捨ては労働者に不利になるので採らない。「◯円（端数切り上げ）」と添える）。
  「簡便法」を選んだときだけ (1)〜(3) を順に適用し、通達どおり 50銭で四捨五入する。
  テストは丸め前の値を固定する（例：`toBeCloseTo(22959.18, 2)`）
- 時給換算が **最低賃金を下回っていないか**（「参考：最低賃金との比較」の枝。判定の主役ではない）：
  都道府県（入力 10）を選んだときだけ出す。比較に使うのは **算定基礎賃金ではなく「最低賃金の対象賃金」**
  （最低賃金法 4条3項・最低賃金法施行規則 1条：精皆勤手当・通勤手当・家族手当・臨時の賃金・賞与・割増賃金を除く）で、
  上の式のとおり手当の枝 (i)(iii) を引いて出し、同じ月平均所定労働時間で割って時給にする。
  判定は `lib/saitei-chingin.ts` が**既に export している `checkWage(pref, hourlyYen)`** をそのまま呼ぶ
  （同ファイルは触らない。#216 が同じファイルを触っているので「依存なし」を保つ）。
  画面には「最低賃金の比較では住宅手当は含め、精皆勤手当は除きます（割増賃金と逆）」と 1行添える

- 60時間の境目：時間外 70h → 60h × 1.25 ＋ 10h × 1.50。休日労働 8h を足しても 60h の算定に入らない
- **法定休日労働 10h → 10h × 1.35**（8時間を超えても 1.25 を重ねない）。うち深夜 2h → 8h × 1.35 ＋ 2h × 1.60
- 深夜の重なり：時間外 5h のうち深夜 2h → 3h × 1.25 ＋ 2h × 1.50
- 所定内の深夜 8h → 8h × 0.25
- 法定内残業（所定 7h）は 1.00。時給制でも法定内残業の入力が効く
- 除外手当：通勤手当 1万円（i）は単価から外れる。精皆勤手当 5千円（iii）は単価に**残る**。
  最低賃金の対象賃金では逆に、住宅手当（ii）は残り精皆勤（iii）が外れる。「一律の住宅手当」は入力の注記の話なので計算では扱わない
- 最低賃金の比較：`checkWage` に渡す時給が「対象賃金 ÷ 月平均所定労働時間」になっている。都道府県未選択なら比較結果を返さない
- 端数処理：簡便法で 29分は切捨て・30分は切上げ、50銭は切上げ
- 固定残業代：3万円・20時間分（単価 1,200円 → 1,500円 × 20h ＝ 3万円で過不足なし）、25時間なら差額 7,500円
- 時給制の入力で単価がそのまま使われる

## やらないこと

- **未払い残業代の「請求額」を出す。** 遅延損害金・付加金・時効の起算は個別事情で、法律相談の領域。
  「今月の計算上の残業代」に留め、請求は労基署・弁護士へ案内する
- **出退勤の一覧から残業時間を集計する。** 入力が重くなる。時間の合計を入れてもらう（次版で
  「週ごとの入力」を検討）
- **変形労働時間制・フレックス・裁量労働制・管理監督者の判定。** 計算の前提が違う。注意書きで除外する
- **就業規則で法定を上回る率**の入力。まず最低限度で出す（要望があれば率の上書きを次版で）
- **最低賃金チェッカーへの相乗り。** 入力（月給・所定労働時間・手当）と出力（内訳表）が別物で、
  最低賃金チェッカーの「都道府県を選ぶだけ」の軽さを壊す。判定関数だけ共有する
- **事業者向け（36協定の上限チェック・割増賃金の仕訳）。** 個人向けに絞る
- **日給制・年俸制・歩合給（出来高払）。** 施行規則 19条1項には 1号（時給）・2号（日給）・3号（週給）・
  6号（出来高払）・7号（併用）の別があり、とくに**年俸制は賞与相当分も算定基礎に入る**（年俸 ÷ 12 を月給欄に
  入れると単価が過小になる）ので、月給制の式を流用しない。初版は月給制と時給制だけ。注意書きにも明記する
- **労基法改正の時期をページ本文に書く。** 「2027年4月以降の見込み」は仕様書の背景に留める（法案の時期は動く）。
  成立したら解説に 1行足す
