  100円未満切捨てはすべて `lib/nenmatsu-chosei.ts` に**令和8年分の値で入っていて、テストもある**。新しく作るのは「逆向きに並べる」画面だけ
- ブログ型の記事にしない（`tools/docs/CONCEPT.md`）。欄の説明は**入力した数字を埋め込んだ1行の式**として出し、長い読み物にしない

## 提案する仕様

### 入力（源泉徴収票の欄名をそのまま使う）

| 入力 | 必須 | 欄 |
|---|---|---|
| 支払金額 | ○ | 左上「支払金額」 |
| 給与所得控除後の金額（調整控除後） | ○ | その右 |
| 所得控除の額の合計額 | ○ | その右 |
| 源泉徴収税額 | ○ | 右端 |
| 住宅借入金等特別控除の額 | 任意 | 中段（ある人だけ。「（摘要）」欄の住宅ローン控除可能額は使わない） |
| 社会保険料等の金額・生命保険料の控除額・地震保険料の控除額 | 任意 | 中段。入れると「所得控除の額の合計額」の内訳を逆算して見せる |
| 「年調未済」「乙欄」の印 | 任意 | 摘要・種別欄。**印があるときは検算をせず、確定申告の判定へ案内するだけ** |

- 金額は全角数字・カンマ入りの貼り付けを受け付ける（`hankaku-zenkaku` の正規化を流用）
- **入力はどこにも送らない**（端末内の計算だけ。`tool_use` には「検算が一致したか」の真偽と年分だけを送り、金額は送らない。
  [tool-use-coverage.md](./tool-use-coverage.md) の約束どおり）

### 出すもの（上から順に）

1. **4つの欄の検算**（1行ずつ ✓ / ✗ と式）
   - 支払金額 → 給与所得控除後の金額：別表第五で引いた値と一致するか（660万円未満は表、以上は式。`salaryIncome` 系の関数をそのまま使う）。
     「所得金額調整控除」（子育て・特別障害者／給与と年金の両方）で一致しない場合の案内を1行
   - 課税所得 ＝ 給与所得控除後 − 所得控除の合計（1,000円未満切捨て）
   - 年税額 ＝ 速算表 → 住宅ローン控除を引く → ×102.1% → 100円未満切捨て。**これが源泉徴収税額と一致するか**
   - 一致しないときは「よくある理由」を3つまで出す（年の途中の入社で前職分を合算していない・年調未済・
     所得金額調整控除）。**「会社の計算が間違い」とは書かない**
2. **各欄の意味**（入力した数字を埋めた1行の説明。例：「所得控除の額の合計額 1,630,000円 のうち、基礎控除は 1,040,000円（令和8年分・合計所得489万円以下）です」）
3. **令和8年分で変わったところ**（基礎控除 58万→最大104万、給与所得控除の最低保障額 65万→74万。**この人にとって去年の制度ならいくら税額が違ったか**を
   `RULES_R7` で1行。「今年の源泉徴収税額が少ない理由」に答える）
4. **次の行き先**（同じ数字を引き継いでリンク。クエリ文字列で渡し、受け側がまだ読まないなら単なるリンク）
   - ふるさと納税の上限（支払金額・所得控除の合計を渡す）
   - 確定申告が要るか（年調未済・乙欄・給与2,000万円超のとき強く案内）
   - 医療費控除（「源泉徴収票の所得控除には入っていない控除」）

## 一次確認（実装前に確定させる）

1. 国税庁「令和8年分 年末調整のための各種様式」「給与所得の源泉徴収票等の法定調書の作成と提出の手引」（令和8年分）で、
   **源泉徴収票の欄の並びと名称が令和7年分から変わっていないか**（令和7年分で特定親族の欄が新設された。令和8年分の様式の変更点を確かめる）
2. 年税額の計算順（住宅借入金等特別控除を引いてから 102.1% を掛け、100円未満切捨て）を、国税庁「年末調整のしかた」（令和8年分）で確かめる
3. 交付期限（所得税法226条1項「翌年1月31日まで」）と、退職者は退職後1か月以内（同項ただし書き）の文言を e-Gov で確かめる

## テスト（検算ケース）

- 年収 500万円・社会保険料 72万円・基礎控除のみ → `lib/nenmatsu-chosei.ts` の `calcYearTax` と一致すること（同じ関数を2通りに並べたときの整合）
- 年収 160万円（給与所得控除 74万円の境目）・190万円・660万円（表と式の境目）
- 源泉徴収税額 0円（課税所得 0 円）で ✗ にならない
- 住宅ローン控除で年税額が 0 円になるケース
- 1円ずらした入力で ✗ になり、「よくある理由」が出る
- 年調未済の印で検算を出さない

- 「会社の計算が誤っている」と断定する文。✗ のときは理由の候補と、勤務先に確かめる案内まで
