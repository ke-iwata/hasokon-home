- 空いているところ：**インストール不要で、符の組み立て（どこで何符か）を見せながら点数まで出し、早見表も1枚で印刷できる日本語の Web ツール**。符の内訳を見せると「なぜ40符なのか」が分かり、覚える助けになる

### 権利・法令

- 麻雀の点数の数え方（符・翻・満貫の区切り）は**ルールであって著作物ではない**。役の名前も一般名詞
- 牌の絵は**使わない**（文字のボタンで足りる。使うなら自前の SVG）。他サイト・アプリの牌画像や早見表の画像を写さない
- **賭けを助長しない**：点数を円に換算する・精算する機能は作らない（賭博罪＝刑法185条・186条）。「ウマ・オカ」「レート」の語も出さない
- 特定のプロリーグ・団体の名前でルールを呼ばない（「一般的なルール」と書き、項目ごとに切り替える）

## 機能（仕様）

### タブ1：かんたん（符と翻を選ぶ）

- 入力：**親／子**・**ロン／ツモ**・**符**（20・25・30・40・50・60・70・80・90・100・110）・**翻**（1〜13以上）・**本場**（0〜）・**供託のリーチ棒**（0〜）
- 出力：
  - ロン：「**7,700点**」（本場込みの額を大きく。内訳に「基本 7,700 ＋ 本場 300 ＋ 供託 1,000」）
  - ツモ（子）：「**2,000・3,900**」（子の払い・親の払い）と合計
  - ツモ（親）：「**3,900オール**」と合計
  - 満貫以上は名前（満貫・跳満・倍満・三倍満・役満）を添える
- **ありえない組み合わせ**は理由を出して止める：1翻20符（平和ツモは2翻以上）・25符で1翻（七対子は2翻）・20符のロン（平和のロンは30符）

### タブ2：符を数える（形を選ぶ）

- 入力：
  - **あがり方**：ロン／ツモ、**門前かどうか**
  - **面子4つ**：それぞれ「順子／刻子／槓子」×「明（鳴いた）／暗」×「中張牌（2〜8）／么九牌（1・9・字牌）」をボタンで選ぶ
  - **雀頭**：数牌・客風／役牌（三元牌・場風・自風）／連風牌
  - **待ち**：両面・双碰／嵌張・辺張・単騎
  - **特殊形**：七対子（25符固定）・平和（ツモ20符／ロン30符）
- 出力：**符の内訳を1行ずつ**（副底20・門前ロン10・ツモ2・暗刻 么九 8・単騎2…）と、合計・10符単位の切り上げ（例：「32符 → 40符」）。そのまま「翻を選んで点数を出す」に進める
- 点数表（下）と同じ数え方：

| 項目 | 符 |
|---|---|
| 副底 | 20 |
| 門前でロン | 10 |
| ツモ（平和のツモを除く） | 2 |
| 明刻 中張／么九 | 2／4 |
| 暗刻 中張／么九 | 4／8 |
| 明槓 中張／么九 | 8／16 |
| 暗槓 中張／么九 | 16／32 |
| 雀頭が役牌 | 2（連風牌は ルールで 2／4） |
| 嵌張・辺張・単騎待ち | 2 |
| 七対子 | 25（固定・切り上げなし） |
| 平和のツモ | 20（固定） |
| 鳴いて符が20のままのロン（喰い平和形） | 30 にする |

- ロンで完成した刻子は**明刻**として数える（双碰待ちのロン）。画面に一言出す（初心者が最も間違える点）

### タブ3：早見表（印刷用）

- 子・親 × ロン・ツモの4表（符20〜110 × 翻1〜4、満貫以上は別欄）。ルールの切り替え（切り上げ満貫の有無）に追従
- `@media print` で A4 1枚に収める。卓に置ける

### 点数の計算（`tools/lib/mahjong-tensu.ts`）

- 基本点 = 符 × 2^(翻 + 2)
- **2,000 を超えたら満貫（2,000）**。5翻 満貫・6〜7翻 跳満 3,000・8〜10翻 倍満 4,000・11〜12翻 三倍満 6,000・13翻以上 数え役満 8,000（ルールで「三倍満止め」に切り替え）
- 支払い：子のロン＝基本点×4、親のロン＝×6、子のツモ＝子 ×1・親 ×2、親のツモ＝各 ×2。**それぞれ100点未満を切り上げ**
- 本場：ロンは＋300×本場、ツモは各自＋100×本場。供託：＋1,000×本数（あがった人に）
- 役満は 8,000×倍数（ダブル役満の有無はルールで切り替え）

### ルールの切り替え（既定値は「一般的なルール」）

| 項目 | 既定 | 切り替え |
|---|---|---|
| 切り上げ満貫（4翻30符・3翻60符を満貫に） | なし | あり |
| 連風牌の雀頭 | 2符 | 4符 |
| 数え役満（13翻以上） | あり | 三倍満止め |
| ダブル役満 | あり | なし |

- 選んだルールは `localStorage` に覚える（try/catch で包み、失敗しても既定で動く）

### 本文（`page.tsx`。[thin-tool-content.md](./thin-tool-content.md) の型）

- 「符の数え方」「満貫・跳満の区切り」「ツモの払いの分け方」「本場と供託」の4節
- FAQ：「30符4翻は7,700点？8,000点？」（切り上げ満貫のルール差）・「ロンで完成した刻子は明刻？」・「七対子は何符？」・「平和ツモは何符？」
- 相互リンク：games の麻雀ソリティア・サイコロ・ルーレット

## やらないこと

- 牌姿（14枚）を並べて**役を自動判定**する機能（役の判定は量が多く誤りやすい。需要を見て第2段で検討）
- 画像から牌を読み取る機能
- 点数の**円換算・精算・ウマ・オカ**（賭けを助長しない）
- 三人麻雀（北抜き・ツモ損）の点数（第2段で検討）
