## 背景と根拠

### 「◯坪 何平米」「◯畳 何平米」は日本特有の恒常ロングテール

賃貸探し・住宅購入・リフォーム・土地取引のたびに必要になる換算で、
「坪 平米」「30坪 何平米」「6畳 広さ」「1坪 何畳」のような
**数値つきロングテールが無数にある**。海外製の汎用単位換算サイトは
畳（江戸間・京間・団地間の違い）を扱えず、日本語の専門サイトも
不動産会社の記事が多くて計算機として弱い。

当サイトで検索面の立ち上がりが実際に確認できているのは、まさにこの
「数値バリエーションを持つ換算系」：アスペクト比計算は Search Console
（https://hasokon.com/ プロパティ、2026-08-12〜18）で当サイト最多の表示33回、
クエリも「16 9 px」「1920 かける 1080 比率」のような数値つきが並ぶ。
年齢計算も「満何歳何ヶ月」「18歳 何年生まれ」で表示が出ている（同期間）。
坪・平米・畳はこの型の広さ版で、**逆引き早見表**
（[nenrei-hayamihyo-seo.md](./nenrei-hayamihyo-seo.md)・
[aspect-ratio-gyakubiki-seo.md](./aspect-ratio-gyakubiki-seo.md) と同じ戦略）が
そのまま使える。

### 換算根拠が明確で、計算間違いの起きようがない題材

- **1坪 = 400/121 ㎡（≒ 3.305785㎡）**。計量法の尺貫法定義
  （1間=6尺、1坪=1間四方）から厳密に導ける
- **畳は地域・規格で違う**：京間 約1.82㎡／中京間 約1.66㎡／
  江戸間 約1.55㎡／団地間 約1.45㎡。また**不動産の広告表示では
  「畳1枚あたり1.62㎡以上」**と定められている（不動産の表示に関する
  公正競争規約施行規則）。この「畳は1つじゃない」を正面から説明する
  ページが計算機を兼ねると強い（「62万円ではなく65万円」型の誤解訂正枠）

## 現状

- `tools/lib/registry.ts` に単位換算系がゼロ（2026-08-19 確認）。
  「計算・変換」カテゴリはアスペクト比・全角半角・ローマ字などで、
  物理量の換算がない
- 競合の汎用換算サイトは畳の規格差・不動産表示規約に触れないものが多く、
  差別化の余地が明確

## 提案する仕様

1. **変換（双方向・即時）**：坪 ⇔ ㎡ ⇔ 畳 の3すくみをどこに入力しても
   他が更新される形。畳は規格（不動産表示 1.62㎡／江戸間／中京間／京間／
   団地間）をセレクトで切替、既定は不動産表示の1.62㎡
2. **計算根拠の明示**：1坪 = 400/121㎡ を分数のまま定数に持ち、丸めは
   表示時のみ（小数2桁）。換算式と計量法・表示規約の根拠を本文に書く
3. **逆引き早見表（SEOの柱）**：よく引かれる値を静的に並べる
   - 坪→㎡・畳：1・5・10・15・20・25・30・35・40・50・60・70・80・100坪
   - 畳→㎡・坪：4.5・6・8・10・12・14・16・18・20畳
   - 各行に「30坪 = 99.17㎡ ≒ 61.22畳（1.62㎡換算）」の形で3単位併記
     （起票時は「≒ 60.4畳」と書いていたが、99.1735…㎡ ÷ 1.62㎡ = 61.22畳。
     60.4畳になるのは1畳を約1.642㎡としたときで、公正競争規約施行規則の
     1.62㎡と合っていなかった。実装は定数からの計算値で入っている）
4. **用途の文脈**：住宅の広さ感覚（「30坪 = 延床◯㎡はファミリー戸建ての
   標準的な広さ」程度の中立な目安）をFAQで補足し、不動産広告の
   「1畳=1.62㎡以上」ルールも説明
5. **ページ構成**：既存ツールと同じ（metadata / robotsFor / JSON-LD / FAQPage /
   パンくず / AdUnit / 関連ツール）。関連はアスペクト比計算・エアコン電気代
   （部屋の広さつながり）。registry へは `stage: 'preview'` で追加
6. **テスト**：400/121 の厳密換算・畳規格ごとの換算・表示丸めを
   `tools/tests/` の単体テストで固定。早見表の値も registry の定数から
   生成してテストでずれを検知
7. **ページは1本**：`/tools/tsubo-heibei/` に変換機＋早見表を同居させる
   （値ごとの個別ページ量産は薄いページになるのでやらない）

  GA4 の `/tools/tsubo-heibei/` 着地数

## やらないこと

- **ヘクタール・エーカー・反・町などの土地面積全部入り**（初版は
  住まい探しの3単位に絞る。詰め込むと「何のツールか」がぼける。
  需要が見えたら「土地の単位」として別枠を検討）
- **間取り図・帖数からの家賃相場の提示**（相場データの維持が無理。
  計算機と根拠の説明に徹する）
- **値ごとの個別ページ量産**（「30坪 平米」専用URLのような薄いページを
  増やすとサイト全体の評価を下げる。1ページ内の早見表で受ける）
