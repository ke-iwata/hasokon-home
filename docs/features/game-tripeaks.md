# 新ゲーム「トライピークス」（ソリティア定番5種の最後の1枚を埋める）

**状態**：実装済み（2026-08-18。ページ・テストを揃えたPRで `stage: 'public'` に
した。本番反映はタグリリース待ち）
**対象**：`games/`（`hasokon.com/games/tripeaks/`）
**起票**：2026-08-18

---

## 背景と根拠

### ソリティア群はこのサイトで唯一、検索の芽が出ている面

GSC（Search Analytics API・直近28日・2026-08-18 取得）で、ゲーム側で
表示が付いているクエリは引き続きソリティア系に集中している：

- 「ソリティア クロンダイク」11表示（掲載順位 46）
- 「スパイダーソリティアの遊び方」3表示（順位 74.3）
- ページ別でも `games/solitaire/`（20表示・1クリック）と
  `games/spider/`（8表示・1クリック）がゲーム側の実クリック上位

GA4（直近28日）でも `games/block-puzzle/`・`games/minesweeper/` に次いで
`games/solitaire/` が閲覧上位に入る。ソリティアの面を厚くする戦略
（[game-pyramid-solitaire.md](./game-pyramid-solitaire.md)）の継続として、
5本目を提案する。

### 「定番5種」の最後の1枚がトライピークス

世界でいちばん遊ばれているソリティア集（Windows 標準の Microsoft Solitaire
Collection）の収録は **クロンダイク・スパイダー・フリーセル・ピラミッド・
トライピークス** の5種で固定されている。当サイトは前4つを実装済みで、
**トライピークスだけが欠けている**。

- 「ソリティア 種類」系の検索・紹介記事はほぼこの5種を軸に書かれるため、
  5種そろうと「ソリティアがひととおり遊べるサイト」として面の評価が完成する
- ピラミッドと同じ「山札から1枚ずつめくる×場札を減らす」系で、**遊び味は
  「±1でつなげる連鎖」**。ピラミッド（合計13）と補完関係にあり共食いしない
- ルールは1980年代から広く遊ばれている伝統的トランプゲームで権利関係は無害

## 提案する仕様

1. **ルール（標準的なトライピークス）**
   - 山型に3つのピーク（計28枚。裏18枚・表10枚）、残り23枚が山札、1枚が捨て札
   - 捨て札の一番上と**ランクが±1**の場札を取れる（Aと2、KとAもつながる=ラップあり）。
     取った札が新しい捨て札になり、連鎖が続く
   - 覆っていた2枚が両方なくなった裏札は自動でめくれる
   - 場札28枚を全部取れたら勝ち。山札が尽き、取れる札がなくなったら負け
   - 連鎖数をスコアとして表示する（連鎖が伸びるほど高得点。リプレイ動機になる）
2. **操作（スマホ最優先・タップのみ）**
   - 取れる札をタップするだけ。ドラッグ不要。取れない札は短い揺れで無効を伝える
   - 山札タップで1枚めくる。残り枚数を常時表示する
3. **成績**：`_records` でクリア回数・クリア率・最長連鎖を保存
4. **ページ構成（既存ゲームページと同じ）**
   - ルール／コツ（「裏札が多いピークから崩す」「連鎖の設計」）／由来／FAQ
     （JSON-LD・パンくず込み）
   - registry への追加でソリティア群5ページの相互リンクに自動で乗る
5. **実装の再利用**
   - カード描画 `games/app/_cards/CardView.tsx`、デッキ `lib/cards.ts`、
     成績 `_records` をそのまま使う。CPU対戦なし・1人用でピラミッドと同規模

## 期待される効果

- 「ソリティア 無料」「ソリティア 種類」の面で定番5種が完結し、既に表示が
  出ている `solitaire`／`spider`（順位46・50）の押し上げに寄与する
- トライピークス自体もスマホアプリ紹介記事が定期的に出る安定需要があり、
  ブラウザで登録不要・広告控えめで今すぐ遊べる受け皿は比較的薄い
- 1ゲーム2〜3分と5種の中で最も短く、スキマ時間の再訪・PWAとの相性がよい

## 必要な工数（消費トークン目安）

- ロジック＋テスト＋UI＋ページ執筆：**約150k〜200kトークン**
  （ピラミッドソリティア（PR #115）と同規模。カード基盤再利用・CPU対戦なし）
- レビュー・修正の往復を含めて 250k 以内を見込む

## やらないこと

- **ワイルドカード・アンドゥ課金などアプリ由来の拡張。** 標準ルールのみ
- **ピラミッドとのページ統合。** 検索クエリが別（「トライピークス」で独立に
  検索される）なので、1ゲーム1ページの原則を保つ
