# 最低賃金チェッカーの令和8年度答申データ追補（8県 → 29県、答申の進行に追随する）

**状態**：実装済み（2026-08-18。8都道府県 → 28都道府県。本番反映はタグリリース待ち）。
**第2次追補を提案中**（2026-08-19 起票。秋田・広島の2県。下記「第2次追補」の節）。
残り県は答申が出しだい、この仕様書の手順で同じように追補する。
**対象**：`tools/lib/saitei-chingin.ts`・`tools/tests/saitei-chingin.test.ts`
**起票**：2026-08-18

## 背景と根拠

`/tools/saitei-chingin/`（最低賃金 早見表・チェッカー）は、令和8年度改定を
「目安ベースの見込み」と「答申済み」を `RevisionStatus` で区別して見せる設計にしてある
（[saitei-chingin-checker.md](./saitei-chingin-checker.md)）。設計どおりに動いているが、
**データが答申の進行に追いついていない。**

- ツールが `answered` を持つのは **8都道府県**
  （北海道・千葉・東京・神奈川・愛知・三重・大阪・兵庫。`DATA_CHECKED_AT = '2026-08-14'`）
- 実際には **2026-08-17 時点で29都道府県が答申済み**（集計サイトの追跡による。
  8月の毎週、複数県ずつ答申が出ている状況）

つまり**21県ぶんの確定情報が「見込み」のまま表示されている**。8月〜9月は
地方最低賃金審議会の答申が毎週出る時期で、「(県名) 最低賃金 いくら」の検索が
1年でいちばん動く。確定額を出せる県が多いほど、このツールの答えの価値が上がる。

さらに今年は**目安（Aランク54円・B/C 56円）を上回る県が多い**
（宮城・鳥取は+60円）。見込み表示は目安から機械的に足した額なので、
**上振れした県では見込みが実際の答申額より低く出ている**。仕様書が
「目安から機械的に足した額を確定額として見せてはいけない」と定めたとおりの
状況が現に起きており、見込みのままにする不利益が具体化している。

`saitei-chingin.ts` の約束（「出典を確認せずにエントリを足さないこと」）どおり、
実装時に各県労働局の報道発表（一次情報）を1件ずつ確認して `answered.source` に持たせる。

## 提案する仕様

1. **答申済み21県の `answered` を追補する**
   - 各県について労働局の報道発表URLを確認し、`yen`・`effectiveOn`・`source` を追加
   - 労働局の発表がまだ「答申」段階（異議申出期間中）であることは既存の表示系が
     扱えるので、UI変更は不要
2. **`DATA_CHECKED_AT` を作業日に更新する**（残り18県が「確認済みで未答申」だと分かるように）
3. **テストの検証を活かす**：既存の `tests/saitei-chingin.test.ts` が
   出典欠落・額の逆転（答申額 < 現行額）を落とすので、追補エントリもそのまま検証に乗る
4. **残り18県の追補は答申が出しだい同じ手順で行う**（この仕様書の手順を再利用する。
   例年9月上旬までに全県出そろい、10月に発効日を迎えると表示は自動で「発効済み」に変わる）

## 期待される効果

| 効果 | 測り方 |
|---|---|
| 29県で「見込み」ではなく確定の答申額を表示できる | 該当県の表示が `answered` になること |
| 目安超えの県（+57〜60円）で実際より低い額を見せている状態が解消する | 宮城・鳥取などの表示額が答申額に一致すること |
| 8〜10月の「最低賃金 いくら」検索の受け皿として答えの鮮度が競合並みになる | GSC の `/tools/saitei-chingin/` の表示・クリック |

金額を出すツールの数字が制度の現在地と合っている、という前提を保つ変更であり、
[hatarakizon-r8-hokenryoritsu.md](./hatarakizon-r8-hokenryoritsu.md) と同じ位置づけ。

## やらないこと

- **集計サイトの数字をそのまま転記する。** 必ず労働局の報道発表で裏取りする
  （集計サイトは所在の手がかりとしてだけ使う）
- **UI・ロジックの変更。** `RevisionStatus` の設計が答申期をそのまま扱えるので、
  今回はデータの追補だけ
- **未答申18県の見込み表示をいじる。** 見込みは目安ベースのままでよい
  （答申が出た県から順に確定表示へ移す）
