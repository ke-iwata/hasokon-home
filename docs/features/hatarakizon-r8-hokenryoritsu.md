# 社会保険 損得計算機の料率が令和8年度に追随しておらず、子ども・子育て支援金が引かれていない

**状態**：提案（2026-08-13）
**対象**：`tools/lib/hatarakizon.ts`・`tools/tests/hatarakizon.test.ts`
**起票**：2026-08-13

---

## 背景と根拠

`/tools/hatarakizon/`（社会保険 損得計算機）は「社会保険に加入すると手取りがいくら減るか」に
金額で答えるツールである。**その手取りの計算に使っている保険料率が2つ古く、
2026年4月に始まった控除が1つ丸ごと抜けている。**

`tools/lib/hatarakizon.ts` の料率定数はこうなっている。

```ts
/** 健康保険料率（本人負担・労使折半後）。協会けんぽの全国平均 約9.98%の半分 */
export const HEALTH_RATE = 0.0499;   // lib/hatarakizon.ts:55

/** 介護保険料率（本人負担・労使折半後）。40〜64歳のみ */
export const KAIGO_RATE = 0.008;     // lib/hatarakizon.ts:58
```

保険料はこの2つだけで組み立てられている（`calcPremiums()`、142〜147行目）。

```ts
const health = roundPremium(std * (HEALTH_RATE + (kaigo ? KAIGO_RATE : 0))) * 12;
```

### 1. 介護保険料率は 1.62%（確定値）で、1.6% ではない

全国健康保険協会「令和8年度の都道府県毎の保険料率」（2026-08-13 取得）に
**「全国一律の介護保険料率（1.62％）」**と明記されている。労使折半後は 0.81%。
コードの `0.008`（＝1.6%の半分）は改定前の値である。

### 2. 健康保険料率の全国平均は 9.9% で、9.98% ではない

同じページの都道府県別料率（2026-08-13 取得）:

| 都道府県 | 令和8年度の料率 |
|---|---|
| 東京都 | 9.85% |
| 埼玉県 | 9.67% |
| 大阪府 | 10.13% |

コメントにある「全国平均 約9.98%」は令和8年度の水準ではない。
令和8年度は全国平均 **9.9%**（労使折半後 4.95%）で、**引き下げ**られている。

**いずれも令和8年3月分（4月納付分）から適用済み**で、起票時点で**5か月前に切り替わっている**。

### 3. 子ども・子育て支援金（2026年4月開始）が1円も引かれていない

これがいちばん大きい。協会けんぽの同ページに、令和8年4月分から
**全国一律 0.23% の子ども・子育て支援金が保険料率に加わる**と書かれている。労使折半なので
本人負担は **0.115%**。健康保険料と同じく標準報酬月額にかかり、給与から天引きされる。

**このサイトはそのことを知っている。** `tools/lib/kosodate-shienkin.ts` に確定値として入っている。

```ts
{
  fiscalYear: 2026,
  era: '令和8年度',
  rate: 0.0023,
  status: '確定',
  note: '全国一律0.23%（被用者保険）。労使折半のため本人負担は0.115%。',
}
```

ところが `hatarakizon.ts` は `支援金` にも `shienkin` にも一切触れていない。

```console
$ grep -l "支援金\|shienkin" tools/lib/hatarakizon.ts tools/lib/nenshu-kabe.ts
$ echo $?
1
```

**同じサイトの2つのツールが、同じ人の同じ給与明細について違うことを言っている。**
`/tools/kosodate-shienkin/` は「あなたは月345円引かれます」と答え、
`/tools/hatarakizon/` は同じ人の手取りをその345円を引かずに出す。

## 現状

どれだけずれるか。標準報酬月額 300,000円（年収360万円相当）の1年分。

| | 現在の計算 | 正しい計算 | 差 |
|---|---|---|---|
| 健康保険（40歳未満） | 179,640円 | 178,200円 | −1,440円 |
| 子ども・子育て支援金 | **0円** | **4,140円** | **+4,140円** |
| 合計（40歳未満） | 179,640円 | **182,340円** | **+2,700円** |
| 合計（40〜64歳） | 208,440円 | **211,500円** | **+3,060円** |

内訳（`roundPremium` は五捨五超入。月額で端数処理してから12倍する実装のまま）:

- 健康保険 現行 `300,000 × 0.0499 = 14,970` → 年 179,640円
- 健康保険 正 `300,000 × 0.0495 = 14,850` → 年 178,200円
- 支援金 正 `300,000 × 0.00115 = 345` → 年 4,140円
- 介護保険 現行 `0.008` → 正 `0.0081`（40〜64歳のみ、上表の下段に反映済み）

**保険料を年 2,700〜3,060円 少なく見積もっており、その分だけ手取りを多く表示している。**
料率の引き下げ（−1,440円）が支援金の欠落（+4,140円）を打ち消しきれず、差は残る。

なお社会保険料は所得税・住民税の社会保険料控除に入るため、保険料が変われば税額も動く
（`calcIncomeTax()` は `socialInsurance` を引数で受けている）。**支援金も医療保険料として
徴収されるので社会保険料控除の対象**であり、定数を直せば税額まで自動で追随する。
手取りの差は上表の額より小さくなるが、方向は変わらない（手取りの過大表示）。

### なぜこのツールで効くのか

金額の絶対値は大きくない。それでも直す理由は、**このツールの存在理由が
「働き損ゾーンの境目はどこか」を1円単位で言い当てることにある**からである。

- 手取りの逆転区間と損益分岐点を出すツールで、保険料を系統的に少なく見ていると、
  **損益分岐点が実際より低い年収に出る**。「ここまで稼げば取り戻せる」の答えが甘くなる
- 標準報酬月額は等級の階段なので、境目付近では数千円の差がそのまま順位を入れ替える
- `updatedAt: '2026-08-12'`（`lib/registry.ts:149`）と表示しているのに、
  中身は令和7年度の料率で動いている

## 提案する仕様

### 1. 料率を令和8年度の値に直す

```ts
/** 健康保険料率（本人負担・労使折半後）。協会けんぽの全国平均 9.9%（令和8年度）の半分 */
export const HEALTH_RATE = 0.0495;

/** 介護保険料率（本人負担・労使折半後）。全国一律1.62%（令和8年度）の半分。40〜64歳のみ */
export const KAIGO_RATE = 0.0081;
```

### 2. 子ども・子育て支援金を保険料に足す

料率は `lib/kosodate-shienkin.ts` が `FISCAL_YEARS` として既に持っている。
**同じ数字を2か所に置かない。** `hatarakizon.ts` からそれを引いて使う。

```ts
import { FISCAL_YEARS } from '@/lib/kosodate-shienkin';

/** 子ども・子育て支援金率（本人負担・労使折半後）。令和8年度の確定値 0.23% の半分 */
const SHIENKIN_RATE = FISCAL_YEARS.find((y) => y.fiscalYear === 2026)!.rate / 2;
```

`calcPremiums()` の健康保険の行に足す。**支援金は健康保険料と一体で徴収されるので、
別建てにせず同じ端数処理に含める**（実際の給与天引きと同じ順序を保つ）。

```ts
const health = roundPremium(
  std * (HEALTH_RATE + SHIENKIN_RATE + (kaigo ? KAIGO_RATE : 0)),
) * 12;
```

`Premiums` の型は変えない。画面の内訳表示で「健康保険料（子ども・子育て支援金を含む）」と
注記を足すだけにする。**内訳を1行増やすと、ツールの主題（働き損の境目）から目が逸れる。**

### 3. 冒頭コメントの一次情報と【データ更新箇所】を直す

`【データ更新箇所】` に支援金率の出どころ（`lib/kosodate-shienkin.ts` の `FISCAL_YEARS`）を
書き足す。料率が2か所に散らないことを、次に触る人に分かるようにしておく。

### 4. テストで固定する（`tools/tests/hatarakizon.test.ts`）

| テスト | 期待 |
|---|---|
| 標準報酬月額300,000・40歳未満の健康保険料（年） | 182,340円 |
| 標準報酬月額300,000・40〜64歳の健康保険料（年） | 211,500円 |
| `HEALTH_RATE + SHIENKIN_RATE` が `kosodate-shienkin` の令和8年度確定値と整合 | 一致すること |
| 支援金を含めた保険料が、含めない場合より必ず大きい | 常に真 |

3つ目が要点である。**`kosodate-shienkin.ts` の料率を更新したときに `hatarakizon` が
置き去りにされたら、テストが落ちる。**今回の不整合そのものを再発させないための一本。

## 期待される効果

| 効果 | 測り方 |
|---|---|
| 同じサイトの2ツールが同じ給与明細について同じことを言うようになる | 上記テストの3本目が通ること |
| 損益分岐点・働き損ゾーンの境目が令和8年度の制度に一致する | 標準報酬月額300,000での保険料が182,340円になること |
| 料率改定を1か所の更新で追えるようになる（次は令和9年度・2027年3月分から） | `FISCAL_YEARS` の更新だけで両ツールが追随すること |

集客の効果を狙う変更ではない。**金額を出すツールの数字が制度と合っている、という前提を回復するもの。**

## やらないこと

- **都道府県別の健康保険料率を選ばせる。** 9.67%〜10.13% の幅があるのは事実だが、
  入力を1つ増やす代償に見合わない。全国平均を使い、画面で「都道府県により数%変わる」と
  断る現在の方針（冒頭コメント17行目）を維持する
- **支援金を保険料の内訳に独立した行として出す。** 給与明細でも健康保険料に含めて
  徴収されるため、実物と食い違う。金額を知りたい人には `/tools/kosodate-shienkin/` がある
- **令和9年度以降の見込み料率で計算する。** `FISCAL_YEARS` は2027年度を`見込み`、
  2028年度を`政府試算`として持っているが、手取りは確定値だけで出す。
  `hatarakizon` は「いまいくら引かれるか」に答えるツールである
- **`nenshu-kabe.ts` にも支援金を入れる。** あちらは壁の**位置**（年収の金額）を答えるツールで、
  支援金は壁の位置を動かさない。手取りを出しているのは `hatarakizon` だけである
