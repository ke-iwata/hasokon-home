## 背景と根拠

### いま世界で一番遊ばれているカジュアルゲームの型が、うちに無い

「8×8の盤面に3つずつ配られるピースを置き、行・列が揃ったら消す」型のパズル
（いわゆる Block Blast 型。系譜としては 1010!・Woodoku と同じ）は、
2024〜2026年のカジュアルゲームで世界最大級のヒットになっており、
2026年8月時点でも日本語のブラウザ移植サイトが乱立するほど需要が続いている
（2026-08-13 Web検索で確認。「ブロックパズル 無料」系のブラウザゲームサイト・
アプリランキング記事が多数ヒットする）。

一方このサイトのゲームは10本（2048・ブロック崩し・フリーセル・麻雀ソリティア・
マインスイーパー・ナンプレ・ノノグラム・リバーシ・ソリティア・スパイダー）で、
**「配置パズル」型が1本も無い**。ノノグラム追加時（[game-nonogram.md](./game-nonogram.md)）に
整理した「同じ型に寄せず、別の入口を作る」方針にも合う。

### ゲームはこのサイトの主要な集客・滞在装置になっている

GA4（2026-08-13 取得 / GA4 Data API `runReport`、`properties/548154955`）の
直近7日のページビュー上位は `/games/`（42）、`/`（36）、`/tools/`（27）、
`/games/solitaire/`（16）、`/games/minesweeper/`（15）と、**ゲームがツールより上位**。
Search Console（2026-08-13 取得）でも「ソリティア クロンダイク」の表示が出始めており、
定番ゲーム名の検索はインデックスさえ載れば表示される。ゲームを1本足すことは
現状もっとも確度の高いコンテンツ拡充になっている。

### 権利関係

- **ゲームの仕組み（メカニクス）自体は著作権・特許の保護対象ではなく**、
  1010!（2014）以降、同型のゲームが多数流通している一般的なジャンル
- ただし **名称と見た目は別**。「Block Blast」「Woodoku」「Blockudoku」等の
  固有名は使わず、一般名詞の「ブロックパズル」を使う（games/CLAUDE.md の
  「ゲームを追加するたびに名称の商標確認」の約束どおり、実装時に
  「ブロックパズル」の商標登録の有無を再確認する）
- グラフィックは自作（既存ゲームと同じトーン）。他作品の配色・演出の模倣はしない

## 現状

`games/app/` に配置パズル型は存在しない。トップ（`/games/`）の一覧にも該当なし。

## 提案する仕様

### ルール

- 8×8の盤面。3種のピース（テトロミノ・ペントミノ風の1〜9マス）が3つずつ配られる
- ピースをドラッグ（スマホはタップで選択→盤面タップで配置、の2操作も併用）で
  空きマスに置く。回転は無し（この型の標準仕様。判断をシンプルに保つ）
- 行または列が埋まると消え、得点。複数同時消し・連続消しはボーナス
- 3つ置き切ると次の3つが配られる。どのピースも置ける場所が無くなったら終了
- 落下も時間制限も無いので、じっくり考えられる（既存の2048と同じ非時間依存型）

### 実装

| ファイル | 内容 |
|---|---|
| `games/lib/block-puzzle.ts` | 盤面・ピース定義・配置判定・消去・得点・終了判定（純関数） |
| `games/tests/block-puzzle.test.ts` | 配置可否・行列同時消し・終了判定・得点の網羅テスト |
| `games/app/block-puzzle/page.tsx` | メタ情報・ルール説明・FAQ（既存ゲームのページ構成を踏襲） |
| `games/app/block-puzzle/Game.tsx` | 盤面UI。`role="grid"` などは既存のグリッドUI（マインスイーパー・ノノグラム）の作法を踏襲 |
| `games/lib/registry.ts` | 一覧に追加 |
| `home/index.html`・`home/404.html`・`home/sitemap-home.xml` | サイト一覧への追加（件数は `scripts/test/home-nav.test.mjs` が見張る） |

- ベストスコアは `localStorage`（2048の `Game.tsx` と同じ作法）
- スマホ最優先。ピースの掴みやすさ（当たり判定を指より大きく）と
  配置プレビュー（置ける場所の色替え）を必須にする

## 期待される効果

- 「ブロックパズル 無料」「ブロックパズル ブラウザ」系の検索需要への入口が1本増える。
  定番ジャンルなのでルール説明コストが低く、直帰しにくい
- 非時間依存のパズルは平均エンゲージメント時間を押し上げる
  （GA4で `/games/block-puzzle/` の平均エンゲージメント時間・再訪率を見る）
- 測り方：追加後4週間の GA4 ページビューと平均エンゲージメント時間、
  Search Console の「ブロックパズル」系クエリの表示回数

## 工数の見積り

- 実装1セッション。消費トークンの目安：**10万〜15万**
  （ゲームロジック＋テストで4〜6万、UI（ドラッグ＆タップ配置）で4〜6万、
  ページ・登録・一覧更新で2〜3万）
- 既存のグリッドUI・スコア保存の作法を再利用できるため、麻雀ソリティアより軽い

## やらないこと

- **回転機能** — この型の標準は回転無し。回転を入れると「どこでも置ける」に寄って
  ゲームオーバーの緊張感が消える
- **時間制限・お邪魔ブロック等の変則モード** — まず定番仕様で出す。
  変則はプレイデータを見てから
- **「Block Blast」等の固有名の使用・SEO上の言及** — 商標リスクを避け、
  一般名詞「ブロックパズル」だけで立てる
