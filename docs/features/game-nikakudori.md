## 背景と根拠

### 日本のブラウザゲームで最古参級の定番なのに、サイトにまだない

- 麻雀牌のペアを「曲がり2回以内の経路」で取っていくこのジャンル
  （「二角取り」「四川省」と呼ばれる）は、日本の無料ブラウザゲームポータルの
  **看板常設ジャンル**。ダンボール・SDIN・ゲームのつぼ・無料ゲームnet 等、
  主要ポータルのほぼすべてが置いており（2026-08-20 に各サイトで確認）、
  アプリ紹介媒体でも2026年版の特集が組まれ続けている恒常需要がある
- 当サイトには**麻雀ソリティア（上海型）が既にあり、牌のアセット
  （`games/lib/mahjong-tiles.ts`・`app/mahjong-solitaire/TileFace.tsx`）と
  タップ操作のUIをそのまま再利用できる**。客層も重なる（麻雀牌×パズル）ので、
  相互の「他のゲーム」導線で回遊が見込める

### 権利関係の整理

- **ルール自体は伝統的なペアマッチパズルで権利者はいない**
  （クロンダイク・上海型ソリティアと同じ整理）。麻雀牌の絵柄はパブリックドメイン
- **名称は別問題**。冒頭の状態欄のとおり、「四川省」は商用タイトル由来なので
  既定名から外し、「二角取り」も含めて運営者が J-PlatPat で確認してから
  名称・slug を確定する（上海→麻雀ソリティア、オセロ→リバーシ、
  ピクロス→ノノグラムと同じ判断の型。`games/CLAUDE.md` の
  「新しいゲームを足すときは必ず名称の商標を確認」の約束どおり）

## 提案する仕様

1. **ルール（ジャンル標準）**
   - 盤面に麻雀牌を格子状に並べる（1層のみ。上海と違い重なりなし）
   - **同じ絵柄の2枚**を選ぶと、2枚を結ぶ経路が**盤外を含めて直線3本以内
     （曲がり角2回以内）**で、途中に他の牌がなければ取れる
   - 全部取れればクリア。取れるペアが無くなったら手詰まり
2. **使う牌**：**数牌・字牌の34種のみを使い、花牌・季節牌は使わない**。
   既存の `mahjong-tiles.ts` は花牌4種・季節牌4種を各1枚持ち
   「同じ組なら合う」特殊ルールで動くが、このゲームは**同一絵柄の2枚**を
   取るため、1枚ずつしかない牌は持ち込まない（**各絵柄は必ず偶数枚**にする。
   実装者が牌の共通化で迷わないための線引き）
3. **盤面サイズと難易度**
   - 3段階（例：小 10×6=60枚 / 中 12×7=84枚 / 標準 14×8=112枚。
     いずれも偶数枚。スマホ縦画面では牌を大きめにした小盤面を既定にする）
   - **シャッフルは「必ず解ける」保証つき**（クリア状態から逆順に置いていく
     生成、または生成後にソルバーで可解性を検証してリトライ）。
     乱数は注入できる形にしてテスト可能にする（games の作法どおり）
   - 手詰まり時は「シャッフル」（残り牌を可解に並べ直す・回数無制限だが
     成績に記録）と「もどす」を置く
4. **操作**：タップ2回（1枚目 → 2枚目）だけ。取れたときは**経路の線を一瞬描いて
   消す**（このジャンルの気持ちよさの核。なぜ取れたかが見える）。
   取れないペアをタップしたときは牌を振動させて理由を邪魔しない程度に示す
5. **ヒント**：取れるペアを1組ハイライトする「ヒント」ボタン（使用回数を成績に記録）
6. **成績**：`_records` でクリア回数・最短時間・ヒント/シャッフル使用数を難易度別に保存
7. **画面**：`games/CLAUDE.md` の「1画面に収める」約束に従う。
   牌は麻雀ソリティアのSVG描画を共通化して使う
8. **ページ構成**：既存ゲームページと同じ
   （metadata / `robots: robotsFor('nikakudori')` / JSON-LD(VideoGame+FAQPage+
   BreadcrumbList) / パンくず / 遊び方 / コツ / 由来の解説 / FAQ / AdUnit×2 /
   他のゲーム一覧）。registry へは `stage: 'preview'` で追加。
   本文・FAQでは「このジャンルは『四川省』とも呼ばれます」のように
   **ジャンルの呼び名として触れるにとどめる**（麻雀ソリティアが本文で
   「上海」に触れているのと同じ整理。運営者の商標確認の結果が
   どちらでも本文は成立する書き方にする）
9. **テスト**：経路探索（0曲がり・1曲がり・2曲がり・盤外経由・遮蔽あり）、
   可解性保証、手詰まり検出、シャッフルの可解性、34種のみ・偶数枚の牌構成を
   純関数（`games/lib/nikakudori.ts`）の単体テストで固定

## やらないこと

- **多層の盤面**（それは上海＝既存の麻雀ソリティア。このゲームは1層が標準）
- **制限時間モード**（初版では入れない。落ち着いて遊べるのがブラウザ版の需要）
- **特定アプリ・ポータルの見た目の再現**（牌の並べ方・配色は自前）

## 期待される効果

- 「二角取り 無料」「四川省 無料」「四川省 ブラウザ」等の恒常クエリの受け皿
  （ページ本文がジャンルの両方の呼び名に自然に触れるため、既定名を
  「二角取り」にしても四川省系クエリの受けは立つ）。
  ポータル系が強い帯だが、**スマホで遊びやすい実装**（タップ操作・1画面・
  牌の大きさ）と経路表示の丁寧さで差別化できる
- 麻雀ソリティア・花札こいこいと客層が重なり、ゲーム間回遊と再訪の積み増し
- 効果は GSC の表示（`games/nikakudori/`）と GA4 の滞在時間・再訪で計測
