# 新ツール「割引・パーセント計算」（何%オフ・割引率の逆算・定番計算の1本目）

**状態**：提案（2026-08-20起票、未実装）
**対象**：`tools/`（`hasokon.com/tools/waribiki-percent/` を想定）
**起票**：2026-08-20

---

## 背景と根拠

### 検索ボリューム最大級の「定番計算」がサイトにない

2026-08-20 の競合調査で、当サイトの「お金・社会保険」はニッチ制度系18本と
異常に厚い一方、**検索ボリューム最大級の定番計算（パーセント・割引・消費税・
時間・手取り）がすっぽり抜けている**ことが分かった。ニッチ制度で拾った流入を
定番計算で受け止める「ハブ」がない。

その定番群の中で「割引・パーセント計算」を最初の1本に選ぶ理由：

- **「パーセント計算」「割引計算」「30パーセントオフ 計算」クラスタは
  月間数万規模の常緑クエリ**（セール期・決算期に跳ねる）
- **競合が個人・小規模サイトのみで、大手が不在**。keisan（カシオ）も
  計算ナビもこの形の専用ツールを看板にしていない。
  「需要あり・競合弱い」の比が今回調査した8候補で最良
- 完全ローカル計算・静的エクスポート向きで、既存の割り勘計算機と
  「買い物・お金の暗算を肩代わりする」文脈がつながる

### 検索意図は3方向ある（既存競合は1方向しか受けていないものが多い）

1. **割引後の値段**：「3,980円の30%オフはいくら？」
2. **割引率の逆算**：「12,800円が8,980円になった。何%オフ？」
3. **パーセントの一般計算**：「5,000円の12%は何円？」「80は200の何%？」

小規模競合は1だけのものが多く、**3方向を1ページで受ける**だけで内容面の
差別化になる。

## 提案する仕様

1. **3つの計算モード**（タブではなく縦に並べる。モバイル1画面の約束の範囲で
   最初のモードが折りたたまれずに見える配置）
   - **割引後の値段**：元の値段 × 割引率 → 割引後価格・値引き額。
     割引率はよく使う 5/10/20/30/50/70% のチップ＋自由入力
   - **割引率の逆算**：元の値段と売値 → 何%オフか・値引き額
   - **パーセント計算**：「AのB%は？」「AはBの何%？」「AがBに増えた/減った変化率は？」
2. **二重割引**：「30%オフからさらに20%オフ」が「50%オフではない」ことを
   計算で示す（合計何%オフかを併記）。レジ前の実需で、解説記事が
   多いのにその場で計算できるツールが少ない
3. **税込併記**：割引後価格に消費税10%/軽減8%の税込額をワンタッチで併記
   （独立した消費税ツールは別提案とし、ここでは併記まで）
4. **端数の扱い**：切り捨て/四捨五入/切り上げを選べる（既定は四捨五入）。
   店舗により異なるため、選択肢があること自体が信頼につながる
5. **早見表**：よく引かれる「〇%オフ早見表」（10〜90%、100円〜10,000円の
   代表価格）を静的に置き、「30パーセントオフ 早見表」系のクエリも受ける
6. **ページ構成**：既存ツールと同じ
   （metadata / `robots: robotsFor('waribiki-percent')` / JSON-LD(WebApplication+
   FAQPage+BreadcrumbList) / パンくず / 使い方 / 計算式の解説 / FAQ / AdUnit /
   関連ツール）。registry へは `stage: 'preview'`・カテゴリ「計算・変換」で追加
7. **計算ロジック**：`tools/lib/waribiki-percent.ts` の純関数に置き、
   端数処理・二重割引・逆算の境界値を単体テストで固定
8. **関連導線**：割り勘計算機・（あれば）消費税計算と相互リンク

## やらないこと

- **ポイント還元の実質値引き計算**（初版では入れない。還元率の条件が
  複雑すぎて誤解を生む。FAQで「ポイントは値引きと同じではない」に触れるまで）
- **クーポン併用の店舗別ルール**（一般化できない）
- **独立した消費税計算ツール**（別提案。ここでは税込併記まで）

## 期待される効果

- 「パーセント計算」「割引計算 何パーセント」「〇%オフ 計算」「二重割引 計算」
  等の常緑クエリの受け皿。競合が弱いので、ドメインが若くても
  上位が現実的に狙える帯
- 定番計算の1本目として、ニッチ制度ツール（年収の壁・ふるさと納税等）との
  内部リンク網の起点になる
- 効果は GSC の表示・掲載順位（`tools/waribiki-percent/`）で計測
