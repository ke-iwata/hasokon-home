## 何が抜けているか（2026-11-18、e-Gov 法令API で条文本文を取得して確認）

### A. フリーランス法 第4条第3項〜第5項（再委託の30日）— 画面にも計算にも無い

**特定受託事業者に係る取引の適正化等に関する法律**（令和5年法律第25号）第4条：

- **第3項**：元委託者から業務委託を受けた特定業務委託事業者が、その業務の全部または一部をフリーランスに**再委託**した場合
  （第3条第1項の明示で「再委託である旨、元委託者の氏名又は名称、元委託支払期日その他の公正取引委員会規則で定める事項」を**明示した場合に限る**）は、
  報酬の支払期日は「**元委託支払期日から起算して三十日の期間内**において、かつ、できる限り短い期間内」に定める
- **第4項**：定めなかったときは**元委託支払期日**が、30日を超えて定めたときは「**元委託支払期日から起算して三十日を経過する日**」が支払期日とみなされる
- **第5項ただし書**：フリーランス側の責めに帰すべき事由で払えなかったときは、その事由が消滅した日から**60日（第3項の場合は30日）以内**

いまの実装との食い違い：

| 箇所 | いま | 条文 |
|---|---|---|
| `tools/lib/shiharai-kijitsu.ts` | `legalDueDate(received)` が受領日＋59日だけ。再委託の分岐が無い（`再委託` の語が 0 件） | 再委託（明示あり）なら**元委託支払期日＋29日**（元委託支払期日を1日目として30日目） |
| `tools/app/shiharai-kijitsu/page.tsx` の FAQ「フリーランスへの発注は？」 | 「第4条で、受領日から60日以内に報酬の支払期日を定めます」と言い切り | 再委託（明示あり）は**受領日ではなく元委託支払期日から30日**。受領日から60日より**遅くなることがある**（元委託の期日が受領日の50日後なら80日目まで） |
| 仕様書 [shiharai-kijitsu-toriteki.md](./shiharai-kijitsu-toriteki.md) | 「再委託の例外：第3項で、元委託の支払期日から起算して30日以内」と1行あるが、「作るもの」に落ちていない | — |

- 再委託の30日は**期日を遅くしてよい方向の特則**なので、ツールが60日だけを出すと、再委託を受けたフリーランスには「もう遅れている」と誤って見え、
  発注側（中間の事業者）には「60日を超えたら違反」と実際より厳しく見える。どちらの読者にも条文と違う答えになる
- 取適法（旧下請法）には再委託の特則は**無い**。取適法の対象でもある組み合わせ（`verdict: 'both'`）では、取適法の60日が別にかかることを並べて出す

### B. 取適法 第6条第2項（不当な減額にも遅延利息）— 画面に無い

**製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律**（昭和31年法律第120号）第6条第2項：

> 委託事業者は、中小受託事業者の責めに帰すべき理由がないのに製造委託等代金の額を減じたときは、……製造委託等代金の額を**減じた日又は**中小受託事業者の給付を**受領した日から起算して六十日を経過した日の**いずれか**遅い日から**当該減じた額の支払をする日までの期間について……公正取引委員会規則で定める率を乗じて得た金額を遅延利息として支払わなければならない。

- 元の仕様書（38行目）には書いてあるが、`page.tsx` にも `Calculator.tsx` にも「減額」「減じ」の語が 0 件
- 「振込手数料を勝手に差し引かれた」「協賛金の名目で引かれた」は**取適法の相談でいちばん多い型**で、検索でも「下請法 減額 遅延利息」は支払遅延と並んで引かれる
- 計算は第1項と同じ部品で足りる：起算日を `max(減じた日, 受領日＋60日)` にし、元本を「減じた額」にするだけ

## 提案する直し方

### A. 再委託の30日

1. `lib/shiharai-kijitsu.ts`
   - 定数 `SAIITAKU_LIMIT_DAYS = 30`（【データ更新箇所】。フリーランス法第4条第3項）
   - `saiitakuDueDate(motoDue: DateParts): DateParts` → 元委託支払期日＋29日
   - `Applicability` に `saiitakuApplies: boolean` を足すのではなく、**入力側に「再委託で、元委託の支払期日を明示されている」のチェックと元委託支払期日の日付**を足す
     （再委託かどうかは資本金・従業員からは決まらないため）
2. `Calculator.tsx`（「納品日から期日を出す」モード）：フリーランス法がかかる判定のときだけ、折りたたみで
   「再委託で、発注書に元委託の支払期日が書いてある」チェック → 元委託支払期日の入力。結果を
   「**元委託支払期日 ◯/◯ を1日目として30日目＝◯/◯ まで**（フリーランス法第4条第3項）」に切り替える（`verdict: 'freelance'` のとき）。
   - **`verdict: 'both'` のときは、見出し（大きく出す日付）を早いほうにする。** 取適法には再委託の特則が無いので、
     **取適法の受領日から60日目と、フリーランス法の再委託の30日目のうち早い日**に払えば両方を満たし、遅いほうに合わせると取適法の60日を超えるおそれがある。
     ふつうは取適法の60日目が早いので、見出しは「**◯/◯ まで**（取適法第3条：受領日から60日目）」、
     フリーランス法の再委託の期日は**補足**として「フリーランス法だけで見れば元委託支払期日から30日目＝◯/◯ まで（第4条第3項）。取適法の対象でもあるので、早いほうの ◯/◯ までに」と小さく出す。
     再委託の30日目のほうが早いときは、見出しをそちらにする（`min` を取るだけ）
   - どちらの法律で扱われるかは、いまの画面どおり「所管の窓口で確かめてください」のまま
3. **「第4条の60日」と言い切っている箇所をすべて直す**（FAQ だけ直すと同じページの中で答えが食い違う。main `1b08ba6` 時点で4か所）：
   | 箇所 | 直し方 |
   |---|---|
   | `page.tsx` の FAQ「フリーランスへの発注は？」 | 1文足す：「再委託で、元委託者の名前と元委託の支払期日などを明示されているときは、受領日からではなく**元委託の支払期日から30日以内**です（第4条第3項）。」 |
   | `page.tsx` 209〜210行（本文「フリーランス法第4条の60日ルールがかかります」） | 「（再委託で元委託の支払期日などを明示されているときは、元委託の支払期日から30日）」を添える |
   | `Calculator.tsx` 544行（`フリーランス法：第4条の60日がかかります`） | 「第4条の60日（再委託は元委託の支払期日から30日）がかかります」 |
   | `Calculator.tsx` 552行（役員2人以上の法人の注記） | 同じく「（再委託は元委託の支払期日から30日）」を添える |

   本文「計算のしかた」に h3「再委託のとき（フリーランス法）」を1つ。行番号は main が動けばずれるので、実装時に `第4条の60日` と `60日ルール` で grep して取り直す
4. 明示が無い再委託は特則に当たらない（第3項の括弧書き）ので、**チェックを外せば60日に戻る**ことを画面で一言

### B. 減額の遅延利息

1. `lib/shiharai-kijitsu.ts`：`reductionInterest(reducedAmount, received, reducedOn, paidOn)` → `{ fromDate, days, interest }`。
   起算日は `max(reducedOn, 受領日＋60日)`、率・日割り・円未満の扱いは第1項の `lateInterest` と同じ部品を使う（同じ規則を2か所に書かない）
2. 「遅延利息を出す」モードに「減額された分」の切り替えを足し、`減額された額`・`減額された日`（支払日に差し引かれたならその日）を入れる
3. `page.tsx` に FAQ を1問：「振込手数料や協賛金を差し引かれた分にも遅延利息はつきますか？」
   → 「中小受託事業者の責めに帰すべき理由がないのに減額したときは、減じた日と受領日から60日を経過した日の遅い方から、減じた額を払う日まで年14.6%（第6条第2項）。
   振込手数料を受注側の負担にすることを発注時に書面で合意していない場合の差し引きは減額に当たりうる」まで。**「違法です」と断定しない**
   （振込手数料の扱いは公取委の運用基準・Q&A で文言を確かめてから書く。確かめられなければ FAQ は第6条第2項の条文の言い換えだけにする）
4. フリーランス法には遅延利息の規定が無いので、`lateInterestApplies: false` のときは減額の切り替えも出さない

## やらないこと

- **明示の要件（公正取引委員会規則で定める事項）の中身の判定**：チェック1つで「明示されている」とみなす。何を明示すればよいかは公取委の資料へのリンクで足りる
- **前払金の配慮（第4条第6項）**：努力義務で計算に乗らない。本文にも書かない
- **振込手数料が減額に当たるかの判断**：条文の当てはめまで
