**状態**：**実装済み（2026-09-19。本番反映はタグリリース待ち）**。
起票は 2026-09-18。**2026-09-19 の企画レビュー（#231）の必須2点を反映済み**
（通算3年の起点は「事業所が制度の利用を申し出た月」・利用の停止についての案内）。

## 背景と根拠

### 制度の要点（2026-09-18 取得。一次資料は日本年金機構「保険料調整制度とは」）

年金制度改正法（令和7年法律第69号）で、短時間労働者への適用拡大に合わせて
**通算3年の時限措置**として新設された。
一次資料：[日本年金機構「保険料調整制度とは」](https://www.nenkin.go.jp/service/kounen/hokenryo/hokenryochosei/gaiyo.html)
（同ページのちらし `gaiyo.files/chirashi202610.pdf`・パンフレット `gaiyo.files/pamphlet202610.pdf`）。

| 項目 | 内容 |
|---|---|
| 開始 | **2026年（令和8年）10月1日** |
| 使える事業所 | **(a) 2026年10月1日以降に「任意特定適用事業所」になった事業所**（被保険者数 50人以下で労使合意により適用拡大する事業所）。**(b) 2027年10月以降、企業規模要件の縮小（51人以上 → 36人以上 → …）で新たに「特定適用事業所」になった事業所**。**2026年9月30日以前から任意特定適用事業所だった事業所、および既存の特定適用事業所（51人以上）は対象外** |
| 対象者 | その事業所で新たに健康保険・厚生年金に加入した短時間労働者のうち、**標準報酬月額 12.6万円以下**（月収おおむね 13万円未満） |
| 事業主の申出 | **任意。** 事業主が「保険料調整開始申出書」を提出した事業所だけ（対象日から 2年以内） |
| 本人負担の割合（1〜2年目） | 標準報酬月額 88,000円以下 **25%**／98,000円 **30%**／104,000円 **36%**／110,000円 **41%**／118,000円 **45%**／126,000円 **48%**（残りは事業主負担） |
| 3年目 | 軽減幅が半分になる：88,000円 **37.5%**／98,000円 40%／104,000円 43%／110,000円 45.5%／118,000円 47.5%／126,000円 49% |
| 期間 | **事業所が制度の利用を申し出た月から通算3年**（本人の加入月からではない）。
一次資料は「事業所が制度の利用を申し出た月から通算3年間が経過する月まで」「制度利用開始月から通算して3年目は
保険料軽減割合が1〜2年目の半分となります」としている。**途中で加入した人は、自分の加入から3年ではなく
事業所の残り期間しか軽減されない**。4年目から労使折半（50%）に戻る |
| 利用の停止 | **事業主の申出ではやめられない**（「被保険者の保険料負担軽減のための制度であり、事業主からの申出でやめることはできません」）。ただし**途中で自動停止される場合がある** |
| 事業主の追加負担 | いったん納付し、3か月後の保険料から控除される（国が補填）。**事業主の実負担は増えない** |

軽減の対象は**健康保険料・厚生年金保険料**。

**【確認済み】2026-09-19 にパンフレット（`pamphlet202610.pdf`）を読んで、留保していた点は決着した。**

1. **介護保険料・雇用保険料は軽減の対象外**（確定）。Q5 の注記が
   「**賞与に関する保険料や、介護保険料、子ども・子育て支援金は、制度の対象外です**」と明記している。
   Q1 の注記も「対象となる保険料は、賞与に関するものを除いた厚生年金保険料・健康保険料です」。
2. **「労働時間を減らして条件に入った人は除く」という要件は無い**（確定）。Q3-1 の対象被保険者は
   **4条件すべて**に当てはまる短時間労働者：①対象事業所で勤務 ②週の所定労働時間が20時間以上かつ
   フルタイムの3/4未満 ③標準報酬月額が12.6万円以下（月収13万円未満）④学生ではない
   （夜間学生や休学中を除く）。ほかに 70歳以上の高齢任意加入（健保のみ対象）・複数事業所で加入・
   産休育休で保険料免除中の人が対象外と書かれている。

**子ども・子育て支援金は軽減されない**（上記1のとおり。**起票時の「健保の割合に従う想定」は誤りだった**）。
[hatarakizon.ts](../../tools/lib/hatarakizon.ts) は支援金を健康保険料と同じ行・同じ端数処理で足しているので、
**割合は健康保険の料率にだけ掛ける**こと（支援金・介護まで巻き込むと軽減額が過大に出る）。

そのほかパンフレットで確認できたこと：軽減額は「通常の保険料額 × 保険料軽減割合」で
**厚生年金保険料と健康保険料は別々に計算**し、1円未満は四捨五入する。
**「被保険者が将来受け取る年金額への影響はありません」**と明記されている。
対象事業所は起票時に書いた (a)(b) より広く、任意適用事業所の個人事業所を含む❶〜❹の4類型
（ただし本人が入力できる情報ではないので、ツールの方針は変えない）。
自動停止は「対象被保険者数が0人になった場合」（Q8）。

### いまの計算機がどう外れるか

`hatarakizon.ts` の `calcPremiums()` は `lib/shaho-ryoritsu.ts` の**労使折半後の本人負担率**
（健康保険 4.95%・厚生年金 9.15% ほか）で保険料を出している。制度の対象者は、
同じ標準報酬月額でも健康保険・厚生年金の本人負担が **25〜48%** なので、年額で次のぶんだけ違う
（協会けんぽ全国平均・厚生年金 18.3%・40歳未満・支援金は健保に含めた概算。実装時に `calcPremiums()` で再計算する）：

| 標準報酬月額（年収の目安） | 折半（いまの表示） | 1〜2年目の本人負担 | 差（年） |
|---|---|---|---|
| 88,000円（約106万円） | 約 15.1万円 | 約 7.6万円（25%） | **約 7.5万円** |
| 104,000円（約125万円） | 約 17.7万円 | 約 12.8万円（36%） | 約 5.0万円 |
| 126,000円（約151万円） | 約 21.5万円 | 約 20.6万円（48%） | 約 0.9万円 |

年収 106万円前後では本人負担が**年 7万円以上**変わる。`hatarakizon` の
「働き損ゾーン」（加入で手取りが減る年収帯）と「損益分岐点」（いくら稼げば取り戻せるか）は
この保険料から出しているので、**対象者にはゾーンの幅も分岐点も違う数字を見せている**。
`nenshu-kabe` の「106万円の壁」の説明も、「撤廃された」だけで「軽減がある」に触れていない。

## 提案する仕様

### 前提：いまの加入判定のままでは、対象者の画面にセレクトが出ない

**これが実装前にいちばん先に解く問題。** 制度の対象事業所は「**2026年10月以降に任意特定適用事業所に
なった事業所**（被保険者数 50人以下）」等なので、**対象者は全員「従業員51人以上ではない勤務先」の人**。
ところが `nenshu-kabe.ts` の `evaluateShaho()` は、`size51` が `false` だとそこで打ち切る：

```ts
// tools/lib/nenshu-kabe.ts:282-288（2026-09-19 確認）
if (!(input.size51 && input.hours20)) {
  return {
    kind: 'not-applicable',
    reason: '勤務先の社会保険に加入するのは「従業員51人以上」かつ「週20時間以上」の両方を満たす場合です。',
  };
}
```

`calcHatarakizon()` はこれを受けて即 return するので、`size51 = false` では**保険料も働き損ゾーンも
損益分岐点も計算されない**。「`size51 = true` のときはセレクトを出さない」（制度の対象外だから）と
合わせると、**どちらに転んでも対象者には何も表示されない**。

| 入力 | 実際の意味 | いまの挙動 |
|---|---|---|
| `size51 = true` | 51人以上＝**制度の対象外** | 計算される（セレクトは出さない） |
| `size51 = false` | 50人以下＝**制度の対象者** | **「対象外です」で打ち切り。セレクトを置く画面が存在しない** |

**この打ち切りの文言は、施行後は事実としても正しくない。** 任意特定適用事業所は 50人以下でも
短時間労働者を加入させるので、「加入するのは51人以上かつ週20時間」は誤りになる。

#### 直し方：チェックボックス1つを3択にする

UI もいまは「勤務先の従業員が51人以上」のチェックボックス1つ（`tools/app/hatarakizon/Calculator.tsx:236-240`）で、
「50人以下だが加入することになった勤務先」を表現できない。**`ShahoStatus` / `evaluateShaho()` に
真ん中の状態を足す**：

| 勤務先 | 加入判定 | 保険料調整制度 |
|---|---|---|
| 従業員51人以上（特定適用事業所） | 週20時間以上で加入 | **対象外**（セレクトを出さない） |
| **50人以下だが社会保険に加入することになった（任意特定適用事業所）** | **加入する** | **セレクトを出す** |
| 50人以下で加入しない | 対象外（いまの文言のまま） | — |

- `KabeInput` の `size51: boolean` を、3値（`'over51'` / `'optional-covered'` / `'not-covered'`）に置き換える。
  既存の呼び出しが壊れるので、**移行の仕方（別フィールドを足して段階的に移すか、一度に置き換えるか）も
  実装時に決める**
- **既存の壁判定（`WALL_DEFS` の `applies: (i) => … i.size51 && i.hours20`）の結果が変わらないことを
  テストで固定する。** `'over51'` は従来の `true`、`'not-covered'` は従来の `false` と同じ結果になること
- **この変更があるので「セレクトを1項目足すだけ」では収まらない。** 工数を積み直した（下記）

### 入力（`hatarakizon` に足す1項目）

「**勤務先が保険料調整制度を使い始めてから何年目ですか？**」のセレクト（既定：**使っていない／わからない**）

- 使っていない／わからない → いまの計算（折半）
- 使っている（**勤務先の利用開始から1〜2年目**）
- 使っている（**勤務先の利用開始から3年目**）

**年数は「本人が加入してから」ではなく「事業所が制度の利用を申し出てから」で数える。**
ヘルプ文は「**勤務先が制度を使い始めてから何年目か（勤務先に確認）**」とする。
途中入社・途中加入の人は自分の加入年数と一致しないので、ここを取り違えると軽減が切れる時期を誤る。

制度は**事業主の申出制**なので、既定は「使っていない」。対象事業所の条件（2026年10月以降に
任意特定適用事業所になった、または 2027年10月以降の規模要件縮小で特定適用事業所になった）は
入力に持ち込まず、**ヘルプ文と FAQ で「あなたの勤務先が対象かは勤務先に確認」**と案内する。
`size51`（従業員51人以上か）が `true` のときは制度の対象外なので、**セレクトを出さない**
（既存の特定適用事業所は対象外。2027年10月の規模要件縮小後は `size51` の意味が変わるので、
そのときに [nenshu-kabe-2026-10-wall-removal.md](./nenshu-kabe-2026-10-wall-removal.md) の表に沿って直す）。

### 計算（`tools/lib/hatarakizon.ts`）

- `lib/shaho-ryoritsu.ts` に**制度データ**を足す：`HOKENRYO_CHOSEI = { startsOn: '2026-10-01', years: 3, shares: [{ standardMax: 88_000, y12: 0.25, y3: 0.375 }, { standardMax: 98_000, y12: 0.30, y3: 0.40 }, …, { standardMax: 126_000, y12: 0.48, y3: 0.49 }] }`。
  出典 URL と確認日をコメントに残す（他の料率と同じ約束）
- `calcPremiums(income, kaigo, chosei?)` に第3引数（`'none' | 'y12' | 'y3'`）を足す。
  標準報酬月額が 126,000円を超えるときは割合を適用しない（対象外）。
  **健康保険料（支援金を含まない本体だけ）と厚生年金保険料**に `share / 0.5` を掛け、
  子ども・子育て支援金・介護保険料・雇用保険料はそのまま（**2026-09-19 の確認で、
  支援金も軽減の対象外だと分かった**。起票時は「支援金も健保の割合に従う」と書いていた）。
  端数処理は既存どおり（月額で丸めてから年額）
- `calcHatarakizon()` の結果に `choseiApplied: boolean` と `choseiSavings`（折半との差・年額）を足し、
  画面で「制度で軽くなっている分」を出せるようにする
- **年金の増分（`recoverYears`）は変えない。** 本人負担が減っても標準報酬月額は同じで、
  将来の年金額は変わらない。「払った保険料を何年で取り戻せるか」は本人負担が減るぶん短くなるので、
  そこは本人負担の実額で計算する（これがこの制度の「得」の核心）

### `nenshu-kabe`（**注記だけ。手取り比較は作らない**）

**`tools/lib/nenshu-kabe.ts` には import 文が1つも無く、保険料・手取りの計算を持っていない**
（壁の判定と説明文だけ。2026-09-19 確認）。`tools/app/nenshu-kabe/Calculator.tsx` が import しているのも
`@/lib/nenshu-kabe` だけで、`hatarakizon` への依存はゼロ。したがって
「加入後の手取り比較にセレクトを足す」は**手取り比較機能の新規追加**にあたり、この提案の範囲を超える。

- **やること**：106万円の壁の説明文に「2026年10月からは撤廃。勤務先が保険料調整制度を使う場合、
  加入後の保険料は最長3年、本人負担が 25〜48% に軽減される（金額は社会保険 損得計算機へ）」の注記と、
  `/tools/hatarakizon/` へのリンクを足す
- **やらないこと**：`nenshu-kabe` に手取り比較を作ること。金額は `hatarakizon` の役割で、
  同じ計算を2か所に置かない（作るなら別提案として工数を積む）
- ただし **`evaluateShaho()` の3択化は `nenshu-kabe.ts` にある**ので、そのファイルは触る

### テスト

- 標準報酬月額 88,000円・1〜2年目：健康保険・厚生年金の本人負担が
  **制度適用前（労使折半＝全体の 50%）の半分＝全体の 25%**。介護・雇用保険は不変
  （表の「25%」は**保険料全体に対する本人の割合**で、折半額に対する割合ではない）
- **制度を適用しても `benefits`（加入して増える厚生年金などの給付）が変わらないこと。**
  本人負担が減っても標準報酬月額は同じなので将来の年金額は変わらない。
  **この制度でいちばん誤りやすいところなので、テストで固定する**
- 3択の置き換えで**既存の壁判定の結果が変わらない**こと（`'over51'` = 従来の `true`、`'not-covered'` = 従来の `false`）
- 126,000円・3年目：49%。134,000円：割合を適用しない（折半のまま）
- `size51 = true` のときはセレクトの値にかかわらず折半
- 施行日前（`asOf < 2026-10-01`）は既存どおり（既存の `asOf` の仕組みに乗せる）

## 期待される効果

**まず、対象になる人は多くない。** 軽減を受けられるのは「**50人以下**で、**2026年10月以降に新たに**
任意特定適用事業所になり、**かつ事業主が申出した**事業所」の短時間労働者だけ。
**10/1 の賃金要件撤廃で新たに加入する人の大多数（51人以上の既存の特定適用事業所で働く短時間労働者）は
軽減の対象外**で、入力の既定も「使っていない／わからない」なので、大半の利用者には表示が 1円も変わらない。
**「サイト全体の数字を動かす施策」ではなく、「該当する人に誤った数字を出さないための修正」**として見てほしい。

- **正確さ（これが主目的）**：**該当する人**に対して「働き損ゾーン」と「損益分岐点」を
  実際より広く（＝「働かないほうが得」の側に）見せる状態を無くす。年収 106万円前後の対象者で
  本人負担は年 7万円以上違う。CONCEPT.md の「勝ち筋は正確さと深さ」に直結する
- **副次：加入判定そのものの誤りが直る。** 3択化によって「50人以下でも任意特定適用事業所なら加入する」が
  表現できるようになる。いまの「加入するのは51人以上かつ週20時間」という文言は、施行後は事実として誤り。
  **対象者の広さでいえば、こちらのほうが効く**
- **検索**：「保険料調整制度 計算」「保険料調整制度 手取り」は解説記事しか無い（2026-09-18 時点）。
  施行後 1〜3か月で `/tools/hatarakizon/` の Bing 着地が増えるかを GA4 の `landingPage` で見る
  （比較基準：2026-09-04〜09-17 の 3 セッション）。**ただし上のとおり母数が小さいので、
  数字が動かなくても失敗とはしない**

## やらないこと

- **勤務先が対象事業所かどうかの判定。** 「2026年10月以降に任意特定適用事業所になったか」「事業主が申出したか」は
  本人が入力できる情報ではない。勤務先に確認するよう案内する
- **事業主側の追加負担額・還付の計算。** 事業主向けで、このサイトの客層（本人）と違う。事業主の実負担は増えない旨を FAQ に書くだけ
- **3年の途中で標準報酬月額が変わる場合の月割り。** 年額の概算ツールなので、選んだ年目の割合で通す。FAQ に「等級が変わると割合も変わる」と書く
- **自動停止の条件の実装。** 一次資料は「自動停止される場合がある」とだけ書いており、条件を本人が判断できない。FAQ で勤務先に確認するよう案内するにとどめる
- **`nenshu-kabe` への手取り比較の新規追加。** 上記のとおり同ファイルは計算を持っていない。
  金額は `hatarakizon` の役割で、同じ計算を 2か所に置かない
- **2027年10月以降の規模要件縮小（36人以上）の先取り。** `size51` の意味が変わるので別の改修。[nenshu-kabe-2026-10-wall-removal.md](./nenshu-kabe-2026-10-wall-removal.md) の表を持つ
