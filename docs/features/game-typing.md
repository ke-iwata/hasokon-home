**状態**：提案（2026-09-09 起票、未実装。2026-09-10 レビュー指摘を反映）。
実装したら `stage: 'wip'` から始め、判定リストを満たしたら `preview` → `public` に上げる。
**対象**：`games/`（`hasokon.com/games/typing/` を想定）

**名称の商標確認は運営者のタスク**（この環境から J-PlatPat を引けない。
色水ソート・二角取り・ボルダリングと同じ）。確認対象は「**タイピング練習**」。
一般名称（行為の名前）と考えられるが、未確認のものを確認済みのように扱わない。
既存タイトル（寿司打・e-typing 等）の名称・題材・演出は**一切参照しない**。

## 背景と根拠

- 「タイピング練習」「タイピングゲーム 無料」は**新社会人・在宅ワーカー・
  ブランク明けの再就職者の evergreen 需要**。
  当サイトにはスネーク・2048・ナンプレ・ピンボールなど**キーボード操作に
  対応済みのゲームはある**（矢印キー等。いずれもタッチ・スワイプの代替があり
  キーボードは任意）が、**キーボードを必須とするゲーム・キーボードでしか
  成立しないジャンルは1本もない**。その間口を広げる提案
- GA4 の直近28日では、ゲームは滞在が長い（ブロックパズル 平均833秒・大富豪 858秒）。
  タイピング練習は「毎日数分やる」**反復訪問型**で、この強みと相性がよい
- **`/games/` 配下はデスクトップが多数派**（GA4 直近28日・2026-09-10取得：
  desktop 26ユーザー（65%）・mobile 13（33%）・tablet 1。サイト全体では
  desktop 169ユーザー・82%）。キーボード前提でも訪問の約2/3にはそのまま刺さり、
  タッチのみの端末を案内画面に回す影響は限定的と判断できる（案内画面の設計は下記）
- カード・盤面と違って権利関係の論点が少ない（出題する語彙を自前で持てば、
  既存タイトルの要素を使う必要がない）

## 提案する仕様

### 遊び方（1ラウンド60秒）

1. 画面に「お題の語」（ひらがな＋ローマ字表記）が出る
2. ローマ字で打つ。正しいキーは文字が確定し、間違いはその場で赤くなる（進まない）
3. 1語打ち切ると次の語。60秒で何文字打てたかを競う
4. 結果は **KPM（1分あたり打鍵数）・正確率・打てた語数**。
   既存の `lib/records.ts`（[game-records.md](./game-records.md)）で自己ベストを保存

### 難易度（3段階）

| レベル | 出題 | 対象 |
|---|---|---|
| やさしい | 2〜4文字のひらがな語（ねこ・りんご） | ホームポジション練習中 |
| ふつう | 5〜8文字の日常語（さんぽみち・ゆうびんきょく） | 一般 |
| むずかしい | 長めの語・促音/拗音/長音を含む（しゅっぱつしんこう） | 速度を競う |

### 出題語彙はデータとして持つ

- `games/lib/typing-words.ts` に**自前の語彙リスト**（レベル別・各100語以上）を持つ。
  パスワード生成の日本語ワードリスト（`tools/lib/password-words.ts`）で確立した
  「語彙をデータで持ち、品質をテストで固定する」型を踏襲する
- テストで固定すること：語数・重複なし・使用文字種（ひらがなのみ）・長さの範囲・
  **ローマ字変換表との整合**（変換できない文字が混ざっていないこと）

### ローマ字判定は複数表記を受け付ける

- 「し」= si / shi、「ちゃ」= tya / cha、「ん」= n / nn（次の文字により）など、
  **ヘボン式・訓令式の両方**を受け付ける。判定表は `games/lib/typing-romaji.ts` に持つ
- 判定表の設計は `tools/lib/hebon-romaji.ts`（ヘボン式変換の実装済み知見）を参照する。
  ただし方向が逆（ローマ字→かなの照合）なので流用ではなく参照にとどめる
- 促音（っ = 子音重ね）・「ん」の n 1打/2打の分岐が判定の山場。テストで網羅する

### キーボード前提の扱い（このサイト初の論点）

- **スマホ（タッチのみ）の場合は、遊べない理由と「パソコンで遊んでください」の案内を出す**。
  ソフトキーボードでのローマ字打ちは練習にならず、中途半端に対応すると
  「操作できない」印象だけ残る。mobile-one-screen の約束（1画面に収める）は
  案内画面にも適用する
- **案内画面を行き止まりにしない。** キーボードの要らない他のゲーム
  （ブロックパズル・ソリティア・2048など2〜3本）へのカードを案内画面に置き、
  検索から来たタッチ端末の利用者をサイト内で拾う（そのまま離脱させると
  ゲームの滞在時間の平均も押し下げる）
- 検出は「物理キーボードの keydown が来たら遊べる」を正とし、タッチデバイスでも
  外付けキーボード（iPad等）なら遊べるようにする

### SEO

- 想定キーワード：「タイピング練習 無料」「タイピングゲーム ブラウザ」
  「タイピング 練習 大人」。ビッグワードは競合が強いので、
  ページ本文にホームポジション・ローマ字表（ヘボン式変換ツールへの内部リンク）の
  解説を置いてロングテールを拾う
- **児童向けを明示的に狙わない。** 小学生・GIGAスクール系のキーワードは使わない。
  児童向けを明示すると広告配信側の「児童向けコンテンツ」の扱い
  （パーソナライズ広告の制限）の確認が必要になり、当サイトには前例が無い。
  ローマ字入力に絞る設計は元々大人の練習用と噛み合っている
- `metadata` に `robots: robotsFor('typing')`（feature-flags の約束）

## 公開の判定リスト（preview に上げる条件）

- [ ] ローマ字判定：複数表記（si/shi・tya/cha・n/nn・っ）のテストが通る
- [ ] 語彙リストの品質テスト（語数・重複・文字種・変換整合）が通る
- [ ] 60秒ラウンドが Esc/リトライで正しくリセットされる
- [ ] タッチのみの端末で案内が出て、外付けキーボードなら遊べる
- [ ] 自己ベスト（KPM・正確率）が `records` に保存され再訪時に出る

## やらないこと

- **かな入力対応。** ローマ字入力のみ（利用者の大半をカバーし、判定が単純になる）
- **英文・コード打ちモード。** 需要はあるが初版は日本語ローマ字に絞る（次版候補）
- **対戦・ランキング（他人との比較）。** サーバーが要る。自己ベストのみ
- **寿司・料理などの演出テーマ。** 既存タイトルの連想を避け、シンプルな出題表示にする
