## 背景と根拠

### 令和8年8月1日に日額が改定されたばかり（時事性）

雇用保険の賃金日額・基本手当日額の上限額等は毎年8月1日に改定される。
令和8年度分は**令和8年7月31日の官報で公布され、8月1日から適用**
（[厚労省の告知ページ](https://www.mhlw.go.jp/stf/newpage_74837.html)）。
「失業保険 上限 いくら」「基本手当日額 令和8年」の検索が立ち上がる時期で、
最低賃金チェッカー（[saitei-chingin-checker.md](./saitei-chingin-checker.md)）と
同じ「改定直後に正確な数値で受ける」型がそのまま使える。

令和8年8月1日からの基本手当日額（取得日 2026-08-19、厚労省告知・官報より）:

| 区分 | 改定後 |
|---|---|
| 上限（30歳未満） | 7,450円 |
| 上限（30〜44歳） | 8,270円 |
| 上限（45〜59歳） | 9,110円 |
| 上限（60〜64歳） | 7,830円 |
| 下限（全年齢） | 2,562円 |

### 「失業保険 いくら」は社会保険クラスタ最大級の恒常クエリ

当サイトの編集上の強みは「制度改正を数字に落とす」社会保険・税ツール群
（傷病手当金・高額療養費・年収の壁・在職老齢年金・最低賃金）。
退職・失業まわりはその中心的な生活イベントなのに、**受け皿が1本もない**。
「失業保険 計算」「失業手当 いくら もらえる」「自己都合 失業保険 いつから」は
季節に関係ない大ボリュームの定番で、傷病手当金（病気で休む）と対になる
「辞めたらいくら」の枠を埋める。

### 令和7年4月の給付制限短縮を正確に説明している競合が少ない

自己都合退職の給付制限は**令和7年4月1日から原則2ヶ月 → 1ヶ月に短縮**され、
教育訓練等を受ける場合は給付制限自体が解除される（雇用保険法改正）。
古い「2ヶ月（または3ヶ月）」のまま説明している解説記事・計算機がまだ多く、
在職老齢年金の「62万円ではなく65万円」（[zaishoku-rorei-nenkin.md](./zaishoku-rorei-nenkin.md)）と
同じ「よくある誤解の訂正」構成が効く。

## 提案する仕様

1. **入力**：退職前6ヶ月の賃金総額（または月給の平均。賞与は除くことを明記）、
   年齢、被保険者であった期間、退職理由（自己都合／会社都合等・障害者等の
   就職困難者）
2. **計算（雇用保険法16〜23条・令和8年8月1日改定値）**
   - 賃金日額 = 退職前6ヶ月の賃金総額 ÷ 180（上限・下限を年齢区分で適用）
   - 基本手当日額 = 賃金日額 × 給付率 50〜80%（60〜64歳は45〜80%。
     賃金日額に応じて逓減する法定の算式をそのまま実装し、テストで固定）
   - 所定給付日数 = 離職理由 × 年齢 × 被保険者期間の法定テーブル
     （自己都合 90/120/150日、特定受給資格者 90〜330日、就職困難者 150〜360日）
   - 総支給額の目安 = 基本手当日額 × 所定給付日数
3. **スケジュール表示（差別化の柱）**：待期7日と給付制限（自己都合は
   **令和7年4月から原則1ヶ月**、5年内に3回以上の離職は3ヶ月、教育訓練で解除）を
   踏まえ、「申請からいつ・いくら振り込まれるか」のタイムラインを表示
4. **よくある誤解の訂正**：「自己都合は2ヶ月もらえない」は旧制度である旨を
   本文とFAQで明示。手取りではなく賃金（額面）で計算する点、賞与を含めない点も
5. **【データ更新箇所】**：日額の上限・下限と給付率の屈折点は毎年8月1日改定。
   最低賃金チェッカーと同じく、定数を1ファイルにまとめてコメントで改定月を明記
6. **ページ構成**：既存ツールと同じ（metadata / robotsFor / JSON-LD /
   FAQPage / パンくず / AdUnit / 関連ツール）。関連には傷病手当金・年収の壁・
   最低賃金を置く。registry へは `stage: 'preview'` で追加
7. **テスト**：賃金日額の上限下限適用・給付率の逓減・給付日数テーブル・
   給付制限（1ヶ月／3ヶ月／解除）を `tools/tests/` の単体テストで固定

## 期待される効果

- 「失業保険 計算」系の恒常クエリ＋毎年8月の改定クエリの受け皿。
  社会保険クラスタの内部リンク網（傷病手当金⇔失業保険⇔年収の壁）が太くなる
- 計測：Search Console のクエリ「失業保険」「基本手当」の表示・順位、
  GA4 の `/tools/shitsugyo-hoken/` 着地数

## 工数（消費トークン目安）

- 実装 約150k〜200k（給付率の逓減算式と給付日数テーブルのテスト込み）。
  レビュー往復込みで 250k 以内

## やらないこと

- **雇用保険の全給付の網羅**（再就職手当・教育訓練給付・高年齢求職者給付は
  初版では対象外。FAQで存在に触れるにとどめ、需要が見えたら別ツール）
- **受給資格の有無の判定**（被保険者期間12ヶ月/6ヶ月要件の細かい判定は
  ハローワークの決定事項。目安である旨を明記して単純化する）
- **住民税・国保・年金の免除減免の計算**（別の制度。関連ツールとしての
  リンクにとどめる）
