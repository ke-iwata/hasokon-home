# 新ゲーム「スネーク」（権利フリーの定番アーケード2本目）

**状態**：提案（2026-08-18 起票）。実装時は `wip` で入れ、ページ・テストが
揃ったPRで `public` に上げる（home のカード・llms.txt は公開PRで追加）
**対象**：`games/`（`hasokon.com/games/snake/`）
**起票**：2026-08-18

---

## 背景と根拠

### 「短時間×リプレイ」のアーケード枠が1本しかない

GA4（直近28日・2026-08-18 取得）でゲーム側の滞在が長いのは
`block-puzzle`（平均セッション725秒・ページ別で最長）と `2048`（428秒）で、
**「数十秒で1プレイ・すぐもう1回」型がこのサイトの強い型**だと分かっている。
一方、いま公開中のアーケード系（リアルタイム操作）は `breakout` の1本だけ
（`pinball` は preview に退避中）。この型の面がまだ薄い。

### スネークは権利フリーで、いまも現役の定番

- ヘビゲームは1970年代の Blockade 系に始まる**ジャンルとして確立した公知の
  ルール**で、特定社の権利物ではない（当サイトの「権利関係的に無害」の条件を
  満たす）。Nokia の Snake や Google 検索の隠しヘビゲームで誰もが遊び方を
  知っており、**説明ゼロで遊び始められる**
- 2026年8月時点のブラウザゲーム紹介記事（Game8「おすすめ無料ブラウザゲーム」等）
  でも「ヘビゲーム」が定番枠で取り上げられ続けている。「ヘビゲーム」
  「スネークゲーム」は Google のイースターエッグ需要も含め恒常クエリ
- 実装が軽く、`breakout` で作ったリアルタイム進行の作法
  （ゲームループ・開始待ち・一時停止）をそのまま再利用できる

## 提案する仕様

1. **ルール（クラシック標準）**
   - 格子状の盤面（縦横 17×17 目安。1画面に収まる範囲で実装時に調整）
   - ヘビは一定間隔で1マス進む。餌を食べると1節伸び、スコア+1
   - 壁か自分の体に当たったらゲームオーバー（壁すり抜けなしの標準ルール）
   - 一定スコアごとに進行間隔を少し縮めて加速（上限あり）
2. **操作（スマホ・PC両対応）**
   - スマホ：**盤面のスワイプ**で方向転換（4方向）。誤操作防止に
     現在の逆方向への転換は無効（標準の作法）
   - PC：矢印キー / WASD。スペースで一時停止
   - 開始はタップ/キーで明示スタート（`games` の「スタート待ち」の約束どおり）
3. **成績**：`_records` でハイスコア・プレイ回数を保存。
   ゲームオーバー時に「ハイスコア更新」を出してリプレイ動機にする
4. **画面**
   - `games/CLAUDE.md` の「1画面に収める」約束に従う（盤面は正方形・
     `main .card` 内に収め、390×720 / 360×640 で横スクロールなし）
   - 盤面は `breakout` と同じ作りを流用（ロジックは純関数の
     `games/lib/snake.ts` に置き、進行はテスト可能なステップ関数にする）
5. **ページ構成（既存ゲームページと同じ）**
   - metadata / JSON-LD / パンくず / 遊び方 / コツ（「壁際を周回して
     スペースを保つ」等）／由来（Blockade→Nokia→Google の系譜は
     読み物としても検索面でも強い）／FAQ
   - `lib/registry.ts` へ追加（`stage: 'wip'` で入れる）
6. **テスト**：進行・成長・当たり判定・逆方向転換の無効・加速を
   ステップ関数の単体テストで固定（`breakout` のテストと同じ粒度）

## やらないこと

- 壁すり抜けモード・障害物・2人対戦などの変種（まず標準1本）
- リアルタイムランキング（`_records` のローカル記録のみ）

## 期待される効果

- 「ヘビゲーム」「スネークゲーム 無料」の恒常クエリへの受け皿と、
  説明不要ゲームによる回遊・再訪の積み増し（`block-puzzle` で実証済みの
  「短時間×リプレイ」型の2本目）
- アーケード系の面が `breakout` と2本になり、ゲーム一覧のジャンルの幅が広がる
- 効果は GA4 の `games/snake/` セッション時間・再訪、GSC の表示で計測
