### いまの一覧の形（本番 2026-11-24 に Playwright で確認）

- `games/app/page.tsx` は `publicGames` を registry の並び順で**見出しなしの1つのグリッド**に流している。

- 「トランプ」「パズル」で探しに来た人も、ソリティア系 6 本が続いたあとに何があるかが分からない

## 提案する仕様

### A. registry に `genre` を持たせる

`GameDef` に必須の `genre: GameGenre` を足す。値は4つに絞る（多いと見出しだけが並ぶ）。

| genre | 入るもの（公開中 28 本の割り当て案） |
|---|---|
| `トランプ・花札` | ソリティア・スパイダー・フリーセル・ピラミッド・トライピークス・ゴルフ・大富豪・七並べ・神経衰弱・スピード・ダウト・花札こいこい（12） |
| `ボード・対戦` | リバーシ・五目並べ・麻雀ソリティア（※）・ヨット（4） |
| `パズル・脳トレ` | ナンプレ・ノノグラム・数字つなぎ一筆書き・四角わけパズル・橋かけパズル・マインスイーパー・2048・ヒット＆ブロー・色水ソート・ブロックパズル（10） |
| `アクション` | ブロック崩し・スネーク（2） |

※ 麻雀ソリティアは対戦ではないが「牌・ダイスを使う卓上の遊び」としてヨットと同じ箱に入れる。**割り当ての最終判断は実装 PR のレビューで決めてよい**（割り当て表はこの仕様書の付録扱い）。
wip / preview のゲームにも `genre` は必須（公開する PR で考え直さないで済むように）。

### B. 一覧ページ（`games/app/page.tsx`）

1. リード文の下に**ジャンル目次**を置く：`<nav aria-label="ジャンル">` に `<a href="#genre-card">トランプ・花札 12</a>` のようなページ内リンクを4つ。
   横に並ぶチップ（スマホでは折り返し）。**`.quicknav` は使わない**（home の約束とは別物だが、名前の衝突を避ける）
2. ジャンルごとに `<section id="genre-…">` と `<h2>`・件数（tools の `.section-title` と同じ組み方）
3. ジャンル内の並びは registry の並び順のまま（「人気順」は計測が薄いので入れない）
4. **スマホ（幅 480px 未満）だけ、カードを2列の小さい形にする**：絵の高さを抑え、説明文は出さず名前だけ。
   1画面に 6〜8 本見えるのが目安。デスクトップは今の大きいカードのまま（絵がこのページの売り）
5. `publicGames` を通す約束は変えない。**`games` を直に `filter` しない**（ジャンル分けは `publicGames.filter((g) => g.genre === genre)`）

### C. 構造化データ

`@graph` に、ジャンルごとの `ItemList`（`itemListElement` に各ゲームの URL と名前）を足す。
リッチリザルトの対象ではないが、**AI クローラーと Bing が一覧の構造を読み取れる**ようにするのが目的。
JSON-LD のゲーム名・URL は registry から作る（手で書かない）。

### D. テスト（`games/tests/genre.test.ts`）

- registry の全ゲームが4つの `genre` のどれかを持つ
- 一覧に出るゲームの数＝`publicGames.length`（ジャンル分けで落ちたものが無い）。wip / preview が出ない
- 各ジャンルの `id` がページ内リンクの `href` と一致する
- JSON-LD の `ItemList` の URL 数＝`publicGames.length`

### やらないこと

- **絞り込み・検索ボックス・並べ替え UI。** 28本なら見出しと目次で足りる。60本を超えたら考える（ここに書いておく）
- **「人気」セクション。** PV の差が小さく、毎回入れ替えると一覧の `lastmod` が動いて IndexNow が騒ぐ
- **ジャンル別の一覧ページ（`/games/trump/` など）を新しく建てる。** 薄いページが増えるだけ。見出しで足りる
- ゲームページ下部の「他のゲーム」を同じジャンルで出す — 効きそうだが**別提案**（tools の [related-tools-topical.md](./related-tools-topical.md) の結果を見てから）
- home（`home/index.html`）のゲームの節の並べ替え。home にはビルド工程が無いので、別に考える

## 期待される効果

| 効果 | 物差し（GA4。導入前後の各 8 週で比べる） |
|---|---|
| 一覧に着地した人がゲームまで進む | `/games` 着地のエンゲージメント率 30%（desktop）→ **60%** 以上 |
| 下のほうのゲームが見つかる | 公開中で 28 日の PV が 0〜2 のゲーム 11 本 → **6 本以下** |
| AI 経由の入口が働く | `chatgpt.com` → `/games` 着地のページ/セッション 2.2 → **2.8** 以上 |

件数が小さいので「傾向」として見る。悪化したら（エンゲージメント率が下がったら）スマホの2列だけ戻せるように、B-4 は CSS の1ブロックに閉じる。
