# 新ツール「酒税改正 早見表・負担額計算」（2026年10月のビール減税・第三のビール/チューハイ増税対応）

`home/index.html` のカードと `home/llms.txt` の行を足す）

## 背景と根拠

### 2026年10月1日に酒税が変わることが確定しており、施行日が目前

平成29年度税制改正で決まった酒税の段階的見直し（2020年10月 → 2023年10月 →
2026年10月）の**最終段階**が 2026年10月1日 に施行される。

| 種類 | 現行（350mlあたり） | 2026年10月〜 | 増減 |
|---|---|---|---|
| ビール | 63.35円 | 54.25円 | **▲9.10円（減税）** |
| 発泡酒・第三のビール（新ジャンル） | 46.99円 | 54.25円 | **＋7.26円（増税）** |
| チューハイ・サワー等（その他の発泡性酒類） | 28.00円 | 35.00円 | **＋7.00円（増税）** |

ビール系飲料の税率は 155,000円/kl に一本化され、**ビールは安く、
第三のビール・チューハイは高くなる**という「上げ下げが混在する」改定になる。
数値は実装時に一次資料（下記）で必ず突き合わせること。

### 検索需要の時期が読め、いままさに立ち上がる局面

- 「ビール 値上げ」「第三のビール 値上げ いつ」「チューハイ 増税」は
  施行1〜2か月前から急増する消費者検索の定番。**今日が2026-08-19なので、
  需要の立ち上がりに先回りできる残り時間はわずか**
- 「買いだめすべきか」の判断が種類で逆になる（ビールは待つと安くなり、
  第三のビール・チューハイは9月中に買うほうが得）ため、
  **早見表が「答え」になるテーマ**。ニュース記事は税率を伝えるだけで、
  「自分の飲み方でいくら変わるか」を計算できるページはまだ少ない
- [tabako-zei-neage.md](./tabako-zei-neage.md)（2026年10月・2027年4月の
  たばこ増税）と**同じ「施行日が確定した制度改定を早見表で先回りする」型**で、
  しかも施行月が同じ10月。2本並ぶと「2026年10月の家計負担」の面が取れる

### 既存ツールとの相性

家計負担系クラスタ（たばこ税・年収の壁・社会保険損得・エアコン電気代）に
「飲料の負担」の面を足せる。たばこ税ページとの相互リンクで
「2026年10月に変わるもの」の回遊が作れる。

## 提案する仕様

構成・UIは [tabako-zei-neage.md](./tabako-zei-neage.md) の相似形（実装も流用できる）。

1. **改定早見表**
   - 種類別（ビール／発泡酒・第三のビール／チューハイ等）× 容量別（350ml・500ml）の
     税額の推移（現行 → 2026年10月〜）と増減額を表で表示
   - 2020年10月・2023年10月の過去の段階も1行ずつ載せ、
     「段階的見直しの最終回」だと分かる形にする（読み物としての検索面も取る）
2. **負担額計算**
   - 入力：種類ごとの週あたり本数（350ml / 500ml 別）
   - 出力：月間・年間の負担増減額（ビールの減税とチューハイ等の増税を
     合算し、**プラスにもマイナスにもなる**ことをそのまま見せる）
   - 「9月中に買うと得なもの・待つと得なもの」の仕分けを結果に添える
3. **データの持ち方**
   - 税率・施行日は `lib/shuzei-kaisei.ts` に【データ更新箇所】コメント付きの
     静的テーブルで持つ。**実装時に国税庁の税率表・財務省資料
     （下記の一次情報）で数値を確定させること**
   - 小売価格は各社の改定発表しだいのため扱わない（税額の増減のみを計算し、
     その旨を明記する）
4. **FAQ**：「なぜビールだけ安くなる？（税率一本化）」「ワイン・日本酒は変わる？
   （2023年10月で一本化済み・今回は対象外）」「店頭価格はいくら変わる？
   （税額差＋消費税分が目安。改定は各社の発表による）」など
5. **SEO**：WebApplication + FAQPage + BreadcrumbList の jsonLd。
   registry へは `stage: 'preview'` で追加し、公開判断は運営者
   （公開PRで home の一覧・llms.txt に追加）

## やらないこと

- **銘柄別の価格データベース**（たばこ税と同じ理由。税額の増減に限定する）
- **ワイン・清酒・ウイスキー等の税率表**（2026年10月改定の対象外。
  足すと「何が変わるのか」がぼやける）
- **飲酒の推奨・健康影響の記述**（事実としての税額の提示に留める。
  20歳未満の飲酒防止の注記のみ入れる）

## 期待される効果

- 「ビール 減税」「第三のビール 値上げ」「チューハイ 増税 いくら」の
  検索ピーク（9月〜10月）の受け皿。改定の1か月前に公開できれば
  ニュース連動の流入をそのまま拾える
- たばこ税ページと合わせ「2026年10月の家計負担」で面が取れる
- 効果は GSC の表示・クリック（`/tools/shuzei-kaisei/`）と
  GA4 のセッションで計測。施行後も「酒税 いくら」の恒常クエリが残る
