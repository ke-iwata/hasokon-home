# 新ゲーム：五目並べ（CPU対戦の2本目。リバーシの基盤を再利用）

**状態**：提案（2026-08-14）
**対象**：`games/`（`hasokon.com/games/gomoku/`）
**起票**：2026-08-14

---

## 背景と根拠

### 「対戦型」の入口が1本しかない

現在の11本（ブロックパズルのPR含む）のうち、相手と競う対戦型は
**リバーシ1本だけ**。ソリティア系3本・パズル系が大半で、
「CPUと勝負したい」層の受け皿が薄い。ノノグラム追加時に整理した
「同じ型に寄せず、別の入口を作る」方針
（[game-nonogram.md](./game-nonogram.md)）に沿うと、次の1本は
対戦型の2本目が筋がいい。

### 定番ゲーム名の検索はインデックスさえ載れば表示される

Search Console（2026-08-14 取得 / https://hasokon.com/ プロパティ）では
「ソリティア クロンダイク」の表示が出始めており、定番ゲーム名クエリは
ドメインが若くても表示に載ることが確認できている。GA4（2026-08-14 取得 /
GA4 Data API `runReport`、`properties/548154955`）でも直近28日のPV上位は
`/games/`（42）が `/tools/`（27）を上回り、**ゲームが集客と滞在の主力**。
「五目並べ 無料」「五目並べ ブラウザ」は definitions が固まった定番クエリで、
恒常的な検索がある。

### リバーシで作った基盤がそのまま効く

リバーシ（[game-reversi.md](./game-reversi.md)、`games/lib/reversi.ts`）で
「盤面UI・手番管理・CPU思考・強さ選択・結果表示」の型ができている。
五目並べは**盤が大きくなるだけで同じ骨格**であり、11本の中で
いま一番安く追加できる対戦型になっている。

### 権利関係

- 五目並べのルールは伝統ゲームであり著作権・特許の保護対象ではない
- 「五目並べ」「連珠」は一般名詞（連珠は競技ルールの名称）。
  games/CLAUDE.md の約束どおり、実装時に名称の商標登録の有無を再確認する
- 「オセロ」のような商標地雷は現時点で確認されていないが、
  アプリ固有名（「〇〇五目」等）は使わず一般名詞の「五目並べ」で出す

## 提案する仕様

### ルール（v1はカジュアルに割り切る）

- 盤は**13×13**（スマホの画面幅でマスが潰れない上限。連珠公式の15×15は
  360px幅で1マス24px程度になり操作しづらいため採らない）
- 先に5つ並べたほうが勝ち。**禁じ手（三三・四四・長連）は入れない**。
  カジュアル層には説明コストが利益を上回る。解説内で「競技ルールでは
  先手に禁じ手がある」ことだけ触れる
- 先手は交互（1局ごとに入れ替え）。先手有利の緩和はこれで足りる
- 手番表示・待った（1手戻す）・投了。リバーシと同じ操作系に揃える

### CPU

- 強さ3段階（リバーシと同じUI）
- 思考は評価関数ベース：自分と相手の「連の長さ×開放度」をスコア化し、
  上位候補だけ浅く読む。ミニマックスの深読みは不要
  （5連の脅威検出＝即勝ち・即防ぎさえ正確なら、初級〜中級の体感は成立する）
- 1手あたりの思考は最大でも数百ms（13×13=169マス、候補は着手済みの近傍のみ）

### 記録

[game-records.md](./game-records.md)（PR #56）の枠組みに乗せ、
強さ別の勝・敗・分を記録する（リバーシと同じ形）。

### 実装

| ファイル | 内容 |
|---|---|
| `games/lib/gomoku.ts` | 盤面・勝敗判定・CPU思考（150行程度） |
| `games/app/gomoku/page.tsx` | ページ本体（リバーシの構成を流用） |
| 一覧・sitemap・OGP | 既存ゲーム追加時と同じ更新一式 |

## 期待される効果

- 「五目並べ」系の定番クエリの受け皿ページを獲得（競合は多いが、
  広告過多な老舗サイトが上位に多く、軽量・無登録・スマホ最適で差別化できる）
- 対戦型が2本になり、リバーシからの回遊先ができる（関連ゲーム相互リンク）

## 工数の目安

- リバーシの骨格再利用が効くため、ゲーム追加としては最安クラス
- 実装1セッション：**おおよそ10〜12万トークン**（ロジック＋UI＋テスト＋一覧更新）

## やらないこと

- 禁じ手（三三など）の実装。競技連珠モードは需要が見えてから
- 人対人のオンライン対戦（サーバーが要る。静的サイトの範囲外）
- 15×15盤・盤サイズ選択（v1は13×13固定。要望が出たら選択式を検討）
