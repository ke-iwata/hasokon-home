### 経年車の重課（よくある誤解の中心）

- 自動車税（種別割）：ガソリン・LPG 車は**新規登録から13年を超えた年度**、ディーゼル車は 11 年超から**おおむね15%重課**。EV・FCV・天然ガス・ハイブリッド（ガソリン）は対象外
- 軽自動車税（種別割）：最初の検査から13年を経過した三輪以上は**おおむね20%重課**（自家用乗用の四輪は 12,900円）
- 「13年を超えた」は**年度で判定**する。2013年4月に登録した車は、13年を経過する 2026年4月を含む**令和9年度（2027年5月の通知）から**重課、という読み方を自治体の案内で確かめ、テストに入れる（下記「まだ確かめていないこと」1）
- 重量税は13年・18年の2段階（車検の時点の経過年数）。**自動車税と重量税で「13年」の数え方が違う**ことを画面で分けて見せる

### よくある誤解（本文・FAQ で正面から答える）

1. 「環境性能割がなくなったから車を買うときの税金はゼロ」→ **重量税（新車は3年分）と、登録翌月から3月までの種別割の月割は残る**
2. 「13年経ったらすぐ上がる」→ 自動車税は**13年を超えた次の年度**の通知から。重量税は**その後の最初の車検**から
3. 「EV は重量税がかからない」→ いまは新車と初回車検が免税。**2028-05-01 以後の車検から新しい負担が加わる予定**で、額は2026年12月の大綱で決まる
4. 「軽は月割で戻ってくる」→ 軽自動車税には**月割も還付もない**（4月1日の所有者に1年分）。登録車は抹消すると月割で還付

### 競合（2026-10-31 の Web 調査）

### 入力

| 項目 | 形 | 既定 |
|---|---|---|
| 車の種類 | 登録車（乗用・自家用）／軽自動車（四輪・乗用・自家用） | 登録車 |
| 動力 | ガソリン・LPG／ディーゼル／ハイブリッド（ガソリン）／EV・FCV／PHEV | ガソリン |
| 総排気量（登録車・EV 以外） | 上の表の10区分のセレクト | 1.0〜1.5L |
| 初度登録（軽は最初の検査）の年月 | 年・月 | 今月 |
| 車両重量 | 0.5t ごとのセレクト（〜0.5t … 〜2.5t、2.5t 超） | 〜1.5t |
| エコカー減税の区分（新車3年以内のみ） | 「わからない」／免税／▲75%／▲50%／▲25%／本則 | わからない |

- 営業用・トラック・バス・二輪は**受け付けない**（対象外と明示）。税率の区分が多く、保守できないため
- グリーン化特例（種別割の軽課）は、**登録の翌年度1年分だけ**。区分を選ばせず、「対象になりうる」案内に留める（一次確認のあとで入れるか決める）

### 出力

1. **今年度（令和8年度）の自動車税／軽自動車税（種別割）**。重課なら重課後の額と「標準 ◯円 → 重課 ◯円」
2. **重課が始まる年度**（例：「令和9年度（2027年5月の通知）から 45,400円」）。すでに重課なら「令和◯年度から重課」
3. **次の車検の重量税**（2年分）。初度登録から次の車検の時期を推定し、13年・18年の境目とエコカー減税の期間（2026-05-01〜2027-04-30／2027-05-01〜2028-04-30）を当てる
4. **1年あたりの合計**（種別割 + 重量税÷2）と、**10年の推移の表**（年度ごとに種別割と車検の年の重量税）
5. **令和8年度改正で変わったこと**：環境性能割の廃止で「2026-04-01 以後の購入は取得時の税が◯円減った（取得価額を入れた人のみ・0〜3%の幅で表示）」、EV・PHEV なら「2028-05-01 以後の車検から新しい負担（額は令和9年度改正で決まる）」
6. **買う・手放すときの月割**：登録車は登録の翌月から3月までの月割、抹消登録の翌月からの月割還付の目安。軽は月割・還付なしと明示

### ロジック（`tools/lib/jidosha-zei.ts`。純関数のみ）

- `shubetsuwari({ kind, power, displacementClass, firstRegistered, fiscalYear })`：税率表と重課判定
- `jukaStartFiscalYear({ kind, power, firstRegistered })`：重課が始まる年度
- `juryozei({ kind, weightClass, power, firstRegistered, inspectionDate, ecoClass })`：車検時の2年分（新車は3年分）
- `monthlyProration({ annual, registeredOn | deregisteredOn })`：月割（100円未満の扱いは一次確認で決める）

## やらないこと

- **営業用・トラック・バス・二輪・特種用途車**：税率の区分が多く、利用者が少ない。対象外と明示する
- **自動車取得税・旧環境性能割の過去の額の計算**：廃止済みで、更正請求（5年以内）は自治体の案内に任せてリンクだけ置く
- **任意保険・自賠責・ガソリン税**：税金ではない、または個別の商品に踏み込む（民間の商品名は出さない）
- **EV の新しい負担の予想額**：令和9年度改正で決まるまで出さない（「平均的な税負担と同水準が基本」という方針の文言だけ引用する）

## 期待される効果

- **5月の納税通知の山**（「自動車税 いくら」「自動車税 13年」）と、**12月の令和9年度大綱**（「EV 重量税」）の2つの入口を持つ。どちらも毎年来る
- 既存の上位（酒税・たばこ税・ふるさと納税）と同じ「改正があった税の早見」の型で、Bing・AI アシスタント経由の流入が見込める
- 測り方：GA4 の `landingPage = /tools/jidosha-zei` のセッションを 2027-01 と 2027-05 に見る。Bing Webmaster（`scripts/bing-search-stats.mjs`）で「自動車税」を含むクエリの表示回数
