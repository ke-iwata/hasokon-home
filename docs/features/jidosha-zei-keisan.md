### 経年車の重課（よくある誤解の中心）

- 自動車税（種別割）：ガソリン・LPG 車は**新規登録から13年を超えた年度**、ディーゼル車は 11 年超から**おおむね15%重課**。EV・FCV・天然ガス・ハイブリッド（ガソリン）は対象外
- 軽自動車税（種別割）：最初の検査から13年を経過した三輪以上は**おおむね20%重課**（自家用乗用の四輪は 12,900円）
- 「13年を超えた」は**年度（4月〜3月）で区切る**。宮城県「自動車税のグリーン化（重課・軽課）について」 https://www.pref.miyagi.jp/soshiki/zeimu/car-green.html （2026-11-03 確認）：
  **令和8年度の重課の対象は、ガソリン・LPG 車で初回新規登録が平成25年3月31日以前**のもの（ディーゼル車は平成27年3月31日以前）。同ページの例の表は「平成24年度に初回登録された車が令和8年度から重課」。
  つまり**重課が始まる年度 = 初回新規登録の年度 + 14**（ディーゼルは + 12）。2013年3月登録は令和8年度から、**2013年4月登録は令和9年度（2027年5月の通知）から**。
  - 企画レビューで「暦年の12月で区切る案内が多いのでは」と指摘があった。上の宮城県の案内は年度の区切りで、福岡県・静岡県の資料も同じ書き方だった（2026-11-03 の検索結果）。**実装の最初に地方税法の附則の条文で確定させる**（「まだ確かめていないこと」1）。条文が暦年の区切りなら、この節と公開条件の期待値を直してから実装に入る
  - 重課後の額（2019年9月以前の税率に約15%を上乗せ。宮城県の表）：1L以下 33,900円・1.5L以下 39,600円・2L以下 45,400円・2.5L以下 51,700円。2019年10月以後に登録した車は 2032 年度まで重課の対象にならないので、この表だけで足りる（2.5L 超の区分は条文で確かめる）
- 重量税は13年・18年の2段階（車検の時点の経過年数）。**自動車税と重量税で「13年」の数え方が違う**ことを画面で分けて見せる

### よくある誤解（本文・FAQ で正面から答える）

1. 「環境性能割がなくなったから車を買うときの税金はゼロ」→ **重量税（新車は3年分）と、登録翌月から3月までの種別割の月割は残る**
2. 「13年経ったらすぐ上がる」→ 自動車税は**13年を超えた次の年度**の通知から。重量税は**その後の最初の車検**から
3. 「EV は重量税がかからない」→ いまは新車と初回車検が免税。**2028-05-01 以後の車検から新しい負担が加わる予定**で、額は2026年12月の大綱で決まる
4. 「軽は月割で戻ってくる」→ 軽自動車税には**月割も還付もない**（4月1日の所有者に1年分）。登録車は抹消すると月割で還付
5. 「売ったら（名義変更したら）残りの月の分が戻ってくる」→ 月割の還付は**抹消登録（廃車・輸出）のときだけ**。名義変更（売却・譲渡）では県から還付されず、その年度の税は4月1日の所有者に1年分かかる（売買の当事者どうしで精算するかどうかは契約の話で、ツールでは扱わない）

### 競合（2026-10-31 の Web 調査）

- 自動車税の早見表・計算（中古車販売・カー用品会社のサイト）：排気量と登録時期の表はあるが、**改正の時系列（環境性能割・エコカー減税の2段階・EV の新負担）を1枚で出すものは無い**

## 仕様

### 入力

| 項目 | 形 | 既定 |
|---|---|---|
| 車の種類 | 登録車（乗用・自家用）／軽自動車（四輪・乗用・自家用） | 登録車 |
| 動力 | ガソリン・LPG／ディーゼル／ハイブリッド（ガソリン）／EV・FCV／PHEV | ガソリン |
| 総排気量（登録車。EV・FCV は出さない） | 上の表の10区分のセレクト | 1.0〜1.5L |
| 取得価額（任意。2026-03-31 以前の購入との比較を見たい人だけ） | 円 | 空欄 |
| 初度登録（軽は最初の検査）の年月 | 年・月 | 今月 |
| 車両重量 | 0.5t ごとのセレクト（〜0.5t … 〜2.5t、2.5t 超） | 〜1.5t |
| エコカー減税の区分（新車3年以内のみ） | 「わからない」／免税／▲75%／▲50%／▲25%／本則 | わからない |

- 営業用・トラック・バス・二輪は**受け付けない**（対象外と明示）。税率の区分が多く、保守できないため
- グリーン化特例（種別割の軽課）は、**登録の翌年度1年分だけ**。区分を選ばせず、「対象になりうる」案内に留める（一次確認のあとで入れるか決める）

### 出力

1. **今年度（令和8年度）の自動車税／軽自動車税（種別割）**。重課なら重課後の額と「標準 ◯円 → 重課 ◯円」
2. **重課が始まる年度**（例：「令和9年度（2027年5月の通知）から 45,400円」）。すでに重課なら「令和◯年度から重課」
3. **次の車検の重量税**（2年分）。初度登録から次の車検の時期を推定し、13年・18年の境目とエコカー減税の期間（2026-05-01〜2027-04-30／2027-05-01〜2028-04-30）を当てる
4. **1年あたりの合計**（種別割 + 重量税÷2）と、**10年の推移の表**（年度ごとに種別割と車検の年の重量税）
5. **令和8年度改正で変わったこと**：環境性能割の廃止で「2026-04-01 以後の購入は取得時の税が◯円減った（取得価額を入れた人のみ。燃費の区分で税率が変わるので、0〜3%（軽は 0〜2%）の幅で表示し、1つの額に決めない）」。取得価額が空欄なら、廃止前の税率の幅の案内だけを出す、EV・PHEV なら「2028-05-01 以後の車検から新しい負担（額は令和9年度改正で決まる）」
6. **買う・手放すときの月割**：登録車は登録の翌月から3月までの月割、抹消登録の翌月からの月割還付の目安。軽は月割・還付なしと明示

### ロジック（`tools/lib/jidosha-zei.ts`。純関数のみ）

- `shubetsuwari({ kind, power, displacementClass, firstRegistered, fiscalYear })`：税率表と重課判定。**EV・FCV は排気量の入力を受けず、1L 以下の区分の額**（2019-10-01 以後の登録 25,000円／それより前 29,500円）にする。2028年度以後に新規登録する EV・FCV の重量の区分は、令和9年度改正で決まるまで「未定」
- `jukaStartFiscalYear({ kind, power, firstRegistered })`：重課が始まる年度
- `juryozei({ kind, weightClass, power, firstRegistered, inspectionDate, ecoClass })`：車検時の2年分（新車は3年分）
- `monthlyProration({ annual, registeredOn | deregisteredOn })`：月割（100円未満の扱いは一次確認で決める）
- 税率表・期間の境目は**定数**にし、`DATA_CHECKED_AT` と出典 URL をコメントに残す（`lib/sokudo-ihan.ts` と同じ書き方）
- EV・PHEV の 2028-05-01 以後の加算は `EV_SURCHARGE_DECIDED = false` の間、**額を出さず「未定」**を返す。大綱の公表後に定数と true を入れる

2. 軽自動車の 13 年超 12,900円 の根拠条文と、軽の「13年」の区切り（最初の検査の**年月**で数えるか、年度で数えるか）
2-2. **EV・FCV の種別割が「総排気量1リットル以下」の区分になる根拠**（地方税法147条の表の書き方）。企画レビューの指摘3
3. 自動車重量税法7条・租税特別措置法の当分の間税率の現行の表（**2026-05-01 以後**の額。軽自動車の 1 台あたりの額を含む）
4. 種別割の月割課税と抹消時の月割還付の条文・端数処理
5. グリーン化特例（令和10年3月末まで）の対象と軽減割合を入れるかどうか

確かめられない区分は、入力のセレクトから外す（推測の額を出さない）。

### 一次確認の結果（2026-11-04。e-Gov 法令API で現行条文を引いた）

1. **重課の年度は年度で区切る（確定）。** 地方税法附則12条の3 1項は「初回新規登録を受けた日から起算して十四年（軽油は十二年）を経過した日の属する年度」。
   日がどこでも「登録の年度＋14（＋12）」になる。対象はガソリン・LPG が**平成27年3月31日まで**、軽油その他が**平成29年3月31日まで**の初回新規登録。
   それより後の登録は現行の条文の対象外なので、画面では「延長されれば」の見込みとして出す。重課後の額は附則12条の4 3項（2019-09-30 までの登録車の10区分。
   1L以下 33,900円〜6L超 127,600円）。**2019-10 以後の登録車の重課後の額は条文に無い**ので「額は未定」と出す
2. **軽の13年（確定）。** 附則30条1項「初回車両番号指定を受けた月から起算して十四年を経過した月の属する年度」から 12,900円。
   2003-10-14 前の指定は「その年の十二月」から数える（平成28年改正法附則14条2項）。2015-03-31 以前の指定は 7,200円（平成26年改正法附則15条）
2-2. **EV・FCV の1L以下の区分**は、地方税法154条5項（諸元による区分は道府県が定める）と道府県の条例による（京都府の税率表「総排気量1リットル以下又は電気を動力源とするもの」）。条文そのものには無い
3. **重量税（確定）。** 本則は自動車重量税法7条（0.5t ごと 3年 7,500円・2年 5,000円、軽は1両）、当分の間税率は租特法90条の11（12,300円・8,200円、軽 9,900円・6,600円）、
   13年は90条の11の3（11,400円、軽 8,200円）、18年は90条の11の2（12,600円、軽 8,800円）。起点は「十三年を経過する月の前月の初日以後」＝**登録から 12年11か月の月**（軽は初度検査の年から13年たった年の12月）。
   エコカー減税は90条の12（令和8年5月1日〜令和10年4月30日、本則の25%・50%・75%、100円未満切捨て）。免税対象車等は90条の11 の当分の間税率から除かれるので、継続車検は本則税率で経年の重課もない
4. **月割（確定）。** 地方税法157条：取得は翌月から、消滅（抹消）はその月まで。4項で**所有者の変更は年度の末日に変更があったものとみなす**ので、名義変更では売主に還付も買主に月割の課税も無い。
   端数は確定金額の100円未満切捨て（20条の4の2第3項）として、還付は「年額 − 抹消した月までの月割」で出す（目安と表示）
5. **グリーン化特例は入れた。** 附則12条の3 2項・30条2項：EV・PHEV（と基準を満たす天然ガス車）が 2025-04-01〜2028-03-31 に初回新規登録 → 翌年度分だけ概ね75%軽減（1L以下 6,500円、軽 2,700円）。
   EV・PHEV は条件なしで対象なので、区分を選ばせずに当てられる
6. **継続車検の本則税率は「その車検のとき」の燃費で決まる（実装レビュー #457 で指摘）。** 租特法90条の11・90条の11の2・90条の11の3 が当分の間税率と経年の重課から除く「免税対象車等」は、
   90条の12 1〜4項の各号の車（＋施行令51条の2 の古い基準の車）で、各号は**2030年度燃費基準の達成率**で定義されている。新車のときに受けた区分は引き継がれない。
   いちばん低い4項（▲25%）が **85%以上（2027-04-30 までは 80%）** なので、継続車検はこの率で判定する。このため入力は「エコカー減税の区分」ではなく
   **「2030年度燃費基準の達成率（%。任意）」** にした（新車の3年分の区分も、期間と達成率から決める）。初回の継続車検の免税は 125%以上（5項）
7. **2027年5月〜の「本則税率 80%以上」の区分は、成立した条文に見当たらない。** 90条の12 は1項（免除 105%）・2項（×25% 100%）・3項（×50% 95%）・4項（×75% 85%）まで。
   施行令51条の2 も2020年度基準・2010年度基準の古い車だけで、2030年度基準の80%の区分は無い（2026-11-04 確認）。
   環境省の資料（大綱段階）にある区分なので、**計算ではエコカー外（当分の間税率）として扱い、表には「—」と注記**する。根拠の条文が見つかったら `ECO_PERIODS` の r8b に戻す

## やらないこと

- **営業用・トラック・バス・二輪・特種用途車**：税率の区分が多く、利用者が少ない。対象外と明示する
- **自動車取得税・旧環境性能割の過去の額の計算**：廃止済みで、更正請求（5年以内）は自治体の案内に任せてリンクだけ置く
- **任意保険・自賠責・ガソリン税**：税金ではない、または個別の商品に踏み込む（民間の商品名は出さない）
- **EV の新しい負担の予想額**：令和9年度改正で決まるまで出さない（「平均的な税負担と同水準が基本」という方針の文言だけ引用する）

## 期待される効果

- **5月の納税通知の山**（「自動車税 いくら」「自動車税 13年」）と、**12月の令和9年度大綱**（「EV 重量税」）の2つの入口を持つ。どちらも毎年来る
- 既存の上位（酒税・たばこ税・ふるさと納税）と同じ「改正があった税の早見」の型で、Bing・AI アシスタント経由の流入が見込める
- 測り方：GA4 の `landingPage = /tools/jidosha-zei` のセッションを 2027-01 と 2027-05 に見る。Bing Webmaster（`scripts/bing-search-stats.mjs`）で「自動車税」を含むクエリの表示回数
