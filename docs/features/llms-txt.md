# llms.txt を置く（AIアシスタント経由の流入への備え）

**状態**：実装済み（2026-08-14。本番反映はタグリリース待ち）
**対象**：`home/`（`hasokon.com/llms.txt`）
**起票**：2026-08-14

---

## 背景と根拠

### AIアシスタント経由の流入が実際に観測され始めた

GA4（2026-08-14 取得 / GA4 Data API `runReport`、`properties/548154955`）の
直近28日のチャネル別セッションに **「AI Assistant」チャネルが出現した**
（Direct 57 / Organic Search 47 / Unassigned 6 / Organic Social 2 /
**AI Assistant 1** / Cross-network 1 / Referral 1）。

1件と小さいが、これは「ChatGPTなどのAIアシスタントがこのサイトを
回答内で紹介し、ユーザーがそこから来た」ことを意味する。2026年時点で
AI経由の参照流入は検索業界全体で増加が続いており、**従来の検索順位とは
別の入口**として無視できなくなりつつある。ドメインが若く従来SEOの
立ち上がりに時間がかかるこのサイトにとって、AI経由は
**先行者の少ないうちに取れる入口**でもある。

### このサイトは「AIが引用しやすいサイト」の条件を既に満たしている

- 各ツールが単機能で、ページのタイトル・説明が明確（「年収の壁 計算機」等）
- 法改正の施行日・金額など、AIが回答に使いたがる一次情報系の数字を扱っている
- robots.txt は `User-agent: *` / `Allow: /` で、AIクローラーを弾いていない
  （2026-08-14 確認）

足りないのは、**サイト全体の構成を機械可読にまとめた案内**だけ。

## 提案する仕様

### home/llms.txt を追加する

[llms.txt の標準形式](https://llmstxt.org/)（H1＋引用ブロック＋セクション別リンク集の
Markdown）で、ドメイン直下 `https://hasokon.com/llms.txt` に置く：

```
# hasokon.com

> 登録不要・無料で使える計算ツールとブラウザゲームのサイト。
> 税金・社会保険など法改正に追随した計算機と、定番ミニゲームを提供する。

## ツール（hasokon.com/tools/）

- [年収の壁 計算機](https://hasokon.com/tools/nenshu-kabe/): 2026年10月の
  106万円の壁撤廃に対応した手取り比較
- [高額療養費 計算機](https://hasokon.com/tools/kogaku-ryoyohi/): 2026年8月改正の
  自己負担限度額
- （…全ツールを1行説明つきで列挙…）

## ゲーム（hasokon.com/games/）

- [ソリティア](https://hasokon.com/games/solitaire/): クロンダイク
- （…全ゲームを列挙…）
```

ポイント：

- **1行説明に「何が計算できるか＋対応している改正」を入れる**。AIは
  リンク文字列だけでなく説明文を根拠に引用先を選ぶため、ここが本体
- URLは必ず `https://hasokon.com/` の絶対URL・末尾スラッシュつき
  （canonical と同じ表記に揃える。[self-canonical-coverage.md](./self-canonical-coverage.md) 参照）

### 運用の約束（home/ の他ファイルと同じ扱い）

- ツール・ゲームを追加したら `index.html` / `404.html` / sitemap と同様に
  llms.txt にも1行足す（CLAUDE.md の「home/ の注意」に1行追記する）
- 大きくなりすぎたら `llms-full.txt` への分割を検討（v1では不要）

## 期待される効果

- AIアシスタントが「年収の壁を計算したい」等の質問に答える際、
  このサイトを発見・引用しやすくなる。効果は GA4 の AI Assistant チャネルの
  セッション数でそのまま計測できる（測定基盤は導入済み）
- 副次効果として、全ページの1行説明を棚卸しすることになり、
  meta description の品質チェックにもなる

## 工数の目安

- 静的ファイル1枚＋CLAUDE.md への運用1行＋整合テスト
  （`scripts/test/` に「llms.txt のURLがサイトの実ページと一致するか」を
  検るテストを1本足すと、リンク切れを恒久的に防げる）
- 実装1セッション：**おおよそ3〜5万トークン**。今回の3提案では最安

## やらないこと

- llms-full.txt（各ページの全文掲載版）。ページ数がまだ少なく、本体の
  HTMLが十分軽いため不要
- AIクローラーの選別（特定ボットのブロック・許可リスト管理）。現状の
  全許可を維持する。広告収益への影響が観測されたら別途起票する
