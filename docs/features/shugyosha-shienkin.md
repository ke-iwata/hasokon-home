### 一次情報（2026-10-20 取得）

- 新旧対照表 https://www.cas.go.jp/jp/houan/261009/jinkousenryaku_shiryo4.pdf

補助（考え方の説明。条文ではない）：社会保障国民会議 2026-09-08 資料3「飲食料品消費税率の臨時的な引下げ及び就業者負担軽減支援金の導入に関する大綱（案）」

#### 支給要件（法律案 第9条）

第9条第1項：次の**すべて**に当たる者に支給する。「前年」＝その年度の初日が属する年の前年（令和9年度分なら **2026年**）。

| 号 | 要件 | 線の高さ | 条文が決めていること |
|---|---|---|---|
| 1 | 前年の**勤労所得の金額**が**所得下限額を超える** | 政令 | 勤労所得＝「給与等の収入金額（所得税法28条2項）に応じ**政令で定めるところにより計算した額**」。事業所得と業務に係る雑所得の合計が**政令で定める額を超える**ときだけ、その合計を足す |
| 2 | 前年の**合計所得金額**（地方税法292条1項13号）が**所得上限額以下** | 政令。**扶養児童の有無と数に応じて**変わる | 扶養児童＝住民税の扶養親族（同項9号）のうち、前年12月31日現在で**19歳未満**の居住者 |
| 3 | （当該年度分の住民税の**所得割＋均等割**）×**政令で定める倍数**＋**社会保険料控除額** − 前年の**公的年金等の収入金額** が**純負担基準額を超える** | 倍数も基準額も政令 | 住民税は道府県民税＋市町村民税。社会保険料控除額は当該年度分の市町村民税のもの（地方税法314条の2第6項）から内閣府令で定めるものを除く |
| 4 | 基準日（その年の**1月1日**）に配偶者がいれば、配偶者の前年の合計所得金額が**政令で定める額以下** | 政令 | — |

- **第9条第2項（2027-04-01〜2029-03-31 の読み替え）**：令和9・10年度分は
  ①**第4号（配偶者の所得）を適用しない**、②扶養児童は**16歳未満**の扶養親族（居住者に限らない）、③第3号の社会保険料控除額は**全額**（内閣府令の除外なし）
- **第9条第4項**：基準日（1月1日）に**日本国内に住所が無ければ支給しない**
- **第9条第3項**：所得下限額・所得上限額・純負担基準額は定期的に検証し、必要なら改定する（＝毎年変わりうる。データは年度ごとに持つ）

#### 支援額（法律案 第10条・附則第3条）

- 第10条第1項（令和11年度分から）：純負担率の状況・就業の促進等の効果を考慮して、**前年の所得の額並びに扶養児童の有無及び数に応じて政令で定める額**
- 第10条第3項（**令和9年度分**）：同上に加え、**総額が飲食料品1%による消費税（地方消費税を含む）の減収見込額を超えないように**して政令で定める額
- 第10条第4項（令和10年度分）：同上の額に、令和11年度分の本則の額の**2分の1を基本とした額を加算**（加算分は 2029年4月払い。第13条第4項）
- 第10条第5項（令和11年度分）：本則の額の**2分の1を基本**とした額
- **附則第3条**：当分の間、額は所得・扶養児童に加えて**社会保険料控除額にも応じて**定める（概要の※3「『年収の壁』に配慮した就業促進特例加算」）
- **法律案には金額・所得の線が1つも書かれていない。** 大綱（案）2頁の図は「定額 → 逓増 → 平ら → 逓減 → ゼロ」の形と、
  逓増開始額は「住民税所得割が課税される水準（単身の非課税限度額は給与収入119万円）を踏まえて」定めるという**考え方**だけ（数字ではない）

| 事項 | 条文 | 内容 |

| 認定 | 第11条第1項・第2項 | 基準日の住所地の**市町村長の認定**を受ける。**当該年度の政令で定める日まで**に請求 |
| 継続 | 第11条第1項ただし書・第5項・第6項 | 前年度までに認定を受け、同じ市町村に住み続けていれば、市町村長が毎年度の額を決定（再請求は不要）。要件を外れれば取消し |
| 職権認定 | 第12条第1項・第3項 | **公金受取口座の登録者**は、市町村長が請求なしで認定できる。通知を受けたら支払日までに**辞退**もできる |
| 支払 | 第13条第3項・第4項 | 認定（または決定）の日から**2か月以内**に年度分を一括。令和10年度分は加算前の額を同様に、**加算分は 2029年4月** |

| **課税** | **第20条** | 「租税その他の公課は、就業者負担軽減支援金として支給を受けた金銭を標準として、課することができない」＝**所得税・住民税はかからない** |
| 配偶者の届出 | 第28条・附則第1条第4号 | 配偶者の所得が第9条第1項第4号の額を超える人は、**3月15日まで**に配偶者の氏名・個人番号等を届け出る（2029-01-01 施行。確定申告書に付記すれば提出したものとみなす） |

**支給の時期（何月か）は法律案に書かれていない**（請求期限も認定の期限も「政令で定める日」）。報道の「秋に年1回」（共同通信 2026-09-30）は画面に書かない。

| 支援金 | 所得の年 | 基準日（住所・配偶者） | 住民税（第3号） | 子の年齢（前年12/31現在） | 配偶者要件 |
|---|---|---|---|---|---|
| 令和9年度分（2027年度） | **2026年** | 2027-01-01 | 令和9年度分 | 16歳未満＝**2011-01-02 以後生まれ** | なし |
| 令和10年度分（2028年度） | 2027年 | 2028-01-01 | 令和10年度分 | 16歳未満＝2012-01-02 以後生まれ | なし |
| 令和11年度分（2029年度） | 2028年 | 2029-01-01 | 令和11年度分 | 19歳未満＝2010-01-02 以後生まれ | **あり** |

## 仕様（政令公布後に実装する形。いま決められる部分だけを確定させる）

### 方針

- **1画面＝「令和◯年度分の支援金の対象か・いくらか」**。年度は令和9年度分から（令和10年度分は 2027年の所得が締まる前に出さない）
- 政令が出るまでは**作らない**。出たら、額の表を `lib/shugyosha-shienkin.ts` の冒頭の定数に1年度ずつ持つ（`kosodate-shienkin.ts` の `FISCAL_YEARS` と同じ形）
- **国の計算機が出たら、ページからリンクする**（「正式な額は市町村の認定で決まる」の一文と一緒に）。競うのではなく、手取り・年収の壁の文脈で前後に置く

### 入力

| 入力 | 型 | 既定 | 使う要件 |
|---|---|---|---|
| 対象年度 | 令和9年度分（固定。翌年度の政令が出たら選択式） | 令和9年度分 | 全部 |
| 前年（2026年）の給与収入（額面・年） | 円 | 空 | 第1号（勤労所得）・第2号（合計所得金額）・第3号 |
| 事業所得・業務に係る雑所得（合計、任意） | 円 | 0 | 第1号（政令の額を超えるときだけ足す）・第2号 |
| 公的年金等の収入（任意） | 円 | 0 | 第2号・第3号（差し引かれる） |
| 社会保険料（年・任意） | 円 | 給与から自動推計（`calcPremiums`）。手入力で上書き可 | 第3号・額（附則第3条） |
| 扶養している子の生年月日（0〜6人） | 日付 | なし | 第2号の上限・額（扶養児童の数）。年度の基準（16歳未満／19歳未満）で数える |
| 1月1日（基準日）に日本国内に住んでいるか | はい／いいえ | はい | 第9条第4項 |
| 1月1日に配偶者がいるか・配偶者の前年の合計所得金額 | 任意 | — | 第4号。**令和9・10年度分は入力欄を出さない**（第9条第2項で適用なし） |
| 公金受取口座の登録 | はい／いいえ／わからない | わからない | 手続きの案内だけ（第12条の職権認定） |

### 出力

1. **判定**：4要件＋住所の要件を1行ずつ「満たす／満たさない／政令の額待ち」で並べる。全部「満たす」なら「対象の見込み」。
   **「対象です」と断言しない**（認定は市町村長。扶養の申告状況・住民税の課税状況は市町村の記録で決まる）
2. **支援額**：政令の表から、所得・扶養児童の数・社会保険料控除額で引いた額。令和10年度分は「秋の分」と「2029年4月の加算分」を分けて出す
3. **どの数字で判定されるか**：「令和9年度分は 2026年の所得・2027年1月1日の住所・令和9年度の住民税で判定されます」
4. **手続き**：公金受取口座を登録していれば市町村の職権で認定されうる（第12条）／していなければ政令で定める日までに請求（第11条第2項）。支払は認定から2か月以内（第13条第3項）
5. **税金**：「支援金に所得税・住民税はかかりません（法律案 第20条）」。**他制度の所得判定（扶養・保育料など）に含まれるかは書かない**（条文に無い）

### 計算式（条文どおり。【政令】は政令の数字が入る定数）

```
扶養児童の数 = 子のうち、年齢(前年12月31日) < 年齢基準 の人数
  年齢基準 = 16（令和9・10年度分） / 19（令和11年度分〜）           … 第9条第1項第2号・第2項
勤労所得 = 【政令】給与収入からの計算額
         + (事業所得 + 業務雑所得 > 【政令】基準額 ? 事業所得 + 業務雑所得 : 0)   … 第9条第1項第1号
合計所得金額 = 給与所得(kyuyoShotoku) + 事業所得 + 雑所得 + 年金所得 …       … 地方税法292条1項13号
純負担 = (住民税 所得割＋均等割) × 【政令】倍数 + 社会保険料控除額 − 公的年金等の収入金額   … 第9条第1項第3号

要件1: 勤労所得 > 【政令】所得下限額
要件2: 合計所得金額 ≤ 【政令】所得上限額[扶養児童の数]
要件3: 純負担 > 【政令】純負担基準額
要件4: 配偶者なし or 配偶者の合計所得金額 ≤ 【政令】配偶者所得上限額（令和11年度分〜）
住所: 基準日に国内に住所あり                                            … 第9条第4項
支援額 = 【政令】表(所得, 扶養児童の数, 社会保険料控除額)               … 第10条・附則第3条
```

【政令】の定数が `null` の間、その要件は `'pending-seirei'` を返し、画面は「政令の額待ち」と出す（**仮の数字を入れない**。報道の「300万円」も入れない）。

## 画面文言の約束

- **成立前・政令前の言い方は `status` / `seirei` から組み立てる**（手で「成立前」「未定」と書かない。kokai-tool-seikaku の A と同じ作法）。
  `title` / `description` には、`status` が `'cabinet-decision'` の間は「（法案）」、`seirei` が `'promulgated'` でない間は「（政令案）」または「額は未定」を入れる（スニペットに画面の印は見えない）
- **「もらえます」「対象です」と断言しない。** 「対象の見込み」「法律案の要件では」。認定するのは市町村長
- **報道の数字（年収300万円程度、総額約6,000億円など）は画面にも FAQ にも書かない**（条文にも政令にも無い）
- **働き方の助言をしない。** 「年収を◯万円に抑えると得」とは書かない。「この年収なら政令の表ではこの額」までを出し、判断は利用者に任せる
  （`hatarakizon` と同じ。逓減域で「働くと支援金が減る」ように見える箇所は、手取りの合計で示す）
- 「給付付き税額控除」は**政府が制度の将来像として使っている呼び名**として1回だけ触れる（法律案の名前は「就業者負担軽減支援金」。税額控除の仕組みは第36条第2項で「引き続き検討」）
- 税の扱いは第20条を引いて「所得税・住民税はかからない」と書く。**それ以上（扶養の判定・保育料・児童扶養手当の所得に入るか）は書かない**
