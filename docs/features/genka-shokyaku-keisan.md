## 背景と根拠

### 改正の中身：40万円未満の特例は、令和8年分だけ 30万円と 40万円が混ざる

令和8年度税制改正（所得税法等の一部を改正する法律・**令和8年法律第12号**、2026-03-31 公布、原則 2026-04-01 施行）で、
**中小事業者の少額減価償却資産の特例（租税特別措置法 28 条の 2）**が次のように変わった。

| | 改正前（〜2026-03-31 取得） | 改正後（2026-04-01 以後取得） |
|---|---|---|
| 取得価額の上限 | **30万円未満** | **40万円未満** |
| 下限 | 10万円以上（10万円未満は所得税法施行令 138 条で全額経費） | 同じ |
| 年間の上限 | 合計 300万円（開業・廃業の年は月割） | **同じ（300万円のまま）** |
| 対象者 | 青色申告の中小事業者（常時使用する従業員 500 人以下） | 青色申告の中小事業者（**400 人以下**。措令 18 条の 5 第 1 項） |
| 期限 | 令和8年3月31日まで | **令和11年3月31日まで**（3年延長） |

- 経過措置（令和8年法律第12号 附則 35 条）：**新法は施行日以後に取得したものに適用し、施行日前に取得したものは従前の例**。
  → **令和8年分（2026年1〜12月）の確定申告では、1〜3月に買った物は 30万円未満、4〜12月に買った物は 40万円未満で判定する**。
  これが「年で判定するのか、取得日で判定するのか」と迷わせる点で、計算機が一番効くところ
- 国税庁 タックスアンサー No.2100（［令和8年4月1日現在法令等］）も「取得価額が 10万円以上 40万円未満（**令和8年3月31日以前に取得したものは 30万円未満**）」と書いている

### 他にも「人によって使える方法が違う」分岐がある

1 つの買い物について、**同時に使える方法が最大 3 つ**ある（例：青色で 15万円のパソコン）。どれを選ぶかで今年の経費と、
**償却資産（固定資産税）の申告に載るか**が変わる。

| 方法 | 条件 | 経費になる時期 | 償却資産税の申告 | 根拠 |
|---|---|---|---|---|
| 少額の減価償却資産（全額） | 取得価額 **10万円未満**（または使用可能期間 1 年未満）。**青色・白色・雑所得すべて可** | 使い始めた年に全額 | **対象外** | 所得税法施行令 138 条・地方税法施行令 49 条 |
| 一括償却資産（3年均等） | **20万円未満**。青色・白色・雑所得すべて可。**月割しない** | 使い始めた年から 3 年、1/3 ずつ | **対象外** | 所得税法施行令 139 条・地方税法施行令 49 条 |
| 中小事業者の少額減価償却資産の特例（全額） | **40万円未満（2026-03-31 以前取得は 30万円未満）**。**青色申告**・事業所得／不動産所得／山林所得のみ（**雑所得は不可**）・従業員 400 人以下・年 300万円まで | 使い始めた年に全額 | **対象**（全額経費にしても申告が要る） | 措法 28 条の 2・措令 18 条の 5 |
| 通常の減価償却 | 上のどれも使わない／使えない | 耐用年数で按分。初年は月割 | 対象 | 所得税法 49 条・同施行令 120 条の 2・132 条 |

- 個人は**届け出なければ定額法**（所得税法施行令 125 条）。定率法は届出が要り、建物（1998-04-01 以後）・建物附属設備と構築物（2016-04-01 以後）は定額法だけ（同 120 条の 2）
- 中古で買った物は**簡便法の耐用年数**を使える（耐用年数省令 3 条）：法定耐用年数を全部過ぎた物は 法定×20%、一部過ぎた物は 法定 −経過年数 + 経過年数×20%。1 年未満切捨て・最低 2 年
- 家事と兼用の物（パソコン・車）は、**判定は取得価額の全額で行い**、経費にするのは事業で使う割合だけ（家事関連費の按分。所得税法 45 条 1 項 1 号・同施行令 96 条）
- 取得価額に消費税を含めるかは**経理方式で決まる**（免税事業者・税込経理は税込、税抜経理は税抜。No.2100 注 5）。
  **税抜 37万円（税込 40.7万円）のパソコンは、税抜経理なら特例の対象、税込経理なら対象外**——インボイスで課税事業者になった人が迷う点

## 提案する仕様

### 入力（すべてブラウザ内で完結。送信しない）

1. **買った物の種類**（上の表から選ぶ。「その他」なら耐用年数を入れる）
2. **取得価額**（円）。入力欄の下に「消費税：免税事業者・税込経理の人は**税込**、税抜経理の人は**税抜**で」と書く。
   付随費用（配送料・設置費）を含める、も 1 行
3. **買った日**（年月日）と **使い始めた月**（年月。既定は買った日と同じ月）。
   **特例の上限は買った日で、月割は使い始めた月で決まる**ので 2 つに分ける（ただし 2 つ目は「買った月と違う」を押したときだけ出す。スマホで縦に長くしない）
4. **申告の種類**：青色申告（事業所得）／白色申告（事業所得）／副業の雑所得（申告不要の 20万円以下も含む）
   - 注記：**家賃収入（不動産所得）の人は初版の対象外**（下記「要確認 3」・「やらないこと」）
   - 注記：副業の雑所得が 20万円以下で所得税の申告が要らない人も、**住民税の申告は要る**（[kakutei-shinkoku-hitsuyo-hantei.md](./kakutei-shinkoku-hitsuyo-hantei.md) の住民税の判定と同じ。経費の計算はこの計算機で出せる）
5. （青色のときだけ）**今年この特例で全額経費にした物の合計**（円。既定 0）と、**開業・廃業の年か**（はい → 営業した月数）
6. **新品／中古**。中古なら **前の持ち主が使っていた年月**（年・月）
7. **事業で使う割合**（%。既定 100。車・パソコン・スマホを選んだら「家事と兼用なら」の注記を出す）
8. **償却方法**：定額法（既定。届け出ていない人はこれ）／定率法（税務署に届け出た人だけ）。ソフトウエアは定額法に固定

従業員 400 人以下の要件は、個人事業主・副業の想定客ではまず満たすので**入力にしない**。結果の注記に 1 行書く。

### 出力

1. **結果の一番上に大きく**：「**今年（令和8年分）の経費：◯円**」と、使った方法の名前・理由を 1 文
   （例：「2026年4月1日以後に買った 40万円未満の物なので、青色申告なら全額をその年の経費にできます（中小事業者の少額減価償却資産の特例）」）
2. **使える方法の比較表**（使えるものだけ。使えないものは理由を 1 行）：
   方法 ／ 今年の経費 ／ 来年以降 ／ 償却資産税の申告に載るか ／ 決算書の書き方（摘要に「措法28の2」など）

### 計算仕様（`tools/lib/genka-shokyaku.ts`。純関数のみ）

```ts
// 【データ更新箇所】2026-10-16 e-Gov で確認
export const SHOGAKU_LIMIT = 100_000           // 所令138 未満
export const IKKATSU_LIMIT = 200_000           // 所令139 未満
export const TOKUREI_SWITCH_DATE = '2026-04-01' // 令和8年法律第12号 附則1条・35条
export const TOKUREI_LIMIT_BEFORE = 300_000    // 〜2026-03-31 取得
export const TOKUREI_LIMIT_AFTER = 400_000     // 2026-04-01〜 取得
export const TOKUREI_END_DATE = '2029-03-31'    // 措法28の2① 令和11年3月31日まで
export const TOKUREI_ANNUAL_CAP = 3_000_000    // 年300万円（開業・廃業年は月割）
export const TEIGAKU_RATE: Record<number, number>   // 別表第八 2〜50年（e-Gov の値を写す。1/n で計算しない：3年は 0.334、9年は 0.112）
export const TEIRITSU_200: Record<number, {rate:number; revised:number; guarantee:number}> // 別表第十
```

- `tokureiLimit(acquiredOn)`：2026-04-01 以後なら 400,000、それより前なら 300,000、2029-04-01 以後は `null`（特例なし）
- `availableMethods(input)`：
  - `cost < 100,000` → 全額（どの申告でも）
  - `cost < 200,000` → 一括償却（どの申告でも）
  - `kind === '青色' && cost >= 100,000 && cost < tokureiLimit(acquiredOn) && 既使用額 + cost <= annualCap` → 特例（`annualCap` は開業・廃業年は 3,000,000 × 月数 ÷ 12。月数は 1 か月未満切上げ〔措法 28 条の 2 第 2 項〕）
  - 常に通常の減価償却（10万円未満でも「通常償却を選ぶ」はありうるが、初版は比較表に出さない）
- `usedLife(legalYears, elapsedMonths)`：月で計算。全部経過 → `floor(legal×12×0.2/12)`、一部経過 → `floor((legal×12 − elapsed + elapsed×0.2)/12)`、最低 2
- `straightLine(cost, life, startMonth, years)`：毎年 `cost × rate`、初年は `× 月数/12`、未償却残高 −1 円を上限
- `decliningBalance(cost, life, startMonth)`：調整前償却額 ＝ 期首未償却残高 × 償却率。償却保証額 ＝ 取得価額 × 保証率。
  調整前 < 保証額 になった年の期首残高を改定取得価額とし、以後 改定取得価額 × 改定償却率。初年は月割。最後は 1 円残す
- 事業割合：`経費 = 償却費 × 割合`。**未償却残高は償却費の全額で減らす**（経費にした部分だけ減らすのではない）
- **端数（要確認 1）**：償却費・経費の 1 円未満の扱いは、令和8年分の「青色申告決算書の書き方」で確かめてから決める。
  確かめるまでは **1 円未満切捨て**（経費を多めに出さない側）とし、画面に「1 円未満の扱いは会計ソフト・税務署の案内に合わせてください」と書く

### FAQ（7 問）

1. **30万円未満が 40万円未満になったのはいつから？** — 2026年4月1日以後に**取得した**物から。2026 年分の申告でも、1〜3 月に買った物は 30万円未満のまま（附則 35 条）
2. **白色申告でも 40万円未満の物を全額経費にできる？** — できない。白色でも 10万円未満は全額、20万円未満は 3 年の一括償却は使える。青色の判定へリンク
3. **副業（雑所得）でパソコンを買ったら？** — 特例は事業所得・不動産所得・山林所得だけ。10万円未満の全額と一括償却は雑所得でも使える
4. **税込 40万7千円・税抜 37万円のパソコンは対象？** — 経理方式で決まる。免税事業者・税込経理は税込で判定するので対象外、税抜経理なら対象
5. **12月に買って 12月に使い始めたら？** — 通常の減価償却は 1 か月分だけ。特例・10万円未満・一括償却は月割しないので、年内に使い始めれば今年の経費（「節税になる」とは言わない。事実だけ）
6. **全額経費にしたのに償却資産税の申告が要るのはなぜ？** — 10万円未満と一括償却の物は対象外だが、特例で全額経費にした物は対象のまま（地方税法施行令 49 条）。免税点 150万円の説明を 1 行
7. **中古車の耐用年数は？** — 簡便法の式と例（4 年落ちの普通自動車は 2 年）。見積もれるなら見積もった年数でもよい

## やらないこと

- **建物・建物附属設備・構築物・不動産所得**：賃貸用の建物は耐用年数の選び方（構造・用途・中古）と、措令 18 条の 5 第 2 項の貸付けの除外が絡む。
  客層も別（不動産投資）。需要を見て別提案にする
- **法人**：法人税の特例（措法 67 条の 5）は事業年度で判定し、従業員要件・対象法人の範囲も違う。個人に絞る
- **旧定額法・旧定率法（2007-03-31 以前取得）と 250% 定率法（2007-04-01〜2012-03-31 取得）**：いま新しく調べる人はまずいない。画面で「対象外」と断る
- **特別償却・税額控除（中小企業経営強化税制など）**：要件が別で、入力が倍になる
- **「どの方法が得か」の推奨**：その年と翌年以降の所得、償却資産税の免税点で答えが変わり、税務相談（税理士法 52 条）に近づく。比較表で**事実を並べるまで**
- **耐用年数の全表**：別表第一だけで数百行。よく買う物 13 種＋「その他（年数を入れる）」に絞り、全表は e-Gov へリンク
- **資本的支出・除却・売却**：初版では扱わない。売却した年の償却費の扱い（No.2100 の手引き「資産を譲渡した場合の特例」）は FAQ にも書かない
