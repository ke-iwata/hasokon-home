# 高額療養費 自己負担限度額 計算機（2026年8月改正・年間上限の新設に対応）

**状態**：提案（2026-08-13）
**対象**：`tools/`（新規ツール `kogaku-ryoyohi`）
**起票**：2026-08-13

---

## 背景と根拠

### なぜ今か：12日前（2026年8月1日）に制度が変わったばかりで、このサイトに1本も無い

厚生労働省「高額療養費制度を利用される皆さまへ」（2026-08-13 取得）に、
**令和8年8月から自己負担限度額を見直すこと**、および
**月額の上限とは別に「年間上限」を新設すること**が明記されている。
所得区分の13区分への細分化は**令和9年8月**からの第2段階として続く。

制度改正は2段階になっている。

| 時期 | 内容 |
|---|---|
| **2026年8月1日**（施行済み） | 月額上限の引上げ、**年間上限の新設** |
| 2027年8月1日 | 所得区分を13区分に細分化し、月額上限をさらに見直し |

**起票時点で第1段階は12日前に施行済み**である。すでに変わった制度で、
いま病院にかかっている人が「今月いくらまでで済むのか」を調べている。

### このサイトの実測では「新しくて具体的な制度」だけが上位に入っている

Search Analytics API、`tool.hasokon.com`、2026-05-15〜2026-08-11（88日間、2026-08-13取得）。

| ページ | 表示 | クリック | 掲載順位 |
|---|---|---|---|
| `/kosodate-shienkin/`（子ども・子育て支援金） | 3 | 1 | **4.3** |
| `/roulette/` | 16 | 2 | 6.9 |
| `/warikan/` | 14 | 2 | 12.3 |
| `/shobyo-teate/`（傷病手当金） | 11 | 0 | 57.4 |
| `/hebon-romaji/` | 48 | 1 | 50.6 |
| `/furusato-nozei/` | 17 | 0 | **82.8** |
| `/aspect-ratio/` | 30 | 0 | **80.0** |

**評価の高い順位は、検索需要の大きさと逆の並びになっている。**
`ふるさと納税` `アスペクト比` のような**大きくて古い**主戦場では 80位台に沈み、
`子ども・子育て支援金` のような**小さくて新しい**制度では 4.3位に入っている。
支援金は2026年4月に始まったばかりの制度で、解説記事の蓄積が薄いところに先に置けたためである。

**高額療養費は、その支援金と同じ条件が揃っている**——制度自体は古いが、
**8月1日に変わった数字と、まったく新規の「年間上限」については、どのサイトもまだ薄い。**

### 既存ツールと噛み合う：傷病手当金を調べる人は、高額療養費も調べる

`/tools/shobyo-teate/` は「病気で働けない間の収入」に答えるツールで、
実測クエリは `傷病手当金 いくらもらえる` `傷病手当計算` である。
**同じ人が同時に抱えている問題が「治療費はいくらまでかかるのか」**であり、
それに答えるツールがサイトに無い。

「お金・社会保険」カテゴリの現状を、**お金が動く向き**で並べるとこうなる。

| 向き | ツール |
|---|---|
| 取られる | `kosodate-shienkin` |
| もらう | `shobyo-teate`・`zaishoku-rorei-nenkin` |
| 戻る | `nenmatsu-chosei` |
| 働き方を決める | `nenshu-kabe`・`hatarakizon` |
| **払う上限が決まっている** | **無し** |

高額療養費は「**払う額に天井がある**」という、他のどれとも違う型の制度である。

## 提案する仕様

`/tools/kogaku-ryoyohi/`。**入力3つ、出力4つ。**

### 入力

| 入力 | 選択肢・範囲 | 何に使うか |
|---|---|---|
| 年齢区分 | 70歳未満 / 70歳以上 | 限度額表の切り替え |
| 所得区分 | 標準報酬月額の区分（70歳未満）／課税所得の区分（70歳以上） | 適用する行 |
| 1か月の医療費（10割） | 円 | 限度額の計算と、窓口3割負担との差 |
| 過去12か月の該当回数 | 0〜3回以上 | 多数回該当の判定 |

**所得区分は「年収の目安」も併記して選ばせる。** 標準報酬月額を即答できる人は少ない。

### 出力

1. **今月の自己負担限度額**（改正後）
2. **窓口で払う3割負担額との差＝あとで戻る額**
3. **多数回該当になった場合の限度額**（4か月目以降）
4. **年間上限に対する現在地**（2026年8月から新設。令和8年8月1日〜令和9年7月31日の通算）

### 譲らないこと：改正前後を必ず並べる

`zaishoku-rorei-nenkin.md`（62万円か65万円か）、`nenmatsu-chosei`（令和8年度改正は12月1日施行）と
同じ論点である。**2026年7月以前の診療分には旧限度額が適用される。**
新しい額だけを出すと、7月に受診した人が誤った額を見る。
**診療月を基準に、適用される限度額を選ぶ。**

### 実装時に一次情報で確定させる数値

改正後の月額上限は、**厚生労働省の告示・資料で1円単位まで確定させてから実装する。**
起票時点で確認できている引上げ幅（二次情報。要検証）は次のとおり。

| 所得区分（70歳未満） | 改正前の月額上限 | 引上げ幅 | 改正後（**要確定**） |
|---|---|---|---|
| ア（標報83万円以上） | 252,600円 +（医療費−842,000）×1% | +17,700円 | 270,300円 + 1% |
| イ（標報53〜79万円） | 167,400円 +（医療費−558,000）×1% | +11,700円 | 179,100円 + 1% |
| ウ（標報28〜50万円） | 80,100円 +（医療費−267,000）×1% | +5,700円 | **85,800円 + 1%** |
| エ（標報26万円以下） | 57,600円 | +3,900円 | 61,500円 |
| オ（住民税非課税） | 35,400円 | +1,500円 | 36,900円 |

区分ウの 85,800円 は複数の二次情報で一致しているが、**表全体を厚労省の一次資料で
突き合わせてから定数にする。**年間上限（区分ウで約53万円とされる）も同様である。

**この検証を済ませるまで実装に入らない。** 金額を出すツールで、
二次情報のまま定数を置くことはしない（`docs/features/` の既存仕様書と同じ扱い）。

### データの持ち方

限度額表は施行日つきで持ち、**2027年8月の第2段階（13区分）を後から足せる形にする。**
`lib/nenshu-kabe.ts` の `effectiveFrom` / `effectiveUntil` と同じ考え方で、
運営者が手で切り替える運用にはしない。

### 触るファイル

| ファイル | 内容 |
|---|---|
| `tools/lib/kogaku-ryoyohi.ts` | 限度額表（施行日つき）・多数回該当・年間上限の計算 |
| `tools/app/kogaku-ryoyohi/page.tsx` | メタデータ・FAQ・構造化データ |
| `tools/app/kogaku-ryoyohi/Calculator.tsx` | 入力と結果表示 |
| `tools/lib/registry.ts` | ツール登録（`お金・社会保険`） |
| `tools/tests/kogaku-ryoyohi.test.ts` | 区分ごとの境界値・多数回該当・改正前後の切替 |
| `home/index.html` | サイト一覧に1行追加 |

`lib/shaho-grades.ts` の標準報酬月額の等級表を所得区分の判定に再利用できる
（`kosodate-shienkin`・`shobyo-teate`・`hatarakizon` に続いて4つ目の利用者になる）。

### 内部リンク

`shobyo-teate` ↔ `kogaku-ryoyohi` を相互に張る。**傷病手当金（収入）と高額療養費（支出）は、
同じ人の同じ時期の裏表**であり、`RelatedTools` の関連付けに実質的な理由がある。

## やらないこと

- **限度額適用認定証・マイナ保険証の手続き案内を厚くする。** 手続きは加入している
  健康保険組合ごとに違い、正確に書ききれない。**制度の説明はリンクに留め、金額の計算に徹する**
- **世帯合算を初版に入れる。** 同一世帯・同一месяц の21,000円以上の自己負担を合算する仕組みだが、
  入力が人数分に増えて画面が別物になる。**まず本人1人の月額上限を出す。**需要が確認できたら足す
- **医療費控除（確定申告）との比較。** 別制度で、それだけで1ツールになる。
  `nenmatsu-chosei` の隣に置く話であって、このツールに混ぜない
- **2027年8月の13区分を先に実装する。** 区分の中身が確定していない。
  **データ構造だけ施行日つきにしておき、数字は確定してから足す**
- **保険適用外の費用（差額ベッド代・先進医療）の計算。** 高額療養費の対象外であり、
  混ぜると「これも上限に入る」と誤解される。**対象外であることは本文で明示する**
