## 背景と根拠

### 2026-08-05 に「飲食料品の消費税 8% → 1%（2027年4月1日から2年間）」が閣議決定された

政府は 2026年8月5日の臨時閣議で給付付き税額控除の導入に関する基本方針を決定し、
**飲食料品の消費税率を 2027年4月1日から 2029年3月31日までの2年間、8% から 1% に引き下げる**
方針と、**関連法案を秋の臨時国会に提出する**ことを定めた。
**主たる出典は首相官邸の総理会見（2026-07-30 https://www.kantei.go.jp/jp/105/statement/2026/0730kaiken.html 。
「飲食料品の消費税率１％への引下げを、令和９年４月より２年間先行させる」「９月には大綱を決定した上で、
臨時国会に法案を提出」）**。時事通信 2026-08-05（ https://www.jiji.com/jc/article?k=2026080500718&g=pol ）は
補助（記事 URL は数か月で消える）。閣議決定文書の名称（報道では「『給付付き税額控除』の制度導入の
基本方針」）は記事からの引用なので、**実装時に内閣官房・財務省に載る原本で文書名を確認し、見つかれば
その URL を主たる出典にする**（[boei-tokubetsu-shotokuzei.md](./boei-tokubetsu-shotokuzei.md) の
「大綱は閣議決定であって条文ではない。最終的に引くのは改正法」と同じ作法）。
「0% ではなく 1%」なのはレジ改修の期間（0% だと10〜12か月、1% なら5〜6か月）のため、
1% 相当分は中低所得の勤労者への給付で「実質ゼロ」にする設計とされている。

**このサイトが Bing で取れている需要は、まさにこの型（税制改正 × 早見表 × 負担額計算）**である
（下記の計測値）。酒税（2026年10月）・たばこ税（2027年4月〜）に続く3本目で、
規模は消費税がいちばん大きい（全世帯に効く）。

### 消費税計算そのものは通年の定番需要

「消費税 計算」「税込 税抜 計算」は電卓系サイトの定番上位で、
CASIO の計算サイトが公開していたランキングでも BMI・日数計算と並ぶ常連だった
（2020 年時点の公表値 https://www.casio.co.jp/release/2020/1225_keisan/ 。現行ページは移転済み）。
さらに「これは 8% か 10% か」（軽減税率の判定）は 2019年10月以来つねに検索される。
**2027年4月からは「8% か 10% か 1% か」の3択になり、判定の需要が増える。**

### サイトとの噛み合わせ

- **`tools/lib/waribiki-percent.ts` が消費税率（10% / 8%）と丸め方式（切り捨て・四捨五入・切り上げ）を
  すでに持っている**。「【データ更新箇所】消費税率は法改正で動きうる唯一の数字」と書かれた
  2定数（`TAX_RATE_STANDARD` / `TAX_RATE_REDUCED`）と `TAX_UPDATED_AT`。**1% が入ると
  この前提（税率は2つ）が崩れる**ので、税率の表を新しい `lib/shohizei.ts` に移し、
  割引計算機はそこから import する（同じ数字を2か所に置かない。`kosodate-shienkin.ts` ↔

- 酒税改正・たばこ税・インボイスと「税」でつながる。インボイス計算機は「2割特例が
  2026年9月30日で終わる → 2027年2〜3月の確定申告」で同じ時期に動く
- 「関連」導線：割引・パーセント計算 ↔ 消費税計算 ↔ 酒税改正 ↔ インボイス

## 提案する仕様

1ページに **3つの入口**を置く（それぞれ h2 で分け、URL は1つ）。

**これは `tools/docs/CONCEPT.md` の「使えるWebツールを1ページ1つ置いていく」に対する意図的な例外**である。
理由：検索語は「消費税 計算」「軽減税率 対象」「食料品 消費税 1% いくら安くなる」の3系統だが、
**問いは1つ（この品にかかる消費税はいくらか）**で、判定 B は A・C の税率選択の前提になる。
登録問題（[google-index-recovery.md](./google-index-recovery.md)）の最中に薄いページを3枚に割るより
1枚を厚くするほうが良い、という判断でもある。**後続の提案が「3機能でも1ページで良い」の前例として
引かないこと。** B のデータ（`shohizei-items.ts`）は、将来 B だけを別ページに切り出せるよう
A・C から独立した純データにしておく。

### A. 税込 ⇔ 税抜 計算（通年の定番）

- 入力：金額、**入力が税込か税抜か**、税率（**10% ／ 8%（軽減）／ 1%（2027年4月〜・飲食料品）**）、
  端数の丸め（切り捨て［既定］／四捨五入／切り上げ。`waribiki-percent.ts` の型 `Rounding`・
  選択肢 `ROUNDINGS`・関数 `roundBy()` を流用）。
  **既定の丸めは割引計算機（`DEFAULT_ROUNDING = 'round'`＝四捨五入）と違う。** `shohizei.ts` に自分の既定
  `DEFAULT_TAX_ROUNDING: Rounding = 'floor'` を持ち、`waribiki-percent.ts` の `DEFAULT_ROUNDING` は共有しない
  （同じ部品だからと揃えないこと。理由は次の項）
- 出力：税抜・消費税額・税込の3つを**同時に**出し、**3税率の横並び**も出す
  （「この税込 1,080 円の品は 1% なら 1,010 円」）
- 早見表：税抜 100〜10,000 円の 8% / 10% / 1% の税込額。1% の列は法案成立まで見出しに印
- **丸めは「店ごとに違う」と明記する。** 消費税額の1円未満は事業者の任意（国税庁「消費税の
  端数処理」）で、レシートと1円ずれることがある。切り捨てを既定にするのは実務で最も多いため

### B. 軽減税率チェッカー（これは 8% か 10% か）

- **品目を検索すると税率と理由が出る**。全 40〜50 項目を `lib/shohizei-items.ts` にデータとして持つ。
- 出典は国税庁「消費税の軽減税率制度に関する Q&A（個別事例編）」
  https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/qa_03.htm
  （一括ダウンロードの PDF は https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/03-01.pdf 、
  **令和8年4月改訂版**。2026-09-18 に確認。起票時に書いた `pdf/0018007-023.pdf` は 404 だった）
  と「軽減税率制度の概要」 https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/index.htm 。
  **実装時に再確認し、切れていたら index.htm →「Q&A 目次一覧」（`qa_mokuji.htm`）から辿る**
- 入れる項目（例）。**実装時に Q&A の設問番号を1件ずつ添える**：

| 項目 | 税率 | 理由 |
|---|---|---|
| スーパーの食品・飲料（酒類以外） | 8% | 飲食料品 |
| ビール・チューハイ・日本酒（酒税法の酒類） | 10% | 酒類は対象外 |
| ノンアルコールビール・甘酒（1%未満） | 8% | 酒類に当たらない |
| みりん（本みりん） ／ みりん風調味料 | 10% ／ 8% | 酒類か否か |
| レストランで食べる ／ 同じ店で持ち帰る | 10% ／ 8% | 外食は対象外。持ち帰りは飲食料品の譲渡 |
| コンビニのイートイン ／ 持ち帰り | 10% ／ 8% | 購入時の意思確認 |
| 出前・宅配ピザ ／ ケータリング・出張料理 | 8% ／ 10% | 出前は譲渡、ケータリングは役務 |
| 学校給食・有料老人ホームの食事（一定額以下） | 8% | 例外規定 |
| 栄養ドリンク（医薬部外品） ／ 清涼飲料 | 10% ／ 8% | 医薬品・医薬部外品は食品でない |
| ミネラルウォーター ／ 水道水 | 8% ／ 10% | 水道水は飲用以外にも使う |
| 食用の氷 ／ 保冷用の氷・ドライアイス | 8% ／ 10% | 用途 |
| ペットフード・家畜の飼料 | 10% | 人の飲食用でない |
| おもちゃ付きのお菓子（税抜1万円以下・食品が価額の2/3以上） | 8% | 一体資産の特例 |
| 週2回以上発行の定期購読の新聞 ／ コンビニで買う新聞・電子版 | 8% ／ 10% | 定期購読契約が要件 |
| 通販の食品の送料（別途表示） | 10% | 送料は役務 |
| おせち・ケーキの予約（商品の引き渡し） | 8% | 飲食料品の譲渡 |

- **画面の型は自転車の反則金チェッカー（`tools/app/jitensha-hansokukin/Calculator.tsx`）を流用する。**
  開いた直後から全項目が種類別（酒類・外食・飲料・その他）に並び、「品目をしぼり込む（任意）」の
  検索欄はあってもなくても使える。タップで税率と理由が出る。40〜50件なら初期表示で全部並べても
  長くならない（スマホで「空の検索欄だけ」の初期画面にしない）。
  読み（ひらがな）の対応は `searchBehaviors()` の仕組みをそのまま使う。ヒットしない語は
  「国税庁の Q&A で確認してください」＋リンク（**判定を断言しない**。個別事例は税務署の判断）
- **2027年4月以降の列**：法案成立後は「1%（飲食料品）／ 8%（新聞）／ 10%」の3列表示に切り替える。
  報道では **定期購読の新聞は 8% のまま**とされているが（補助金ポータル 2026-09
  https://hojyokin-portal.jp/columns/food_tax ）、**法案の条文で確認するまで表に書かない**

### C. 食料品 1% でいくら安くなるか（2027年4月〜）

- 入力：**1か月の食費（外食・酒類を除く、税込）**。プリセットに総務省「家計調査」の平均
  （単身世帯・2人以上の世帯。**実装時に最新年の「食料」から外食・酒類を引いた額を入れ、年と表番号を添える**）
- 計算：軽減額 ＝ 税込額 × (1 − 1.01 / 1.08) ＝ 税込額 × **約 6.48%**。
  月 70,000 円なら月 4,537 円・年 54,444 円、2年間で約 10.9 万円。
  **見出しと結果の脇に「最大で」と添え、上限の目安と読める書き方にする**（税込 8% の価格がそのまま
  1% に置き換わる前提。便乗値上げ・値下げ遅れは確実に報じられるので織り込まない旨を明記）
- 出力：月・年・2年間（2027-04〜2029-03）の軽減額、**「給付付き税額控除の給付は含まない」**の注記
- 早見表：月の食費 3 万〜15 万円 × 軽減額
- **やらない**：給付額の計算（制度設計が未公表）、外食・酒類を 1% にする（対象外の方針）、
  「実質ゼロ」の表現（給付の条件が決まっていない）

### 法案の状態と表示（【データ更新箇所】）

`lib/shohizei.ts` の冒頭に、`kosodate-shienkin.ts` の `status: '確定' | '見込み' | '政府試算'` と同じ形で持つ：

```ts
export const FOOD_RATE_2027 = {
  rate: 0.01,
  from: '2027-04-01',
  to: '2029-03-31',
  /** 'cabinet-decision'（閣議決定・法案未成立）→ 'enacted'（成立）→ 'in-force'（施行）。
   *  法案が否決・修正されたらここを直す。UI の印はこの値だけを見る */
  status: 'cabinet-decision',
  decidedOn: '2026-08-05',
  /** 一次資料。閣議決定文書の原本 URL が見つかればそれに差し替える（時事の記事 URL は消えるので使わない） */
  source: 'https://www.kantei.go.jp/jp/105/statement/2026/0730kaiken.html',
} as const;
```

`status` の値は英語だが、`kosodate-shienkin.ts` の `'確定' | '見込み'` に揃えて日本語にしてもよい（実装者の判断）。

- `cabinet-decision` の間：A・B・C の 1% 部分に「閣議決定済み（2026-08-05）。法案は秋の臨時国会で
  審議中。成立前です」の印。**検索結果のスニペットには印が見えないので、`title` / `description` には
  「（予定）」または「（法案審議中）」を必ず含める**（「2027年4月〜 食料品1%」とだけ出ると成立済みの
  事実として読まれる）。「決定」「確定」とは書かない。
  `tools/tests/shohizei.test.ts` に「`cabinet-decision` のとき `description` に『予定』を含む」を 1件足す
- `enacted` になったら：印を「成立（法律番号）」に変え、`title` / `description` から「（予定）」を外し、
  B の新聞の扱いを条文どおりに入れる。**「1% の対象」が現行の軽減税率の範囲とずれた場合は B・C の両方に
  効くので、対象範囲を条文で確認する**
- **法案が通らなかった場合**：`status: 'withdrawn'` を足して C を非表示にし、A・B は 8%/10% の
  2税率に戻す（ツール自体は消さない。通年需要の A・B が残る）
- `updatedAt` と `TAX_UPDATED_AT` を状態を変えるたびに直す

## やらないこと

- **給付（給付付き税額控除）の額を計算する。** 制度設計が未公表。決まったら別ツールとして起票する
- **法案成立を待ってから作る。** 成立（2026 秋）と施行（2027-04）の間にページを育てる時間が要る。
  待つと「成立の週」に大量に出る記事に埋もれる。閣議決定済みなので「方針」として書ける
  （[boei-tokubetsu-shotokuzei.md](./boei-tokubetsu-shotokuzei.md) が「税額表の公開待ち」で
  止めているのは、**計算に必要な数字が無い**から。今回は 1% という数字と期間が決まっている）
- **軽減税率の判定を断言する。** 個別事例は国税庁 Q&A の範囲に限り、無い語は Q&A へ誘導する
- **割引計算機に足して済ませる。** 検索語が違う（「割引」と「消費税」）。
  （A・B・C を 1つの URL に置くのは上記のとおり CONCEPT.md への意図的な例外であり、
  割引計算機に相乗りしない理由とは別）
- **事業者向け（POS 改修・区分記載・インボイスの税率区分）。** 家計向けに絞る。事業者向けは
  インボイス計算機の側で扱う
- **地方消費税の内訳（7.8% + 2.2% など）を出す。** 家計には不要。FAQ に一文だけ
