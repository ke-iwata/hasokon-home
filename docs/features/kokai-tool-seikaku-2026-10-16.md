### A. 青色申告特別控除：住民税所得割を「所得税の課税所得 × 10%」で出している

`tools/lib/aoiro-shinkoku-kojo.ts` の `taxFor()`：

```ts
const taxableIncome = floor1000(income + otherIncome - deduction - otherDeductions);
return { taxableIncome, incomeTax: …, residentTax: Math.floor(taxableIncome * RESIDENT_RATE) };
```

`otherDeductions` は画面の「ほかの所得控除の合計（円）」で、ヒントは「**基礎控除**・社会保険料控除・小規模企業共済等掛金控除などの合計」。
利用者は所得税の基礎控除（令和8・9年分は合計所得489万円以下で104万円）を入れるが、**住民税の基礎控除は43万円**なので、
住民税の課税所得が61万円小さく出る。さらに、所得税の課税所得が0円に張り付くと住民税の増減も0円になる。

再現（`judge()` を直接実行。事業所得・複式簿記・書面申告、令和8年分 55万円 → 令和9年分 10万円、ほかの所得控除 1,040,000 円）：

| 控除前の所得 | 本ツールの住民税所得割（令和8年分の控除 → 令和9年分の控除） | 正しくは（基礎控除43万円・調整控除・所得割の非課税） |
|---|---|---|
| 100万円 | 0円 → 0円（**合計「変わりません」**） | 0円（総所得金額等45万円で所得割非課税）→ 44,500円（課税所得47万円 − 調整控除2,500円）。**約4.5万円増える** |
| 150万円 | 0円 → 36,000円（増 36,000円） | 49,500円 → 94,500円（**増 45,000円**） |
| 300万円 | 141,000円 → 186,000円（増 45,000円） | 199,500円 → 244,500円（増 45,000円。差は合うが額が約5.8万円ずれる） |

- 所得税の側は正しい（150万円で 0円 → 18,378円）
- 「書面申告で55万円 → 10万円」は所得が小さい白色に近い層で効く改正なので、**誤りがいちばん出る層が主な利用者**
- 根拠：地方税法 314条の2 第2項（住民税の基礎控除 43万円。合計所得2,400万円以下）、同 附則3条の3 第4項（所得割の非課税：35万円×(人数+1)＋10万円、単身45万円）、
  地方税法 314条の6（調整控除）。基礎控除の額は本リポジトリでも `lib/furusato-nozei.ts` の `basicDeductionResidentTax()`（43万円）として持っている
- 同じ「課税所得を所得税と住民税で分けずに使う」形は、`kyuyo-nenkin-kojo` では起きていない（`basicDeductionResidentTax()` と `adjustmentDeduction()` で別に計算している）

### B. 相続税：未成年者控除・障害者控除で納付税額が0円でも「相続税がかかります。」

`tools/lib/sozokuzei-keisan.ts` の `perHeirTax()` の `verdict` は、課税価格の合計が基礎控除を超え、配偶者の税額軽減が使われていなければ `'tax'`
（`VERDICT_MESSAGES.tax = '相続税がかかります。'`）。納付税額の合計が0円かどうかを見ていない。

再現（`perHeirTax()` を直接実行）：

| 入力 | 本ツール | 正しくは |
|---|---|---|
| 相続人は子1人（2016-05-01生・相続開始 2026-05-01 で10歳）、取得 3,700万円 | 「**相続税がかかります。**」・納付税額の合計 **0円**（総額10万円 − 未成年者控除10万円。引ききれない70万円） | 納める相続税は0円。**申告も不要** |
| 相続人は子1人（36歳・一般障害者）、取得 3,700万円 | 「相続税がかかります。」・0円 | 同上 |

- 根拠：相続税法 27 条 1 項（e-Gov 法令API で原文を取得）。申告義務は「課税価格の合計額が基礎控除額を超える場合において、
  その者に係る…**第十五条から第十九条まで、第十九条の三から第二十条の二まで**…の規定による相続税額があるとき」。
  **19条の2（配偶者の税額軽減）は除かれ、19条の3（未成年者控除）・19条の4（障害者控除）・19条（暦年課税分の贈与税額控除）は含まれる**。
  つまり配偶者の税額軽減で0円なら申告が要る（本ツールの `zero-by-spouse-relief` の文言は正しい）が、未成年者控除・障害者控除・贈与税額控除で0円なら申告義務は無い
- 見出しと金額（0円）が食い違い、「かかる＝申告が要る」と読ませる。結果のすぐ上の FAQ「申告は必要？（0円でも要る場合）」の
  1 文目「課税価格の合計が基礎控除を超えるときは申告が必要です」も同じ言い切り

## 提案する仕様

### A. 住民税を住民税の控除で計算する（`tools/lib/aoiro-shinkoku-kojo.ts`・`Calculator.tsx`）

- 入力欄を「**基礎控除を除く**所得控除の合計（社会保険料控除・小規模企業共済等掛金控除など）」に改め、基礎控除は合計所得金額から自動で引く
  - 所得税：`basicDeductionIncomeTax(合計所得)`（令和8・9年分は同じ表。`lib/furusato-nozei.ts` から import）
  - 住民税：`basicDeductionResidentTax(合計所得)`（43万円）
  - 合計所得は 控除前の所得 − 青色申告特別控除 ＋ ほかの所得。**令和8年分の控除と令和9年分の控除で合計所得が違う**ので、基礎控除は両側で取り直す（489万円・655万円の段差をまたぐ人がいる）
- `TaxSide` に住民税の課税所得 `residentTaxable` を足し、住民税所得割は `residentTaxable × 10% − 調整控除`（`adjustmentDeduction()`。人的控除差は基礎控除分の 5万円だけ）
- 所得割の非課税（総所得金額等が45万円以下。扶養を聞かないので単身の線）に当たる側は 0 円にする。限度額は `lib/juminzei-hikazei.ts` の `limits({ dependents: 0, kyuchi: 1 })` を使い、ここに持たない
- 生命保険料控除・地震保険料控除など所得税と住民税で額が違う控除は「同じ額で入れた概算」と画面の注に 1 行書く（入力欄を2つに分けない）
- 画面の表に「住民税の課税所得」の行を足す（いまの「課税所得」は「所得税の課税所得」に名前を変える）
- 旧い入力の解釈との互換は要らない（保存していない）

### B. 納付税額0円の見出しを分ける（`tools/lib/sozokuzei-keisan.ts`・`Calculator.tsx`・`page.tsx`）

- `Verdict` に `'zero-by-credits'` を足す：課税価格の合計 > 基礎控除・`payableTotal === 0`・配偶者の税額軽減が使われていない
- 文言：`'納める相続税は0円です（未成年者控除・障害者控除などで差し引ききれたため）。この場合、申告は要りません。'`
  - 配偶者の税額軽減で0円の人がいる場合は従来どおり `'zero-by-spouse-relief'`（配偶者の税額軽減は申告が要件。27条1項で19条の2が除かれている）を優先する
  - 小規模宅地等の特例を使ってこの額になった場合は申告が要るので、`SMALL_LAND_NOTE` をこの区分にも添える
- 一部の人だけが0円で、ほかの人に納付税額があるときは従来どおり `'tax'`（0円の人の行は表で分かる）
- FAQ「申告は必要？（0円でも要る場合）」の 1 文目を「課税価格の合計が基礎控除を超え、**未成年者控除・障害者控除などを引いても納める税額が残る人**は申告が必要です」にし、
  配偶者の税額軽減・小規模宅地等の特例は0円でも申告が要件、という既存の 2 文目以降は残す（FAQ は `FAQPage` の JSON-LD にも出る）

## やらないこと

- **扶養人数・級地を聞いて住民税の非課税を正確に判定すること**（青色申告特別控除の計算機の主題ではない。単身の線だけを当て、注で断る）。
  正確な判定は住民税非課税の判定ツールに任せる
- **生命保険料控除などの住民税の額を別に入れさせること**（入力が増える。概算と断る）
- **相続税の未成年者控除・障害者控除の扶養義務者への振替**（現状どおり扱わない。引ききれない額を出すだけ）
- 点検して誤りが無かった13本の変更

## 期待される効果

- 「書面申告で55万円 → 10万円」で住民税が**約4.5万円上がる**人に「変わりません」と出すのをやめる（所得の小さい個人事業主ほど誤りが大きかった）
- 相続税で、申告の要らない人に「相続税がかかります」と出して税理士・税務署への不要な相談に向かわせるのをやめ、
  配偶者の税額軽減（申告が要る）との違いを結果の見出しで分ける。税理士法 52 条の線（個別の税務相談に当たらない概算）を崩さない文言のまま
