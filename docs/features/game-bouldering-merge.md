# ボルダリング合体パズル（フルーツ合体パズルを差し替える・多角形の当たり判定）

**状態**：起票（2026-09-07）。**フルーツ合体パズル（`fruit-merge`）を置き換える**。
運営者の「フルーツじゃなくてボルダリングを題材にしたものって出来ます？」
「当たり判定はホールドの形に沿ってほしい」「ゲームはひとつに統一しよう」から。
`stage` は `'wip'` から始め、判定リストを満たしたら `preview` → `public`。

**名称の商標確認は運営者のタスク**（この環境から J-PlatPat を引けない。
色水ソート・二角取りと同じ）。確認対象は「**ボルダリング**」。
一般名称（スポーツの種目名）と考えられるが、**未確認のものを確認済みのように扱わない**。
ホールドの種類名（ガバ・カチ・ピンチ・スローパー・ポケット等）は
クライミングの一般的な用語なのでそのまま使う。

**対象**：`games/`（`hasokon.com/games/bouldering-merge/` を想定）

## なぜ差し替えるのか（並べない理由）

物理も操作も同じゲームが2本並ぶと、**サイトとしては薄い重複**になる
（検索でも共食いし、保守も二重になる）。フルーツ合体パズルは
`stage: 'wip'` で**一度も公開していない**ので、いま差し替えれば
公開URLもインデックスも傷つかない（feature-flags の「一度公開したものを
引っ込めるのは別の作業」に当たらない）。

題材としてはボルダリングのほうが噛み合っている。**ホールドの種類には
「持ちやすさ＝大きさ」の自然な段階がある**ので、
「小さくて持てないホールドを合体させて、でかいガバにする」という
動機がフルーツの「ただ大きくする」より分かりやすい。

## 当たり判定：凸多角形（SAT）

**円ではなく形に沿わせる**（運営者の要望）。ここが今回の主な作業。

- 各段は**1つの凸多角形**。頂点は重心を原点とした正規化座標で持つ
- 衝突判定は **SAT（分離軸定理）**。重なっていれば、最も浅い軸を法線とする
- **接触点は面のクリッピングで2点まで作る**。1点しか作らないと、
  平らな面で接している多角形が支えられずに回り続ける（円には無い問題）
- 質量・慣性モーメントは多角形の面積から求める（面密度は一定）
- **広い判定を先に通す**。外接円で弾いてから SAT に入れないと、
  60個で総当たりすると重い

### 凹みは当たり判定に入れない

ポケットの指穴、ガバのえぐれは**絵だけ**で、当たり判定は外側の凸形。
凹みまで当たり判定にすると、
1つのホールドを複数の凸形に分ける（凸分解）ことになり、
**積み上がりの安定がまるごと難しくなる**（このゲームの公開の条件そのもの）。
穴に他のホールドがはまる遊びは狙っていないので、見合わない。

### 円のときと変わる前提

- **多角形は面で止まる。** 円は1点で接するので転がり続けたが、
  多角形は平らな面が下になると止まる。これは望ましい変化
- **積み上がりは円より不安定になりやすい。** 接触点が2点必要なのはこのため。
  60個の山で震え・すり抜けが出ないことをテストで固定する（下の判定リスト）
- **合体で生まれるホールドは形も変わる。** 親より大きくなるうえ形も違うので、
  生まれた位置で他のホールドや壁に刺さりうる。**生まれた時点で箱の中に収め、
  重なっていれば押し出す**（フルーツ版で床ぎわの合体が箱から出ていた件の一般化）

## 引き継ぐもの（フルーツ版で作ったもの）

作り直すのは形と絵で、**遊びの骨格と、直した罠は引き継ぐ**。

- 段の比・落ちてくるのは小さい5段だけ・連鎖・ゲームオーバーライン・落下予測線
- **摩擦は接触点の速度に当てる**（`applyFriction`）。中心の速度に当てると
  効きが「転がり」ではなく「接着」になる
- **止めるのは時間で判断する**（`REST_TIME`）。速さを見た瞬間に0にすると、
  斜面のものが加速する前に止められ、位置補正のぶんだけジリジリ動く
- **絵は平塗り＋輪郭線**。球の陰影と白い光沢は使わない
- **影は本体と一緒に回さない**（光は場面に対して固定）
- 記録は `lib/records.ts`、演出は `Game.tsx` の ref（状態に持たせない）

## 公開の条件（preview 段階で運営者が短時間で判定できるリスト）

1. 幅320pxで遊ぶ範囲が1画面に収まる
2. **60個積んでも震えない・すり抜けない・深くめり込まない**（テストで固定）
3. 1プレイが3〜10分に収まる
4. 中位のスマホで60fps（**多角形は円より重いので、ここは実測で確かめる**）

## やらないこと

- **凸分解（1ホールドを複数の凸形で作る）**。上記のとおり見合わない
- 特定メーカーの商品ホールドの形をなぞること。ホールドは造形物なので、
  実在商品の意匠をなぞらない。**種類の一般的な形**として自分で起こす
- 課題（ルート）を登る遊び。これは落ち物とは別のゲーム
