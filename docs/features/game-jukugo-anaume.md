## 提案する仕様

### ルール

- 十字の5マス。真ん中が空き。上・左の字は「その字＋□」、下・右の字は「□＋その字」で熟語になる（矢印で向きを示す）
  - 例：上「看」・下「気」・左「重」・右「院」 → □＝「病」（看病・病気・重病・病院）
- **答えは1字。** 表の中で4つすべてを満たす字が複数あるときは、**どれでも正解**にして「別解」として表示する（出題時に別解が無いものを優先して選ぶ）

### モード

1. **きょうの1問**（日替わり。日付から決まる。3段：小学生（教育漢字のみ）・中学生（常用漢字）・おとな（常用漢字・やや難しい熟語））
2. **れんしゅう**（続けて何問でも。正解数と連続正解を記録）
3. 解き方：**4択**（既定。スマホで片手）／**読みで入れる**（「びょう」と打つと候補が出る。手書き入力は作らない）
- ヒント：
  - 1回目：**4語のうち1語を選び、その語での真ん中の字の読みの頭の1字を、語を添えて出す**（例：「□気 の □ は『び』から」）。真ん中の字は語によって読みが変わる（生：せい／しょう、人：じん／にん）ので、読みだけを単独で出さない。どの語を選ぶかは問題ごとに決定的（日替わりは種から）
  - 2回目：4語のうち別の1語の意味の1行
- **読み入力**：4語のどれかでの真ん中の字の読み（ひらがな）を打てば、正解の字が候補に出る（例：「病」なら「びょう」。「へい」〈疾病〉を語に含む問題なら「へい」でも可）。候補は `kanji.ts` の音訓からその読みを持つ字を、同じ段の範囲で並べる
- **スマホでは読み入力の欄に自動フォーカスしない**（キーボードが出て盤が隠れる。[ことばあて](./game-kotoba-ate.md)と同じ）。既定は4択で、読み入力は切り替えたときだけ

### 解いたあと

- 4つの熟語の読みと短い意味（自前で書いた1行）を並べる
- 結果の共有（ネタバレしない。既存の `shareText()` の型）：1行目に「熟語パズル 11/23 小学生 1回目で正解・ヒント0・連続3日」、2行目に試した回数ぶんの ❌…⭕、3行目に URL。答えの字・4つの字は出さない

### 熟語の表（`games/lib/jukugo/words.ts`）

- **自前で編む。** 二字熟語 2,000 語前後（**最初は 800 語で出し、正確さを優先して増やす**）。各語に「読み・学年（2字のうち高いほう）・意味の1行・`since`（その語を足した表の版）」を持たせる
  - 小学生の段に出る語（両方の字が教育漢字）は、**意味の1行も子ども向けの言葉で書く**
  - **読みが2つある語（人気：にんき／ひとけ、生物：せいぶつ／なまもの など）は出題から外す**か、読みを1つに決めて意味の1行と揃える
  - 人名・地名・固有名詞は入れない
  - 学年は文部科学省「学年別漢字配当表」（教育漢字 1,026 字）と「常用漢字表」（2,136 字、2010 年内閣告示）で判定。**表外字を含む語は入れない**
  - 意味は自分で書く（辞書の語釈を写さない。著作物になるため）
  - 下品な語・差別語・病名を答えにする出題は避ける（`excluded` 欄で落とす。例の「病」はそのまま使える一般語）
### 字の表（`games/lib/jukugo/kanji.ts`）

- 常用漢字 2,136 字それぞれの**音訓（ひらがなで正規化）と学年（教育漢字なら1〜6、それ以外は「中学以上」）**を持つ
- 出典：**常用漢字表（平成22年内閣告示第2号）の音訓**と、**学年別漢字配当表（小学校学習指導要領〈平成29年告示〉の別表）**。どちらも告示で、著作権法13条により権利の目的にならない。ファイル冒頭に出典を書く
- 熟語の表のテスト（字が常用漢字か・学年の値）もこのファイルを引く

### 出題（`games/lib/jukugo/generate.ts`）

- 真ん中の字を選び、その字を2字目にもつ語から2つ・1字目にもつ語から2つを選ぶ。**別解の数を数え、0 のものを優先**
- **4択の誤答は「同じ段の字で、4語のうち2〜3語は作れるが、4語全部は作れない字」**から選ぶ。表から機械的に作れて、それらしさも出る。足りないときは「真ん中の字と同じ読みを持つ同じ段の字」（`kanji.ts` の音訓）で埋める。**「形の似た字」の一覧は作らない**（自前で編む手間に見合わない）
- 小学生の段は、盤の4字・答え・誤答すべてを教育漢字に限る

### 日替わりを動かさない

- 「今日」は **`games/lib/daily.ts` の `localDateKey()`** で決める（端末のローカル日付。UTC を経由すると日本時間の0〜9時に前日の問題が出る）。乱数は **`mulberry32(dailySeed(key, version))`**。`Math.random()` は使わない
- **表を足すと過去・今日・未来の問題がすべて変わる問題を、版の切り替え表で防ぐ**（[ことばあて](./game-kotoba-ate.md)のレビューと同じ論点）：

```ts
/** 日替わりの版。from の日以降にその版を使う。**公開後は既存の行を書き換えない（行を足すだけ）** */
export const DAILY_VERSIONS = [
  { from: '2026-12-01', version: 1 },
  // 表を 800 → 2,000 語に増やしたら { from: '<切り替える日>', version: 2 } を足す
] as const;
```

  - ある日の問題は「その日に当たる版 `v`」と「`since <= v` の語だけの表」から作る。**表を足しても、切り替え日より前の日は1字も変わらない**
  - 生成の手順（`generate.ts`）を変えるときも同じく版を上げ、切り替え日以降だけを変える
  - テスト：版1の期間の30日分の問題をスナップショットに固定し、表に語を足しても一致することを確かめる

### 画面

- 縦長の1画面に収める（[mobile-one-screen.md](./mobile-one-screen.md)）。十字の盤・4択ボタン・ヒント・次へ
- 字は大きく（盤の字 40px 以上）。シニアの利用を前提に、**ボタンは 48px 以上**・色だけで正誤を伝えない（○×の記号を併記）
- 漢字の字形は端末のフォントに任せる（Web フォントを読まない。軽さ優先）

### 記録

- `games/lib/records.ts` の既存の項目だけで持つ（**改修はしない**）。キーはモード×段ごと
  - `plays`・`wins`：解いた数・正解した数
  - `streak`：日替わりの連続日数（きょうの1問だけ）
  - `bestScore`：**練習の最高連続正解**（表示は「最高◯問連続」）
  - いまの連続正解（何問続いているか）は**記録せず、画面上だけ**に出す

### テスト（`games/tests/jukugo.test.ts`）

- 表のすべての語が2字で、両方の字が常用漢字表にある／学年の値が配当表と一致
- 日替わりが同じ日付で同じ問題・違う日で違う問題（365 日分で重複が少ない）
- **版の固定**：版1の期間の30日分のスナップショットが、`since: 2` の語を表に足しても変わらない
- 熟語の表の品質：読みはひらがなだけ／語の重複が無い／読みが2つある語の除外リストに当たる語が出題されない
- ヒントの読みが、添えた語での真ん中の字の読みと一致する／読み入力で、4語のどの読みを打っても正解の字が候補に出る
- 生成した問題が4つとも表の語になっている／別解の列挙が正しい
- 4択の誤答が、4つの熟語を全部は満たさない
- 小学生の段の問題（盤の4字・答え・**4択の誤答**）に教育漢字以外が出ない
- `robots: robotsFor('jukugo-puzzle')`（既存の `stage.test.ts`）

### 広告の位置

既存のゲームと同じ（盤の下、解いたあとの解説の下）。**盤と4択の間には置かない**（誤タップを防ぐ）

### やらないこと

- 三字・四字熟語、部首の合体パズル：別の遊び。需要を見てから
- 手書き入力（認識ライブラリが重い）
- 他誌・他サイトの問題の転載、外部の辞書 API（送信なしの約束）
- 対戦・ランキング（サーバーが要る）
