## 提案する仕様

### ルール

- 十字の5マス。真ん中が空き。上・左の字は「その字＋□」、下・右の字は「□＋その字」で熟語になる（矢印で向きを示す）
  - 例：上「看」・下「気」・左「重」・右「院」 → □＝「病」（看病・病気・重病・病院）
- **答えは1字。** 表の中で4つすべてを満たす字が複数あるときは、**どれでも正解**にして「別解」として表示する（出題時に別解が無いものを優先して選ぶ）

### モード

1. **きょうの1問**（日替わり。日付から決まる。3段：小学生（教育漢字のみ）・中学生（常用漢字）・おとな（常用漢字・やや難しい熟語））
2. **れんしゅう**（続けて何問でも。正解数と連続正解を記録）
3. 解き方：**4択**（既定。スマホで片手）／**読みで入れる**（「びょう」と打つと候補が出る。手書き入力は作らない）
- ヒント：1回目で読み（音読み）の頭の1字、2回目で4つの熟語のうち1つの意味

### 解いたあと

- 4つの熟語の読みと短い意味（自前で書いた1行）を並べる
- 結果の共有（ネタバレしない絵文字の並び。[ことばあて](./game-kotoba-ate.md)の型）

### 熟語の表（`games/lib/jukugo/words.ts`）

- **自前で編む。** 二字熟語 2,000 語前後。各語に「読み・学年（2字のうち高いほう）・意味の1行」を持たせる
  - 学年は文部科学省「学年別漢字配当表」（教育漢字 1,026 字）と「常用漢字表」（2,136 字、2010 年内閣告示）で判定。**表外字を含む語は入れない**
  - 意味は自分で書く（辞書の語釈を写さない。著作物になるため）
  - 下品な語・差別語・病名を答えにする出題は避ける（`excluded` 欄で落とす。例の「病」はそのまま使える一般語）
- 出題（`games/lib/jukugo/generate.ts`）：真ん中の字を選び、その字を2字目にもつ語から2つ・1字目にもつ語から2つを選ぶ。**別解の数を数え、0 のものを優先**。日替わりは日付の種で決定的に選ぶ
- 4択の誤答は「同じ読み」「形の似た字」から選ぶ（それっぽいが4つ全部は満たさない字。満たしてしまう字は除く）

### 画面

- 縦長の1画面に収める（[mobile-one-screen.md](./mobile-one-screen.md)）。十字の盤・4択ボタン・ヒント・次へ
- 字は大きく（盤の字 40px 以上）。シニアの利用を前提に、**ボタンは 48px 以上**・色だけで正誤を伝えない（○×の記号を併記）
- 漢字の字形は端末のフォントに任せる（Web フォントを読まない。軽さ優先）

### 記録

- `games/lib/records.ts` の既存の形で、モード×段ごとの正解数・連続正解・日替わりの連続日数を端末に保存（改修はしない）

### テスト（`games/tests/jukugo.test.ts`）

- 表のすべての語が2字で、両方の字が常用漢字表にある／学年の値が配当表と一致
- 日替わりが同じ日付で同じ問題・違う日で違う問題（365 日分で重複が少ない）
- 生成した問題が4つとも表の語になっている／別解の列挙が正しい
- 4択の誤答が、4つの熟語を全部は満たさない
- 小学生の段の問題に教育漢字以外が出ない
- `robots: robotsFor('jukugo-puzzle')`（既存の `stage.test.ts`）

### 広告の位置

既存のゲームと同じ（盤の下、解いたあとの解説の下）。**盤と4択の間には置かない**（誤タップを防ぐ）

### やらないこと

- 三字・四字熟語、部首の合体パズル：別の遊び。需要を見てから
- 手書き入力（認識ライブラリが重い）
- 他誌・他サイトの問題の転載、外部の辞書 API（送信なしの約束）
- 対戦・ランキング（サーバーが要る）
