（`app/minesweeper/Game.tsx` 104行目に「スマホには右クリックがないので、旗モードをボタンで切り替える」）。

**空いているのはジャンルのほうである。** 9本のうち
**トランプ3本・数字パズル3本・アクション2本・ボードゲーム1本**で、
**「絵合わせ（同じ絵柄の2枚を消す）」が1本も無い。** 麻雀ソリティアがそこに入る。

### なぜ麻雀ソリティアか

1. **タップ2回だけで完結する。** 同じ牌を2つ選ぶ。それだけ。
   ドラッグもキーボードも要らず、**モバイルとデスクトップで操作が完全に同じ**になる。
   既存のトランプ3本と同じ「タップで選択→タップで確定」の型がそのまま使える
2. **日本での需要が古くて太い。** 1986年からある定番で、無料ブラウザゲームサイトの
   定番枠。`スパイダーソリティアの遊び方` が表示5回・掲載順位74.4 で拾えているように、
   **この系統は「遊び方」クエリも連れてくる**
3. **1回が短い。** 1面5〜15分で、スキマ時間に合う。モバイルからの流入と相性が良い
4. **権利関係が無害**（次節）

### 権利関係の確認：ゲーム名に「上海」を使ってはいけない

**このジャンルの日本での通称は「上海」だが、この名前は使えない。**

- 「上海」は1986年に Activision が発売したゲームのタイトルで、
  日本では2001年からサン電子（サンソフト）が正規販売元となり、
  **サンソフトが日本国内で商標を保有している**
- 一方、**麻雀牌の意匠そのものは伝統的なもので権利者がいない。**
  牌の絵柄（萬子・筒子・索子・字牌・花牌）を自前のSVGで描く分には問題がない
- ルール自体はアイデアであり著作権の保護対象外。
  英語圏の一般名称は "Mahjong Solitaire"、Windows 同梱版は "Mahjong Titans"

**したがって、ツール名は「麻雀ソリティア」とする。** slug は `mahjong-solitaire`。
本文で「『上海』の名前で知られる」と**説明として言及する**のは事実の記述であり、
商品名として名乗るのとは別なので許容される。ただし
**`<title>`・`h1`・`registry.ts` の `name` には「上海」を入れない。**

`docs/features/game-reversi.md` で「オセロ」ではなく「リバーシ」を選んだのと同じ判断である
（「オセロ」はメガハウスの登録商標）。**このサイトはすでに一度この判断をしている。**

## 何を作るか

`/games/mahjong-solitaire/` に1本。

### ルール（初版）

- 牌136枚を「亀（Turtle）」レイアウトに積む。**初版はこの1レイアウトだけ**
- **選べる牌**：左右どちらかが空いていて、かつ上に牌が乗っていない牌
- 同じ絵柄の選べる牌を2つタップすると消える。全部消せばクリア
- 花牌（春夏秋冬）・季節牌は**同じ組の中ならどれとでも合う**（伝統ルール）

### 実装の要点

| 項目 | 方針 |
|---|---|
| 牌のデータ | `games/lib/mahjong-tiles.ts`。34種×4枚＝136枚 |
| レイアウト | `games/lib/mahjong-solitaire.ts` に3次元座標 `[layer, x, y]` の配列で持つ |
| 「選べるか」の判定 | 座標から左右・上の占有を引く純関数。**ここがテストの本体** |
| 牌の絵 | **自前のSVGコンポーネント**。`app/GameIcon.tsx` や リバーシの石と同じ方針 |
| 詰み検出 | 選べる牌の中に同じ絵柄の組が無くなったら「詰み」を出して やり直し / ヒント を促す |
| 補助機能 | もどす（undo）・ヒント（消せる組を1つ光らせる）・シャッフル。既存9本と同じ並び |

### クリア可能な配り方にする

**ランダムに積むと、詰みが避けられない配置が普通に出る。**
これは麻雀ソリティアで最も体験を壊す点で、既存の無料サイトの多くがここで雑になっている。

対策は**逆再生で配る**：空のレイアウトに対して、
「いま置ける2枚の位置」を選んで同じ絵柄のペアを置く、を68回繰り返す。
こうして作った配置は、**同じ順で消せば必ずクリアできる**ことが構成から保証される。

（最短手順が存在するだけで、途中で消す順を間違えれば詰むことはある。
そのために undo とヒントを付ける。）

**難易度は「レイアウトの層の深さ」ではなく「同じ絵柄の分散のさせ方」で作る。**
初版は難易度を分けず、亀レイアウト1つ・逆再生生成の1種類だけにする。

### テスト（`games/tests/mahjong-solitaire.test.ts`）

| ケース | 期待 |
|---|---|
| 選択可能判定 | 左右が塞がった牌は選べない / 上に乗られた牌は選べない |
| 花牌・季節牌 | 同じ組の別の牌と合う。組をまたぐと合わない |
| 逆再生生成 | 生成した136枚が34種×4枚ちょうどになる |
| 逆再生生成 | **生成時の逆順に消すと必ず全消しできる**（100回まわす） |
| 詰み検出 | 選べる牌に組が無い盤面で `deadlock` が立つ |

**「生成した盤面は必ずクリアできる」を100回まわすテストが要である。**
生成器が壊れたときに、遊んでみるまで気づけない類のバグなので、
`games/lib/nonogram` が出題の妥当性をテストしているのと同じ位置づけで入れる。

## 想定する効果

- **絵合わせジャンルの空白が埋まる。** 既存9本と食い合わない
- **モバイルで完全に成立する。** タップ2回だけなので、
  検索表示の過半（103/197）を占めるモバイルからの流入を受け止められる
- **滞在時間が伸びる。** 1面5〜15分。マインスイーパ（1,137秒）・
  スパイダー（1,091秒）と同じ帯に入る想定。AdSense の表示機会に直結する
- **CTRの高い側に本数を足せる。** ゲームは10.2%、ツールは3.0%。
  同じ表示回数あたりで3倍取れている側を厚くする

## 工数の見積もり

**中〜大（150〜200k トークン）。** 既存ゲームより重い。理由は牌の絵にある。

| 内訳 | 目安 |
|---|---|
| `lib/mahjong-tiles.ts`（34種の定義） | 15k |
| `lib/mahjong-solitaire.ts`（レイアウト・選択判定・逆再生生成・詰み検出） | 45k |
| **牌のSVG（34種）** | **60k** |
| `app/mahjong-solitaire/`（Game.tsx・page.tsx・FAQ・遊び方） | 45k |
| `tests/mahjong-solitaire.test.ts` | 25k |
| `registry.ts`・`home/index.html` の一覧追加 | 10k |

**牌のSVGが最大の費目。** 萬子は漢数字＋「萬」、筒子は円の配置、索子は竹の並び、
字牌は漢字1文字、花牌は4種。**索子（1〜9の竹の並び）と筒子（円の配置）が手間**で、
ここを規則的に生成できれば大きく減らせる。
逆に、この1点を安く済ませようとして絵文字や既製フォントに逃げると、
`registry.ts` のコメントが書いているとおり
「絵文字は端末ごとに絵柄も色も変わり、サイトの配色に馴染まない」問題を踏む。

**先に `lib` とテストだけ作って動くことを確かめ、SVGを別PRに分けてもよい。**

## やらないこと

- **複数レイアウト**（ピラミッド・要塞など）は初版では入れない。
  座標データを足すだけで増やせる作りにしておき、亀1つで出す
- **タイム計測・ランキング**は入れない。サーバーを持たない静的サイトなので
  ランキングは実装できず、タイムだけ出しても比較対象が無い
- **BGM・効果音**は入れない。既存9本にも無く、モバイルでの自動再生も難しい
- **「上海」という名前**は、前述のとおり使わない。
  検索でその語を拾う必要があるが、それは**本文中の説明**で足りる
