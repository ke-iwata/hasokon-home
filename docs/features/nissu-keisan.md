# 新ツール「日数計算・期日計算」（恒常需要の非YMYL定番ツール・年齢計算とのクラスタ形成）

**状態**：実装済み（2026-08-15）。`tools/nissu-keisan/` で公開
**対象**：`tools/`（`hasokon.com/tools/nissu-keisan/`）
**起票**：2026-08-15

---

## 背景と根拠

### 「日数計算」は定番ツール系サイトの最上位級の恒常需要

「日数計算」「何日後」「営業日 計算」は、大手計算サイト
（keisan.casio.jp・ke!san 等）で常に上位に置かれている定番中の定番で、
季節性がなく恒常的に検索される。支払期日・契約期間・提出期限・
イベントまでの残り日数など用途が広く、YMYLの審査リスクもない。

### 直前に追加した「年齢計算・西暦和暦変換」とクラスタを組める

年齢計算（[nenrei-keisan.md](./nenrei-keisan.md)、2026-08-14実装）と同じ
「日付まわりの定番計算」のクラスタに属する。相互の `RelatedTools` リンクで
日付系ツールの面ができ、単発ページより検索評価が積み上がりやすい。
既存の日付ロジック（うるう年・月末処理）の考え方も再利用できる。

### 競合との差別化

大手は広告が多く入力欄が小さい。当サイトの既存ツールと同じく
「登録不要・入力すると即計算・スマホで押しやすい」に寄せる。
営業日計算まで1ページで完結するサイトは意外に少ない。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **日数計算（日付A→日付B）**
   - 出力：経過日数（初日を含む／含まないの切り替え）、週数＋端数、
     月数＋端数、それぞれの曜日
   - 「今日から」をワンタップで入れられるプリセット
2. **期日計算（○日後・○営業日後）**
   - 日付＋日数 → 期日（○日前も負数でなくトグルで対応）
   - **営業日モード**：土日と日本の祝日（振替休日・国民の休日を含む）を
     除いて数える。年末年始などの独自休業日は扱わない（FAQで明記）
3. **祝日データの持ち方**
   - `lib/nissu-keisan.ts` に内閣府「国民の祝日について」のCSVを写した
     静的テーブルを**【データ更新箇所】**コメント付きで持つ（当年＋翌年分）
   - 祝日は毎年2月頃に翌年分が官報公示される。確定済みの年しか持たない。
     テーブルの範囲外の日付で営業日計算が要求されたら
     「祝日データの範囲外」と明示して概算にしない
   - テストは内閣府CSVと突き合わせた代表ケース（GW・年末年始・振替休日）
     と、うるう年・月末（1/31の1ヶ月後）の境界を固定する
4. **FAQ**：「初日を含む・含まないはどう選ぶ？（民法140条の初日不算入の
   原則に触れる。ただし法的助言はしない）」「営業日はどこまで考慮？」
   「祝日データはいつのもの？（データ最終更新日を表示）」など
5. **SEO**：WebApplication + FAQPage + BreadcrumbList の jsonLd。
   `llms.txt`・sitemap・home の一覧・registry への追加も実装PRで行う

### やらないこと

- 時間・時刻の計算（時間の足し引きは別ツールの領域）
- 海外の祝日・企業independentな休業日カレンダー
- 和暦での入力（和暦は年齢計算・西暦和暦変換ツールの領域。相互リンクで誘導）

## 期待される効果

- 「日数計算」「○日後 いつ」「営業日 計算」系の恒常検索の獲得。
  当サイトの非YMYL定番枠（年齢計算・アスペクト比・半角全角など）の拡充
- 年齢計算との相互リンクで日付系クラスタが2本になり、
  どちらかが評価されたときにもう片方へ回遊が生まれる
- 祝日テーブルは将来「祝日一覧・カレンダー」系ページへの転用も可能
