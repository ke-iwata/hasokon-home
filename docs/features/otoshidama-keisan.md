### 需要と競合の状況（2026-11-12 の Web 調査）

「お年玉 相場」「お年玉 いくら」「お年玉 年齢別」「お年玉 新札 両替」「ポチ袋 書き方」は毎年12月〜1月の定番クエリ。
上位は**記事型**（金融機関・メディアのコラム）が並び、表を眺めて自分で足し算させる。調べた範囲で足りていないのは：

1. **合計と「何を何枚両替するか」を出してくれるものが無い。** 甥・姪・孫が5人いて「小学生3千円・中学生5千円・高校生1万円」なら
   合計と、1万円札・5千円札・千円札が何枚要るかを数えるのは毎年の手作業。**新札の両替は銀行の窓口・両替機で事前に要る**ので、
   枚数が分かることに実用の価値がある
2. **学年を生年月日から出してくれない。** 「早生まれだから今年は何年生？」は迷いどころ。当サイトは `lib/nenrei.ts` の
   `gradeTurningAge()`（4月1日生まれは前の学年。年齢計算ニ関スル法律・民法143条）を既に持っている
3. **相場の数字に出典が無い。** 記事の「小学生は3,000円」は書き手の目安か、民間の調査（調査会社・金融機関）。
   **公的な調査は金融広報中央委員会（知るぽると、現 J-FLEC）の「子どものくらしとお金に関する調査（第3回）2015年度」**だけで、
   これは**受け取る側の総額**（図表9）を学年別に出している。**渡す側の1人あたりの額は、公的な数字が無い**
4. **贈与税の扱いを書いていない記事が多い。** お年玉は社交上の贈答として通常は贈与税の対象外（相続税法基本通達21の3-9）。
   「孫に10万円渡したら？」の相談が毎年出る

**本文には競合の名前を出さない。** 民間の調査の数字も引かない（出典の確かさがまちまちで、毎年変わる）。

## 提案する仕様

### 入力と出力

**入力**（行を足していく表。初期は3行）：

| 欄 | 内容 |
|---|---|
| 呼び名（任意） | 「たろう」「姪」など。**保存も送信もしない**（画面の中だけ） |
| 学年 or 生年月日 | 「未就学（0〜6歳）／小1〜小6／中1〜中3／高1〜高3／大学・専門／社会人」から選ぶか、生年月日を入れて自動 |
| 金額 | 1,000・2,000・3,000・5,000・10,000 のボタンと自由入力（500円単位） |

**既定の金額**は「学年ごとの金額」を上でまとめて決める欄で入れる（例：未就学 1,000／小学生 3,000／中学生 5,000／高校生 10,000）。
**この既定値は「当サイトの初期値」と明記し、相場とは書かない**（公的な数字が無いため。上の 3）。行ごとに上書きできる。

**出力**：

1. **合計額**（大きく）と人数
2. **用意するお札と硬貨の枚数**：1万円札・5千円札・千円札・500円玉（2千円札は既定では使わない。切り替えで使う）
3. **ポチ袋の数**（＝人数）と、**お札の折り方の目安**（千円札は三つ折りが入る袋が多い、の一般的な案内まで）
4. 1人ずつの表（呼び名・学年・金額・入れるお札）
5. **受け取る側の総額の分布（2015年度・知るぽると）**と、この子1人の額の位置づけ（「この額は、小学生 高学年が1年に受け取る総額の最多の帯〈1〜2万円〉の◯割」）
6. 年の表示：「2027年（令和9年）の干支は未（ひつじ）」。`lib/nenrei.ts` の `zodiac()` / `sexagenary()`（丁未）から出す

### 計算の約束（テストで固定する）

1. **学年は `lib/nenrei.ts` の関数で出す。** 基準日は「渡す年の1月1日」（2027-01-01）。1月1日時点の学年＝その年度（2026年度）の学年。
   **4月1日生まれは早生まれ（前の学年）**、4月2日生まれから次の学年。新しく学年の式を書かない（年齢計算で1年ずれた前例：[kokai-tool-seikaku-2026-10.md](./kokai-tool-seikaku-2026-10.md)）
2. テストケース（2027-01-01 基準、2026年度の小1＝2019-04-02〜2020-04-01 生まれ）：2020-04-01 生まれは小1、2020-04-02 生まれは未就学、
   2019-04-02 生まれは小1、2019-04-01 生まれは小2。
   年齢の境目の早見を `nenrei-keisan` のテストと同じ値で突き合わせる
3. 未就学の上限・大学の上限は「6歳以下」「高校卒業後〜22歳」のような**学年の帯**で扱い、19歳以上は「大学・専門／社会人」を選ばせる
   （生年月日からは学年の進学先が分からないので、高3の次は自動で決めない）
4. **お札の枚数は、1人ずつの額を大きいお札から割る**（1人に1万2千円なら 1万円札1・千円札2）。**合計額を割らない**（袋ごとに入れるので）
5. 2千円札を使う切り替えのときだけ、2千円・4千円などを2千円札で割る。既定は使わない（両替機で出ないことが多い）
6. 500円未満の端数は入力で弾く（「お年玉は500円単位で入れてください」）
7. 金額の上限は1人 100,000円まで（それ以上は「贈与税の FAQ」を見せる）。合計の上限は設けない
8. **数字の縁起（4・9を避ける）は「慣習として避けられることがある」の注記だけ**にし、警告や自動の書き換えはしない（法的根拠のない慣習のため）

### 本文（[thin-tool-content.md](./thin-tool-content.md) の型）

- 使い方（3ステップ）・計算の考え方（学年の決め方・お札の割り方）・出典（知るぽると 2015・相続税法基本通達21の3-9・年齢計算ニ関スル法律・日本銀行の紙幣の案内）
- **FAQ（4問。JSON-LD の FAQPage に出す）**
  1. お年玉の相場は？ → 公的な「渡す側の相場」の調査は無い。受け取る側の総額は2015年度の公的調査で〜。家族で決めた額で計算できる
  2. 早生まれの子は何年生？ → 4月1日生まれまでが前の学年（年齢計算ニ関スル法律・学校教育法17条）
  3. お年玉に贈与税はかかる？ → 社会通念上相当な額の年末年始の贈答は課税しない（相続税法基本通達21の3-9）。
     **年110万円の基礎控除（相続税法21条の5・租税特別措置法70条の2の4）**とは別の話。大きな額は [贈与税 計算機](/tools/zoyozei-keisan/) へ
  4. 旧札（福沢諭吉の1万円札など）でもよい？ → 2024-07-03 に新しい日本銀行券が発行されたが、**旧券も引き続き使える**（日本銀行）。
     新札の両替は銀行の窓口・両替機で、**手数料がかかることがある**（金融機関の名前は出さない）
- **個別の金融機関名・民間の調査会社名を出さない**（相場の記事型との差別化と、出典の確かさのため）

### 安全とプライバシー

  （[tool-use-coverage.md](./tool-use-coverage.md)）
