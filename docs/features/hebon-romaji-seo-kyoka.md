# ヘボン式ローマ字ページの検索面強化（五十音の変換表・戸籍フリガナ制度・自署FAQ）

**状態**：提案（未実装）
**対象**：`tools/`（`hasokon.com/tools/hebon-romaji/` の `app/hebon-romaji/page.tsx` が中心。変換表のデータは `lib/hebon-romaji.ts` の既存テーブルを流用）
**起票**：2026-08-14

---

## 背景と根拠

### 表示回数がツール中2番目に多いのに、49位で止まっている

Search Console API（2026-08-14 取得 / `https://tool.hasokon.com/` プロパティ、直近28日）で、
ツールページの表示回数は次のとおり。

| ページ | クリック | 表示 | 掲載順位 |
|---|---|---|---|
| `/sleep-cycle/` | 0 | 81 | 11.2 |
| **`/hebon-romaji/`** | **1** | **50** | **49.0** |
| `/aspect-ratio/` | 0 | 36 | 79.2 |
| `/furusato-nozei/` | 0 | 21 | 84.0 |

1位の睡眠サイクルは前日
（[sleep-cycle-nap-and-seo.md](./sleep-cycle-nap-and-seo.md)）に強化済み。
**次に伸びている芽がこのページ**で、90日でも16種類のクエリに表示されており、
すべてパスポート関連の意図（「パスポート 名前 変換」「ヘボン 式 ローマ字」
「パスポート 自署 ローマ字」「佐藤 ローマ字 パスポート」など）。
掲載順位49位は3〜5ページ目相当で、コンテンツの厚み不足が主因とみている。
YMYL色が薄い生活系ページなので、立ち上げ期でも内容改善が順位に反映されやすい
（睡眠サイクルと同じ構造）。

### 競合ページにあって自ページに無いもの

上位表示されている都道府県のパスポート案内（奈良県・大阪府・埼玉県など）と
民間の変換サイトを見ると、共通して**五十音全体のヘボン式対応表**を載せている。
自ページには「間違えやすいルール6行」の表しかなく、
「ヘボン式 一覧」「ヘボン式ローマ字表」というボリュームの大きい
一覧系クエリの受け皿が無い。変換ロジック（`lib/hebon-romaji.ts`）には
五十音・濁音・拗音の完全なテーブルが既にあるので、**表示するだけで済む**。

### 2025年5月の戸籍フリガナ制度に触れていない

改正戸籍法（2025年5月26日施行）で戸籍に氏名のフリガナが記載されるようになり、
旅券法施行規則第9条により**パスポートのローマ字氏名は戸籍のフリガナどおりの
ヘボン式表記**となる運用に変わった（外務省・各都道府県パスポートセンターが告知済み）。
「戸籍 フリガナ パスポート」という新しい検索意図が生まれているが、
ページはこの改正に一言も触れていない。制度改正への追従はこのサイトの柱であり、
検索エンジンへの「情報が新しい」シグナルにもなる。

## 提案する変更

すべて `app/hebon-romaji/page.tsx` の静的コンテンツ追加。計算ロジックは変えない。

1. **五十音のヘボン式変換表を追加**（清音・濁音/半濁音・拗音の3ブロック）。
   データは `lib/hebon-romaji.ts` の既存テーブルから生成して二重管理を避ける。
   見出しは「ヘボン式ローマ字 一覧表（五十音）」とし、一覧系クエリを取りにいく
2. **「戸籍のフリガナとパスポート」の節を追加**：2025年5月26日施行の
   改正戸籍法で戸籍にフリガナが載ること、パスポートの氏名表記は
   戸籍フリガナに基づくヘボン式になること（旅券法施行規則第9条）、
   フリガナの通知・届出とパスポート表記の関係。FAQにも1問追加
3. **自署（サイン）のFAQを追加**：表示クエリ「パスポート 自署 ローマ字」に対応。
   「自署は漢字でもローマ字でもよく、ヘボン式である必要はない」という
   公式運用を1問で答える
4. **title / description の微調整**：「一覧表」「五十音」の語を description に足す
   （titleは現状の「ヘボン式ローマ字変換｜パスポート表記の氏名を自動変換」を維持。
   検索面はコンテンツで広げ、titleの主軸クエリは変えない）

### やらないこと

- 変換ロジック・入力UIの変更（機能は足りている。今回は検索面の受け皿だけ）
- 別ページ（記事ページ）の新設。1ツール1ページの原則を守り、
  既に表示され始めているこのURLに内容を集約する
- 非ヘボン式表記（外国式綴り）の変換対応。判断が窓口ごとに異なり、
  ツールで断定するとかえって危険。案内文で窓口への確認を促す現状を維持

## 期待される効果
