## A. iDeCo の累計の表【優先度：高】

### いまの動き（`tools/lib/ideco.ts` 471〜521行・`tools/app/ideco/Calculator.tsx` 454〜495行）

- `cumulativeUntil(age, JOIN_AGE_LIMIT_BEFORE /* 65 */, contributionMonthly, saving.total)` と `cumulativeUntil(age, JOIN_AGE_LIMIT_AFTER /* 70 */, …)` を、**区分（`InsuredType`）を見ずに**呼んでいる
- 月額は「改正後の限度額でクランプした、いまの拠出額」のまま、70歳まで一定
- 表の下の文言は「加入できる期間が5年延びるぶん、累計の節税額が◯円増えます」（区分によらず5年）

### 一次情報

厚生労働省「iDeCo 加入可能年齢の引き上げイメージ」（https://www.mhlw.go.jp/content/12500000/001714615.pdf 、2026-10-25 に取得して本文を確認）：

> iDeCoの加入者であっても、年齢到達（※）や退職等により国民年金の資格を喪失した後は、iDeCoに加入できない。
> ※国民年金第１号被保険者（自営業者等）:60歳、第２号（サラリーマン等）:65歳、第3号（専業主婦（夫）等）:60歳、任意加入被保険者:65歳

> （対象者パターン1〜3 とも）【拠出限度額：6.2万円/月（企業年金等がある場合は合算）】

- **改正前の制度では、第1号・第3号は60歳まで**（任意加入すれば65歳まで）。第2号は65歳まで（その前に退職すれば退職まで）
- **改正後、国民年金の被保険者でない60〜69歳**（第1号・第3号の60歳以降、第2号の退職後・65歳以降）は、パターン1〜3 に当たれば70歳まで加入でき、**限度額は月6.2万円（企業年金等があれば合算）**。
  第1号の 7.5万円・第3号の 2.3万円は、国民年金の被保険者でいる間の枠

### ずれの例

| 入力 | いまの表（65歳まで／70歳まで） | 正しい前提（改正前の制度／改正後の制度） |
|---|---|---|
| 第1号・40歳・月7.5万円 | 2,250万円（300か月）／**2,700万円**（360か月）・「5年延びる」 | 1,800万円（60歳まで・240か月）／**2,544万円**（7.5万×240＋6.2万×120）・**10年**延びる |
| 第3号・40歳・月2.3万円 | 690万円（300か月）／828万円（360か月） | **552万円**（60歳まで）／828万円（60歳以降も月2.3万円のまま続けた場合。上限6.2万円の内） |
| 第2号・40歳・企業年金なし・月6.2万円 | 1,860万円／2,232万円 | 変わらない（65歳まで第2号の枠、65〜69歳は6.2万円の枠の内） |

- 第1号は**改正後の累計が多すぎ**（60歳以降の7.5万円が6.2万円を超える）、**改正前の累計も多すぎ**（65歳まで）。差の「節税額の増加」は結果的に近い値になることがあるが、両方の列が誤り
- 第3号は改正前の列が多すぎ（65歳まで）で、「延びるぶんの増加」が少なく出る（実際は10年延びる）

### 直し方

1. **加入できる年齢を区分ごとに持つ**（`lib/ideco.ts`。【データ更新箇所】の定数として冒頭に置く）
   - 改正前の制度の終わり：第1号・第3号 **60**、第2号 **65**（`JOIN_AGE_LIMIT_BEFORE` は第2号専用の名前に改めるか、区分→年齢の表にする）
   - 改正後の制度の終わり：区分によらず **70**（パターン1〜3 に当たる場合。画面の注記は今の文言を残す）
   - 国民年金の被保険者でなくなる年齢：第1号・第3号 **60**、第2号 **65**（退職の時期は聞かない。65歳まで勤める前提を注記に書く）
2. **累計は2つの区間の和にする**：`被保険者でいる間（いまの月額）` ＋ `被保険者でなくなってから70歳まで（min(いまの月額, 60歳以降の枠)）`。
   60歳以降の枠は **62,000円 −（第2号で企業年金がある場合は事業主掛金＋他制度掛金相当額）**。第1号・第3号は 62,000円（企業年金の欄は第2号のみ意味を持つ、という今の入力の作りに合わせる）
   - 第3号は「いまの拠出額のまま続けた場合」の表なので、60歳以降に増やせる分（2.3万→6.2万円）は積まない。表の下に「60歳以降は月6.2万円まで増やせます」と1行添える
   - 節税額は今と同じく「いまの課税所得のまま」の按分（60歳以降に所得が変わる点は今の注記のまま）
3. **「加入できる期間が5年延びる」を、計算した年数から組み立てる**（第1号・第3号は10年、第2号は5年）。`page.tsx` の FAQ（52行）の「積み立てられる期間が最大5年延びる」「65歳までと70歳までの累計を並べて」も、
   「第1号・第3号は60歳まで→70歳まで（10年）、第2号は65歳まで→70歳まで（5年）」に直す。表の列見出しも「65歳まで」固定をやめ、「改正前の制度（◯歳まで）」「改正後（70歳まで）」にする
4. **任意加入（60〜64歳の第1号）は初版で扱わない**。表の下の注記に「60歳以降に国民年金に任意加入する方は、65歳まで第1号の枠で出せます（この表には入れていません）」と書く
