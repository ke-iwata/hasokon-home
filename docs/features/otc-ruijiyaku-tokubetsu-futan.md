## 背景と根拠

### 制度の概要（2026-09-19 取得）

2025-12-24 の政府決定（社会保障審議会 医療保険部会の議論を経た厚労大臣・財務大臣合意）と、
2026-05-29 成立の「健康保険法等の一部を改正する法律」で、**市販薬（OTC）と同じ成分の処方薬
（OTC類似薬）に「特別の料金」を新設**する。実施は **2027年3月（令和8年度中）**。

| 項目 | 内容 | 出典 |
|---|---|---|
| 仕組み | 対象医薬品の **薬剤料の 4分の1 を「特別の料金」として患者が全額負担**。残り 4分の3 に通常の給付（3割負担など） | GemMed（医療保険部会の資料引用）・薬事日報 |
| 実質負担率 | 3割負担の人：25% ＋ 75%×30% ＝ **47.5%**（従来 30%）。2割：40%。1割：32.5% | 計算 |

### なぜ当サイトが出すべきか

- **「湿布 いくら上がる」「ロキソニン 自己負担 2027」は、施行の 2〜3 か月前から、対象一覧の
  発表（2026年8月）ですでに検索されている**。計算サイト各社に専用ツールはまだ無く、解説記事
  （薬局・病院・FP）だけ。**数字を出せるページが無い**のは、酒税改正（`shuzei-kaisei`・
  直近14日で着地 20）・たばこ（着地 41）と同じ構図
- 当サイトの医療クラスタ（高額療養費・医療費控除・傷病手当金）と**同じ利用者**（通院している人、
  医療費を気にする人）。高額療養費（直近14日 着地 9・PV 13）から内部リンクで送れる
- **YMYL だが「制度の計算」であって医療判断ではない**（何を処方するかは医師）。
  除外要件を「該当するか」で聞く設計にし、薬の選択には踏み込まない

## 提案する仕様

### 入力（スマホで 1 画面）

| 項目 | 形 | 既定 |
|---|---|---|
| 薬剤料（円） | 数値。**または「薬の種類と日数」から目安を出す**（対象成分ごとの薬価×標準量の早見表を持つ。例：ロキソプロフェン錠 60mg 1日3錠×14日、ヘパリン類似物質油性クリーム 50g） | 1,000 |
| 負担割合 | 3割／2割／1割（未就学児は 2割だが「子ども」で除外） | 3割 |
| 除外に当たるか | チェック：子ども／がん・指定難病・公費負担医療の治療に関わる処方／入院中・退院時／処置等に伴う 14日分以内／医師が長期使用を必要と判断（内服おおむね 50週・外用は通年） | 全部オフ |
| 処方日 | 2027年3月より前か後か（施行前の処方は特別の料金なし） | 画面を開いた日 |

### 出力

1. **窓口で払う額の before / after**：従来（薬剤料×負担割合）→ 改正後（薬剤料×1/4 ＋ 薬剤料×3/4×負担割合）。
   例：薬剤料 1,000円・3割 → **300円 → 475円（＋175円）**。消費税が乗るなら **特別の料金 250円 ＋ 消費税 25円** を分けて表示
   （告示で確認するまでは「消費税は上乗せされる見込み」の注記）
2. **年間の負担増**：処方の頻度（月 1 回など）×差額
3. **市販薬との比較**：同成分の OTC の参考価格帯を「目安」で置く（個別商品名は出さない。
   投資の教科書と同じく民間の商品名を避ける）。**「市販薬に切り替えるべき」とは書かない**
4. **除外に当たる場合**：「特別の料金はかかりません」と、その根拠（中間とりまとめの該当項目）を表示
5. **対象成分の早見表**：77成分をカテゴリ（解熱鎮痛・湿布・抗アレルギー・保湿・ステロイド外用・
   抗真菌・胃薬・便秘薬・去痰薬…）ごとに、代表的な成分名で一覧。検索欄つき（成分名で絞る）

## やらないこと

- **「市販薬に切り替えるべきか」の判断を出す**：どの薬を使うかは医師の判断で、当サイトは制度の
  計算だけを出す。OTC の価格は「目安」に留め、商品名・販売店名を出さない
- **薬価そのものの検索（全 1,100 品目）**：品目名は商品名（先発品名）を含むため、成分名の早見表に留める。
  薬価改定（2027年4月）で数字が動くので、品目単位で持つとメンテが追いつかない
- **施行前の公開**：除外要件・消費税・端数処理は告示で決まる。数字が確定する前に公開すると
  「計算が違う」の指摘を受ける側になる。`wip` で作って 1 月末に `preview`→`public`
- **国民年金の育児期間保険料免除（2026-10-01）早見表**：同日の調査で並んだ候補。免除額は
  月 17,920円×最大 12 か月と定額なので「早見表」にする内容が薄い。育児休業給付金計算機の
  注記 1 行で足りる（別 PR で）
- **BMI・単位換算・和暦変換の汎用ツール**：競合の人気順（JP Tools・カシオ keisan）で上位に
  あり当サイトに無いが、大手が強い常緑クエリで、法改正クエリのような「先回りで取れる」余地が無い。
  次回以降の候補として残す
