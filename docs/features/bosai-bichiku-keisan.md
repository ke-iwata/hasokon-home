# 新ツール「防災備蓄計算」（家族構成から必要量を算出・9月1日防災の日と台風シーズンに向けた季節投入）

**状態**：実装済み（2026-08-15）
**対象**：`tools/`（`hasokon.com/tools/bosai-bichiku-keisan/`）
**起票**：2026-08-15

---

## 背景と根拠

### いまが投入の最適期

台風の接近数は例年9〜10月がピークで、9月1日は「防災の日」。
「防災 備蓄 計算」「非常食 何日分」「水 備蓄 どれくらい」は
8〜10月に検索が急伸する明確な季節性を持つ。
**8月中に main に入れておけばシーズンの立ち上がりに間に合う。**

### 競合が構造的に弱い隙間領域

備蓄計算を提供しているのは保険会社（東京海上日動など）・自治体
（東京都「東京備蓄ナビ」）・防災用品店が中心で、
SEO最適化された専業ツールサイトがほぼ不在。
東京備蓄ナビは良質だが質問が多段で長く、
「家族の人数を入れたら即答」の軽さで差別化できる。

### 非YMYLの安全圏で、既存の生活系クラスタと組める

計算根拠は政府・自治体の公開ガイドライン（内閣府・農林水産省の
備蓄ガイド、東京都の備蓄目安）に置けるため、法的リスクがない。
エアコン電気代・割り勘などの「暮らしの計算」クラスタに、
災害・季節の面を追加できる。

## 提案する仕様

### 構成（1ページ = 1ツールの原則どおり）

1. **入力**：大人・子ども（乳幼児は別カウント）・高齢者の人数、
   ペット（犬・猫）の有無、備蓄日数（3日／7日切り替え。
   7日は大規模災害時の推奨値であることを注記）
2. **出力（必要量リスト）**
   - 飲料水（1人1日3Lを基準）、主食（レトルトご飯・麺など目安個数）、
     主菜（缶詰・レトルト）、カセットボンベ本数、
     簡易トイレ回数分、乳幼児がいる場合は粉ミルク・おむつ、
     ペット分のフード・水
   - 数値の根拠（農水省ガイド・東京都目安）を各項目の注記で明示
3. **印刷用チェックリスト**：計算結果をそのまま買い物リストとして
   印刷できる印刷CSS（チェックボックス付き）。これが競合にない実用差別化
4. **データの持ち方**：係数は `lib/bosai-bichiku.ts` に
   **【データ更新箇所】**コメント付きの静的テーブル。
   実装時に農水省「災害時に備えた食品ストックガイド」・
   東京都の備蓄目安の一次資料と突き合わせて確定させること
5. **FAQ**：「なぜ3日分？7日分？」「ローリングストックとは」
   「水は何を備蓄する？」など
6. **SEO**：WebApplication + FAQPage + BreadcrumbList の jsonLd。
   `llms.txt`・sitemap・home の一覧・registry への追加も実装PRで行う

### やらないこと

- 防災用品のアフィリエイト・商品リンク（広告はAdSense枠のみ）
- 避難所・ハザードマップ検索（位置情報系は扱わない）
- 医薬品・持病者向けの個別助言（YMYL回避。「かかりつけ医に相談」とだけ書く）

## 期待される効果

- 季節性クエリの立ち上がり（8月下旬〜10月）を新規ページで取れる。
  競合が弱いため、ドメインが若い当サイトでも上位が狙える数少ない領域
- 台風・地震の報道のたびに検索が跳ねる「イベントドリブン型」で、
  一度上位を取ればニュース連動の流入が継続する
- 印刷チェックリストはSNS・自治体系サイトからの被リンクを
  獲得しやすい実用コンテンツ

## 工数の目安

- 実装（係数テーブル＋ロジック＋UI＋印刷CSS＋テスト＋FAQ・jsonLd）：**約8〜12万トークン**
- 計算自体は単純（人数×係数×日数）。工数の中心は
  一次資料との突き合わせと印刷用チェックリストのCSS
