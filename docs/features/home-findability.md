# トップから目的のツール・ゲームに辿り着けるようにする

**状態**：実装済み（2026-08-13。本番反映はタグリリース待ち）
**対象**：`home/index.html`・`home/find.js`（新規）・`scripts/test/home-nav.test.mjs`（新規）
**起票**：2026-08-13

---

## 背景と根拠

公開しているツール・ゲーム・アプリが31件になり、トップの一覧が縦に伸びた。
実測（2026-08-13・実装前、Chromiumで計測）:

| 端末 | ページ全高 | ミニゲームの見出しの位置 |
|---|---|---|
| スマホ（390×844） | 6,687px = **7.9画面ぶん** | 4,549px = **5.4画面目** |
| PC（1280×900） | 3,852px = 4.3画面ぶん | 2,622px = 2.9画面目 |

ゲーム目当てで来た人は、スマホで**5画面ぶんスクロールしないと最初のゲームに届かない**。
検索表示の過半がモバイルであることを踏まえると、ここが一番効く。

## 現状（実装前）

- 分類は5つ（お金・社会保険 / 生活・変換 / 決める・選ぶ / ゲーム / アプリ）あるが、
  上から順に読む以外の辿り方が無い
- ヒーローの「ツールを見る」「ゲームで遊ぶ」は `/tools/` `/games/` の一覧ページへ出る導線で、
  トップ内の目的地には飛べない
- 名前が分かっているとき（「フリーセルをやりたい」）でも、目で探すしかない

## 提案する仕様

**1. 分類への近道（`.quicknav`）** — ヒーロー直下に、各分類へのアンカーと件数を並べる。
素のHTMLのアンカーなので、JSが動かない環境でも機能する。

**2. 絞り込み（`home/find.js`）** — 入力した語を含むカードだけを残す。

- 入力欄は**JSが差し込む**（動かない環境に、何も起きない入力欄を見せない）
- 比較の前に、全角英数を半角に・カタカナをひらがなに寄せる
  （「ふりーせる」「ｉＤｅＣｏ」でも引ける）
- 分類の見出しも検索対象に含める（「ゲーム」で10件まとめて引ける）
- **日本語入力の変換中（composition中）は絞り込まない。**
  「年金」を打つ途中の「ねんきん」で0件になり、「一致しません」が変換のたびに点滅するため
- 中身が全部消えた分類は見出しごと畳む。該当なしのときは案内文を出す

## 期待される効果

目的地までの操作が「5画面スクロール」から「1タップ」または「2〜3文字入力」になる。
効果は GA4 の `portal_click`（`analytics.js` が送っている遷移先）で、
トップから各ツール・ゲームへの遷移が増えるかで測る。

## やらないこと

- **読み仮名のデータを持たない。** 「ねんきん」のままでは引けないが、31件すべてに
  読みを書くと、カードを増やすたびに手入力が増える。変換を確定すれば漢字で引ける
- **並べ替え・お気に入り。** 状態を持つとlocalStorageの管理が増える。
  まず到達コストだけを下げて、必要になってから考える
- **`/tools/` `/games/` 側への同種の導線。** あちらは分類が1つずつなので、
  同じ問題は起きていない

## 保守

`.quicknav` の件数は手書きなので、`scripts/test/home-nav.test.mjs` が
実際のカード数との一致を見張っている（ずれると `node --test` が落ちる）。
カードを増やしたら、一覧と近道の数字の両方を直すこと。
