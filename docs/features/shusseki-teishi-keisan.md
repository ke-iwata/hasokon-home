## 背景と根拠

### 答えは条文 1 行なのに、数え方で毎年迷われる

学校保健安全法 19 条（出席停止）と同法施行令 6 条を受けた**学校保健安全法施行規則 19 条 2 号**が、第二種の感染症ごとに
出席停止の期間の基準を決めている。インフルエンザなら

> 発症した後五日を経過し、かつ、解熱した後二日（幼児にあつては、三日）を経過するまで。

迷われるのは次の 3 点で、どれも日付の計算で答えられる。

1. **「発症した後五日を経過」は、発症日を 0 日目として 5 日目が終わるまで**（初日不算入。文部科学省「学校において予防すべき感染症の解説」の図と同じ数え方）。
   最短でも 6 日目から登校できる
2. **「かつ」なので、解熱が遅ければ解熱の条件のほうで延びる**。解熱した日を 0 日目として、2 日目（幼児は 3 日目）が終わるまで
3. **「幼児」は 1 日長い**。保育所・幼稚園・認定こども園に通う子は解熱後 3 日。小学生以上は 2 日

新型コロナは同じ号のチで「発症した後五日を経過し、かつ、症状が軽快した後一日を経過するまで」。解熱ではなく「症状の軽快」で、待つのは 1 日（幼児の区別は無い）。

### 検索の形は「うちの子はいつから行ける」

検索語は「インフルエンザ 出席停止 計算」「インフルエンザ 登校 いつから」「コロナ 登園 いつから」のように、
**自分の子の日付で答えがほしい**形をしている。いまこの需要に答えているのは小児科クリニックのブログと自治体・学校の PDF で、
自動計算があるのはクリニックの一部だけ。条文の号まで示して、幼児／小学生以上・インフルエンザ／コロナ／麻しんほかを 1 画面で切り替えられるものは少ない。

### 当サイトのデータ（2026-10-06、GA4・直近 28 日）

- 流入の中心は Bing（514 セッション）と Yahoo! JAPAN の AI アシスタント経由（`openai` 270）。Google は 6 で、
  Google 未登録の問題（[google-index-recovery.md](./google-index-recovery.md)）は続いている

### 法的根拠（2026-10-06、e-Gov 法令 API で取得）

- **学校保健安全法施行規則（昭和 33 年文部省令第 18 号）**。現行は令和 5 年文部科学省令第 22 号による改正（2023-05-08 施行）が最新
  （`law_revision_id: 333M50000080018_20230508_505M60000080022`）
  - **18 条 1 項 2 号**：第二種の感染症 ＝ インフルエンザ（特定鳥インフルエンザを除く）、百日咳、麻しん、流行性耳下腺炎、風しん、水痘、咽頭結膜熱、新型コロナウイルス感染症、結核、髄膜炎菌性髄膜炎
  - **19 条 2 号**（結核・髄膜炎菌性髄膜炎を除く第二種）。ただし書き「病状により学校医その他の医師において感染のおそれがないと認めたときは、この限りでない」

| 号 | 感染症 | 基準（原文） | 本ツールで日付にできるか |
|---|---|---|---|
| イ | インフルエンザ | 発症した後五日を経過し、かつ、解熱した後二日（幼児にあつては、三日）を経過するまで | **できる** |
| ロ | 百日咳 | 特有の咳が消失するまで又は五日間の適正な抗菌性物質製剤による治療が終了するまで | 「治療開始日から 5 日間」の側だけ参考表示 |
| ハ | 麻しん | 解熱した後三日を経過するまで | **できる** |
| ニ | 流行性耳下腺炎 | 耳下腺、顎下腺又は舌下腺の腫脹が発現した後五日を経過し、かつ、全身状態が良好になるまで | 最短日だけ（「全身状態が良好」は日付にできない旨を併記） |
| ホ | 風しん | 発しんが消失するまで | できない（説明のみ） |
| ヘ | 水痘 | すべての発しんが痂皮化するまで | できない（説明のみ） |
| ト | 咽頭結膜熱 | 主要症状が消退した後二日を経過するまで | **できる** |
| チ | 新型コロナウイルス感染症 | 発症した後五日を経過し、かつ、症状が軽快した後一日を経過するまで | **できる** |

- **「経過する」の数え方**：**文部科学省「学校において予防すべき感染症の解説」の数え方（「発症した日・解熱した日を 0 日目」とする図）を根拠の主にする**。
  施行規則が民法を直接引いているわけではないので、民法 140 条（期間の初日不算入）は「同じ考え方」の補足として添えるにとどめる。
  **実装時に同解説の最新版（令和 5 年度改訂以降）の図と注記を取得し、本仕様書に URL と版を書き足す**
- **保育所**：保育所は学校保健安全法の対象外だが、こども家庭庁「保育所における感染症対策ガイドライン」が同じ基準（インフルエンザは幼児 3 日）を目安として示している。
  **実装時に最新版の版表記と該当ページを確認して出典に足す**
- **大人（職場）**：法令上の出勤停止の基準は無い（インフルエンザ・5 類移行後の新型コロナとも）。勤務先の就業規則・指示に従う。
  本ツールでは「大人の目安として同じ数え方を表示」までにとどめ、義務のように書かない

### 画面（1 画面 2 段。スマホ 390×844 で上段が収まること）

**上段（入力 4 つ）**

1. **病気**：インフルエンザ（既定）／新型コロナ／麻しん（はしか）／おたふくかぜ（流行性耳下腺炎）／プール熱（咽頭結膜熱）／その他（百日咳・風しん・水痘 → 説明だけ出す）
2. **通っているところ**：小学校・中学校・高校・大学（既定）／保育所・幼稚園・認定こども園（＝幼児）／大人（職場）
3. **発症日**（病気によって「腫れが出た日」「症状が消えた日」などラベルを切り替える）
4. **解熱した日**（コロナは「症状が軽快した日」）。**「まだ熱がある」を選べる**（その場合は「今日解熱したら最短で◯日」を出す）
   - **入力欄の補足（1 行）に「解熱」「症状が軽快」の定義を出す。** 利用者がここを誤ると結果が丸ごとずれるため。
     文科省の解説では、解熱は解熱剤を使わずに熱が下がったこと、新型コロナの「症状が軽快」は解熱剤を使わずに解熱し、かつ呼吸器症状が改善傾向にあること、
     とされている見込み。**実装時に同解説の該当記述を確認できたときだけ、その文言で出す**。確認できなければ補足は「迷ったら医師・学校へ」にとどめる
     （FAQ「解熱剤で熱が下がった日は解熱日ですか」と同じ扱い）

**下段（結果）**

- 1 行目を太字で「**10 月 13 日（火）から登校できます**（最短）」。病気・区分により「登園」「出勤の目安」に言い換える
- その下に**2 つの条件のどちらで決まったか**を 1 行：「発症日から数えた条件（6 日目）より、解熱日から数えた条件（解熱の 3 日後）のほうが遅いので、こちらで決まりました」
- **0 日目からのカレンダー**（横スクロールなしの 7 列）。発症日＝0、解熱日＝0 をそれぞれ印、出席停止の日を塗り、登校できる日を枠で強調
- 登校できる日が土日祝なら「**実際に登校するのは◯月◯日（月）**（学校の休みの日は学校の暦に従う）」と 1 行足す（`isBusinessDay()`）。
  **このずらしは `group === 'school'`（小学生以上）のときだけ。** 保育所は土曜も開いていることが多く、月曜にずらすと 1〜2 日余計に休ませる誤案内になる。
  幼児は日付をずらさず「園の開所日に従ってください」と 1 行、大人はずらしも注記も出さない
- 注記（固定）：
  - 「医師が感染のおそれがないと認めたときは、この限りではありません（施行規則 19 条 2 号ただし書き）。迷ったら学校医・かかりつけ医に」
  - 「登校の際の書類（治癒証明書・経過報告書など）は、学校・自治体の様式に従ってください」
  - 「出席停止の日は欠席日数に数えません」（**実装時に指導要録の扱いの一次情報を確認できたら出す。確認できなければ出さない**）

### 計算ロジック（`tools/lib/shusseki-teishi.ts`。純関数のみ）

```ts
type Disease = 'influenza' | 'covid19' | 'measles' | 'mumps' | 'pcf' | 'other';
type Group = 'school' | 'preschool' | 'adult';

interface Rule {
  /** 条文の号（イ・チ…）と原文。画面の出典表示に使う */
  article: string; text: string;
  /** 起点 A（発症・腫脹）から「◯日を経過」。無ければ null */
  afterOnsetDays: number | null;
  /** 起点 B（解熱・軽快・消退）から「◯日を経過」。幼児で変わる病気はここで分岐。
   *  'adult' は法令の基準が無いので、'school'（小学生以上）と同じ日数を目安として返す */
  afterRecoveryDays: (g: Group) => number | null;
  /** 日付にできない条件（「全身状態が良好になるまで」など）。あれば画面に併記 */
  extraCondition?: string;
}

/** 「N 日を経過するまで」→ 出席できる最も早い日 ＝ 起点 + N + 1 日（初日不算入） */
export function firstDayAfter(start: DateParts, days: number): DateParts;

/** 2 条件の遅いほう。どちらで決まったか（'onset' | 'recovery' | 'both'）も返す */
export function earliestReturn(input: { disease: Disease; group: Group; onset: DateParts; recovery: DateParts | null; today: DateParts }): Result;
```

- インフルエンザ：`max(onset + 6, recovery + (preschool ? 4 : 3))`（大人は小学生以上と同じ `+3`。画面では「目安」と明記）
- 新型コロナ：`max(onset + 6, recovery + 2)`（幼児の区別なし）
- 麻しん：`recovery + 4`
- 流行性耳下腺炎：`onset + 6`（＋ `extraCondition`）
- 咽頭結膜熱：`recovery + 3`
- **入力の整合**：解熱日が発症日より前ならエラー。解熱日が今日より後ならエラー（未来の解熱は「まだ熱がある」を選ばせる）
- `recovery === null`（まだ熱がある）なら `recovery = today` として計算し、文面を「今日解熱したとしても、最短で◯日」に切り替える
- 土日祝の判定は `nissu-keisan.ts` から import し、**`group === 'school'` のときだけ**「実際に登校する日」を出す。`HOLIDAY_LAST_YEAR` を超える日付は「祝日は未確認」と注記（既存の作法どおり）

## やらないこと

- **医学的な助言**：症状の見立て・受診の要否・薬の使い方は書かない。「医師が認めたときはこの限りでない」と「迷ったら医師・学校へ」までにとどめる
- **治癒証明書・経過報告書の作成・印刷**：様式は学校・自治体ごとに違う。リンクもしない（個別の学校の PDF を当サイトが案内しない）
- **第三種の感染症（流行性角結膜炎など）・結核**：基準が「医師が認めるまで」で日付にできない。説明の表に 1 行だけ載せる
- **大人の出勤停止を義務として書くこと**：法令上の基準は無い。目安として同じ数え方を出し、「勤務先の就業規則・指示に従ってください」と明記する
- **地域の流行状況の表示**：外部データの取り込み・更新が運用に乗らない（CONCEPT.md の「更新し続けないと死ぬ」型を避ける）
