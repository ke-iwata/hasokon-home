## 背景と根拠

### なぜいま：令和8年分の年末調整は、生命保険料控除の計算が初めて変わる年

令和7年度税制改正で、**23 歳未満の扶養親族がいる人の「一般の生命保険料控除」（新契約）の上限が 4 万円 → 6 万円**になった。
**令和8年分（2026 年の年末調整）が最初の適用**で、会社員は 10 月下旬〜11 月に配られる
「保険料控除申告書」で、この新しい表を自分で当てはめて控除額を書く。

国税庁 No.1140（令和8年4月1日現在法令等）が示す表：

| 区分 | 年間の支払保険料等 | 控除額 |
|---|---|---|
| 新契約（一般・介護医療・個人年金） | 2 万円以下 | 全額 |
| | 2 万円超 4 万円以下 | ×1/2 + 1 万円 |
| | 4 万円超 8 万円以下 | ×1/4 + 2 万円 |
| | 8 万円超 | 4 万円 |
| 旧契約（一般・個人年金） | 2.5 万円以下 | 全額 |
| | 2.5 万円超 5 万円以下 | ×1/2 + 1.25 万円 |
| | 5 万円超 10 万円以下 | ×1/4 + 2.5 万円 |
| | 10 万円超 | 5 万円 |
| **新契約の一般・23 歳未満の扶養親族あり（令和8年分〜）** | 3 万円以下 | 全額 |
| | 3 万円超 6 万円以下 | ×1/2 + 1.5 万円 |
| | 6 万円超 12 万円以下 | ×1/4 + 3 万円 |
| | 12 万円超 | **6 万円** |

- 新旧両方ある区分の控除額は、**「新だけの額」「旧だけの額」「新＋旧の合計（上限 4 万円。特例ありの一般は 6 万円）」のうち最も大きい額**
  （国税庁「令和8年分 年末調整のしかた」24 ページの表：一般の生命保険料は「①、②、③のうち最も大きい金額」。
  保険料控除申告書の欄では「③と④のいずれか大きい金額 又は ⑤の金額」）。
  - 特例が**無い**ときは、旧の支払額が 6 万円超なら旧だけ（最高 5 万円）が大きくなる（旧 6 万円の控除額がちょうど 4 万円なので）。
  - 特例が**有る**ときは、旧が 6 万円超でも、新生命保険料を払っていれば**新＋旧の合計（上限 6 万円）のほうが大きくなる**。
    「年末調整のしかた」24 ページの（注）1：「年齢 23 歳未満の扶養親族を有する場合で支払った新生命保険料の金額があるときは、
    ②の金額よりも③の金額が大きくなりますので、③の金額が控除額となります」。No.1140 も、旧 6 万円以下・6 万円超の**両方の場合**に
    「令和8年以降、23歳未満の扶養親族を有する新生命保険料を支払った場合は最高60,000円」と書いている
  - 例：一般・旧 7 万円＋新 5 万円。特例なし → 旧だけ 4.25 万円（新＋旧は 2 万＋4.25 万で上限 4 万円）。
    特例あり → 新（計算式Ⅱ）4 万円＋旧 4.25 万円＝8.25 万円 → 上限で **6 万円**
  - **実装では「旧 6 万円超なら旧だけ」の分岐を書かない。** 3 つの額を出して最大を採る（申告書の欄と同じ）
- 3 区分の合計の上限は **12 万円**（特例があっても変わらない）
- **特例の適用は令和8年分・令和9年分の 2 年分**（租税特別措置法 41 条の 15 の 5 第 1 項。令和7年度改正で令和8年分として創設され、
  令和8年度改正で適用期限が令和9年分まで延長された。国税庁「源泉所得税の改正のあらまし（令和8年4月）」の 9⑵・7 ページ 2、
  「令和8年分 年末調整のしかた」4 ページ。条文番号は国税庁「令和8年分 給与所得の源泉徴収票等の法定調書の作成と提出の手引」の
  摘要欄の書き方「租税特別措置法第 41 条の 15 の５第１項適用」で確認）。No.1140 の「令和8年分以降」は期限の書き方が粗いので、
  **年分ごとに特例の有無を持つ**（下記 `RULES_BY_YEAR`）
- 出典：国税庁 No.1140 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1140.htm ・
  「令和8年分 年末調整のしかた」 https://www.nta.go.jp/publication/pamph/gensen/nencho2026/01.htm （4 ページ・24 ページ）・
  「源泉所得税の改正のあらまし（令和8年4月）」 https://www.nta.go.jp/publication/pamph/gensen/2026kaisei.pdf
- **実装前に**、令和8年分の保険料控除申告書の様式と記載例（https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2026bun_04.pdf ）の
  計算欄で、特例ありの新旧合算の欄（⑤＝②＋③、最高 6 万円）と「いずれか大きい金額」の欄の書き方を、実装する人がもう一度確かめる
  （2026-10-11 に様式の計算欄の見出し〔計算式Ⅰ・Ⅱ・Ⅲ、①〜⑤、最高 4 万／6 万／5 万円〕までは確認した。

### 法的な位置づけ

- 税額の**一般的な計算**で、個別の税務相談（税理士法 2 条）にはしない。「申告書の書き方の目安。最終的には勤務先・税務署へ」と書く
- **保険会社名・商品名は出さない**（例も「終身保険」「医療保険」などの一般名で）
- 保険の加入・見直しを勧める文は書かない（保険業法の募集に当たる表現を避ける）
