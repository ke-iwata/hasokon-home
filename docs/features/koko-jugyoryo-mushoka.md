# 高校授業料 実質負担 計算機（2026年4月・就学支援金の所得制限撤廃に対応）

**状態**：提案（2026-08-14）
**対象**：`tools/`（`hasokon.com/tools/koko-jugyoryo/`）
**起票**：2026-08-14

---

## 背景と根拠

### 2026年4月に「高校無償化」が大きく変わり、検索需要の山がこれから来る

高等学校等就学支援金制度の改正法が2026年3月31日に成立し、**2026年4月から
所得制限が撤廃**された。私立高校の支給上限は**年45万7,200円**（全国平均授業料水準）に
引き上げられ、公立は年11万8,800円。新たに支給・増額の対象になる生徒は約80万人と
報じられている（2026-08-14 Web検索で確認。文科省の制度改正を解説する記事が
教育系・金融系メディアで多数ヒットする）。

重要なのは**季節性**で、高校の学校説明会・進路決定・出願は**9月〜1月**に集中する。
「私立でいくら戻るのか」「公立と私立で3年間の負担がどれだけ違うのか」を
家庭が具体的に計算したくなるのはまさにこれからの時期であり、
**いま仕込めば需要の立ち上がりに間に合う**。

### 「支援額が一律になった」からこそ、計算機の出番がある

所得制限の撤廃で「もらえるか」の判定は不要になったが、代わりに論点が
**「実際の自己負担がいくら残るか」**に移った：

- 私立の授業料は学校ごとに違い、45万7,200円を超える分は自己負担
- 就学支援金の対象は**授業料のみ**。入学金・施設費・制服・教材・修学旅行などは対象外
- 通信制（単位制）は1単位13,668円 × 年30単位（通算74単位）上限という別体系
- 都道府県の上乗せ助成（東京都・大阪府などは既に実質無償化）が別にある

「無償化と聞いていたのに思ったより払う」というギャップがこの制度の
検索需要の中心であり、単なる制度解説記事ではなく**計算機**が刺さる領域。

### サイトの方針との整合

このサイトのツール群は「法改正×お金の計算機」を柱にしており
（年収の壁・高額療養費・iDeCo・年末調整など、いずれも改正対応が起点）、
本件はその柱にそのまま乗る。子育て世帯向けでは
[kosodate-shienkin](../../tools/app/kosodate-shienkin/) があるが、
あちらは支援金の受給額であり、高校の学費負担の計算機は未提供。関連ツールとして
相互リンクすれば内部リンクの束も強くなる。

## 提案する仕様

### 入力

1. 進学先タイプ：公立（全日制）／私立（全日制）／私立（通信制・単位制）
2. 私立なら年間授業料（初期値は全国平均。学校案内の数字に差し替え可能）
3. 通信制なら年間履修単位数と1単位あたり授業料
4. 任意：入学金・施設費など授業料以外の年間見込み（目安のプリセットつき）

### 出力

- 年間の就学支援金額と、授業料の実質自己負担額
- **3年間の総額**（公立との比較を並記。「私立にした場合の追い金」が一目で分かる）
- 授業料以外は支援対象外であることの明示と、費目別の一般的な目安
- 都道府県の上乗せ助成が別にある旨の案内（v1では代表例の注記に留め、
  47都道府県の個別データ化はやらない）

### 解説コンテンツ（SEO本文）

- 2026年4月改正の要点（所得制限撤廃・私立45万7,200円・対象は授業料のみ）
- 「無償化でも払うもの」一覧（入学金・制服・教材・通学費・修学旅行・部活動）
- 通信制の計算方法（単位制の支給の仕組み）
- 申請方法の概要（学校経由・オンライン申請、授業料との相殺）
- FAQ（よくある誤解：「45万円が振り込まれるわけではない」など）

### 法的根拠（実装時に必ず一次情報で再確認する）

- 高等学校等就学支援金の支給に関する法律（2026年3月31日改正成立、4月1日施行）
- 支給額：公立 118,800円／年、私立 457,200円／年（上限）、
  通信制（単位制）13,668円／単位・年30単位・通算74単位上限
- 文科省「高等学校等就学支援金制度」ページを footnote で必ず参照する

## 期待される効果

- 「高校無償化 計算」「私立高校 無償化 いくら」「就学支援金 いくら」系の
  検索は競合がまだ制度解説記事中心で、**計算機の形で出しているサイトが少ない**。
  ニッチ計算機で1ページ目を取ってきた既存パターン（睡眠サイクル・高額療養費）と
  同じ戦い方ができる
- 9月〜1月の進路シーズンに合わせた季節需要を毎年拾える恒常ページになる

## 工数の目安

- 計算ロジックは単純（上限との min、単位数の掛け算、3年合計）。
  複雑さは制度の正確な説明側にある
- 実装1セッション：**おおよそ10〜15万トークン**
  （ページ実装＋解説＋テスト＋メタ・sitemap・一覧更新。既存ツールの雛形を再利用）

## やらないこと

- 47都道府県の上乗せ助成のデータベース化（更新負荷が高い。v1は注記と外部リンク）
- 高等教育（大学）無償化・給付型奨学金（別制度。別ツールとして検討余地はある）
- 世帯年収の入力（2026年度から国の支援には不要になった。入力項目を増やさない）
