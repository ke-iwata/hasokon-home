## 遊び方（仕様）

### 基本の流れ（ひとりで）

1. **お題の顔を選ぶ**：おかめ・ひょっとこ・おに・だるま・ねこ（**5種**。すべて自前の SVG）。最初は「おかめ」を選んだ状態
2. 「はじめる」を押すと、**顔の輪郭だけが 3 秒見え、そのあとパーツが消える**（＝目かくし。輪郭は薄い線で残すか消すかを「かんたん／ふつう／むずかしい」で切り替え）
   - かんたん：輪郭が見えたまま（小さい子向け）
   - ふつう：輪郭は薄く残る（既定）
   - むずかしい：輪郭も消えて、真っ白な紙の上に置く
3. 画面下の**パーツ置き場**に、まゆ（左右）・目（左右）・鼻・口の **6 枚**が**シャッフルされた順・ランダムな向き（±30°）**で並ぶ
4. パーツを**ドラッグ**（PC・スマホ）または**タップで選んでから顔の上をタップ**して置く。**置いたパーツは見えない**（ふつう・むずかしい）。置いた数だけ「6 枚中 3 枚」と出す
5. 6 枚置き終わると、**「めかくしを とる」ボタン**。押すと顔が現れ、効果音（ミュート可）とともに**できた顔**を見せる
6. 結果：
   - **点数（100 点満点）**と、ひと言（「ほぼ完ぺき！」「なかなかの福顔」「これは大笑い」など5段階）
   - 「正解の顔を重ねる」トグル（半透明で正しい位置を重ねて見せる）
   - **画像で保存**（PNG。端末に保存するだけで、送信しない）・**もう一回**・**次の人へ**（家族モード）

### 家族モード（順番に遊ぶ）

- 2〜6 人の名前（または「1ばん」「2ばん」…）を入れて順番に遊ぶ。1人終わるごとに「次は ◯◯ さん。スマホを渡してね」の画面を挟む（**前の人の顔は伏せる**）
- 全員終わったら、**全員の顔を並べて**点数の順位と「いちばん笑えた顔」を選ぶボタン（選んだ顔に「大賞」の札。点数とは別の楽しみ）
- 名前は端末内だけ（`localStorage` にも残さない。リロードで消える）

### 点数の付け方（`games/lib/fukuwarai.ts`）

パーツごとに**位置のずれ**と**角度のずれ**から 0〜1 を出し、6 枚の重み付き平均を 100 点に直す。

- 位置のずれ `d` は、正しい中心とのユークリッド距離を**顔の幅 W で割った値**（画面サイズに依らない）
- 位置のスコア `p = max(0, 1 − d / 0.25)`（顔幅の 25% ずれたら 0）
- 角度のスコア `a = max(0, 1 − |θ| / 45°)`（`θ` は正しい向きとの差。−180〜180 に正規化）
- パーツのスコア `= 0.8 × p + 0.2 × a`
- 重み：目 2 枚・口 1 枚を各 1.2、まゆ 2 枚・鼻 1 枚を各 0.8（目と口のずれが顔の印象を一番変えるため）
- **左右の取り違え**（左目を右目の位置に置いた）は、左右対称のパーツ（目・まゆ）に限り**入れ替えて採点したほうの高い点**をとる（遊ぶ人が左右を区別できないため）
- 点数は**整数に四捨五入**。顔の外（輪郭の外接矩形の外）に置いたパーツは 0 点

### パーツの回し方

- 置き場のパーツは最初からランダムに傾いている（±30°）。**回すかどうかは任意**
- PC：ドラッグ中にホイール、またはパーツ選択中に `Q` / `E` で 15° ずつ
- スマホ：パーツ選択中に出る「↺」「↻」ボタン（44px 以上）。2本指の回転は実装しない（誤操作が増え、テストしにくい）
- キーボードだけでも遊べる：`Tab` でパーツを選び、矢印キーで顔の上の照準を動かし（`Shift` で大きく）、`Enter` で置く

### 日替わり（任意・あれば）

- 「今日のお題」：日付から顔の種類とパーツの初期の向きを決める（`games/lib/daily.ts` の種を使う）。全員が同じ条件で点数を比べられる
- ベスト点を顔の種類ごとに `records.ts` で保存

## 画面とUI

- **1画面に収める**（[mobile-one-screen.md](./mobile-one-screen.md)）。390×844 で、上 65% に顔、下 35% にパーツ置き場。320×568 でもパーツ 6 枚が2段で収まること
- PC（1366×768）は顔を左、パーツ置き場を右の縦並び
- 顔は `viewBox` 固定の SVG で描き、座標の計算は**SVG の座標系**で行う（画面の px で計算しない。端末の大きさで点数が変わらないように）
- ドラッグは Pointer Events で、`touch-action: none` は**顔とパーツ置き場の中だけ**（ページ全体のスクロールを殺さない）
- 置いたパーツは「ふつう／むずかしい」では描かない。代わりに**置いた場所に何も出さない**（小さな点を出すと答えが分かってしまう）。置き直しはできない（福笑いの遊び方どおり）。ただし「最初から」ボタンはいつでも
- 結果の画面では、顔が現れるアニメーション（0.6 秒。`prefers-reduced-motion` では無し）
- 効果音は既定でオフ。オンにしても1回きりの短い音のみ

## 確かめること（テスト）

`games/tests/fukuwarai.test.ts`：

1. 6 枚すべてを正しい中心・角度 0 で置くと **100 点**
2. 1 枚を顔幅の 25% 以上ずらすと、そのパーツは 0 点（他は満点）→ 全体は重みどおりの点
3. 角度 45° 以上のずれで角度のスコアが 0、180° と −180° が同じ扱い
4. 左目と右目を入れ替えて置いても点が下がらない（左右対称パーツの入れ替え採点）
5. 鼻・口は入れ替え採点の対象にならない
6. 顔の外に置いたパーツは 0 点
7. 点数は SVG 座標で計算され、表示サイズ（viewBox の倍率）を変えても同じ点になる
8. 日替わりの種が同じなら、顔の種類と初期の向きが同じ
9. `stage` と `robots`（既存の `stage.test.ts`）
10. 5 種の顔データが、6 枚のパーツと正しい位置・輪郭を持っている（データの欠けを落とす）

手で確かめること：390×844・320×568 でドラッグ・タップ置き・回転ボタン、1366×768 でマウス・ホイール回転・キーボードだけの操作、家族モードで前の人の顔が伏せられていること。
