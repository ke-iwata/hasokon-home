## 遊び方（仕様）

### 基本の流れ（ひとりで）

1. **お題の顔を選ぶ**：おかめ・ひょっとこ・おに・だるま・ねこ（**5種**。すべて自前の SVG）。最初は「おかめ」を選んだ状態
2. 「はじめる」を押すと、**正解の顔（輪郭とパーツ6枚がそろった完成形）を 3 秒見せる**。3 秒たつと**パーツが消えて**、難易度に応じた輪郭だけが残る（＝目かくし。どこに何があったかを覚える時間）
   - かんたん：輪郭がはっきり残る（小さい子向け）。3 秒の完成形は同じように見せる
   - ふつう：輪郭は薄く残る（既定）
   - むずかしい：輪郭も消えて、真っ白な紙の上に置く
   - 見えるもの・見えないものの全体は下の「難易度ごとの見え方」の表
3. 画面下の**パーツ置き場**に、まゆ（左右）・目（左右）・鼻・口の **6 枚**が**シャッフルされた順・ランダムな向き（±30°）**で並ぶ
4. パーツを**ドラッグ**（PC・スマホ）または**タップで選んでから顔の上をタップ**して置く。**ふつう・むずかしいでは、パーツは置き場を出た瞬間から描かない**（ドラッグ中も、置いたあとも見えない）。**かんたんだけは置いたパーツが見える**。置いた数だけ「6 枚中 3 枚」と出す
5. 6 枚置き終わると、**「めかくしを とる」ボタン**。押すと顔が現れ、効果音（ミュート可）とともに**できた顔**を見せる
6. 結果：
   - **点数（100 点満点）**と、ひと言（「ほぼ完ぺき！」「なかなかの福顔」「これは大笑い」など5段階）
   - 「正解の顔を重ねる」トグル（半透明で正しい位置を重ねて見せる）
   - **画像で保存**（PNG。端末に保存するだけで、送信しない）・**もう一回**・**次の人へ**（家族モード）

### 難易度ごとの見え方

| 見えるもの | かんたん | ふつう（既定） | むずかしい |
|---|---|---|---|
| はじめの 3 秒（正解の顔） | 見える | 見える | 見える |
| 輪郭（3 秒のあと） | はっきり | 薄く | 見えない |
| 置き場の中のパーツ（向きを回すところ） | 見える | 見える | 見える |
| **ドラッグ中のパーツ**（置き場を出てから） | 見える | **描かない**（指・ポインタの位置にも何も出さない） | **描かない** |
| 置いたパーツ | 見える | 見えない | 見えない |
| マウスのカーソル（顔の上） | 通常 | 通常（手の位置は分かる＝紙の福笑いで手の感覚がある程度） | **隠す**（`cursor: none`） |
| キーボードの照準 | 十字＋選んだパーツの形 | **小さな十字だけ**（パーツの形・向きは出さない） | **出さない**（下の矢印キーの移動量だけで置く） |
| スクリーンリーダーへの読み上げ | パーツ名と「顔の右上」などの大まかな場所 | パーツ名と「置きました（6枚中3枚）」だけ。**座標・場所は読み上げない** | 同左 |
| 置いた数（6 枚中 ◯ 枚） | 見える | 見える | 見える |

- **向きは置き場の中で決める**（置き場の中ではパーツが見えるので回せる）。置き場を出たら向きは変えられない
- むずかしいのキーボード操作は、照準が見えないかわりに「照準を顔の中心に戻す」キー（`C`）を置く
- **記録（`records.ts`）は難易度ごとに分ける**（かんたんは置いたパーツが見えて満点を取りやすいため、同じ表に混ぜない）。**「今日のお題」は ふつう に固定**し、全員が同じ条件で比べられるようにする

### 家族モード（順番に遊ぶ）

- 2〜6 人の名前（または「1ばん」「2ばん」…）を入れて順番に遊ぶ。1人終わるごとに「次は ◯◯ さん。スマホを渡してね」の画面を挟む（**前の人の顔は伏せる**）
- 全員終わったら、**全員の顔を並べて**点数の順位と「いちばん笑えた顔」を選ぶボタン（選んだ顔に「大賞」の札。点数とは別の楽しみ）
- 名前は端末内だけ（`localStorage` にも残さない。リロードで消える）

### 点数の付け方（`games/lib/fukuwarai.ts`）

パーツごとに**位置のずれ**と**角度のずれ**から 0〜1 を出し、6 枚の重み付き平均を 100 点に直す。

- 位置のずれ `d` は、正しい中心とのユークリッド距離を**顔の幅 W で割った値**（画面サイズに依らない）
- 位置のスコア `p = max(0, 1 − d / 0.25)`（顔幅の 25% ずれたら 0）
- 角度のスコア `a = max(0, 1 − |θ| / 45°)`（`θ` は正しい向きとの差。−180〜180 に正規化）
- パーツのスコア `= 0.8 × p + 0.2 × a`
- 重み：目 2 枚・口 1 枚を各 1.2、まゆ 2 枚・鼻 1 枚を各 0.8（目と口のずれが顔の印象を一番変えるため）
- **左右の取り違え**（左目を右目の位置に置いた）は、左右対称のパーツ（目・まゆ）に限り**入れ替えて採点したほうの高い点**をとる（遊ぶ人が左右を区別できないため）。左右のパーツは鏡像の形なので、入れ替えて置くと**見た目は少し逆向き**になる（目じり・まゆ尻が内側を向く）。それも福笑いの面白さとして**減点しない**。結果の画面とよくある質問に「左右を逆に置いても点は下がりません（見た目はちょっと変になります）」と書いて伝える
- 点数は**整数に四捨五入**。顔の外（輪郭の外接矩形の外）に置いたパーツは 0 点

### パーツの回し方

- 置き場のパーツは最初からランダムに傾いている（±30°）。**回すかどうかは任意**
- PC：置き場の中で選んだパーツに、ホイールまたは `Q` / `E` で 15° ずつ（**回せるのは置き場の中だけ**。置き場を出たら向きは変えられない。上「難易度ごとの見え方」）
- スマホ：パーツ選択中に出る「↺」「↻」ボタン（44px 以上）。2本指の回転は実装しない（誤操作が増え、テストしにくい）
  - 置き場は顔の下にあり、ボタンは**置き場の上の1行（「6 枚中 ◯ 枚」の表示と同じ行の右端）**に置く。パーツの2段とは重ならない。320×568 でも、顔 → 「6 枚中 ◯ 枚 ／ ↺ ↻」の行（48px）→ パーツ2段の順で1画面に収める
- キーボードだけでも遊べる：`Tab` でパーツを選び、矢印キーで顔の上の照準を動かし（`Shift` で大きく）、`Enter` で置く

### 日替わり（任意・あれば）

- 「今日のお題」：日付から顔の種類とパーツの初期の向きを決める（`games/lib/daily.ts` の種を使う）。**難易度は ふつう に固定**。全員が同じ条件で点数を比べられる
- ベスト点を**顔の種類 × 難易度ごと**に `records.ts` で保存

## 確かめること（テスト）

`games/tests/fukuwarai.test.ts`：

1. 6 枚すべてを正しい中心・角度 0 で置くと **100 点**
2. 1 枚を顔幅の 25% 以上ずらすと、そのパーツは 0 点（他は満点）→ 全体は重みどおりの点
3. 角度 45° 以上のずれで角度のスコアが 0、180° と −180° が同じ扱い
4. 左目と右目を入れ替えて置いても点が下がらない（左右対称パーツの入れ替え採点）
5. 鼻・口は入れ替え採点の対象にならない
6. 顔の外に置いたパーツは 0 点
7. 点数は SVG 座標で計算され、表示サイズ（viewBox の倍率）を変えても同じ点になる
8. 日替わりの種が同じなら、顔の種類と初期の向きが同じ
9. `stage` と `robots`（既存の `stage.test.ts`）
10. 5 種の顔データが、6 枚のパーツと正しい位置・輪郭を持っている（データの欠けを落とす）
