|---|---|---|---|---|

- **主な根拠はエンゲージメント率 37%**（リバーシ 91%）。大富豪の `tool_use` の割合 33% は**「1 局始めた」の割合ではない**：
  `new-<強さ>` は強さ・ルールの変更か「もう一度あそぶ」のときだけ、`<結果>-<強さ>` は **5 回戦をすべて終えたときだけ**送っていて、
  開いた直後の配札・「スタート」・最初の「出す」・「第n回戦へ」では送らない（`games/app/daifugo/Game.tsx` の `start()` と L210）。
  **スタートを押して 3 回戦まで遊んで帰った人も 0 件**になる。リバーシは 1 局（数分）で勝敗を送るので、この割合は比べられない。
  「何人が始めずに帰ったか」は今のデータでは言えないので、下「計測」でイベントを足して測る
- フリーセルは Edge（パソコン）が 22／29 で、そのエンゲージメント率は 27%・平均 43 秒
- 参考までに、リバーシも下の実測ではパソコンで盤の下端が画面からはみ出す。それでも 90% 遊ばれているのは、
  **盤の上半分が見えた時点で 1 手目が打てる**から。大富豪は「スタート」→「自分の手札を選ぶ」→「出す」の
  3 段があり、そのうち後ろの 2 つが画面の外にある

## 提案する仕様

### 1. スタートを押したら、遊ぶ範囲を画面に入れる（全カードゲーム共通・小さく効く）

- スタート（新しい対戦・次の回戦）を押した直後、**手札と操作ボタンの下端が表示領域の外にあるときだけ**、
  CPU の席の上端が画面の上端から 8px の位置に来るようにスクロールする
  （`window.scrollTo({ top: rect.top + scrollY - 8 })`。**ヘッダーは固定されていない**ので、その高さを引く必要はない。実装時に実測で確かめる）
- **♦3 を自分が持っているとき（4 回に 1 回）**：幕（`StartGate`、`show={!begun && !roundOver}`）は手番に関係なく出るので
  「スタート」は押せるが、案内の文言が「札を選んで『出す』と始まります」で、画面外の手札へ誘っている。
  - 1536×730・1920×937 は 2. で手札が収まるので、この場合も問題ない
  - 1366×625 とスマホでは、**案内の文言を「スタートを押すと始まります（あなたが♦3を持っています）」に揃えて、スタートへ誘う**
    （押せばこのフックが効く）。スタートを押さずに手札までスクロールして「出す」人は、いまどおりそのまま始まる（受け入れる）
- `prefers-reduced-motion: reduce` のときは `behavior: 'auto'`（アニメーションしない）
- **すでに収まっているときは動かさない**（スマホで遊んでいる最中に毎回画面が跳ねるのを避ける）
- 共通の小さなフック（`StartGate` と同じ **`app/_cpu/useBringIntoView.ts`**。盤ゲームからも使える）にして、大富豪・七並べ・スピード・神経衰弱・花札・ダウトで使う
  （CSS は増やさない。ファイルを増やすのは TS のフック 1 本だけ）

### 2. 幅 900px 以上・横長の画面では、盤の上の 3 段を 1 段にまとめる（大富豪から）

`app/globals.css` に `@media (min-width: 900px) and (orientation: landscape)` を足す。置き場所は
**大富豪の `.df-*` の通常の規則（L4434〜）より後ろ**（前に置くと同じ詳細度の後勝ちで黙って負ける。games/CLAUDE.md の約束 3 と同じ理由）、
かつ末尾の `@media (max-width: 600px)` より前。

- 「強さ・速さの段」「第1回戦／通算」「記録の帯」を **1 行に横並び**（flex・折り返しあり）。約 130px → 約 50px
- **1 段目は「3 段を 1 行にまとめる」だけ。入れ物の幅（いまは約 728px）は変えない**（ほかのゲームとの見た目の統一を保ち、効果も測りやすくする）。
  幅を広げて CPU の席を左右に置く案は、計測の結果を見てから 2 段目以降で検討する
- **札の大きさ・押す先の 44px は変えない**（games/CLAUDE.md の約束 4）。設定も隠さない（約束 5）

目標（1536×730・1920×937 で、スタートを押した直後、スクロールなしで）：
**手札の全体と「出す」「パス」の下端が表示領域に収まる。** 1366×625 は 1. のスクロールで収まればよい。

### 3. 開始前の表示を局面で出し分ける（上の不具合 2 件）

大富豪に `phase` は無く、開始前は `begun`（と `roundOver`）で決まっている。
- **`begun` が false のあいだは、席の「考え中…」（L375。いまは `isTurn` だけを見ている）と手番の枠（`.df-seat.active`）を出さない**
- 場の文言：**`StartGate`（`app/_cpu/StartGate.tsx`）はほかのゲームと共通の重ねる幕なので手を入れない**。
  大富豪の `children` 側で、`!begun` のときは `.df-field-empty` の文言を空にする（**枠と高さは残す**。約束 1）

### 4. 2 段目：ほかのカードゲームへ広げる

1.〜3. を大富豪で出して、下の「計測」で効いたことを確かめてから、七並べ・スピード・神経衰弱・花札こいこい・ダウトに同じ形を当てる。
花札は設定が多いので、[mobile-one-screen.md](./mobile-one-screen.md) の 4 と同じく畳んだ設定を横に置く案を別途測る。

### フリーセルについて（この PR では直さない）

フリーセルは札が開いた直後から見えていて、大富豪と同じ原因ではない（1536×730 で最も深い列の下端が +120 はみ出す程度）。
Edge から「フリーセル」で来る人は Windows 付属のゲームを探している可能性があり、**原因は別に調べる**。
2. の横並びで記録の帯・手数の行が詰まれば少し上がるので、そのあとの数字を見てから決める。

## 計測（効いたかの判定）

- **1 段目にイベントを足す**：試合ごとに最初に `begun` が true になった瞬間（「スタート」・♦3 での最初の「出す」・「第n回戦へ」のうち最初の 1 回）に
  `trackToolUse('daifugo', 'begin-<強さ>')` を 1 回だけ送る（既存の `started` ref と同じ 1 回だけの扱い）
- **主指標**：「`begin-*` を送ったセッション ÷ ページのセッション」（いまの 33% は基準にならない）
- **出す順番**：①イベントだけを先に出し、**1〜2 週の基準値を取る** → ②1.〜3. のレイアウト変更を出す。
  同時に出すと、効果とイベントを足した分の見分けがつかない。目標は②から 28 日で基準値の **1.3 倍以上**
- 副指標：`/games/daifugo` 着地のエンゲージメント率（いま 37%）
- **GA4 の管理画面で `tool_use` の `action` パラメータをカスタムディメンション（イベント スコープ）に登録する**
  （コードの変更ではない。いまは Data API で `customEvent:action` が引けず、「始めた（`new-*`）」と
  「勝敗」を分けて数えられない。登録した日から先しか溜まらないので、**この提案の実装より先に**運営者が行う）

## 測り方

[mobile-one-screen.md](./mobile-one-screen.md) の「測り方」と同じく、`games/` で `npm run dev` して Playwright で測る。
表示領域を **1536×730・1920×937・1366×625・390×720** の 4 つにし、スタートを押した直後の
`.df-hand` と「出す」の `getBoundingClientRect().bottom` を表示領域の高さと比べる。
**Playwright の `click` は押す前に自動でスクロールする**ので、スタートを押すときは
`page.mouse.click(x, y)` か `element.dispatchEvent('click')` を使い、利用者と同じ「スクロールしていない」状態で測ること
（この起票の実測でも 1366×625 でこれに引っかかった）。

## 期待される効果

- 着地 1 位の大富豪で、エンゲージメント率 37% の「開いたが遊ばずに帰る」を減らす。主指標（`begin-*` の割合）が基準値の 1.3 倍なら、
  同じ流入で遊ぶ人が 1.3 倍
- 年末年始のトランプ系の検索の山（「大富豪 無料」「七並べ オンライン」）の前に、カードゲーム全体の入口を整える
- 開始前の「考え中…」と文字の重なりは、初見の印象（壊れて見える）を直す

## やらないこと

- 札を小さくして縦を詰める（44px の下限。スマホ版と同じ理由）
- 設定を畳んで 1 タップ奥にする（スタート・強さはすぐ押せる場所に置く。cpu-speed.md の導線）
- ページの説明文（リード文）を削る・下へ回す（検索から来た人が何のページかを読む場所。SEO の本文でもある）
- 開いた瞬間に自動でスクロールする（スタートを押す前は、説明を読む人の邪魔をしない）
