## 背景と根拠

### なぜ「なかま分け」か：日替わりのことばパズルで、いちばん伸びている型が当サイトに無い

- 「16語を4つずつ4グループに分ける」型は、英語圏で The New York Times の *Connections*（2023-06 公開）が Wordle に次ぐ日課になった型。
  日本語でも**四字熟語で同じ型にした個人制作の「ヨジワケ」が GIGAZINE に取り上げられ**（2026-01-30）、App Store にも「関連語分類パズル」のような同型のアプリがある。
  **日本語の一般語で、ブラウザで、登録なしの日替わり**は検索で見当たらなかった（2026-11-28）
- 遊びの仕組み（語を4つずつの組に分ける）は著作権で保護される表現ではない。保護されうるのは**名称・画面の見た目・問題そのもの**。だから名前は一般語にし、**問題は全部自前で書く**
- `docs/features/` と `games/` を「なかま」「グループ分け」「Connections」で検索して**提案・見送りの記録が無い**（2026-11-28）。
  ことばのゲームは「当てる」（ことば当て）・「埋める」（熟語パズル）・「探す」（ことば探し）・「つなぐ」（しりとり #564）があり、**「分ける」が空いている**
- 当サイトの日替わり（熟語パズル・15パズル・迷路の「今日の1面」）と同じ「毎日1問」の型で、**再訪の理由**になる

## 提案する仕様

### ルール

1. 4×4 に並んだ 16 個のことばから **4つ選んで「これで決定」**。4つが同じなかまなら、その行が色つきでまとまり、**なかまの名前**（例：「赤いもの」）が出る
2. ちがえば**まちがい1回**。4つのうち3つが同じなかまなら「**あと1つ！**」と出す
3. **まちがいは4回まで**。4回目で終わり、残りのなかまを答えとして開く
4. なかまには**易しい順の4色**（黄・緑・青・紫）を付ける。**色だけで区別しない**（色の帯に「★1〜★4」の印と、なかまの名前を必ず添える）
5. 同じ4つの組み合わせをもう一度出したら「さっきと同じ組み合わせです」と出し、**まちがいに数えない**

### 3段と、れんしゅう

| 段 | なかまの種類 | 例 |
|---|---|---|
| こども（小学生） | 目に見える分類だけ（くだもの・どうぶつ・のりもの・色・からだ） | りんご・みかん…／いぬ・ねこ… |
| ふつう | 分類＋**ひっかけ**（2つのなかまに入りそうな語を1つ混ぜる。ただし答えは1通り） | 「みかん色」の…／「ももたろう」の… |
| おとな | ことば遊び（「◯◯＋がみ（かみ）」になる・「さか◯◯」で別のことば・同じ漢字の読み違い・四字熟語の一部） | て・かた・ながれ・おり（「◯◯がみ」）… |

- **れんしゅう**：過去の日の問題を、段ごとに遊べる（**今日と未来の問題は出さない**）
- 今日の問題は**日本時間の 0 時**に替わる（端末のタイムゾーンに依存しない。[熟語パズル](./game-jukugo-anaume.md)と同じ）

### 問題の作り方（`games/lib/nakama-wake-puzzles.ts`）

- **案 A（推奨）：全部自前で書く。** 1問 = なかま4つ（名前・★・ことば4つ・ひらがなのよみ）。既存の作品・攻略サイト・クイズ本の問題を写さない
- 案 B（採らない）：分類つきの語彙から機械で組む。**1つの語が2つのなかまに当てはまる問題**（答えが2通りになる）を機械では十分に除けない。ひっかけは人が書く
- 入れないもの：固有名詞（人名・地名・商品名・作品名・キャラクター名・企業名）・時事（古びる）・差別語・性的な語。
  **禁止語の一覧は平文でリポジトリに並べない**（[ことば当て](./game-kotoba-ate.md)と同じ可逆の変換をかけたテストのフィクスチャで持つ）
- 問題の日付への割り当ては、**問題の配列の添字 = 公開開始日からの日数**。尽きたら先頭から回す（**回り始める 30 日前に**テストで落として書き足しを促す）

### テストで固定すること（`games/tests/nakama-wake.test.ts`）

1. 1問ごとに：なかまはちょうど4つ・各4語・**16語に重複なし**・★1〜★4 が1つずつ
2. **「別解が無い」**：各語に、その語が当てはまる可能性のあるなかまを `alsoFits`（任意）で書けるようにし、
   `alsoFits` を考えても**4つのなかまへの分け方が1通りしか無い**ことを全探索で確かめる（16語を4つずつに分ける組み合わせは 2,627,625 通り。なかまの候補で枝を刈れば一瞬）
3. 段ごとの語の長さ：こどもはひらがな表示で6文字以内（スマホの 4×4 に収まる）
4. 禁止語に当たらない・固有名詞の印（`proper: true`）が無い
5. 今日の問題の決め方：日本時間 2027-01-01 00:00 の直前・直後で添字が1つ進む（`Date` を固定してテスト）

### 画面

- 幅 390px で **4×4 のカード・まちがいの残り（●●●●）・「シャッフル」「選択を外す」「これで決定」**が1画面に収まる（[mobile-one-screen.md](./mobile-one-screen.md)）
- カードは 44px 以上・文字は折り返さず、長い語は縮める。こどもの段は**ふりがな**（漢字の語は上によみ）
- キーボード：矢印で移動・スペースで選ぶ・Enter で決定（パソコン 88% のため）
- スタート前に時間を測らない。**時間は記録しない**（考えるゲームで、急がせない）

### 結果・共有・記録

- 結果：何回まちがえたか・**解いた順**（★の易しい順に解けたか）
- 共有：**色の四角の並び（🟨🟩🟦🟪）と日付・段だけ**。ことばもなかまの名前も入れない（ネタバレしない）
- 記録は [game-records.md](./game-records.md) の仕組みで端末に：段ごとの連続日数・全問正解の数・まちがい0の数

### ページの構成

1. 見出し・リード（「16個のことばを、4つずつのなかまに分けよう。毎日1問」）
2. ゲーム（段の選択 → 今日の問題）
3. 遊び方（ルール・色と★・ひっかけの説明）
4. FAQ（5問：答えがあっているのに違うと言われた（別解はテストで除いている。ひっかけの説明）／今日の問題はいつ替わる？／過去の問題は遊べる？／学校・高齢者施設のレクで使える？（こどもの段・印刷は無し）／共有するとネタバレする？）
5. JSON-LD（`VideoGame`）と `metadata` の `robots: robotsFor('nakama-wake')`

### 送らない

- GA4 には `game_start`・`game_end` 相当（段・日替わり／れんしゅう・まちがいの数・クリアしたか）だけ。**選んだことば・問題の番号は送らない**

## 期待される効果

- **日課になるゲーム**が1本増える（毎日の再訪。ブロックパズル・ブロック崩し・大富豪の「少数が何度も来る」客と同じ層）
- 「なかま分け ゲーム」「ことば パズル 毎日」「脳トレ ことば 無料」「レク ことば遊び」の検索と、AI 回答の「ブラウザで遊べることばのパズル」に引かれる
- ことばのゲーム（ことば当て・熟語パズル・しりとり）と related でつなぎ、ジャンル「パズル・脳トレ」の厚みを足す

## やらないこと

- 利用者が問題を作って共有する機能（URL に問題を載せることになり、不適切な語の検査ができない）
- 時間制限・スコアのランキング（送信が要る）
- 「Connections」「ヨジワケ」を名前・見出し・説明文に使うこと（本文で型を説明するときも「16個のことばを4つのなかまに分けるパズル」と言い換える）
