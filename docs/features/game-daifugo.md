# 新ゲーム「大富豪」（CPU対戦・トランプ対戦系の1本目）

**状態**：実装済み（2026-08-14。本番反映はタグリリース待ち）
**対象**：`games/`（`hasokon.com/games/daifugo/`）
**起票**：2026-08-14

> 実装時に決めたこと（仕様書に書いていなかった点）：
> - **カード交換で渡す札は自動で選ぶ**。弱い側は最強の札を、強い側は最弱の札を出す。
>   強い側に選ばせる画面を1枚増やすほど勝敗に効かないため
> - **革命は「同じ数字4枚以上」だけ**。5枚以上の階段での革命（階段革命）は入れない
> - **ジョーカーは革命中でも最強のまま**。返せるのはスペ3返しONのときの ♠3 だけ
> - 同じ札の集合が2通りの役に読めるとき（`♠5 ♠6 ジョーカー` など）は
>   1通りに決め打つ。組に読めるなら組を優先し、階段はいちばん弱い札を起点にする
> - `home/404.html` と `home/sitemap-home.xml` は触っていない。404はゲーム一覧
>   （`/games/`）へのリンクだけを持ち、個別ゲームを列挙していないため

## 背景と根拠

### トランプ「対戦」系がカタログの空白になっている

現在のゲーム12本のうちトランプはソリティア系3本（クロンダイク・スパイダー・
フリーセル）だけで、**対戦型のトランプゲームが1本も無い**。
2026-08-14 に主要な無料ゲームポータル（トランプスタジアム・SDIN・プチゲーム・
FMVゲーム・Yahoo!かんたんゲーム・ドコモ ゲーム広場）のラインナップを調査したところ、
どこにも必ず置かれているのに hasokon に無いのが
**大富豪・七並べ・神経衰弱などのトランプ対戦系**だった。

その筆頭が大富豪で、「大富豪 無料」「大富豪 ブラウザ」は日本のトランプゲームで
最大級の定番キーワード。2026年もアプリ紹介記事が更新され続けており、
需要が季節に左右されない定番資産になる。

### 検索データもトランプ系の入口を裏付けている

Search Console（2026-08-14 取得・直近28日）で、games への表示クエリは
「ソリティア クロンダイク」「スパイダーソリティアの遊び方」「ソリティア オンライン」
などトランプ系が最多。**いま来ている数少ない検索者がトランプ好き**であり、
大富豪はこの層への回遊先としてそのまま機能する
（トップの「他のゲーム」導線と関連ゲーム欄で内部リンクする）。

### 権利面が完全にクリーン

大富豪（大貧民）は日本の伝統的なトランプ遊びで、ルールはパブリックドメイン。
名称も一般名称であり、「テトリス」「オセロ」「数独」のような商標問題が無い
（games/CLAUDE.md の商標確認の約束に沿って 2026-08-14 に確認）。
カード絵柄は既存の `_cards` 共通モジュールをそのまま流用できる。

### CPU対戦の実績を積んだ直後で、実装の下地がある

五目並べ（2026-08-13）・リバーシでCPU対戦の設計パターン
（純関数ロジック＋難易度段階＋`lib/{slug}.ts` でのAI）が確立している。
大富豪のCPUは「出せる役の列挙 → 評価して1手選ぶ」の構造で、
探索が要らないぶん五目並べより単純に済む。

## 提案する仕様

### ルール（初期実装）

- プレイヤー1人 ＋ CPU 3人の4人戦。5回戦の通算で階級（大富豪〜大貧民）を決める
- 標準ルール：8切り・革命・縛り・ジョーカー2枚・階級による カード交換
- ローカルルールのON/OFF（都落ち・11バック・スペ3返し）は設定パネルで切り替え。
  初期値は「8切り・革命・縛りON、その他OFF」（もっとも一般的な構成）
- 記録は共通モジュール（`lib/records.ts` / `useRecords`）で勝敗と最高階級を保存。
  ゲームごとの個別 localStorage キーは作らない（game-records.md の約束）

### 実装の構成（games/CLAUDE.md の手順どおり）

1. `lib/daifugo.ts` — 役の判定（単騎・ペア・階段・革命）・合法手の列挙・
   CPUの手選択（弱/普通/強の3段階）を純関数で。乱数は注入可能にする
2. `tests/daifugo.test.ts` — 役判定の境界値（ジョーカー混在の階段・縛り成立・
   8切りの流れ）・ゲーム進行・階級決定を必ず入れる
3. `app/daifugo/Game.tsx` / `app/daifugo/page.tsx` — JSON-LD（VideoGame +
   FAQPage + BreadcrumbList）・遊び方・FAQ・AdUnit×2・パンくず
4. `lib/registry.ts` に追加 → トップ一覧・sitemap に自動反映
5. `home/index.html` / `home/llms.txt` にカード・1行を追加
   （`scripts/test/home-nav.test.mjs` / `llms-txt.test.mjs` が漏れを検知）

### やらないこと（今回の見送り理由も含む）

- **オンライン対人戦**：サーバーレスの静的サイト方針と矛盾するため恒久的にやらない
- **ピラミッドソリティア**：次点候補。カードエンジン流用で工数最小だが、
  「ソリティア4本目」より対戦系の空白を埋めるほうがカタログの幅が出るため後回し
  （需要はあるので次々回以降の候補として残す）
- **花札こいこい**：札48枚のSVG自作が必要で工数が大きい。任天堂等の
  既存札デザインの複製は不可（伝統図案そのものは自由）。将来候補として保留
- **スイカゲーム系マージパズル**：「スイカゲーム」は Aladdin X の商標で名称使用不可。
  物理エンジン導入も必要で、既存カタログと技術的に遠い。見送り

## 期待される効果

- 「大富豪 無料」「大富豪 ブラウザ 無料」系の定番クエリへの新規参入。
  ドメインが若いため上位進出には時間がかかるが、季節性が無いぶん
  一度インデックスされれば長期の入口になる
- 既存のソリティア系流入（現状 games の表示クエリの大半）の回遊先が増え、
  セッション時間・ページ/セッションの改善が見込める
- 「CPU対戦シリーズ」（リバーシ・五目並べ・大富豪）としてカタログの柱が立つ
