### 数え方（書くこと・書かないこと）

- **数え年**：生まれた年を 1 歳とし、1 月 1 日ごとに 1 歳ずつ加える。**数え年 ＝ 対象の年 − 生まれ年 ＋ 1**（誕生日に依らない）
- **七五三**：11 月 15 日ごろに、男の子は 3 歳・5 歳、女の子は 3 歳・7 歳で祝うのが一般的。数え年で祝う慣習と満年齢で祝う家庭の両方がある。
  男の子の 3 歳を祝うかは地域で違う。**本ツールは「数え年なら◯年、満年齢なら◯年」を並べて出し、どちらが正しいとは書かない**
- **厄年**：一般に男性は数え 25・42・61 歳、女性は数え 19・33・37 歳（61 歳を含める寺社もある）を本厄とし、前後 1 年を前厄・後厄とする。
  男性 42・女性 33 を大厄と呼ぶ。**寺社や地域で年齢・区切り（1 月 1 日か立春か）が違う**ので、画面に固定の注記を出す
- **長寿祝い**：還暦（数え 61・満 60）・緑寿（66）・古希（70）・喜寿（77）・傘寿（80）・米寿（88）・卒寿（90）・白寿（99）・百寿（100）。
  還暦以外は**数え年で祝うのが伝統、満年齢で祝うことも多い**ので、両方を出す
- **書かないこと**：厄年の「効果」「避けるべきこと」・特定の寺社の名前や祈祷料・お守りなどの商品。
  宗教的な主張はせず、**年齢と年の対応（暦の計算）だけ**を出す。「お参りの時期は寺社に確認してください」で止める
- **出典**：実装時に一次情報を取り直して `SOURCES` に書く。候補は神社本庁（人生儀礼の案内）・各都道府県神社庁の人生儀礼のページ・
  国立国会図書館レファレンス協同データベース（数え年・年祝いの定義）。**寺社 1 か所の表だけを出典にしない**（地域差があるため 2 か所以上で突き合わせる）

## 提案する仕様

### ページは 2 枚、ロジックは 1 本

検索の意図が「七五三」と「厄年」で分かれ、山の時期も違う（10〜11 月／12〜2 月）。**1 ページ 1 機能**の方針どおり 2 枚に分け、
`tools/lib/toshi-iwai.ts` を共有する。長寿祝いは「年齢の節目」として厄年のページに同居させる（還暦は男性の本厄 61 と同じ年になるため、並べたほうが分かりやすい）。

### 画面 1：七五三（`/tools/shichigosan/`。スマホ 390×844 で入力と結果の 1 件目が収まること）

- 入力：**子の生年月日**（年だけでも可）・**性別**（男の子／女の子／両方表示。既定 両方表示）・**基準の年**（今年・来年。既定 今年、11-16 以降は来年）
- 結果：「**数え年なら 2026 年（3 歳）・満年齢なら 2027 年（3 歳）**」のように、3 歳・5 歳・7 歳のそれぞれを年と、
  その年の 11 月 15 日の曜日つきで並べる。早生まれ（1/1〜4/1）なら「同じ学年のお友だちと揃えるなら」の 1 行を足す（学年は `gradeTurningAge()`）
- 下に「2026 年の七五三 早見表」（上の表。基準の年に追従。**表は計算から生成し手書きしない**）
- 兄弟姉妹：生年月日を 3 人まで足して「同じ年にまとめて祝える年」を出す（数え・満の組み合わせで最初に重なる年）

### 画面 2：厄年・長寿祝い（`/tools/yakudoshi/`）

- 入力：**生年月日**（年だけでも可）・**性別**（男性／女性。女性 61 を含めるかのチェック、既定 含めない）
- 結果：
  1. 「**あなたは 2027 年が本厄（数え 42・大厄）**」または「次の厄年は 2031 年（前厄）」を太字 1 行
  2. 前厄・本厄・後厄の年を一生分（数え 100 まで）の表で。今年の行を強調
  3. 長寿祝いの年を数え・満の 2 列で。「還暦は 2027 年（数え 61／満 60 は同じ年）」
- 下に「2027 年の厄年 早見表」「2027 年の長寿祝い 早見表」（基準の年は今年・来年を選べる。**12 月は既定を来年に**：厄除けの検索は翌年の表を探している）
- 固定の注記：「厄年の年齢や数え方（1 月 1 日で区切るか立春で区切るか）は寺社・地域によって異なります。お参りの時期や作法は、お参りする寺社に確認してください。」

### 計算ロジック（`tools/lib/toshi-iwai.ts`。純関数のみ）

```ts
/** 数え年。対象の年 − 生まれ年 + 1（誕生日に依らない） */
export function kazoeAge(birthYear: number, year: number): number;

/** 数え年 n になる年 / その年中に満年齢 n になる年 */
export function yearOfKazoe(birthYear: number, n: number): number;   // birthYear + n - 1
export function yearOfMan(birthYear: number, n: number): number;     // birthYear + n

type Sex = 'male' | 'female';
type YakuKind = 'mae' | 'hon' | 'ato';
export const HON_YAKU: Record<Sex, readonly number[]>;   // male [25, 42, 61] / female [19, 33, 37]（61 は option）
export const TAIYAKU: Record<Sex, number>;               // male 42 / female 33

/** その年の厄（無ければ null） */
export function yakuOf(birthYear: number, year: number, sex: Sex, opts?: { female61?: boolean }): { kind: YakuKind; age: number; taiyaku: boolean } | null;

/** その年に厄年に当たる生まれ年の表（早見表用） */
export function yakudoshiTable(year: number, sex: Sex, opts?): { age: number; kind: YakuKind; birthYear: number }[];

export const CHOJU: readonly { name: string; reading: string; age: number }[];   // 還暦 61 … 百寿 100（還暦の満は 60）

/** 七五三：子の生まれ年から、数え・満それぞれで 3/5/7 歳になる年 */
export function shichigosanYears(birthYear: number): { age: 3 | 5 | 7; kazoe: number; man: number }[];
```

- 生年月日を入れた場合も**数え年の計算には生まれ年しか使わない**。月日は満年齢の表示・早生まれの判定・和暦（平成 31 年／令和元年の境）にだけ使う
- 年の範囲は 1900〜`TABLE_END_YEAR`（2040）。和暦表示は `warekiYearLabels()`
