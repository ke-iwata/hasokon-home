## 背景と根拠

### 2027 年の前半に、宿泊税の大きな改正が 2 つ続く

| 自治体 | いつから | 何が変わるか | 一次情報 |
|---|---|---|---|
| **東京都** | **2027-04-01 の宿泊分から** | 1 人 1 泊 10,000〜15,000 円未満 100 円・15,000 円以上 200 円の**定額**を、**宿泊料金の 3%** に。非課税の線を **10,000 円未満 → 13,000 円未満**に上げる。対象に**簡易宿所・民泊（新法民泊・特区民泊）**が加わる | [東京都 報道発表 2026-06-30](https://www.metro.tokyo.lg.jp/information/press/2026/06/2026063004)・[主税局 宿泊税](https://www.tax.metro.tokyo.lg.jp/kazei/leisure/shuk/2) |
| **沖縄県** | **2027-02-01 の宿泊分から**（1/31〜2/1 の連泊の 1/31 泊は対象外） | 新設。**素泊まり料金を 1,000 円未満切り捨て → 2%、上限 2,000 円**。修学旅行・部活動の大会参加は課税免除（証明書が要る） | [沖縄県 宿泊税](https://www.pref.okinawa.jp/kurashikankyo/zeikin/1003660/1036559/1041134.html) |

東京の改正は総務大臣の同意が 2026-06-30、条例の公布が 2026-07-01。特別徴収義務者（宿）の事前登録も 2026-07-01 から始まっている。

### 「いくらになるか」は料金を入れないと分からない

定額から定率に変わるので、**同じホテルでも部屋の値段で税額が変わる**。代表的な値で並べるとこうなる（東京・1 人 1 泊。改正後の端数処理は確認前の仮置き）。

| 1 人 1 泊の料金 | いま（〜2027-03-31） | 2027-04-01 から | 差 |
|---|---|---|---|
| 9,000 円 | 0 円 | 0 円 | — |
| 12,000 円 | 100 円 | **0 円**（13,000 円未満は非課税） | **−100 円** |
| 13,000 円 | 100 円 | 390 円 | +290 円 |
| 20,000 円 | 200 円 | 600 円 | +400 円 |
| 50,000 円 | 200 円 | 1,500 円 | +1,300 円 |

**10,000〜12,999 円の宿泊は改正で安くなる**（100 円 → 0 円）。「宿泊税 3%」の報道は値上げの話しかしないので、ここが答えとして価値になる。
あわせて、**12,999 円と 13,000 円で 390 円の差**が出る崖があり、宿の料金設定・利用者の部屋選びの両方で検索される。

### 宿泊税は自治体ごとに形がばらばら

主要どころだけでも 3 通りある（2026-10-13 時点。下の表は実装時に条例で再確認する）。

| 型 | 例 |
|---|---|
| 定率（上限つき） | 沖縄県 2%（上限 2,000 円）、東京都 3%（2027-04〜） |
| 料金の区分ごとの定額 | 京都市（2026-03-01〜）：6,000 円未満 200 円／2 万円未満 400 円／5 万円未満 1,000 円／10 万円未満 4,000 円／10 万円以上 10,000 円。大阪府（2025-09-01〜）：5,000 円未満 0 円／15,000 円未満 200 円／2 万円未満 400 円／2 万円以上 500 円 |
| 県と市町村の二重 | 福岡県・福岡市、北海道・札幌市ほか（県の分＋市町村の分） |

出典：[京都市 報道発表（総務大臣同意）](https://www.city.kyoto.lg.jp/gyozai/cmsfiles/contents/0000345/345893/daijindoui_houdouhappyou.pdf)・
[京都市 多言語チラシ](https://www.city.kyoto.lg.jp/gyozai/cmsfiles/contents/0000236/236952/A4822.pdf)・
[大阪府 宿泊税の改正](https://www.pref.osaka.lg.jp/o050040/zei/alacarte/shukuhakuzei-kaisei.html)

旅行者は「自分の泊まる宿でいくら」を、出張の多い会社員・経理は「精算でいくら上乗せされるか」を、民泊・簡易宿所の運営者は「2027-04 から自分も徴収する側になるか・いくら預かるか」を探す。
**同じ計算を自治体ごとに別のページで探させている**のがいまの検索結果。

### 競合

- 一般向けに**自治体を選んで料金を入れると税額が出る計算機は見当たらない**（2026-10-13、Web 検索で「宿泊税 計算」「宿泊税 東京 3% いくら」を確認。見つかったのは宿向けの業務システムと自作の表計算の紹介だけ）。
  出てくるのは自治体の案内ページ・旅行メディアの記事・宿向けの業務システムの紹介
- 自治体のページは自分の税率しか書かない。記事は「主な自治体の一覧表」までで、**改正の前後を料金ごとに並べるものは無い**

### 当サイトの型との相性

- 「改正の前後を並べる計算機」は**たばこ税（直近 28 日で 312 セッション、当サイトの 1 位）と同じ型**。施行日の前後に検索が立ち、施行後も「いくらか」で残る
- 当サイトの流入は **Bing 59%・AI アシスタント経由（openai・chatgpt.com）33%**（GA4、2026-09-15〜10-12）。
  税率表と根拠をページに持つ計算機は AI アシスタントに引用されやすい（たばこ税・酒税改正のページと同じ）
- 税率は**条例が変わるまで動かない**。表をデータで持てば、改正のたびに 1 行足すだけで済む（CONCEPT.md の「一度作れば放置できる型」）

### 法的根拠

- 宿泊税は地方税法 731 条以下の**法定外目的税**。税率・免税点・課税免除は各自治体の条例で決まり、新設・変更には総務大臣の同意が要る（地方税法 731 条 2 項）
- 「宿泊料金」は素泊まりの料金（食事代・消費税等を含めない）とする自治体が多い（大阪府・京都市・沖縄県の案内）。
  **東京の改正後の「宿泊料金」の定義（消費税を含むか、サービス料を含むか）は実装時に条例で確認する**

## 提案する仕様

### 画面（1 画面 2 段。スマホ 390×844 で上段が収まること）

**上段（入力 4 つ）**

1. **泊まる場所**：東京都（既定）／沖縄県／京都市／大阪府（v1 の 4 つ。下「データ」で増やす）
2. **1 人 1 泊の料金**（素泊まり。円）。補足 1 行「食事代・消費税等は含めない（自治体の定義に従う）」
3. **人数**（既定 1）と**泊数**（既定 1）
4. **泊まる日**（チェックイン日。既定は今日）。連泊は 1 泊ごとにその日の税率を当てる（東京の 2027-03-31〜04-01 の 2 泊は「定額 1 泊＋定率 1 泊」）

**下段（結果）**

- 1 行目を太字で「**宿泊税は 1 人 1 泊 390 円、合計 780 円**（2 人 × 1 泊）」
- 2 行目に**改正の前後**：「2027-03-31 までの宿泊なら 100 円（改正で +290 円）」。改正の予定が無い自治体は出さない
- **境目の 1 行**：「13,000 円未満なら非課税です（あと 1 円安ければ 0 円）」「上限 2,000 円に達しています」など、入力の近くに崖や上限があるときだけ
- **料金ごとの早見表**（折りたたみ）：その自治体の区分・境目の料金と税額を、改正の前後 2 列で
- 課税免除の注記（自治体ごと 1 行。沖縄「修学旅行・部活動の大会参加は免除（証明書が必要）」、大阪「修学旅行生等は免除」）

### データ（`tools/lib/shukuhakuzei.ts`。税率表は自治体ごとのデータ）

```ts
type Rule =
  | { kind: 'flat-tiers'; exemptBelow: number; tiers: { from: number; tax: number }[] }   // 区分ごとの定額（京都・大阪・東京の現行）
  | { kind: 'rate'; exemptBelow: number; rate: number; floorUnit: number; taxFloorUnit: number; cap: number | null }; // 定率（沖縄・東京の改正後）

interface Period { from: string /* 'YYYY-MM-DD' 宿泊日 */; to: string | null; rule: Rule; source: string /* 一次情報 URL */ }
interface Area { id: string; name: string; periods: Period[]; exemptions: string[]; parts?: { name: string; periods: Period[] }[] /* 県＋市の二重課税 */ }

export function taxPerNight(area: Area, price: number, stayDate: string): { tax: number; period: Period; note: Note | null };
export function totalTax(area: Area, price: number, people: number, checkIn: string, nights: number): Breakdown;
```

- 沖縄：`floor(price / 1000) * 1000 * 0.02`、上限 2,000 円（2027-02-01 以降の宿泊日だけ。それより前は 0 円で「2027-02-01 から課税」）
- 東京（改正後）：`price < 13000 ? 0 : 3%`。**`floorUnit`・`taxFloorUnit`・`cap` は条例で確認してから値を入れる**（確認できるまでテストを `todo` で置く）
- 二重課税（県＋市）は `parts` で持ち、結果に「県の分 ◯円・市の分 ◯円」と内訳を出す。**v1 では入れない**（福岡・北海道は v2。下「やらないこと」）
- **最終確認日**をデータに持ち、ページに「税率は 2027-01-◯◯ 時点」と出す。`tools/tests/` で確認日が 180 日より古ければ落とす（データの腐りを CI で止める）

## やらないこと

- **全国すべての自治体を網羅すること**：v1 は東京・沖縄・京都・大阪の 4 つ。県＋市の二重課税（福岡・北海道ほか）は `parts` の型だけ用意し、v2 で 1 自治体ずつ足す（1 自治体 10k 前後）
- **経費・確定申告の扱い**：出張の宿泊税を経費にできるか・消費税の扱いは書かない（税理士の領域。誤ると害が大きい）
- **宿向けの申告書・帳簿**：特別徴収義務者の申告様式は自治体ごとに違う。計算は同じ式で使えるが、申告の案内はしない
- **入湯税・宮島訪問税など別の税**：同じ「旅行の税」でも別の法律・別の課税対象。混ぜると誤案内になる
- **為替・外国語版**：訪日客向けの英語ページは需要があるが、サイト全体が日本語のみの方針。別提案にする
