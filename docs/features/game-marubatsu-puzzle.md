## 背景と根拠

  4位 ブロックブラスト、7位 漢字分解パズル。Google Play 日本・無料ゲーム（Similarweb 09-16）：
  **10位 NYT Games（Wordle・Crossword）**、18位 Meowdoku、30位 Color Logic
- LinkedIn の日替わりパズル群では、**Queens（星置き）に次いで遊ばれているのが Tango**
  （○と×を並べる 6×6 のバイナリーパズル）。攻略サイトが毎日答えを載せるほどの定着
  （pinpointdaily.org ほか）。**同ルールの古典が「バイナリーパズル（Binairo / Takuzu）」で、
  2009年から新聞のパズル欄にある**。ルール自体に権利は無い
- 当サイトの Bing 流入が付いている論理パズル：ナンプレ（直近14日 PV 39・平均滞在 58分）、

  高さ規則・タップ操作）で出せる

### ルール（一般に流通している形。出典：puzzle-binairo.com・LinkedIn Tango のヘルプ）

1. 各マスに ○ か × を置く（偶数辺の正方形。6×6・8×8・10×10）
2. **各行・各列で ○ と × の数が同じ**
3. **同じ記号を縦横に 3 つ以上並べない**
4. （古典の追加則）同じ並びの行・列を作らない
5. （Tango 型の追加則）マスとマスの間に **＝**（同じ記号）・**×**（違う記号）の印がある場合はそれに従う

当サイトは **2・3・5 を採用し、4 は採らない**（4 は解く手がかりとして弱く、初心者が気づけない。
Tango も 4 を持たない）。印（5）は 8×8 以上の「むずかしい」で使う。

## 提案する仕様

### 盤面と操作

- サイズ：**6×6（かんたん）・8×8（ふつう）・10×10（むずかしい・印つき）**。既定は 6×6
- タップで **空 → ○ → × → 空** を巡回。長押し（PC は右クリック）で逆順。
  ドラッグで同じ記号を連続配置（ノノグラムと同じ）
- **違反の即時表示**：3 連続・数の超過・印の不一致を、該当する行・列・マスを赤で示す。
  ペナルティは無し（トレンド作の「間違えても減らない」に合わせる）
- **ヒント**：「次に確定できるマス」を 1 つ光らせ、**理由を 1 行で出す**
  （例：「この行は ○ があと 1 つ。ここに置くと 3 連続になるので ×」）。Meowdoku がいちばん褒められている点
- 元に戻す／やり直す／盤面リセット。タイマー表示（消せる）

### 生成器（`games/lib/marubatsu/`）

1. バックトラックで制約を満たす完成盤を作る
2. マスをランダムに空けていき、**一意解ソルバ**（伝播：3 連続禁止・数の上限・印 ＋ 詰まったら二分探索）が
   一意でなくなる直前で止める
3. 難易度は「解くのに二分探索が要るか」と空きマス数で分ける。**むずかしいは伝播だけで解けない盤**
4. **一意解であることをテストで保証**（生成 200 盤×3 サイズ、CI で 10 秒以内。ヨットの
   #160 の教訓で、テスト時間の上限を先に決める）
5. 日替わり 1 問：日付をシードにした決定的生成（`seedrandom` 相当の小さな PRNG を `lib/` に置く）。
   **#232 が先に入っていればその仕組みを使い、無ければここで作って #232 が使う**

### 共有・記録

- クリア時に「○×パズル 6×6 2:31 🟢🟢🔵…」のような**ネタバレにならない結果テキスト**をコピー
  （Wordle 型。X・LINE の intent リンク）。**サイトで初の共有ボタン**になるので、
  `game-records.md` に「共有文の形式」を 1 節足す（別 PR）
- 連続日数（ストリーク）は localStorage。記録モジュールに `streak` を足す

## やらないこと

- **漢字分解パズル**（App Store 7 位）：機構は自由だが、**良い問題を人手で選ぶコストが本体**
  （漢字の部品分解データ CHISE/KanjiVG から自動生成すると、正解が文字として不自然なものが混ざる）。
  データ整備に 100k 超が要り、ゲームというより出題集の編集になる。次回以降の候補
- **ひらがなの単語当て（Wordle 型）**：単語リストの編集と濁点・小書きの扱いが設計の本体で、
  既存の「ことのはたんご」が定着している。日替わり＋共有の型は本提案で先に作る
- **矢印ぬきパズル・砂ブロック**：どちらも流行中だが、前者は 3D 表現、後者は砂シミュレーションが
  スマホで重い。当サイトは desktop 86% だが、ゲームだけは mobile が多いので見送る
- **同じ並びの行・列を禁じる古典則（4）**：上記のとおり
- **対人・対 CPU**：一人で解くパズルなので無し
