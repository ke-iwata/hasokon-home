# 新ゲーム「色水ソート」（Water Sort型・リラックス系パズルの1本目）

**状態**：提案（2026-08-19 起票。実装するかは運営者の判断待ち）
**対象**：`games/`（`hasokon.com/games/color-sort/` を想定）
**起票**：2026-08-19

---

## 背景と根拠

### 2021年から続く巨大ジャンルなのに、サイトに「リラックス系」枠がない

- 色水を試験管の間で注ぎ替えて色ごとに揃える「ウォーターソート／カラーソート」型は、
  2021年ごろからスマホのパズル無料ランキングの常連で、**2026年8月現在も
  国内ランキング紹介記事（マイベスト等）に複数のソート系が載り続けている**
  定着ジャンル。ブラウザ移植も Poki・Yahoo!ゲーム系・国内ミニゲームサイトに
  多数あり、**「暇つぶし パズル」需要の定番枠**になっている
- いまの games 21本は「考える」（ソリティア群・ナンプレ・ノノグラム）か
  「操作する」（ブロック崩し・スネーク）に寄っていて、
  **頭を使わず手を動かして整う「リラックス系」が1本もない**。
  ジャンルの空白を1本で埋められる
- GA4（2026-08-19 取得・直近14日）でも `block-puzzle` 平均725秒・`2048` 370秒と
  「単純操作の繰り返し」型の滞在が長く、このサイトの強い型と合う

### 権利関係は無害（ただし名称は実装時に商標確認）

- **メカニクス（同色を上に注ぐ・4杯で満杯・全部揃えたらクリア）は
  特定社の権利物ではなく**、同型アプリ・ブラウザ版が多数共存している
  ジェネリックなルール。ルール自体は著作権で保護されない
  （ブロックパズル・2048 と同じ整理）
- 特定アプリ（Water Sort Puzzle 等）の**名称・画面デザイン・配色・
  効果音をなぞらない**。試験管の描画・色は当サイトのトーンで独自に作る
- 呼び名は一般記述の「色水ソート」を第一候補にする。
  **実装時に J-PlatPat で「カラーソート」「ウォーターソート」等の
  商標登録を確認**し、登録があれば一般記述的な別名（「色水の並べ替えパズル」等）
  に切り替える（スネーク・ナンプレで踏んだ手順と同じ）

## 提案する仕様

1. **ルール（ジャンル標準）**
   - 試験管に4段まで色水が入る。**いちばん上の色と同じ色の上（または空の試験管）
     にだけ注げる**。連続する同色はまとめて移動
   - すべての試験管が「空」か「同色4段」になればクリア
   - 手詰まり防止に「もどす」（直近30手）と「最初から」を置く
2. **難易度と出題**
   - 3段階（色数と試験管の本数で調整。例：5色+2空 / 8色+2空 / 12色+2空）
   - 盤面は**解ける状態から逆操作で生成**（クリア状態から乱数で注ぎ戻す）。
     乱数は注入できる形にしてテスト可能にする（games の作法どおり）
   - クリアするごとに次の盤面を自動生成（デイリー固定問題はやらない）
3. **操作**：タップ2回（注ぎ元 → 注ぎ先）だけ。選択中の試験管は持ち上げ表示。
   もう一度タップで選択解除。ドラッグ不要（スマホ最優先）
4. **成績**：`_records` でクリア回数・最少手数・連続クリアを難易度別に保存
5. **画面**：`games/CLAUDE.md` の「1画面に収める」約束に従う。
   試験管はSVGで描き、色は色覚多様性に配慮して**色+模様（縞・点）の併用**を
   オプションで用意する（リラックス系は高齢層・女性層が多く、配慮が効く）
6. **ページ構成**：既存ゲームページと同じ
   （metadata / JSON-LD(VideoGame+FAQPage+BreadcrumbList) / パンくず / 遊び方 /
   コツ / FAQ / AdUnit×2 / 他のゲーム一覧）。registry へは `stage: 'preview'` で追加
   （`games/CLAUDE.md` の追加手順どおり、公開が決まるまで `'preview'`）
7. **テスト**：注げる条件・まとめて移動・クリア判定・逆操作生成の可解性を
   純関数（`games/lib/color-sort.ts`）の単体テストで固定

## やらないこと

- **レベル番号つきのステージ制**（何百面ものレベルデータの維持は無理。
  自動生成＋難易度3段階で足りる）
- **広告視聴で試験管追加などの救済**（広告と遊びを絡めない。もどすで足りる）
- **特定アプリの見た目の再現**（トレードドレス回避。当サイトのトーンで独自に描く）

## 期待される効果

- 「色水 パズル」「水 入れ替え パズル」「カラーソート 無料」等の
  恒常クエリの受け皿と、リラックス系という新ジャンルによる滞在・再訪の積み増し
- ソリティア群（考える）・アーケード（操作する）に次ぐ第3の柱として
  ゲーム一覧の幅が広がる
- 効果は GA4 の `games/color-sort/` セッション時間・再訪、GSC の表示で計測
