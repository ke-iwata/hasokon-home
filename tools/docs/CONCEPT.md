# プロジェクトのコンセプトと方針

このドキュメントは、**なぜこのサイトを作っているのか / どういう判断でこの形になったのか**を残すものです。
実装の進め方は [CLAUDE.md](../CLAUDE.md)、デプロイ手順は [DEPLOY.md](../DEPLOY.md) を参照してください。

---

## 1. ゴール

検索結果の上位を取れるサイトを作り、広告で収益を得る。

明確な制約が2つあります。

- **記事を書き続けられない** — 運営者はコンテンツ制作が得意ではなく、継続的な発信を前提にしたモデルは破綻する
- **エンジニアである** — コードを書くのは苦ではない（バックエンドエンジニア）

この2つから、**「コンテンツ=コード」で一度作れば放置できる型**を選びました。

## 2. なぜ「ツール型サイト」なのか

ブログ型は「更新し続けないと死ぬ」ため最初に除外しました。
代わりに、`○○ 計算` `○○ 変換` のような**明確な意図を持つ検索クエリ**に対して、
使えるWebツールを1ページ1つ置いていく形にしています。

この型の利点:

| 観点 | ツール型 | ブログ型 |
|---|---|---|
| 制作物 | コード（得意） | 文章（不得意） |
| 鮮度劣化 | しにくい（計算式は古びない） | しやすい |
| 継続更新 | ほぼ不要 | 必須 |
| 順位の安定性 | 高い（実用性で評価される） | 競合の更新で流動 |

## 3. キーワード調査で分かったこと（2026年7月時点）

### 却下した候補

汎用の定番ツール（睡眠計算・アスペクト比・ローマ字変換・割り勘・cron生成など）は
**すでに個人ツールサイトが乱立していて、後発で定番キーワードを取るのは困難**でした。
AIでツールを量産できるようになったこの1〜2年で埋まった領域です。

### 見つけた空白

**「新制度 × 計算ツール」**。新しい制度・法改正が始まった直後は、

- 検索需要が爆発している
- なのに上位は**銀行・社労士・メディアの解説記事ばかりで、計算ツールが存在しない**

という状態になります。ここに計算機を置けば、記事より先に答えを出せるので勝てます。

第1弾に選んだ **子ども・子育て支援金（通称「独身税」）** がまさにこれで、
2026年4月に全給与所得者から徴収が始まったのに、当時ツールは1件しかありませんでした。

### この型は繰り返せる

税制改正・社会保険改正は毎年あります。改正が出るたびに計算機を1本追加する、
という**プレイブックとして運用**できます。増える作業は執筆ではなく開発なので、制約1に反しません。

## 4. サイト構成の方針

- **1ページ = 1ツール**。トップ（`/`）は全ツールへの入り口となる一覧
- 各ツールページは「ツール本体 → 解説 → FAQ」の順。**ツールを最上部に置く**（答えを最短で出す）
- ツールだけのペラページにしない。解説とFAQを添えるのは、
  1. AdSense審査に通すため
  2. 検索意図の周辺クエリ（「〜とは」「いつから」）も拾うため
- **入力データは一切サーバーに送らない**（全てブラウザ内で完結）。これはプライバシー上の売りでもあり、
  静的サイトで完結させられる理由でもある

## 5. 収益化の方針

- **Google AdSense** を主軸。お金系はクリック単価が比較的高い
- 広告枠は「計算結果の下」「解説の下」に配置済み（`className="adslot"` のプレースホルダ）
- **計算機より上には広告を置かない** — UX悪化 → 直帰率上昇 → 順位下落という典型的な失敗を避けるため
- 申請は公開の2〜4週間後（インデックスされ、検索流入が出てから）
- 現実的な期待値: 月1万PVで月2,000〜5,000円程度。4月（徴収月）やニュース時にスパイクする

## 6. 現在のツール一覧と位置づけ

| ツール | 位置づけ |
|---|---|
| 子ども・子育て支援金 計算機 | **本命**。新制度型の第1弾 |
| 年収の壁 計算機 | 準本命。2025〜26年の改正で数値が動いており、古い情報のページが多い |
| 傷病手当金 計算機 | competitorは多いが、お金系の厚みとして |
| 睡眠サイクル / エアコン電気代 / 割り勘 | サイト全体の網羅性・回遊性のため。単体での上位獲得は期待薄 |
| ヘボン式ローマ字変換 / アスペクト比計算 | 同上。ただしヘボン式は実装品質（促音・撥音・長音の正確さ）で差別化余地あり |

**サイト全体の厚みはドメイン評価にプラスに働く**ため、勝ち目の薄いツールも置く価値があります。
ただし優先度は「新制度型 > その他」で判断してください。

## 7. リスクと前提

- **お金系はGoogleがE-E-A-T（権威性）を重視する領域**。個人ドメインだと時間がかかる可能性がある
  → 対策として、各ページに**一次情報（こども家庭庁等）へのリンクと出典を明記**している
- 新規ドメインは最初の1〜3ヶ月ほぼ圏外が普通。**3ヶ月目以降のロングテールから**が本番
- 最初の勝負どころは **2027年度の支援金料率が報じられるタイミング（2027年初頭）**
